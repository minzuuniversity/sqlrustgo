# 职业健康管理规程

**文件编号**: SMP-SEC-002 | **类别**: 安全与卫生

---

## 1. 目的

建立职业健康管理制度，保护员工健康，预防职业病。

## 2. 适用范围

适用于高原彝药厂所有员工。

## 3. 职责

| 部门 | 职责 |
|------|------|
| 人力资源部 | 职业健康管理 |
| 安全部门 | 安全监督 |
| 各部门 | 配合管理 |

## 4. 职业健康管理内容

| 内容 | 说明 |
|------|------|
| 入职体检 | 从事有害作业前 |
| 在岗体检 | 定期体检 |
| 离岗体检 | 离岗时体检 |
| 职业病防护 | 防护用品配发 |

## 5. 职业病防护

| 类型 | 防护措施 |
|------|----------|
| 粉尘 | 口罩、通风 |
| 噪声 | 耳塞、隔音 |
| 化学 | 防护手套、通风 |
| 辐射 | 防护服、屏蔽 |

## 6. 健康档案

| 内容 | 要求 |
|------|------|
| 体检记录 | 保存10年 |
| 职业病记录 | 长期保存 |
| 防护用品记录 | 保存5年 |

## 7. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 职业健康档案 | 员工离职后10年 | 人力资源部 |
| 体检报告 | 10年 | 人力资源部 |
