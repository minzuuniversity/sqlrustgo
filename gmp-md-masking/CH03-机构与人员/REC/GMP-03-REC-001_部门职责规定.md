# 部门职责规定

**文件编号**: SP-ORG-001
**版本**: V1.0
**生效日期**: 2026-01-01
**审核人**: __________
**批准人**: __________

---

## 1. 目的

明确公司各部门的职责分工，确保各部门职责清晰、协调配合，建立有效的质量管理体系，符合《药品生产质量管理规范（2010年修订）》第十九条要求。

---

## 2. 范围

适用于公司所有部门，包括生产、质量、技术、仓储、销售、行政等各职能部门。

## 4. 各部门职责

### 4.1 总经理

| 职责类别 | 具体职责 |
|----------|----------|
| 战略决策 | 制定公司发展战略、经营方针 |
| 质量管理 | 确保质量管理体系建立、实施和持续改进 |
| 资源配置 | 配备足够资源确保质量管理体系有效运行 |
| 人员管理 | 任命关键人员，考核绩效 |
| 法规合规 | 确保公司合法合规运营 |
| 外部沟通 | 负责与监管部门的沟通协调 |

### 4.2 质量负责人

| 职责类别 | 具体职责 |
|----------|----------|
| 质量体系 | 全面负责质量管理体系建立、实施和持续改进 |
| 放行权 | 物料、中间产品、成品最终放行批准 |
| 质量受权 | 药品放行审核，确保符合注册批准和质量标准 |
| 监管协调 | 配合监管部门检查，负责整改落实 |
| 质量事故 | 组织重大质量事故调查处理 |
| 供应商 | 批准合格供应商名单 |
| 变更评估 | 评估变更对产品质量的影响 |

### 4.3 质量保证部（QA）

| 职责类别 | 具体职责 |
|----------|----------|
| 体系维护 | 维护质量管理体系，确保有效运行 |
| 文件管理 | 负责GMP文件的管理、审核、发放、回收 |
| 变更控制 | 负责变更控制管理，评估变更影响 |
| 偏差处理 | 负责偏差处理、审批CAPA措施 |
| 自检 | 负责GMP自检组织、实施 |
| 供应商审计 | 负责供应商审计计划的制定和实施 |
| 客户投诉 | 负责客户投诉的处理和跟踪 |
| 召回管理 | 负责药品召回的组织实施 |
| 验证 | 负责验证管理工作 |
| 培训 | 负责GMP培训的组织实施 |

**部门人员配置建议**：
- 部门经理：1人
- 文件管理员：1-2人
- 现场QA：3-5人
- 验证工程师：1-2人
- 供应商审计员：1-2人

### 4.4 质量控制部（QC）

| 职责类别 | 具体职责 |
|----------|----------|
| 物料检验 | 原辅料、包装材料检验 |
| 成品检验 | 产品检验、稳定性考察 |
| 过程监控 | 生产过程质量监控、环境监测 |
| 方法验证 | 分析方法验证、转移 |
| 仪器维护 | 实验室仪器维护、校验 |
| 标准品管理 | 对照品、试剂管理 |
| OOS调查 | 超标结果调查处理 |
| 留样管理 | 留样观察、管理 |
| 档案管理 | 检验记录归档、质量标准管理 |

**部门人员配置建议**：
- 部门经理：1人
- 检验组长：2人
- 检验员：4-8人
- 留样管理员：1人

### 4.5 生产部

| 职责类别 | 具体职责 |
|----------|----------|
| 生产计划 | 制定生产计划、组织生产实施 |
| 工艺执行 | 按照工艺规程组织生产，确保工艺执行正确 |
| 批记录 | 审核批记录，确保记录完整、准确 |
| 设备管理 | 负责生产设备的使用、维护、保养 |
| 车间卫生 | 负责生产车间清洁、卫生 |
| 清场管理 | 负责生产前清场、换品种清场 |
| 偏差报告 | 发现偏差及时报告，参与偏差调查 |
| 培训 | 负责生产人员岗位技能培训 |

**部门人员配置建议**：
- 部门经理：1人
- 车间主任：2人
- 工艺员：2-3人
- 班组长：4-6人
- 操作工：按生产规模配置

### 4.6 设备工程部

| 职责类别 | 具体职责 |
|----------|----------|
| 设备管理 | 设备选型、采购、验收、档案管理 |
| 设备确认 | 负责设备确认（DQ/IQ/OQ/PQ） |
| 维护保养 | 制定设备维护保养计划并组织实施 |
| 计量管理 | 计量器具的定期校验 |
| 公用系统 | HVAC、水系统、压缩空气等公用系统运行维护 |
| 验证支持 | 支持生产工艺验证、清洁验证 |
| 备件管理 | 备品备件管理 |
| 计量检定 | 配合计量部门完成仪器仪表校验 |

**部门人员配置建议**：
- 部门经理：1人
- 设备工程师：2-3人
- 维修技师：2-4人
- 公用系统操作：2-3人

### 4.7 仓储部

| 职责类别 | 具体职责 |
|----------|----------|
| 物料接收 | 物料入库接收、验收 |
| 物料储存 | 物料、成品储存管理，确保储存条件符合要求 |
| 物料发放 | 按指令发放物料、成品 |
| 库存管理 | 库存盘点、效期管理 |
| 温湿度监控 | 仓库温湿度监控、记录 |
| 不合格品管理 | 不合格品隔离、存放 |
| 退货处理 | 配合退货处理 |
| 清洁卫生 | 仓库区域清洁、卫生 |
| 设备维护 | 仓库相关设备（空调、除湿机等）维护 |

**部门人员配置建议**：
- 部门经理：1人
- 仓库主管：1-2人
- 仓库管理员：4-6人
- 装卸工：按需配置

### 4.8 销售部

| 职责类别 | 具体职责 |
|----------|----------|
| 市场开发 | 市场开拓、客户开发 |
| 销售管理 | 销售计划制定、销售业绩管理 |
| 客户管理 | 客户档案建立、客户评估 |
| 客户服务 | 客户投诉初步受理、反馈 |
| 退货受理 | 受理客户退货申请 |
| 召回配合 | 配合药品召回实施 |
| 药品发运 | 成品出库、发运 |
| 销售记录 | 销售记录建立、维护 |

**部门人员配置建议**：
- 部门经理：1人
- 区域经理：按区域配置
- 销售代表：按业务规模配置
- 客服人员：2-3人

### 4.9 采购部

| 职责类别 | 具体职责 |
|----------|----------|
| 供应商开发 | 供应商开发、资料收集 |
| 采购执行 | 按需求计划执行采购 |
| 供应商协调 | 供应商沟通、交货协调 |
| 价格管理 | 采购价格谈判、成本控制 |
| 物料验收配合 | 配合物料验收 |
| 供应商评估 | 提供供应商评估资料 |

**部门人员配置建议**：
- 部门经理：1人
- 采购员：2-3人

### 4.10 行政部（人力资源）

| 职责类别 | 具体职责 |
|----------|----------|
| 人员招聘 | 人员招聘、入职办理 |
| 培训管理 | 培训计划制定、培训组织（QA主导） |
| 绩效考核 | 员工绩效考核 |
| 薪酬福利 | 薪酬福利管理 |
| 劳动关系 | 劳动合同管理 |
| 人员档案 | 人事档案管理 |
| 健康管理 | 员工健康检查组织 |

### 4.11 财务部

| 职责类别 | 具体职责 |
|----------|----------|
| 成本核算 | 产品成本核算 |
| 资金管理 | 资金计划、支付管理 |
| 资产管理 | 固定资产管理 |
| 税务管理 | 税务申报、缴纳 |
| 审计配合 | 配合内外部审计 |

## 5. 部门协调机制

### 5.1 例行会议

| 会议类型 | 频率 | 参加人员 | 主要议题 |
|----------|------|----------|----------|
| 质量分析会 | 月度 | QA/QC/生产/销售 | 质量问题分析、投诉回顾 |
| 生产调度会 | 周 | 生产/QA/仓储/采购 | 生产计划、质量问题 |
| 管理层会议 | 月度 | 总经理/各部门负责人 | 经营目标、质量目标达成 |
| 验证会议 | 按需 | QA/生产/设备/工程 | 验证进展、问题协调 |

### 5.2 跨部门协作流程

| 流程 | 主导部门 | 配合部门 |
|------|----------|----------|
| 偏差处理 | QA | 生产、QC、设备、仓储 |
| 变更控制 | QA | 生产、技术、设备、注册 |
| 供应商审计 | QA | 采购、QC |
| 客户投诉处理 | QA | 销售、生产、QC |
| 产品召回 | QA | 生产、销售、仓储 |
| 验证实施 | QA | 生产、设备、工程 |
