# 文件起草审核批准流程

**文件编号**: SMP-DOC-010 | **类别**: 文件管理

---

## 1. 目的

规范文件起草、审核、批准流程，确保文件质量。

## 2. 适用范围

适用于高原彝药厂所有GMP文件。

## 3. 职责分工

| 角色 | 职责 |
|------|------|
| 文件管理员 | 发放、回收、归档 |
| 起草人 | 编写文件初稿 |
| 审核人 | 审核文件内容 |
| 批准人 | 批准文件生效 |

## 4. 流程步骤

| 步骤 | 内容 | 责任人 | 时限 |
|------|------|--------|------|
| 1 | 起草文件 | 相关部门 | - |
| 2 | 部门审核 | 部门负责人 | 3工作日 |
| 3 | QA审核 | 质量保证部 | 5工作日 |
| 4 | 相关会签 | 相关部门 | 3工作日 |
| 5 | 批准生效 | 质量受权人 | 2工作日 |
| 6 | 编号发放 | 文件管理员 | 1工作日 |
| 7 | 培训实施 | 相关部门 | 生效后7日 |
