# 文件修订管理规程

**文件编号**: SMP-DOC-009 | **类别**: 文件与记录管理

---

## 1. 目的

建立文件修订控制程序，确保文件修订规范、可控、可追溯。

## 2. 适用范围

适用于高原彝药厂所有GMP文件的修订管理。

## 3. 修订类型

| 类型 | 触发条件 | 修订范围 |
|------|----------|----------|
| 定期审查修订 | 文件到期审查 | 全面审查 |
| 变更性修订 | 法规变化、组织变化等 | 部分内容 |
| 纠错性修订 | 发现错误 | 错误部分 |
| 改进性修订 | 优化操作 | 改进部分 |

## 4. 职责

| 部门 | 职责 |
|------|------|
| 文件使用部门 | 提出修订申请 |
| 质量保证部 | 评估和批准修订 |
| 原起草部门 | 执行修订 |

## 5. 修订流程

### 5.1 修订申请

| 信息 | 内容 |
|------|------|
| 文件信息 | 文件编号、名称、版本 |
| 修订原因 | 说明修订必要性 |
| 修订内容 | 具体修订内容 |
| 申请人 | 部门、姓名、日期 |

### 5.2 修订评估

| 评估项目 | 评估内容 |
|----------|----------|
| 修订必要性 | 是否确实需要修订 |
| 修订范围 | 影响范围的评估 |
| GMP符合性 | 修订后是否符合GMP |
| 关联影响 | 是否影响其他文件 |

### 5.3 修订审批

| 修订类型 | 审批级别 |
|----------|----------|
| 重大修订 | 质量负责人 |
| 一般修订 | QA部门负责人 |
| 小幅修订 | 部门负责人 |

### 5.4 修订实施

| 步骤 | 内容 |
|------|------|
| 原文件标注 | 在原文件中标注修订位置 |
| 新版本编写 | 按修订内容编写新版本 |
| 审核批准 | 按新文件流程审核批准 |
| 分发回收 | 发放新版本，回收旧版本 |

## 6. 修订标识

| 标识方式 | 使用场景 |
|----------|----------|
| 修订栏 | 文件中标注修订位置和内容 |
| 修订页 | 单独标注修订页 |
| 版本变更 | 版本号升级 |

## 7. 修订记录

每份文件应保存修订历史记录，包括：
- 修订版本
- 修订日期
- 修订内容描述
- 修订原因
- 批准人

## 8. 文件审查周期

| 文件类型 | 审查周期 |
|----------|----------|
| 质量手册 | 每3年 |
| 管理规程 | 每2年 |
| 标准操作规程 | 每2年 |
| 技术标准 | 每3年 |
| 记录表单 | 每2年 |

## 9. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 文件修订申请表 | 5年 | 质量保证部 |
| 修订审批记录 | 5年 | 质量保证部 |
| 修订历史记录 | 随文件 | 质量保证部 |
