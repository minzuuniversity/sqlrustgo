# [COMPANY-SHORT] 质量手册  
## 文件控制程序（QMP‑001）

---

## 1. 目的  
确保公司所有质量体系文件（包括质量手册、程序文件、作业指导书、记录表格等）实行受控管理，实现版本唯一、发放可追朔、回收与销毁有据可查，满足《药品生产质量管理规范》（GMP）第 4.2 章“文件与记录管理”的要求。

## 2. 适用范围  
本程序适用于公司内部所有质量体系文件的编制、审核、批准、发放、变更、回收及销毁全过程。

## 3. 职责  

| 角色 | 主要职责 |
|------|----------|
| 质量部 | 负责文件的统一编号、版本管理、发放登记、回收与销毁的监督。 |
| 文件编写部门 | 负责文件的起草、修订及提供必要的支持文件。 |
| 部门负责人 | 负责本部门文件的初审及批准。 |
| 质量负责人 | 负责文件的最终批准、版本发布及监督执行。 |
| 文件管理员（文控） | 负责具体的发放、回收、销毁登记及文件存档。 |

## 4. 定义  

- **受控文件**：经正式批准、编号并列入《受控文件清单》的文件。  
- **非受控文件**：仅供内部参考、未列入受控清单的文件。  
- **版本号**：采用“主版本.次版本”形式（如 1.0、1.1、2.0），主版本在结构或重要内容变更时递增，次版本在局部修订时递增。  

## 5. 工作程序  

### 5.1 文件的编号与版本管理  

1. **编号规则**：`QMP‑XXX‑YY`  
   - `QMP`＝质量手册（Quality Manual Procedure）  
   - `XXX`＝文件序号（001‑999）  
   - `YY`＝版本号（如 01、02）。  
2. 每一次修订须在《修订历史》中登记，注明修订原因、日期、编制人、审核人、批准人。  
3. 文档标题、编号、版本号必须在文件首页显著位置标注。

### 5.2 文件的编制、审核与批准  

1. 编制部门依据业务需求起草文件。  
2. 编制完成后填写《文件审查表》，交部门负责人审查。  
3. 审查通过后提交质量部进行合规性审查。  
4. 质量负责人批准后，文件正式生效并纳入受控文件清单。

### 5.3 文件的发放（发放记录）  

1. 文件管理员依据《受控文件清单》制作《文件发放登记表》，内容包括：  
   - 文件编号、版本号、文件标题  
   - 发放日期  
   - 领用部门、领用人签名  
   - 发放人（文件管理员）签名  
2. 领用人必须在领取后检查文件完整性并在登记表上签字。  
3. 发放记录由文件管理员保存，保存期限为文件失效后 **10 年**。

### 5.4 旧版文件的回收与销毁  

1. 当文件升版或废止时，质量部发布《文件回收/销毁通知》，明确需回收的版本号、回收期限。  
2. 各领用部门在规定期限内将旧版文件交回文件管理员。  
3. 文件管理员核对回收数量后填写《文件回收/销毁记录》，记录：  
   - 文件编号、版本号  
   - 回收数量、回收日期  
   - 销毁方式（如碎纸、焚烧）  
   - 销毁日期、实施人、监销人签名  
4. 销毁必须在质量部指定地点进行，确保信息不可恢复。  
5. 销毁记录保存期限同发放记录。

### 5.5 文件的归档与检索  

1. 受控文件原件（包括纸质和电子版）统一归档于质量部档案室。  
2. 电子文件须存入公司文档管理系统（EDMS），设置访问权限。  
3. 档案检索采用文件编号、版本号、标题、关键词等方式。

### 5.6 培训与认知  

1. 新版文件发布后，质量部组织相关人员进行培训，确保理解文件要求。  
2. 培训记录记 入《培训记录表》，包括培训内容、参加人员、培训日期、讲师签名。
