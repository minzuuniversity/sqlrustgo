# 自检与审计

**文件编号:** REG-GMP-041
**版本号:** V1.0

## 1. 自检要求

**第309条** 企业应定期进行自检，评估质量管理体系的有效性。

### 自检流程
1. 制定年度自检计划
2. 组建自检组
3. 编制检查表
4. 实施检查
5. 编写报告
6. 整改跟踪

## 2. 自检内容

| 模块 | 主要内容 |
|------|---------|
| 机构人员 | 人员资质、培训 |
| 厂房设施 | 洁净区环境、维护 |
| 设备 | 确认状态、校准 |
| 物料 | 供应商、储存、检验 |
| 生产 | 工艺执行、偏差 |
| 质量控制 | 检验方法、仪器 |
| 文件 | 文件受控、记录 |
| 投诉召回 | 处理及时性 |

## 3. 供应商审计

- 首次审计（现场）
- 定期审计（1-3年）
- 飞行检查
- 审计报告保存

## 4. 审计发现分类

| 分类 | 定义 | 处理 |
|------|------|------|
| 严重不符合 | 严重违反GMP | 立即整改 |
| 一般不符合 | 违反GMP要求 | 限期整改 |
| 观察项 | 潜在风险 | 关注改进 |
