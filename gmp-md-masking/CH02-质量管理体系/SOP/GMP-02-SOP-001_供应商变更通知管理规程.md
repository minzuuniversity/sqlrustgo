# 供应商变更通知管理规程

**文件编号**: SMP-VAL-006 | **类别**: 验证与确认

---

## 1. 目的

建立供应商变更通知管理程序，评估供应商变更对产品质量的影响。

## 2. 适用范围

适用于高原彝药厂所有物料供应商的变更管理。

## 3. 职责

| 部门 | 职责 |
|------|------|
| 质量保证部 | 变更评估管理 |
| 采购部 | 收集变更通知 |
| 质量控制部 | 检验评估 |
| 生产部 | 工艺评估 |

## 4. 供应商需通知的变更

| 变更类型 | 示例 |
|----------|------|
| 生产地址变更 | 工厂搬迁 |
| 生产工艺变更 | 工艺参数调整 |
| 原材料变更 | 原料来源变化 |
| 生产规模变更 | 批量调整 |
| 质量标准变更 | 检验方法变更 |

## 5. 变更评估流程

| 步骤 | 内容 |
|------|------|
| 1 | 收到变更通知 |
| 2 | 初步评估影响 |
| 3 | 决定是否需要验证 |
| 4 | 实施必要的验证 |
| 5 | 决定是否批准 |
| 6 | 更新供应商资料 |

## 6. 评估内容

| 评估项目 | 内容 |
|----------|------|
| 产品质量影响 | 是否影响产品质量 |
| 注册影响 | 是否需要申报 |
| 供应稳定性 | 是否影响供货 |

## 7. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 变更通知评估 | 10年 | 质量保证部 |
| 供应商资料更新 | 10年 | 质量保证部 |
