# 厂房设施变更控制规程

**文件编号:** SOP-QA-CC-002
**版本号:** V1.0

## 1. 目的

规范厂房、设施的变更控制，确保任何影响药品质量的厂房设施变更经过充分评估和确认。

## 2. 适用范围

- 厂房建筑、结构变更
- 洁净区划分、级别变更
- 空调净化系统变更
- 纯化水、注射用水系统变更
- 压缩空气、氮气等公用系统变更
- 排水、通风系统变更

## 3. 职责

| 角色 | 职责 |
|------|------|
| 工程部 | 编制变更方案，负责实施 |
| QA | 组织变更评估，批准一般变更 |
| 质量总监 | 批准重大变更 |
| 验证部门 | 变更后验证 |

## 4. 特殊要求

### 4.1 洁净区变更
- 必须进行洁净度验证
- 需重新确认洁净区级别
- 必要时进行工艺验证

### 4.2 公用系统变更
- 空调系统变更需进行IQ/OQ/PQ
- 水系统变更需进行全面验证
- 需更新SOP和维护计划
