纠正与预防措施（CAPA）管理规程

1、目的

建立一个系统性的流程，用于识别、调查、处理和确认纠正与预防措施的有效性，以消除已发生或潜在不合格项的根本原因，防止问题的再次发生或发生，从而推动产品质量体系的持续改进。

2、范围

本规程适用于从所有质量活动中识别出的、需要采取系统性纠正与预防措施的所有问题。这些问题的来源包括但不限于：

偏差

超标 / 超常结果（OOS/OOT）

投诉与召回

内外部审计 / 检查的发现项

工艺性能与产品质量监测趋势的 adverse trend

设备 / 设施故障的重要趋势

变更控制后的有效性确认

-     风险管理输出

3、职责

各相关部门：负责报告问题、参与 CAPA 调查、执行批准的 CAPA 措施。

质量保证部（QA）：作为 CAPA 流程的归口管理部门。负责 CAPA 的审核、批准、跟踪、趋势分析和效果确认。确保 CAPA 流程的合规性与有效性。

CAPA 所有者：由 QA 指定的、对 CAPA 全过程负责的个人（通常来自问题相关部门或 QA），负责推动调查、制定计划并确保 CAPA 按时完成。

质量受权人 / 质量总监：负责批准重大或复杂的 CAPA 计划及最终报告。

4、定义

纠正：为消除已发现的不合格所采取的措施。

纠正措施：为消除已发现的不合格或其他不期望情况的根本原因所采取的措施，以防止其再次发生。

预防措施：为消除潜在不合格或其他潜在不期望情况的根本原因所采取的措施，以防止其发生。

根本原因：导致问题发生的最底层原因，如果该原因被消除，则可以防止问题的再次发生。

5、规程

5.1 CAPA 流程启动

CAPA 流程的启动应基于来自 5.2 节所述来源的数据分析和正式决定。当识别到系统性、重复性或重大问题时，应由 QA 经理组织评估，并决定是否启动正式的 CAPA 流程，并生成唯一的CAPA 编号。

5.2 数据来源与信息输入

CAPA 的输入应是数据驱动的。以下来源应被定期回顾，以识别 CAPA 机会：

偏差与 OOS/OOT 的趋势分析报告

客户投诉的季度 / 年度回顾

内外部审计 / 检查发现项的汇总

生产工艺与产品质量数据的统计趋势（如控制图）

变更控制记录的回顾

-    设备故障与维护记录

5.3 问题描述

CAPA 记录必须包含清晰、准确的问题描述，应使用具体数据说明：

何事：明确是什么问题。

何地：问题发生的地点或流程环节。

何时：问题发生或被发现的时间。

程度：问题的严重性、影响范围（如涉及的产品、批次、数量）。

5.4 根本原因调查

这是 CAPA 流程中最关键的步骤。

调查方法：应使用结构化的工具进行调查，例如：

5Why 分析法：持续追问 “为什么”，直至找到根本原因。

鱼骨图：从人、机、料、法、环、测等多个维度进行全面分析。

失效模式与影响分析（FMEA）：适用于对潜在问题的分析。

根本原因确认：必须通过客观证据（如数据、试验、验证）来确认所识别的原因是否为根本原因。应区分根本原因与表面原因。

5.5 纠正与预防措施的制定

纠正：首先描述为控制当前问题、减少影响而采取的立即行动（如隔离批产品、进行返工）。

纠正措施：针对已确认的根本原因，制定具体措施以防止问题再次发生。例如：修订 SOP、增加培训、优化工艺参数、改进设备设计。

预防措施：将措施的应用范围扩展到类似产品、工艺或系统，以防止同类问题的发生。例如：将某个设备的改进措施推广到所有同类设备；将某个产品的工艺控制经验纳入到新品研发的控制策略中。

措施计划必须明确、可衡量，并规定：

措施内容

责任部门 / 责任人

计划完成日期

5.6 CAPA 计划的批准

完整的根本原因分析和 CAPA 行动计划应由 CAPA 所有者提交至 QA 经理进行审核批准。对于涉及多部门、影响重大或资源投入高的 CAPA，应报质量受权人 / 质量总监批准。

5.7 CAPA 措施的执行与跟踪

责任部门需在计划完成日期前执行所有批准的措施。

QA 或 CAPA 所有者负责跟踪整个 CAPA 计划的执行进度，并定期向管理层报告。任何延期都必须提交书面申请并经 QA 经理批准。

5.8 效果确认

这是确保 CAPA 有效性的关键环节。在 CAPA 措施完成后，必须进行效果确认：

方法：确认方法必须是客观、可量化的。例如：

对比措施实施前后的关键绩效指标（KPIs）。

审核一定时期内的相关数据，确认问题未再发生。

通过再验证或额外测试来证明措施有效。

责任人：效果确认应由独立于措施执行的人员（通常是 QA）进行。

结论：必须明确记录确认结果和结论（例如：“措施有效，问题已解决” 或 “措施无效，需重新启动调查”）。

5.9 CAPA 关闭

当所有措施已执行完毕，且效果确认已证明措施有效后，CAPA 所有者可将 CAPA 文件提交给 QA 经理进行最终审核批准，予以关闭。

5.10 CAPA 效果的趋势监测

已关闭的 CAPA 应作为质量体系回顾的输入。QA 应定期回顾所有 CAPA，以评估 CAPA 系统的整体有效性，并识别是否存在系统性或重复性问题未被有效解决。
