# 变更控制程序

**文件编号:** SOP-QA-CC-001
**版本号:** V1.0
**生效日期:** 2025年1月1日
**责任人:** 质量保证部
**适用范围:** 全厂所有药品生产相关变更

---

## 1. 目的

建立变更控制程序，确保对药品质量有潜在影响的任何变更都经过充分评估、批准和确认，防止因变更导致产品质量问题。

## 2. 适用范围

适用于以下变更：
- 厂房、设施、设备变更
- 工艺、处方变更
- 物料、供应商变更
- 检验方法变更
- 文件、记录变更
- 计算机系统变更
- 注册申报资料变更

## 3. 职责

| 角色 | 职责 |
|------|------|
| 变更申请人 | 提出变更申请，填写《变更申请表》 |
| 相关部门 | 评估变更对本部门的影响 |
| QA经理 | 组织变更评估，批准/否决变更 |
| 质量总监 | 批准重大变更 |
| 验证部门 | 变更实施后的确认/验证 |

## 4. 变更分级

| 级别 | 定义 | 审批人 |
|------|------|-------|
| 重大变更 | 可能影响产品质量、注册标准、法规符合性的变更 | 质量总监 |
| 一般变更 | 对产品质量无直接影响，但需评估的变更 | QA经理 |
| 微小变更 | 文字错误、排版调整等 | 部门经理 |

## 5. 变更控制流程

### 5.1 变更申请
- 申请人填写《变更申请表》（附件1）
- 明确变更内容、原因、实施计划
- 提交QA评估

### 5.2 变更评估
QA组织相关部门评估：
- 对产品质量的潜在影响
- 对法规符合性的影响
- 是否需要验证/确认
- 所需资源、时间
- 风险评估

### 5.3 变更批准
- 微小变更：部门经理批准
- 一般变更：QA经理批准
- 重大变更：质量总监批准

### 5.4 变更实施
- 按批准方案实施
- 做好变更记录
- 完成后进行确认/验证

### 5.5 变更关闭
- 确认变更达到预期目标
- 更新相关文件
- 关闭变更单

## 6. 时限要求

| 阶段 | 时限 |
|------|------|
| 评估完成 | 申请后15个工作日 |
| 批准完成 | 评估后10个工作日 |
| 实施完成 | 批准后按计划执行 |
