# 偏差与投诉关联管理规程

**文件编号:** SOP-QA-DEV-CLM-001
**版本号:** V1.0

## 1. 目的

建立偏差与投诉的关联分析机制，从源头发现质量问题。

## 2. 关联分析

### 2.1 投诉触发偏差的条件
- 同一问题重复投诉
- 严重不良反应投诉
- 涉及产品内在质量问题

### 2.2 偏差触发投诉回顾的条件
- 重大偏差
- 批次召回相关偏差
- 涉及关键质量属性

### 2.3 关联分析内容
- 时间关联（偏差发生→投诉时间）
- 批次关联（同批次产品）
- 现象关联（相似问题）
- 根本原因关联（系统性缺陷）

## 3. 流程

1. 投诉记录中标注关联的偏差编号
2. 偏差记录中标注可能关联的投诉
3. 定期进行关联性分析（季度）
4. 根据分析结果制定改进措施
