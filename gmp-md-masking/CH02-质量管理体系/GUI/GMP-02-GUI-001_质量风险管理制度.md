# 质量风险管理制度

**文件编号**: SMP-QMS-002 | **类别**: 质量管理体系

---

## 1. 目的

建立质量风险管理体系，系统识别、评估和控制药品生命周期中的质量风险，确保产品质量和患者安全。

## 2. 适用范围

适用于高原彝药厂所有与药品质量相关的风险评估活动。

## 3. 职责

| 部门 | 职责 |
|------|------|
| 质量保证部 | 负责风险管理制度的维护和监督执行 |
| 各相关部门 | 参与本领域的风险评估 |
| 质量负责人 | 批准重大风险的控制措施 |

## 4. 风险管理的原则

1. **预防为主**：在风险发生前识别和控制
2. **基于科学**：风险评估应基于科学数据和知识
3. **与保护患者相关**：风险评估的最终目的是保护患者
4. **与质量相关**：关注可能影响产品质量的风险
5. **与GMP要求一致**：符合GMP规范要求

## 5. 风险评估流程

### 5.1 风险识别

| 方法 | 适用范围 |
|------|----------|
| FMEA（失效模式与影响分析） | 工艺、设备、系统 |
| FTA（故障树分析） | 复杂系统分析 |
| HAZOP（危害与可操作性分析） | 工艺过程 |
| PEST/ SWOT分析 | 战略风险 |
| 检查表法 | 日常审计 |

### 5.2 风险评估

**风险评分矩阵**

| 可能性 | 严重性 | 风险等级 |
|--------|--------|----------|
| 高 | 高 | 高 |
| 高 | 中 | 高 |
| 高 | 低 | 中 |
| 中 | 高 | 高 |
| 中 | 中 | 中 |
| 中 | 低 | 低 |
| 低 | 高 | 中 |
| 低 | 中 | 低 |
| 低 | 低 | 低 |

### 5.3 风险控制

| 风险等级 | 控制措施 | 审批级别 |
|----------|----------|----------|
| 高风险 | 必须降低至可接受水平 | 质量负责人 |
| 中风险 | 应尽可能降低 | 部门负责人 |
| 低风险 | 保持监控 | 主管 |

### 5.4 风险沟通与审查

- 风险评估结果应与相关方沟通
- 定期审查风险控制措施的有效性
- 新信息出现时应重新评估风险

## 6. 风险评估应用领域

| 应用领域 | 触发条件 |
|----------|----------|
| 验证与确认 | 新设备、新工艺、新系统 |
| 变更控制 | 重大变更实施前 |
| 偏差调查 | 重大偏差原因分析 |
| 投诉处理 | 严重投诉原因分析 |
| 供应商审计 | 关键物料供应商评估 |
| 工艺监控 | 趋势异常时 |

## 7. 文件要求

风险评估应形成文件，包括：
- 风险评估的目的和范围
- 参与人员
- 使用的评估方法和工具
- 风险识别和分析过程
- 控制措施
- 结论和建议

## 8. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 风险评估报告 | 10年 | 质量保证部 |
| 风险控制措施 | 10年 | 质量保证部 |
