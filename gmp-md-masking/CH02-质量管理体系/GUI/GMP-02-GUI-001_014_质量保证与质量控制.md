# 质量保证与质量控制

**文件编号:** REG-GMP-002
**版本号:** V1.0

## 1. 质量保证（QA）的定义

**第8条** 质量保证（QA）是确保所有药品符合其预期用途和注册标准所要求的质量的全部计划安排。

## 2. QA系统的组成

```
质量保证体系
├── 质量管理组织架构
├── 文件体系
├── 变更控制
├── 偏差管理
├── CAPA管理
├── 投诉与召回
├── 自检与审计
├── 供应商管理
├── 验证管理
└── 产品放行
```

## 3. 质量控制（QC）

**第11条** 质量控制是取样、检验、确保产品符合标准的过程。

| QC职责 | 具体内容 |
|-------|---------|
| 取样 | 按规定方法取样，代表性 |
| 检验 | 按标准方法检验 |
| 放行判断 | 决定物料/产品是否放行 |
| 稳定性考察 | 定期留样观察 |
| 异常调查 | OOS/OOT调查 |

## 4. QA与QC的关系

- QA负责建立和改进质量体系
- QC负责执行质量检测
- QA指导QC工作
- QC数据支持QA决策
- 两者相互配合，共同确保产品质量

## 5. 关键要求

- QA必须独立于生产部门
- QA和QC人员必须经过适当培训
- 实验室必须满足GLP基本要求
- 所有质量活动必须有记录
