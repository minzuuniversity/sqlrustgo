# 数据完整性管理规程

**文件编号**: SMP-COM-002 | **类别**: 计算机系统

---

## 1. 目的

建立数据完整性管理程序，确保数据在整个生命周期内完整、准确、可靠。

## 2. 适用范围

适用于高原彝药厂所有GMP相关数据的完整性管理。

## 3. 数据完整性原则（ALCOA+）

| 原则 | 说明 |
|------|------|
| Attributable | 可归属到操作者 |
| Legible | 清晰可读 |
| Contemporaneous | 同步记录 |
| Original | 原始记录 |
| Accurate | 准确 |
| Complete | 完整 |
| Consistent | 一致 |
| Enduring | 持久 |
| Available | 可获取 |

## 4. 数据完整性要求

| 要求 | 内容 |
|------|------|
| 创建 | 真实、及时创建 |
| 修改 | 记录修改原因 |
| 删除 | 不允许删除数据 |
| 审计追踪 | 记录所有操作 |

## 5. 电子数据管理

| 要求 | 内容 |
|------|------|
| 访问控制 | 按岗位授权 |
| 审计追踪 | 开启并审查 |
| 备份 | 定期备份 |
| 归档 | 按规定归档 |

## 6. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 数据完整性评估 | 10年 | 质量保证部 |
| 审计追踪审查记录 | 10年 | 质量保证部 |
