## 二、核心问题分析

### 问题1: 偏差登记场景意图路由失败 (最严重)

**失败率**: 90% (9/10)

**典型失败案例**:
| 场景ID | 查询 | 错误返回 |
|--------|------|----------|
| P1-B001 | 登记偏差：批次B20260411-01，混合机M-102转速异常 | 《2025年度验证总计划》 |
| P1-B003 | 登记偏差：批次B20260411-03，充填机压力不稳定 | 胶囊充填机再确认方案 |
| P1-B004 | 登记偏差：批次B20260411-04，包装机打码模糊 | 泡罩包装机再确认报告 |
| P1-B007 | 登记偏差：批次B20260411-07，制粒机筛网破损 | 制粒机运行日志 |

**根因分析**:
1. **意图识别失败**: "登记偏差" 查询被当作普通文档检索，而非偏差登记场景
2. **路由策略缺失**: 没有为"登记偏差"设计专门的路由策略
3. **关键词权重问题**: 文档中"登记"关键词权重低于"验证"、"报告"等词

**建议改进**:

```yaml
意图路由_偏差登记:
  检测关键词:
    - "登记偏差"
    - "偏差登记"
    - "偏差录入"
    - "偏差记录"
    - "偏差报告"
  排除关键词:
    - "验证总计划"
    - "再确认方案"
    - "再确认报告"
    - "清洁验证"
  目标文档类型:
    - 偏差处理规程
    - 偏差登记表
    - 偏差调查程序
  路由到:
    - gmp_deviation_register
    - sp_qms_017_偏差登记
```

### 问题2: GMP条款查询不精确匹配

**失败率**: 26.7% (4/15)

**典型失败案例**:
| 场景ID | 查询 | 错误返回 |
|--------|------|----------|
| P1-Q001 | GMP 第 84 条条款内容 | GMP第82条-设备维护保养 |
| P2-Q001 | GMP 法规第 107 条内容 | GMP第82条-设备维护保养 |

**根因分析**:
1. 当查询包含"第XX条"时，系统使用语义相似度匹配而非精确匹配
2. 文档命名格式不统一（"GMP第82条" vs "第82条"）
3. 索引时未提取条款编号作为精确检索字段

**建议改进**:

```yaml
精确匹配_GMP条款:
  触发条件:
    - 查询包含 "第XX条"
    - 查询包含 "GMP第XX条"
    - 查询包含 "条款XX"
  匹配策略:
    - 优先精确匹配条款编号
    - 不使用语义相似度排序
    - 返回结果必须包含查询的条款编号
  示例:
    查询"第84条" → 必须返回包含"第84条"的文档
    不能返回"第82条"即使语义相似
```

### 问题3: SOP语义查询返回验证报告

**失败率**: 6.7% (1/15)

**典型失败案例**:
| 场景ID | 查询 | 错误返回 |
|--------|------|----------|
| P1-S001 | 如何进行设备清洁 | 泡罩机清洁验证报告 |

**根因分析**:
1. "设备清洁"关键词同时匹配清洁SOP和清洁验证报告
2. 验证报告的向量相似度高于SOP（可能因为文档更长、内容更丰富）
3. 没有根据查询意图区分SOP和验证报告的优先级

**建议改进**:

```yaml
优先级排序_SOP查询:
  查询类型: SOP语义查询
  优先级规则:
    1. 文档名称包含"SOP"或"操作规程"
    2. 文档元数据标注为"SOP"
    3. 文档类型字段为"标准操作规程"
  降权规则:
    - 文档名称包含"验证报告"降权
    - 文档名称包含"确认方案"降权
  适用查询:
    - "如何进行XX"
    - "XX操作步骤"
    - "XX方法"
    - "XX流程"
```

## 三、OpenClaw侧改进建议

### 3.1 高优先级改进

#### 3.1.1 偏差登记意图路由新增

```python
# 建议在 intent_routing.py 中新增

DEViation_REGISTER_KEYWORDS = [
    "登记偏差", "偏差登记", "偏差录入", "偏差记录",
    "偏差报告", "偏差编号", "偏差台账", "偏差分级"
]

def is_deviation_register_intent(query: str) -> bool:
    """检测是否是偏差登记意图"""
    return any(kw in query for kw in DEViation_REGISTER_KEYWORDS)

def route_deviation_register(query: str) -> list[str]:
    """偏差登记场景路由"""
    if is_deviation_register_intent(query):
        return [
            "sp_qms_017_偏差登记",  # 新建
            "sp_qms_009_偏差调查",
            "偏差记录表",
            "偏差登记表"
        ]
    return []  # 不匹配则不返回无关文档
```

#### 3.1.2 GMP条款精确匹配优化

```python
# 建议在 semantic_search.py 中新增

import re

def extract_gmp_article(query: str) -> str:
    """从查询中提取GMP条款编号"""
    patterns = [
        r'第(\d+)条',
        r'GMP第(\d+)条',
        r'条款(\d+)'
    ]
    for pattern in patterns:
        match = re.search(pattern, query)
        if match:
            return match.group(1)
    return None

def exact_match_gmp_article(query: str, documents: list) -> list:
    """GMP条款精确匹配"""
    article = extract_gmp_article(query)
    if article:
        # 精确匹配包含该条款编号的文档
        return [doc for doc in documents if f"第{article}条" in doc.title]
    return []
```

## 七、结论

OpenClaw在v5版本中已经取得了显著进步（从Phase 1的48.8%提升到81.1%），但在以下方面仍有改进空间：

1. **意图路由精细化**: 偏差登记等特殊场景需要专门路由策略
2. **精确匹配能力**: GMP条款查询需要精确匹配而非模糊匹配
3. **结果排序优化**: SOP查询应优先返回SOP而非验证报告

建议按照本文档的优先级顺序进行改进，并在改进后重新进行164场景测试验证。
