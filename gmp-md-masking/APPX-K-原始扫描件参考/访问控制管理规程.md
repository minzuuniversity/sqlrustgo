# 访问控制管理规程

**文件编号**: SMP-COM-004 | **类别**: 计算机系统

---

## 1. 目的

建立计算机系统访问控制管理程序，确保系统安全、数据安全。

## 2. 适用范围

适用于高原彝药厂所有计算机系统的访问控制。

## 3. 访问控制级别

| 级别 | 说明 | 权限 |
|------|------|------|
| 系统管理员 | 系统管理 | 全部 |
| 管理员 | 业务管理 | 大部分 |
| 用户 | 业务操作 | 按职责 |
| 访客 | 只读 | 有限 |

## 4. 访问控制原则

| 原则 | 说明 |
|------|------|
| 最小权限 | 仅授予必要权限 |
| 职责分离 | 关键操作需多人 |
| 需则知 | 需要时才知道 |

## 5. 用户管理

| 要求 | 内容 |
|------|------|
| 创建 | 申请审批后创建 |
| 修改 | 权限变更需审批 |
| 删除 | 离职/调动时删除 |
| 定期审查 | 定期审查权限 |

## 6. 密码管理

| 要求 | 内容 |
|------|------|
| 复杂度 | 大小写字母、数字、符号 |
| 长度 | 至少8位 |
| 更换周期 | 90天 |
| 历史记录 | 不可重复使用 |

## 7. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 用户权限记录 | 10年 | IT部门 |
| 密码更换记录 | 5年 | IT部门 |
