```bash
cd ~/sqlrustgo && cargo build -p sqlrustgo-gmp
SQLRUSTGO_HOME=~/gmp-qa ./target/debug/sqlrustgo-gmp-cli
```

- `VectorSearch` — bge-m3 cosine similarity (1024维)
- `SqlSearch` — SQL WHERE 精确过滤
