# 厂房设施验证管理规程

## 1. 目的

建立并规范公司厂房及配套设施的全生命周期验证流程，确保厂房布局、建筑特性及设施功能符合预定生产用途和工艺要求，能够持续维持适宜的生产环境，保障产品质量安全，符合最新版 GMP 及 ICH Q9、Q10 指南要求。

## 2. 范围

2.1 适用于公司所有与药品生产相关的厂房及设施，包括：

- 生产厂房（含洁净区与非洁净区）；
- 辅助设施（空气净化系统、给排水系统、压缩空气系统、真空系统、温湿度控制系统）；
- 公用设施（变配电系统、消防系统、废弃物处理系统）；
- 仓储设施（原料库、成品库、阴凉库、危险品库）。

2.2 涵盖验证全流程，包括设计确认（DQ）、安装确认（IQ）、运行确认（OQ）、性能确认（PQ），以及厂房设施改扩建、重大维修后的再验证。

2.3 涉及工程部、生产部、QA 部、QC 部、安全环保部等相关部门的验证活动。

## 3. 术语与定义

3.1 厂房设施验证：证明厂房及设施的设计、安装、运行和性能符合预定用途和质量标准的有文件证明的系列活动，包括 DQ、IQ、OQ、PQ。

3.2 设计确认（DQ）：确认厂房设施的设计方案符合 GMP 要求、工艺需求及相关法规标准的活动。

3.3 安装确认（IQ）：确认厂房设施的建筑施工、设备安装及系统配置符合设计图纸和安装规范的活动。

3.4 运行确认（OQ）：确认厂房设施在空载或模拟运行状态下，所有功能及参数符合设计要求的活动。

3.5 性能确认（PQ）：确认厂房设施在正常运行条件下，能够持续满足生产工艺及环境控制要求的活动。

3.6 洁净区：需要对环境中尘粒及微生物数量进行控制的区域，根据洁净度等级分为 A、B、C、D 级。

## 4. 职责

| 部门 | 职责 |
| --- | --- |
| 工程部 | 负责厂房设施设计、施工及安装管理；主导 DQ、IQ、OQ 实施，编制验证方案与报告；提供设计图纸、施工记录等技术资料；负责日常维护及维修后的再验证申请。 |
| 生产部 | 参与 DQ 阶段工艺需求确认；提供 PQ 阶段生产负荷参数；协助进行设施运行测试；确认设施符合生产操作需求。 |
| QA 部 | 审核验证方案与报告；监督验证过程合规性；参与风险评估；批准验证结果及再验证周期；复核环境监测数据。 |
| QC 部 | 执行 PQ 阶段环境检测（如洁净度、微生物）；提供检测数据报告；确保检测方法经过验证。 |
| 安全环保部 | 参与 DQ 阶段安全环保设计确认；审核消防、废弃物处理系统验证结果；监督环保设施合规运行。 |
| 质量负责人 | 批准重大验证方案与报告；审批再验证周期；决策重大风险控制措施。 |

## 5. 管理内容与要求

### 5.1 验证策划与启动

5.1.1 验证启动条件：新厂房建成后、设施安装完成后、厂房设施改扩建 / 重大维修后，或定期再验证周期届满时，由工程部填写《厂房设施验证申请表》（附件 1），提交 QA 部审核。

5.1.2 风险评估：QA 部组织跨部门小组采用 FMEA 工具（参考 WI-QA-002-A《风险评分标准指南》）开展评估，重点识别：

- 洁净区布局合理性、系统交叉污染风险、环境参数失控影响等；
- 对 RPN≥32 或严重性（S）=5 的高风险项（如无菌车间压差失控），在验证方案中强化测试要求；
- 风险评估报告作为验证方案附件归档。

5.1.3 验证方案制定：工程部牵头编制方案，内容至少包括：验证目的、范围、设施信息、风险评估结果、确认项目与方法、可接受标准、责任人、时间计划及异常处理流程。

### 5.2 设计确认（DQ）

5.2.1 实施时机：厂房建设 / 设施采购前，设计方案最终确定后。

5.2.2 确认内容：

- 选址与布局：厂区周边无扩散性污染源，功能区域（生产区、生活区、仓储区）划分明确且分隔合理；洁净区与非洁净区间有缓冲设施，人员 / 物料流避免交叉污染。
- 建筑设计：厂房面积与生产能力匹配，顶棚、墙面、地面采用无毒、易清洁、防霉材料，墙角为漫弯形设计以防积污；洁净区门窗闭合严密，窗户装防虫害窗纱。
- 系统设计：空气净化系统的洁净度等级、换气次数符合工艺要求；给排水系统管路分离，标识清晰，排水流向由高洁净区至低洁净区；消防系统与生产环境兼容。
- 安全环保：废弃物处理系统符合环保标准，危险品库有防爆、防渗设计。

5.2.3 输出文件：《设计确认报告》，附设计图纸、资质证明等，经质量负责人批准后方可实施施工 / 安装。

### 5.3 安装确认（IQ）

5.3.1 实施时机：厂房施工 / 设施安装完成后，OQ 实施前。

5.3.2 实施主体：工程部主导，QA 部监督，相关部门参与。

5.3.3 确认内容：

- 施工质量核查：核对建筑尺寸、材料规格与设计图纸一致性；检查地面平整度、墙面密封性、洁净区吊顶接缝严密性。
- 设施安装确认：空气净化系统的高效过滤器安装牢固，密封完好；给排水管路连接无渗漏，材质符合要求（如与药品接触管路为 316L 不锈钢）；仪表（温湿度计、压差计）已校准。
- 文件核查：施工记录、材料合格证、设备说明书、校准证书等文件齐全有效。

5.3.4 可接受标准：所有项目 100% 符合设计要求，文件完整可追溯。

5.3.5 输出文件：《安装确认报告》，附支持性资料，经 QA 审核后归档。

### 5.4 运行确认（OQ）

5.4.1 实施前提：IQ 通过且报告批准后。

5.4.2 确认内容：

- 系统功能测试：空气净化系统启动后，风机运行正常，风阀调节灵敏；温湿度控制系统在设定范围内稳定运行，波动幅度≤±1℃（温度）、±5% RH（湿度）；消防系统报警功能 100% 有效。
- 关键参数测试：测试洁净区各房间压差（如 A/B 级区相对室外正压≥15Pa）、空气净化系统换气次数（如 D 级区≥15 次 / 小时）；给排水系统水压、流量达标。
- 安全功能验证：模拟停电、设备故障等应急场景，确认备用系统（如 UPS 电源）启动正常；废气处理系统排放达标。

5.4.3 抽样要求：每个参数至少连续测试 3 次，记录完整数据。

5.4.4 输出文件：《运行确认报告》，经 QA 审核后进入 PQ 阶段。

### 5.5 性能确认（PQ）

5.5.1 实施前提：OQ 通过，生产设备安装到位，环境清洁完成。

5.5.2 确认内容：

- 环境参数稳定性测试：在模拟生产负荷下，连续 7 天监测洁净区温湿度、压差，每天记录 3 个时间点数据；按 GB 50073-2013 标准测试洁净度（尘埃粒子、沉降菌），A/B 级区至少测试 5 个点位。
- 系统协同性验证：空气净化系统与生产设备同时运行，验证洁净度维持能力；给排水系统在高峰用水时段的压力稳定性。
- 仓储设施验证：阴凉库连续 7 天监测温湿度，确保符合 2-10℃要求；危险品库通风、防爆设施运行正常。

5.5.3 可接受标准：

- 洁净区尘埃粒子、微生物数量符合对应等级标准（如 ISO 5 级区≥0.5μm 粒子≤3520 个 /m³）；
- 温湿度控制在设定范围内，波动幅度符合要求。

5.5.4 输出文件：《性能确认报告》，附测试数据和分析结果，经 QA 审核后归档。
