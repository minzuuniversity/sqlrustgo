## 1. 目的

建立洁净区压差监控管理规范，确保洁净区与非洁净区之间、不同洁净级别区域之间保持适当的压差，防止污染和交叉污染，符合《药品生产质量管理规范（2010年修订）》第三十八条要求。

---

## 2. 范围

适用于公司所有洁净区（包括D级、C级、A/B级洁净区）的压差监控管理，包括：
- 洁净区与外界（走廊、非洁净区）的压差监控
- 不同洁净级别区域之间的压差监控
- 关键操作间（如称量室、灌装间）的压差监控
- 气锁间（缓冲间）的压差监控

## 4. 定义

### 4.1 压差（Differential Pressure, ΔP）
指两个相邻区域之间的空气压力差值，通常以帕斯卡（Pa）为单位。

### 4.2 正压
洁净区压力高于相邻区域压力，可防止外界污染物进入洁净区。

### 4.3 负压
洁净区压力低于相邻区域压力，用于防止洁净区内污染物扩散到外界。

### 4.4 压差监控点
在洁净区关键位置安装的压差传感器或压差计。

## 5. 压差标准

### 5.1 GMP规定的压差要求

| 区域类型 | 压差要求 | 说明 |
|----------|----------|------|
| 洁净区与非洁净区之间 | ≥10Pa | 正压 |
| 不同洁净级别之间 | ≥10Pa | 高级别向低级别 |
| A/B级区与其他区域 | ≥15Pa | 更严格控制 |

### 5.2 公司内部压差标准

| 区域分级 | 压差要求 | 警报限 |
|----------|----------|--------|
| A/B级区 → C级区 | ≥15Pa | 12Pa |
| C级区 → D级区 | ≥10Pa | 8Pa |
| D级区 → 一般区 | ≥10Pa | 8Pa |
| 气锁间 → 洁净走廊 | 5-15Pa | 3Pa/18Pa |
| 缓冲间 → 操作间 | 5-15Pa | 3Pa/18Pa |

### 5.3 各区域压差设定

| 监测位置 | 正常压差 | 报警限（低/高） |
|----------|----------|-----------------|
| 洁净区入口 | +15Pa | 12Pa / 25Pa |
| A级区入口 | +15Pa | 12Pa / 25Pa |
| C级走廊 | +10Pa | 8Pa / 20Pa |
| D级走廊 | +10Pa | 8Pa / 20Pa |
| 气锁间 | +10Pa | 5Pa / 18Pa |
| 卫生间/更衣室 | -5Pa | -10Pa / 0Pa |

## 6. 压差监控设备

### 6.1 设备类型

| 设备类型 | 精度要求 | 应用场景 |
|----------|----------|----------|
| 指针式压差计 | ±1Pa | 现场显示 |
| 数显压差计 | ±0.5Pa | 现场显示+信号输出 |
| 压差传感器 | ±0.5Pa | 连续监控+报警 |
| 压差变送器 | ±0.5%FS | 集成到BAS系统 |

### 6.2 安装位置

| 位置 | 安装数量 | 说明 |
|------|----------|------|
| 洁净区总入口 | 1个/入口 | 监测洁净区与外界的压差 |
| 各洁净区走廊入口 | 1个/入口 | 监测不同区域的压差 |
| 气锁间 | 1个/间 | 监测气锁间两侧的压差 |
| 关键操作间 | 1个/间 | 监测关键区域压差 |
| 围绝科区域 | 1个/区域 | 监测负压区域 |

### 6.3 设备校准

| 校准类型 | 周期 | 执行部门 |
|----------|------|----------|
| 现场比对 | 每季度 | 设备工程部 |
| 第三方校准 | 每年 | 外部校准机构 |
| 故障后校准 | 维修后 | 外部校准机构 |

## 9. 压差异常处理

### 9.1 报警分级

| 级别 | 压差范围 | 处理时限 | 处理方式 |
|------|----------|----------|----------|
| 一级报警 | < 设定值50% | 即时 | 立即停止生产，排查原因 |
| 二级报警 | 50%-80%设定值 | 30分钟内 | 排查原因，必要时停止生产 |
| 三级报警 | 80%-100%设定值 | 2小时内 | 加强监控，查找原因 |

### 9.2 异常处理流程

```
压差异常报警/发现 → 确认报警真实性 
→ 评估对产品质量的影响 → 排查原因 → 采取纠正措施
→ 填写偏差报告 → 验证压差恢复 → 恢复生产
```

### 9.3 常见异常及处理

| 异常现象 | 可能原因 | 处理措施 |
|----------|----------|----------|
| 压差突然为零 | 过滤器堵塞、风机故障、门开启 | 检查风机、更换过滤器、确认门状态 |
| 压差持续下降 | 过滤器堵塞、泄漏 | 清洁或更换过滤器、检查密封 |
| 压差波动大 | 风机运行不稳、季节变化 | 调节风机、检查风机皮带 |
| 压差反向 | 风机反转、风门开度过大 | 检查风机转向、调节风门 |

### 9.4 偏差报告

压差异常超过处理时限或导致生产中断时，应：
1. 发起偏差调查
2. 评估对产品质量的影响
3. 必要时扩大环境监测范围
4. 制定预防措施

## 10. 压差趋势分析

### 10.1 分析频率

| 分析类型 | 频率 | 执行部门 |
|----------|------|----------|
| 周趋势分析 | 每周 | 设备工程部 |
| 月度分析 | 每月 | QA |
| 季度分析 | 每季度 | QA |

### 10.2 分析内容

| 分析内容 | 说明 |
|----------|------|
| 压差波动范围 | 是否在正常范围内 |
| 报警次数统计 | 各级别报警次数 |
| 异常趋势 | 压差是否有下降趋势 |
| 设备运行状态 | 风机、过滤器状态 |

### 10.3 趋势判定

| 判定结果 | 标准 | 处理 |
|----------|------|------|
| 正常 | 无超标、趋势平稳 | 继续监控 |
| 关注 | 压差接近限值 | 加强监控 |
| 异常 | 持续下降或频繁报警 | 制定纠正措施 |
