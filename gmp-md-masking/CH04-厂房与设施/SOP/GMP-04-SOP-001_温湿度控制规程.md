# 温湿度控制规程

**文件编号**: SP-FAC-011
**版本**: V1.0
**生效日期**: 2026-01-01
**审核人**: __________
**批准人**: __________

---

## 1. 目的

建立洁净区及仓储区域温湿度控制管理规范，确保药品生产、储存过程中的环境条件符合要求，防止药品因环境温湿度不当而影响质量，符合《药品生产质量管理规范（2010年修订）》第三十八条要求。

---

## 2. 范围

适用于公司以下区域的温湿度控制：
- D级、C级、A/B级洁净区
- 原辅料仓库
- 成品仓库
- 中间产品暂存区
- 实验室
- 其他需要温湿度控制的区域

---

| 部门/岗位 | 职责 |
|-----------|------|

## 4. 定义

### 4.1 温湿度控制
通过空调、加湿、除湿等设备对环境温度和湿度进行调控，使其维持在规定范围内的活动。

### 4.2 温湿度监控点
安装温湿度传感器/记录仪的位置。

### 4.3 温湿度偏差
环境温湿度超出规定范围的情况。

---

## 5. 温湿度标准

### 5.1 GMP规定的温湿度要求

| 区域类型 | 温度要求 | 湿度要求 |
|----------|----------|----------|
| 洁净生产区 | 18-26℃ | 45-65%RH |
| 洁净区实验室 | 18-26℃ | 45-65%RH |
| 口服固体制剂 | 18-26℃ | 45-65%RH |
| 注射剂生产 | 18-26℃ | 45-65%RH |
| 仓库（常温） | 10-30℃ | 35-75%RH |
| 仓库（阴凉） | ≤20℃ | 35-75%RH |
| 仓库（冷藏） | 2-8℃ | 不作规定 |
| 实验室 | 20-25℃ | 45-60%RH |

### 5.2 公司内部温湿度标准

| 区域 | 温度(℃) | 湿度(%RH) | 报警限 |
|------|---------|-----------|--------|
| A/B级洁净区 | 20-24 | 45-60 | ±5 |
| C级洁净区 | 18-26 | 45-65 | ±5 |
| D级洁净区 | 18-26 | 45-70 | ±5 |
| 原辅料仓库 | 10-30 | 35-75 | 超出限值即报警 |
| 成品仓库 | 10-30 | 35-75 | 超出限值即报警 |
| 阴凉仓库 | ≤20 | 35-75 | 超出限值即报警 |
| 冷藏仓库 | 2-8 | - | ±2℃ |
| 实验室 | 20-25 | 45-60 | ±3 |

## 6. 温湿度监控设备

### 6.1 设备类型

| 设备类型 | 精度要求 | 应用场景 |
|----------|----------|----------|
| 温湿度计（指针式） | ±1℃/±5%RH | 现场显示 |
| 温湿度计（数显） | ±0.5℃/±3%RH | 现场显示+记录 |
| 温湿度传感器 | ±0.5℃/±3%RH | 连续监控+报警 |
| 温湿度记录仪 | ±0.5℃/±3%RH | 数据记录 |
| 温湿度变送器 | ±0.5℃/±3%RH | 集成到BAS系统 |

### 6.2 安装位置

#### 洁净区

| 区域 | 安装数量 | 位置要求 |
|------|----------|----------|
| A/B级区域 | 1个/间 | 距地面1.2m，远离送风口 |
| C级区域 | 1个/50㎡ | 均匀分布 |
| D级区域 | 1个/100㎡ | 均匀分布 |
| 人流/物流通道 | 1个/通道 | 位置代表性 |

#### 仓库

| 区域 | 安装数量 | 位置要求 |
|------|----------|----------|
| 常温库 | 1个/200㎡ | 均匀分布 |
| 阴凉库 | 1个/100㎡ | 均匀分布 |
| 冷藏库 | 1个/库 | 温度最差点 |
| 特殊区域 | 1个/区 | 按需增加 |

### 6.3 设备校准

| 校准类型 | 周期 | 执行部门 |
|----------|------|----------|
| 现场比对 | 每季度 | 设备工程部 |
| 第三方校准 | 每年 | 外部校准机构 |

## 9. 温湿度异常处理

### 9.1 报警分级

| 级别 | 超出范围 | 处理时限 | 处理方式 |
|------|----------|----------|----------|
| 一级 | 超出允许范围≥5℃/≥10%RH | 即时 | 立即停止作业，排查原因 |
| 二级 | 超出允许范围≥2℃/≥5%RH | 1小时内 | 排查原因，采取措施 |
| 三级 | 超出允许范围<2℃/<5%RH | 2小时内 | 加强监控，查找原因 |

### 9.2 异常处理流程

```
温湿度异常报警/发现 → 确认报警真实性 
→ 评估对产品质量的影响 → 排查原因 
→ 采取纠正措施（调节空调/除湿/加湿）
→ 填写偏差报告 → 验证温湿度恢复 → 恢复生产
```

### 9.3 常见异常及处理

| 异常现象 | 可能原因 | 处理措施 |
|----------|----------|----------|
| 温度偏高 | 空调制冷不足、人员过多、设备发热 | 调节设定温度、检查制冷系统 |
| 温度偏低 | 空调制热过度、新风过大 | 调节设定温度、检查加热系统 |
| 湿度偏高 | 除湿能力不足、新风湿度大 | 开启除湿机、调节新风 |
| 湿度偏低 | 加湿不足、暖通过度 | 开启加湿器、调节加湿量 |
| 局部温湿度异常 | 气流组织不合理 | 调整风口位置、风量 |

### 9.4 偏差报告

温湿度异常超过处理时限或导致生产中断时，应：
1. 发起偏差调查
2. 评估对产品质量的影响
3. 必要时对相关物料/产品进行评估
4. 制定预防措施

## 10. 温湿度调控设备操作

### 10.1 空调系统操作

| 操作 | 要求 |
|------|------|
| 开机前检查 | 确认电源、水源正常，过滤器压差正常 |
| 参数设定 | 按区域标准设定温湿度参数 |
| 运行监控 | 检查运行电流、冷热媒介温度 |
| 停机 | 按正常程序停机，记录运行时间 |

### 10.2 除湿机操作

| 操作 | 要求 |
|------|------|
| 开机前检查 | 确认排水管畅通、水箱空置 |
| 参数设定 | 设定目标湿度 |
| 运行监控 | 检查排水情况、运行电流 |
| 维护 | 定期清洁蒸发器、冷凝器 |

### 10.3 加湿器操作

| 操作 | 要求 |
|------|------|
| 使用水质 | 使用纯化水或去离子水 |
| 参数设定 | 设定目标湿度 |
| 运行监控 | 检查水位、水质、喷雾情况 |
| 维护 | 定期清洁水箱、喷头 |
