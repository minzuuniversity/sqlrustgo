# 数据完整性 ALCOA 原则详解

## 1. 概述

ALCOA 原则是确保数据完整性的国际通行准则，被 FDA、EMA、WHO 等药品监管机构广泛采用。

## 2. ALCOA 原则详解

### 2.1 A - Attributable (可归属)

**定义**: 数据可以追溯到产生数据的个人

**要求**:
- 纸质记录：手写签名或首字母缩写
- 电子记录：用户登录账户

**最佳实践**:
```
✓ 记录上标注产生数据的人员姓名/ID
✓ 记录修改时标注修改人
✓ 系统日志记录操作人
```

**常见问题**:
```
✗ 多人共用账号
✗ 记录无签名
✗ 无法追溯操作人
```

### 2.2 L - Legible (清晰)

**定义**: 数据可读、易读、持久

**要求**:
- 纸质记录：字迹清晰、不得涂改
- 电子数据：格式标准、可正常读取

**最佳实践**:
```
✓ 使用蓝色或黑色墨水笔记录
✓ 记录文字清晰可辨
✓ 电子数据采用标准格式保存
```

**常见问题**:
```
✗ 字迹潦草无法辨认
✗ 涂改后看不清原始数据
✗ 电子数据格式不标准
```

### 2.3 C - Contemporaneous (同步)

**定义**: 数据在产生时即时记录

**要求**:
- 操作与记录同步
- 不得事后补记
- 记录时间真实准确

**最佳实践**:
```
✓ 操作完成后立即记录
✓ 记录包含日期和时间
✓ 偏差/异常即时记录
```

**常见问题**:
```
✗ 事后集中补填记录
✗ 记录时间早于实际操作
✗ 批记录提前签字
```

### 2.4 O - Original (原始)

**定义**: 数据为首次采集的记录

**要求**:
- 保存原始数据
- 保留原始记录副本
- 电子数据保留源数据

**最佳实践**:
```
✓ 原始记录不得销毁
✓ 保留数据备份
✓ 电子数据加密存储
```

**常见问题**:
```
✗ 原始记录丢失
✗ 覆盖原始数据
✗ 未备份关键数据
```

### 2.5 A - Accurate (准确)

**定义**: 数据真实、准确反映实际操作

**要求**:
- 数据记录真实
- 计算准确
- 不得伪造数据

**最佳实践**:
```
✓ 复核人核对数据
✓ 异常数据调查
✓ 数据审计追踪
```

**常见问题**:
```
✗ 数据计算错误
✗ 伪造数据
✗ 填报数据与实际不符
```

## 3. 计算机化系统要求

### 3.1 审计追踪

**要求**:
- 系统必须开启审计追踪功能
- 记录所有数据修改
- 审计追踪不得关闭

**检查要点**:
```
✓ 审计追踪功能开启
✓ 修改记录完整
✓ 修改时间可追溯
```

### 3.2 权限管理

**要求**:
- 不同岗位设置不同权限
- 管理员权限受控
- 离职人员账户及时停用

**权限矩阵**:
| 角色 | 创建 | 修改 | 删除 | 审核 |
|------|------|------|------|------|
| 操作员 | ✓ | 自己的 | ✗ | ✗ |
| 主管 | ✓ | ✓ | 需审批 | ✓ |
| QA | ✗ | ✗ | ✗ | ✓ |
| IT管理员 | ✓ | ✓ | ✓ | ✗ |

### 3.3 数据备份

**要求**:
- 定期备份数据
- 备份数据可恢复
- 异地存储

**备份策略**:
| 数据类型 | 备份频率 | 保留时间 |
|----------|----------|----------|
| 批记录 | 实时 | 5年 |
| 检验数据 | 每日 | 5年 |
| 系统日志 | 每周 | 2年 |

## 4. 常见缺陷案例

### 4.1 案例一：记录不及时

**缺陷描述**: 检验人员事后集中补填检验记录

**风险评估**: 高 - 可能掩盖OOS结果

**整改措施**:
- 安装时间同步系统
- 培训同步记录重要性
- 增加复核环节

### 4.2 案例二：权限共用

**缺陷描述**: 多个检验员共用一个检验系统账号

**风险评估**: 高 - 无法追溯操作人

**整改措施**:
- 每人分配独立账号
- 定期检查账号使用情况
- 离职人员账号立即停用

### 4.3 案例三：审计追踪关闭

**缺陷描述**: 液相色谱系统审计追踪被关闭

**风险评估**: 严重 - 数据真实性无法保证

**整改措施**:
- 立即开启审计追踪
- 调查是否有人为关闭
- 完善权限管理规程
