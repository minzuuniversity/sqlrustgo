# 药品投诉处理管理规程

## 1. 目的

规范药品投诉的接收、调查、处理和回复流程，确保患者用药安全。

## 2. 范围

适用于公司生产的所有药品的投诉处理，包括：
- 质量问题投诉
- 不良反应投诉
- 服务态度投诉
- 包装破损投诉

## 3. 职责

3.1 客户服务部：投诉接收和初步记录
3.2 质量部：投诉调查和处理
3.3 生产部：配合调查
3.4 法规部：必要时向监管部门报告

## 4. 投诉分类

| 类别 | 定义 | 处理时限 |
|------|------|----------|
| 紧急 | 可能导致严重健康危害 | 24小时 |
| 高优先级 | 严重质量问题 | 7工作日 |
| 一般 | 其他问题 | 15工作日 |

## 5. 处理流程

### 5.1 投诉接收
- 记录投诉日期、内容、联系方式
- 判断投诉类别
- 分配处理责任人

### 5.2 投诉调查
- 调取相关批记录
- 必要时现场调查
- 留样样品检测

### 5.3 处理措施
- 纠正措施：立即改进
- 预防措施：避免再发

### 5.4 投诉回复
- 及时回复客户
- 说明调查结论
- 如有赔偿需审批

## 6. 投诉分析

- 每月汇总分析
- 识别趋势和系统性风险
- 触发CAPA或偏差
