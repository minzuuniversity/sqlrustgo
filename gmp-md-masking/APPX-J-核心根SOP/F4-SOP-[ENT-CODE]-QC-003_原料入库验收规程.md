# 原料入库验收规程

## 1. 目的

规范原料（原辅料）的入库验收流程，确保入库原料符合质量标准要求。

## 2. 范围

适用于公司采购的所有原料（原药材、提取物、辅料）的入库验收。

## 3. 验收流程

### 3.1 验收步骤

```
到货 → 资料审核 → 外观检查 → 取样 → 检验 → 判定 → 入库/拒收
```

### 3.2 资料审核

来料时需审核：
- 供应商检验报告 (COA)
- 送货单/发票
- 供应商资质（生产许可证、营业执照）
- 物料放行单

### 3.3 外观检查

| 检查项 | 合格标准 | 不合格表现 |
|--------|----------|------------|
| 性状 | 符合规定 | 变色、结块、异物 |
| 包装 | 完整、清洁 | 破损、污染、潮湿 |
| 标识 | 清晰、完整 | 信息不全、模糊 |

## 4. 取样要求

### 4.1 取样量

| 批量 | 取样件数 | 取样量 |
|------|----------|--------|
| ≤5件 | 逐件 | ≥100g/件 |
| 6-50件 | 5件 | ≥100g/件 |
| 51-100件 | 6件 | ≥100g/件 |
| >100件 | 7件 | ≥100g/件 |

### 4.2 取样操作

1. 双人取样
2. 使用专用取样器
3. 清洁消毒取样工具
4. 样品密封粘贴标识
5. 填写取样记录

## 5. 检验项目

### 5.1 性状检验

- 外观、颜色
- 气味
- 粒度、水分

### 5.2 鉴别检验

- 化学鉴别
- 薄层鉴别
- 红外鉴别

### 5.3 含量测定

- 液相色谱法 (HPLC)
- 滴定法
- 重量法

### 5.4 特殊检验

| 物料类型 | 特殊项目 |
|----------|----------|
| 中药材 | 灰分、浸出物、农药残留 |
| 提取物 | 浓度、提取率 |
| 微生物 | 需氧菌总数、霉菌 |

## 6. 判定标准

### 6.1 合格判定

所有检验项目符合标准 → 判定合格 → 发放合格报告 → 入库

### 6.2 不合格判定

任何一项不合格 → 判定不合格 → 填写偏差记录 → 隔离存放 → 通知供应商 → 退货/降级

### 6.3 复验

对检验结果有异议 → 申请复验 → 备样复验 → 重新判定

## 7. 储存条件

| 物料类型 | 温度 | 湿度 | 特殊要求 |
|----------|------|------|----------|
| 普通原料 | ≤30℃ | ≤65%RH | 阴凉干燥 |
| 活菌制剂 | 2-8℃ | - | 冷藏 |
| 避光物料 | - | - | 避光储存 |
| 易吸潮 | - | <60%RH | 密闭 |
