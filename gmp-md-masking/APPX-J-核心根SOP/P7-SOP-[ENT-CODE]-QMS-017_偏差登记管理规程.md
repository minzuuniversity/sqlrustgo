# 偏差登记管理规程

## 1. 目的

建立偏差的识别、登记、初步评估流程，确保所有偏差得到及时记录和初步处理。

## 2. 范围

适用于生产、质量控制、仓储、设备等过程中发现的所有偏差。

## 3. 定义

偏差：与已批准的文件（工艺规程、质量标准、检验方法等）的任何偏离。

## 4. 偏差分类

| 类别 | 说明 | 举例 |
|------|------|------|
| 关键偏差 | 可能影响产品质量 | 关键参数超标 |
| 主要偏差 | 可能影响产品质量 | 设备故障 |
| 次要偏差 | 轻微偏离 | 记录不及时 |

## 5. 偏差登记流程

### 5.1 发现偏差
- 发现人立即记录
- 保持偏差现场
- 通知班组长

### 5.2 初步评估
- 评估对产品质量的潜在影响
- 确定偏差类别
- 决定是否需要偏差处理

### 5.3 偏差登记
- 填写偏差登记表
- 分配偏差编号
- 通知质量部

## 6. 偏差编号规则

格式：DEV-YYYY-NNNN
示例：DEV-2025-0001

## 7. 与偏差调查的关系

- 登记只是记录
- 关键偏差需启动偏差调查
- 偏差登记是偏差处理的前提
