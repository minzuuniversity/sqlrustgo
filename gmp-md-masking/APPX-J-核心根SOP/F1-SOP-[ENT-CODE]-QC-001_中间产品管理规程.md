# 中间产品管理规程

## 1. 目的

建立中间产品（又称中间体、在制品）的质量控制标准，确保中间产品符合质量标准要求，保证最终产品质量。

## 2. 范围

适用于公司生产过程中产生的所有中间产品，包括：
- 制粒工序后的颗粒
- 胶囊填充前的粉末
- 包衣后的制剂半成品
- 其他中间工艺产物

## 3. 职责

| 部门 | 职责 |
|------|------|
| 生产部 | 中间产品生产、标识 |
| 质量部 | 中间产品检验、放行 |
| 仓库 | 中间产品储存、养护 |

## 4. 中间产品质量标准

### 4.1 颗粒（制粒工序）

| 项目 | 标准 | 检验方法 |
|------|------|----------|
| 外观 | 类白色颗粒，无结块 | 目测 |
| 粒度 | 20-80目 ≥85% | 筛分法 |
| 水分 | ≤5.0% | 干燥失重 |
| 堆密度 | 0.35-0.50g/mL | 量筒法 |

### 4.2 胶囊填充粉

| 项目 | 标准 | 检验方法 |
|------|------|----------|
| 外观 | 均匀粉末，颜色一致 | 目测 |
| 水分 | ≤4.5% | 卡尔费休法 |
| 装量差异 | ±7.5% | 法定量 |
| 流动性 | 休止角≤40° | 漏斗法 |

## 5. 中间产品标识

### 5.1 标识内容

中间产品容器上必须标识：
- 产品名称
- 批号
- 规格
- 数量
- 生产日期
- 有效期
- 工序名称
- 检验状态（待验/合格/不合格）

### 5.2 检验状态标识

| 状态 | 标识颜色 | 处置 |
|------|----------|------|
| 待验 | 黄色 | 等待检验结果 |
| 合格 | 绿色 | 可转入下工序 |
| 不合格 | 红色 | 隔离存放，等待处理 |

## 6. 中间产品储存

### 6.1 储存条件

| 产品类型 | 温度 | 湿度 | 期限 |
|----------|------|------|------|
| 颗粒 | ≤25℃ | ≤60%RH | 72小时 |
| 填充粉 | ≤25℃ | ≤45%RH | 48小时 |
| 包衣半成品 | ≤25℃ | ≤50%RH | 24小时 |

### 6.2 储存要求

1. 中间产品必须存放于专用中间站
2. 不同批次不得混放
3. 离开中间站需重新计算有效期

## 7. 中间产品转移

### 7.1 转移条件

中间产品转移至下一工序必须满足：
- 检验合格
- 在有效期内
- 包装完整
- 标识清晰

### 7.2 转移记录

转移时需填写《中间产品转移记录》，内容包括：
- 产品名称、批号
- 数量
- 转移时间
- 转入工序
- 交接人签名

## 8. 不合格中间产品处理

不合格中间产品必须：
1. 粘贴红色不合格标识
2. 移至不合格品区隔离
3. 填写偏差记录
4. 等待质量部处理决定
