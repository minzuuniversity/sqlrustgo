# [PRODUCT-A-CAPSULE]工艺规程

## 1. 目的

建立[PRODUCT-A-CAPSULE]生产工艺过程控制标准，确保产品质量符合注册标准。

## 2. 范围

适用于[PRODUCT-A-CAPSULE]（批准文号：[REG-NO-SAMPLE]）的生产全过程。

## 3. 职责

3.1 生产部：负责按照本规程组织生产
3.2 质量部：负责过程监控和成品检验
3.3 设备部：负责设备维护保养

## 4. 工艺流程

### 4.1 工艺流程图

```
原料验收 → 提取 → 浓缩 → 制粒 → 胶囊填充 → 包装 → 成品入库
```

### 4.2 关键工艺参数

| 工序 | 关键参数 | 控制范围 |
|------|----------|----------|
| 提取 | 加水量 | 药材量的8-10倍 |
| 提取 | 提取温度 | 80-100℃ |
| 提取 | 提取时间 | 2小时 |
| 浓缩 | 真空度 | -0.08~-0.06MPa |
| 浓缩 | 温度 | 60-70℃ |
| 制粒 | 制粒温度 | 50-60℃ |
| 填充 | 装量差异 | ±7.5% |

## 5. 过程控制要点

### 5.1 提取工序
- 每批记录提取液量、颜色、气味
- 浓缩前检测相对密度

### 5.2 制粒工序
- 整粒后进行粒度检查
- 记录制粒溶液用量

### 5.3 填充工序
- 每15分钟检测一次装量
- 每批检测崩解时限

## 6. 质量标准

### 6.1 原料标准
- [HERB-A]：水分≤13%，总灰分≤8%
- [HERB-D]：水分≤12%，浸出物≥15%
- 香加皮：水分≤11%，紫丁香苷≥0.05%

### 6.2 成品标准
- 性状：硬胶囊，内容物为棕褐色粉末
- 水分：≤9.0%
- 崩解时限：≤30分钟
- 装量差异：符合规定
