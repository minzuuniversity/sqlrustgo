# CAPA触发条件判定指南

## 1. 目的

帮助质量人员准确判断偏差是否需要启动CAPA，提供标准化的判定依据。

## 2. CAPA触发判定矩阵

### 2.1 按偏差级别判定

| 偏差级别 | 必须启动CAPA | 条件启动CAPA | 可不启动CAPA |
|-----------|--------------|---------------|---------------|
| **关键偏差** | ✅ | - | - |
| **主要偏差** | - | ✅ (重复发生) | ✅ (首次发生) |
| **次要偏差** | - | ✅ (重复发生) | ✅ (首次发生) |
| **微小偏差** | - | - | ✅ |

### 2.2 按偏差类型判定

| 偏差类型 | CAPA必要性 | 判定理由 |
|----------|-------------|----------|
| 关键质量属性(CQA)超标 | 必须 | 可能影响患者安全 |
| 关键工艺参数(CPP)偏离 | 必须 | 可能影响产品质量 |
| 重复发生偏差 | 必须 | 系统性问题 |
| OOS/OOT | 必须 | 检验结果不可靠 |
| 投诉相关偏差 | 必须 | 可能影响患者 |
| 外观偏差(视觉) | 条件 | 需评估系统性 |
| 记录偏差 | 条件 | 需评估数据完整性 |
| 环境偏差(轻微) | 可不 | 即时纠正即可 |

### 2.3 按发生频次判定

| 发生频次 | CAPA必要性 | 判定理由 |
|----------|-------------|----------|
| 同一设备第2次 | 必须 | 可能存在系统性问题 |
| 同一物料第2次 | 必须 | 供应商或来料可能有问题 |
| 同一工序第2次 | 必须 | 工艺可能存在缺陷 |
| 不同设备/物料/工序 | 可不 | 可能是偶发事件 |

## 3. 判定流程

### 3.1 判定步骤

```
步骤1: 确定偏差级别
         ↓
步骤2: 确定偏差类型
         ↓
步骤3: 评估发生频次
         ↓
步骤4: 查阅判定矩阵
         ↓
步骤5: 做出CAPA必要性判定
         ↓
步骤6: 如需启动，填写《CAPA关联评估表》
```

### 3.2 判定记录

每次判定必须记录：

| 判定要素 | 记录内容 |
|----------|----------|
| 偏差编号 | DEV-YYYY-NNNN |
| 偏差级别 | 关键/主要/次要/微小 |
| 偏差类型 | CQA/CPP/OOS/投诉/其他 |
| 发生频次 | 第N次/是否为重复 |
| 判定结论 | 必须/条件/可不启动CAPA |
| 判定理由 | 详细说明 |
| 判定人 | 签字 |
| 判定时间 | 日期时间 |

## 4. 典型案例分析

### 4.1 案例一：关键偏差必须启动CAPA

**场景**: 含量检验结果超出规格限度（OOS）

**分析**:
- 偏差级别: 关键
- 偏差类型: OOS
- 发生频次: 首次
- 判定: **必须启动CAPA**

**理由**: OOS意味着检验结果不可靠，必须进行根本原因调查，可能影响患者安全

### 4.2 案例二：主要偏差重复发生

**场景**: 同一台混合机第2次出现混合不均匀偏差

**分析**:
- 偏差级别: 主要
- 偏差类型: 工艺参数偏离
- 发生频次: 第2次（重复）
- 判定: **必须启动CAPA**

**理由**: 重复发生表明设备可能存在系统性故障，必须进行CAPA

### 4.3 案例三：次要偏差首次发生

**场景**: 批记录填写不完整，仅缺复核人签名

**分析**:
- 偏差级别: 次要
- 偏差类型: 记录偏差
- 发生频次: 首次
- 判定: **条件启动CAPA**

**理由**: 首次发生的记录偏差可能是个别疏忽，需评估是否为系统性问题。如评估为个别事件，可不启动CAPA但需加强培训

### 4.4 案例四：微小偏差

**场景**: 标签轻微错位，但内容正确

**分析**:
- 偏差级别: 微小
- 偏差类型: 包装偏差
- 发生频次: 首次
- 判定: **可不启动CAPA**

**理由**: 对产品质量和患者安全无影响，可即时纠正并记录

## 5. 特殊情况判定

### 5.1 偏差关联多个产品

**判定原则**: 以风险最高的产品为准

**示例**: 同一批物料问题影响3个产品
- 处理: 按最严重的影响启动CAPA
- 记录: 在CAPA中说明影响范围

### 5.2 CAPA执行中发现新偏差

**判定原则**: 评估新偏差与原CAPA的关联性

| 情况 | 处理方式 |
|------|----------|
| 新偏差是原CAPA未覆盖范围 | 单独启动新CAPA |
| 新偏差是原CAPA执行过程中的问题 | 更新原CAPA范围 |
| 新偏差与原CAPA完全无关 | 单独启动新CAPA |

### 5.3 监管检查发现的偏差

**判定原则**: 监管检查中发现的偏差**必须启动CAPA**

**理由**: 监管关注点通常是系统性或重大问题

## 6. 判定争议处理

### 6.1 争议解决流程

```
部门意见 → QA意见 → 质量负责人意见 → 最终决定
```

### 6.2 判定原则

当存在争议时：
1. 以患者安全为导向
2. 以法规合规为底线
3. 以风险评估为依据
4. 保守原则：倾向于启动CAPA

## 7. 判定时效要求

| 偏差级别 | CAPA判定时限 |
|----------|--------------|
| 关键偏差 | 偏差关闭后5工作日内 |
| 主要偏差 | 偏差关闭后10工作日内 |
| 次要偏差 | 偏差关闭后15工作日内 |
| 微小偏差 | 不要求 |
