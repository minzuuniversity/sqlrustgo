# CAPA与偏差关联管理规程

## 1. 目的

建立 CAPA 与偏差的关联管理机制，确保偏差调查后正确启动 CAPA，防止同类偏差重复发生。

## 2. 范围

适用于所有偏差调查后需要启动 CAPA 的情况，包括：
- 关键偏差
- 重复发生偏差
- 严重偏差
- 监管检查发现的问题

## 3. CAPA 与偏差的关系

### 3.1 关系定义

| 关系类型 | 说明 | 触发条件 |
|----------|------|----------|
| 偏差→CAPA | 偏差调查后启动CAPA | 关键偏差、重复偏差 |
| CAPA→偏差 | CAPA执行中发现偏差 | CAPA实施过程中的偏差 |
| 独立CAPA | 不关联偏差的CAPA | 投诉、审计、趋势分析 |

### 3.2 触发规则

**必须启动 CAPA 的情况**:
```
1. 关键偏差（对产品质量有潜在影响）
2. 主要偏差（对产品质量有影响）
3. 重复发生偏差（同一设备/物料/工序的第2次偏差）
4. 监管检查中发现的严重不符合项
5. 客户投诉中的系统性问题
6. 趋势分析显示的恶化趋势
```

**可以不启动 CAPA 的情况**:
```
1. 微小偏差（对产品质量无影响）
2. 首次发生的轻微偏差
3. 明确根本原因的即时纠正
```

## 4. 关联流程

### 4.1 偏差→CAPA 流程

```
偏差登记 → 偏差调查 → 根本原因分析 → 评估是否启动CAPA
                                                      ↓
                                              ┌─────────┴─────────┐
                                              ↓                   ↓
                                         启动CAPA           不启动CAPA
                                              ↓                   
                                         填写关联表           
                                              ↓
                                         CAPA执行            
                                              ↓
                                         有效性验证          
                                              ↓
                                         CAPA关闭            
                                              ↓
                                         偏差关闭            
```

### 4.2 关联记录

偏差调查完成后必须填写《CAPA关联评估表》：

| 评估项目 | 评估结论 |
|----------|----------|
| 偏差级别 | 关键/主要/次要/微小 |
| 根本原因 | 设备/物料/方法/人员/其他 |
| 是否重复发生 | 是/否 |
| 是否启动CAPA | 是/否 |
| 不启动CAPA理由 | （如选择否） |

## 5. CAPA 编号规则

### 5.1 编号格式

```
CAPA-YYYY-NNNN
  │     │    │
  │     │    └─ 序号（0001-9999）
  │     └───── 年份（2025）
  └─────────── CAPA前缀
```

### 5.2 与偏差关联的编号

当 CAPA 关联偏差时，在编号后加注关联的偏差编号：
```
CAPA-2025-001 (关联DEV-2025-015)
```

## 6. CAPA 有效性评估

### 6.1 有效性指标

| 指标类型 | 指标定义 | 目标值 |
|----------|----------|--------|
| 偏差消除率 | 同类偏差发生率降低 | ≥80% |
| 按时完成率 | CAPA按时完成比例 | ≥95% |
| 整改有效率 | CAPA整改通过率 | ≥90% |

### 6.2 有效性验证周期

| CAPA类型 | 验证周期 |
|----------|----------|
| 紧急CAPA | 完成后1个月 |
| 重大CAPA | 完成后3个月 |
| 一般CAPA | 完成后6个月 |

### 6.3 有效性评估标准

**有效**: 同类偏差在验证期内未再发生

**部分有效**: 同类偏差发生率降低≥50%但<80%

**无效**: 同类偏差发生率降低<50%或增加

## 7. 偏差与 CAPA 台账管理

### 7.1 必须关联记录

| 关联字段 | 说明 |
|----------|------|
| 偏差编号 | DEV-YYYY-NNNN |
| CAPA编号 | CAPA-YYYY-NNNN |
| 关联类型 | 偏差→CAPA / CAPA→偏差 |
| 关联时间 | 关联建立时间 |
| 关联人 | 关联建立人 |

### 7.2 查询要求

系统必须支持：
```
1. 按偏差编号查询关联的CAPA
2. 按CAPA编号查询关联的偏差
3. 按时间范围查询关联对
4. 按部门/产品查询关联统计
```

## 8. 常见问题处理

### 8.1 偏差关闭后发现需要启动CAPA

**处理流程**:
1. 重新开启偏差记录
2. 补充根本原因分析
3. 启动CAPA
4. 重新关闭偏差

### 8.2 多个偏差关联同一CAPA

**处理方式**:
- 为每个偏差单独建立关联记录
- CAPA中说明关联多个偏差
- 有效性验证时综合评估

### 8.3 CAPA执行过程中发现新偏差

**处理方式**:
- 登记新偏差
- 评估是否需要单独启动CAPA
- 在原CAPA中记录新偏差
