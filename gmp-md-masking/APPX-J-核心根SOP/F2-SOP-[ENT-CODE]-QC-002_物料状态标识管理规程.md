# 物料状态标识管理规程

## 1. 目的

规范物料（原辅料、包装材料、中间产品、成品）的状态标识，确保物料在整个供应链中可追溯，防止混淆和误用。

## 2. 范围

适用于公司所有物料的状态标识管理，包括：
- 原料
- 辅料
- 包装材料
- 中间产品
- 成品

## 3. 状态定义与标识

### 3.1 物料状态分类

| 状态 | 定义 | 标识颜色 | 标识牌 |
|------|------|----------|--------|
| 待验 | 等待检验 | 黄色 | 物料待验牌 |
| 合格 | 检验合格 | 绿色 | 物料合格牌 |
| 不合格 | 检验不合格 | 红色 | 物料不合格牌 |
| 复验期 | 已过复验期 | 橙色 | 物料复验牌 |
| 冻结 | 因偏差等原因冻结 | 蓝色 | 物料冻结牌 |

### 3.2 标识内容

每个物料标识必须包含：
- 物料名称
- 供应商/生产商
- 批号
- 规格
- 数量
- 来料日期
- 检验状态
- 有效期/复验期

## 4. 储存条件标识

### 4.1 温湿度敏感物料

| 标识 | 含义 | 颜色 |
|------|------|------|
| 2-8℃冷藏 | 需冷链储存 | 浅蓝色 |
| 15-25℃阴凉 | 需阴凉储存 | 白色 |
| 避光 | 需避光储存 | 黑色 |
| 干燥 | 需防潮储存 | 黄色 |

### 4.2 特殊物料标识

| 物料类型 | 标识 | 颜色 |
|----------|------|------|
| 麻醉药品 | 麻精药品 | 紫色 |
| 精神药品 | 精神药品 | 紫色 |
| 贵重物料 | 贵重物料 | 金色 |
| 危险品 | 危险化学品 | 红色 |

## 5. 标识管理要求

### 5.1 标识悬挂位置

- 货架物料：悬挂于货架前端
- 散装物料：悬挂于容器上
- 批次堆放：悬挂于批次前端

### 5.2 标识检查

| 检查频率 | 检查内容 | 责任人 |
|----------|----------|--------|
| 入库时 | 标识完整性 | 仓管员 |
| 每日 | 标识清晰度 | 仓管员 |
| 每周 | 标识正确性 | QA |
| 每月 | 全面检查 | 质量部 |

### 5.3 标识更新

以下情况必须立即更新标识：
- 检验完成后更新状态
- 复验期到期重新复验
- 偏差发生时冻结物料
- 出库后更新数量

## 6. 不合格物料标识

不合格物料必须：
1. 粘贴红色"不合格"标识
2. 移至不合格品区
3. 填写《不合格品处理记录》
4. 等待处理决定（降级/退货/销毁）
