# 验证状态标识管理规程

## 1. 目的

规范设备、设施、工艺的验证状态标识管理，确保验证状态清晰可追溯，防止误用未验证或验证过期的设备设施。

## 2. 范围

适用于公司所有需要验证的设备、设施、工艺，包括：
- 生产设备
- 检验设备
- 空调净化系统 (HVAC)
- 纯化水系统
- 压缩空气系统
- 工艺方法

## 3. 验证状态分类

### 3.1 状态定义

| 状态 | 英文 | 定义 | 标识颜色 |
|------|------|------|----------|
| 已验证 | Verified | 完成所有确认项目 | 绿色 |
| 验证中 | In Progress | 验证正在进行 | 黄色 |
| 验证过期 | Expired | 验证有效期已过 | 红色 |
| 验证暂停 | Suspended | 因偏差等原因暂停 | 蓝色 |
| 未验证 | Not Verified | 尚未进行验证 | 灰色 |

### 3.2 验证有效期

| 设备/系统类型 | 验证有效期 | 再验证周期 |
|---------------|------------|------------|
| 关键生产设备 | 2年 | 每年监控 |
| 一般生产设备 | 3年 | 每2年监控 |
| HVAC系统 | 1年 | 每年监测 |
| 纯化水系统 | 1年 | 每年监测 |
| 压缩空气 | 1年 | 每半年监测 |
| 检验设备 | 1年 | 每年校准 |
| 工艺验证 | 3年 | 每年产品回顾 |

## 4. 标识内容

### 4.1 设备验证标识牌

| 内容 | 说明 |
|------|------|
| 设备编号 | 唯一编号 |
| 设备名称 | 中文名称 |
| 验证状态 | 当前状态 |
| 验证报告编号 | 最近验证报告 |
| 验证日期 | 最近验证时间 |
| 有效期至 | 验证到期时间 |
| 责任人 | 设备负责人 |

### 4.2 检验设备校准标识

| 内容 | 说明 |
|------|------|
| 仪器编号 | 唯一编号 |
| 校准状态 | 已校准/待校准 |
| 校准日期 | 最近校准时间 |
| 校准有效期 | 到期时间 |
| 校准机构 | 内部/外部 |
| 校准证书号 | 证书编号 |

## 5. 标识位置

### 5.1 设备标识

- 设备主体显著位置
- 操作面板附近
- 设备档案袋表面

### 5.2 系统标识

- 系统控制室门口
- 关键参数显示面板
- 系统流程图上

## 6. 状态变更管理

### 6.1 变更流程

```
状态变更申请 → 变更评估 → 变更批准 → 执行变更 → 更新标识
```

### 6.2 触发状态变更的情况

| 触发条件 | 目标状态 | 处理时限 |
|----------|----------|----------|
| 验证到期 | 验证过期 | 到期前3个月启动再验证 |
| 设备改造 | 验证暂停 | 改造前完成评估 |
| 重大偏差 | 验证暂停 | 偏差发生后2周内 |
| 纠正性维护 | 验证暂停 | 维护前评估 |

### 6.3 状态变更记录

每次状态变更必须记录：
- 变更原因
- 变更内容
- 风险评估
- 批准人
- 变更日期

## 7. 日常检查

### 7.1 验证状态检查频率

| 检查类型 | 频率 | 责任人 |
|----------|------|--------|
| 外观检查 | 每日 | 操作员 |
| 功能检查 | 每周 | 设备员 |
| 状态核查 | 每月 | 设备部 |
| 有效期核查 | 每季度 | QA |

### 7.2 预警机制

| 预警类型 | 预警时间 | 通知对象 |
|----------|----------|----------|
| 即将到期 | 到期前3个月 | 设备部 |
| 即将到期 | 到期前1个月 | 设备部+QA |
| 已过期 | 过期当日 | 设备部+QA+质量负责人 |

## 8. 设备使用前检查

### 8.1 使用前检查清单

设备使用前必须确认：
- [ ] 验证状态标识牌已悬挂
- [ ] 验证在有效期内
- [ ] 清洁状态标识在有效期内
- [ ] 校准标识在有效期内
- [ ] 最近一次运行记录正常

### 8.2 禁止使用情况

以下情况禁止使用设备：
```
✗ 验证已过期
✗ 清洁已过期
✗ 校准已过期
✗ 未完成验证
✗ 处于偏差调查中
```
