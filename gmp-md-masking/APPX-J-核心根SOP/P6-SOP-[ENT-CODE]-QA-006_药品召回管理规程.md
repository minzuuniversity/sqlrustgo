# 药品召回管理规程

## 1. 目的

建立药品召回的启动、分类、实施和验证标准，确保存在安全隐患的药品能够及时召回。

## 2. 范围

适用于公司生产的药品召回管理，包括：
- 一级召回：可能引起严重健康危害
- 二级召回：可能引起暂时健康危害
- 三级召回：一般不会引起健康危害

## 3. 职责

3.1 质量部负责人：召回决策
3.2 销售部：流通渠道管理
3.3 生产部：库存管理
3.4 总经理：召回批准

## 4. 召回分类

| 级别 | 定义 | 时限要求 |
|------|------|----------|
| 一级 | 严重危害或死亡 | 24小时内启动 |
| 二级 | 暂时性危害 | 48小时内启动 |
| 三级 | 一般问题 | 72小时内启动 |

## 5. 召回流程

### 5.1 召回启动
- 评估安全风险
- 确定召回级别
- 编制召回计划

### 5.2 通知
- 通知经销商和医疗机构
- 向监管部门报告
- 准备召回公告

### 5.3 实施
- 收集渠道库存
- 统一回收处理
- 记录召回数量

### 5.4 关闭
- 编制召回报告
- 监管部门确认
- 采取预防措施

## 6. 与投诉的关系

- 严重投诉可能触发召回评估
- 召回记录需反馈给投诉处理
- 两者共享信息管理系统
