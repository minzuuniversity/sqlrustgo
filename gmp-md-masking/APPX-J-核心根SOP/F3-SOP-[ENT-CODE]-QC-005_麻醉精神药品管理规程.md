# 麻醉药品和精神药品管理规程

## 1. 目的

加强麻醉药品和精神药品的监督管理，确保安全合规，防止流弊事件发生。

## 2. 范围

适用于公司生产、经营、使用过程中涉及的：
- 麻醉药品
- 第一类精神药品
- 第二类精神药品
- 罂粟壳

## 3. 定义

### 3.1 麻醉药品

连续使用后易产生身体依赖性，能成瘾癖的药品，如：
- 盐酸吗啡
- 盐酸哌替啶
- 硫酸吗啡缓释片

### 3.2 精神药品

直接作用于中枢神经系统，使之兴奋或抑制的药品，如：
- 苯巴比妥（第一类）
- 地西泮（第二类）

## 4. 储存要求

### 4.1 专用库房

| 要求 | 标准 |
|------|------|
| 安全设施 | 防盗门、监控、报警器 |
| 储存条件 | 控温控湿 |
| 双人双锁 | 必须 |
| 进出记录 | 必须 |

### 4.2 五专管理

| 管理项 | 要求 |
|--------|------|
| 专人负责 | 指定专人管理 |
| 专库储存 | 独立库房 |
| 专柜保管 | 保险柜 |
| 专账登记 | 收支存明细 |
| 专用处方 | 专人开具 |

## 5. 采购管理

### 5.1 资质要求

供应商必须具备：
- 药品生产/经营许可证
- GMP 证书
- 麻醉药品和精神药品生产/经营资质
- 定点批件

### 5.2 采购流程

1. 填写采购申请（注明用途）
2. 质量部审核
3. 公安部门备案
4. 供应商资质审核
5. 签订采购合同

## 6. 验收管理

### 6.1 验收要点

- 双人验收
- 检查封条完整性
- 核对数量、批号
- 填写验收记录
- 当场上锁入库

### 6.2 验收记录

| 内容 | 要求 |
|------|------|
| 批号 | 必须 |
| 数量 | 必须 |
| 有效期 | 必须 |
| 验收人 | 双人签字 |
| 包装完整性 | 必须 |

## 7. 使用管理

### 7.1 领用流程

1. 填写领用申请（注明患者信息）
2. 双人核对
3. 负责人审批
4. 双人发放
5. 记录收支存

### 7.2 处方管理

麻醉药品必须凭：
- 执业医师处方
- 特殊处方权限
- 患者身份证明

## 8. 库存盘点

| 频率 | 内容 | 参与人 |
|------|------|--------|
| 每日 | 数量核对 | 管理员 |
| 每周 | 账实核对 | 管理员+QA |
| 每月 | 全面盘点 | 质量部+财务 |

## 9. 应急处理

### 9.1 流弊事件

发生流弊立即：
1. 启动应急预案
2. 报告公安部门
3. 报告药监部门
4. 企业内部调查

### 9.2 过期/损坏处理

- 填写销毁申请
- 药监部门监督
- 双人销毁
- 记录备案
