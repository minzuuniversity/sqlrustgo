# 纠正与预防措施（CAPA）管理规程

## 1. 目的

建立纠正与预防措施的启动、调查、实施、验证和关闭标准流程，防止偏差重复发生。

## 2. 范围

适用于以下情况引发的CAPA：
- 偏差调查
- 客户投诉
- 内部审计发现
- 监管检查发现
- OOS/OOT结果
- 年度质量回顾

## 3. 定义

3.1 纠正（Corrective）：消除已发现的不合格项
3.2 预防（Preventive）：消除潜在的不合格项
3.3 CAPA：纠正与预防措施的统称

## 4. 职责

| 部门 | 职责 |
|------|------|
| 质量部 | CAPA协调、审核、批准 |
| 发生部门 | 实施CAPA |
| 高层管理 | 重大CAPA批准 |

## 5. CAPA流程

### 5.1 启动
- 填写CAPA启动表
- 确定调查范围和时限

### 5.2 根本原因分析
- 使用鱼骨图、5Why、FMEA等工具
- 明确根本原因

### 5.3 措施制定
- 纠正措施：立即行动
- 预防措施：长期改进

### 5.4 实施与验证
- 执行计划措施
- 验证有效性

### 5.5 关闭
- 编制CAPA报告
- 质量部批准关闭

## 6. 时限要求

| CAPA类型 | 调查完成 | 实施完成 |
|----------|----------|----------|
| 紧急 | 5工作日 | 15工作日 |
| 重大 | 15工作日 | 30工作日 |
| 一般 | 30工作日 | 60工作日 |

## 7. 有效性指标

- 同类偏差发生率降低≥50%
- CAPA按时完成率≥95%
- CAPA验证通过率≥90%
