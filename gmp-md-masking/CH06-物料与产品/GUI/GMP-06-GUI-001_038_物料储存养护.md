# 物料储存养护

**文件编号:** REG-GMP-026
**版本号:** V1.0

## 1. 储存原则

**第165条** 物料应按规定的储存条件储存。

| 原则 | 说明 |
|------|------|
| 分类存放 | 原料/辅料/包材分开放置 |
| 先进先出 | 先入库先出库 |
| 标识清楚 | 名称/批号/效期清晰 |
| 帐物卡相符 | 定期盘点 |

## 2. 温湿度控制

| 物料类型 | 温度 | 湿度 |
|---------|------|------|
| 一般物料 | 10-30°C | 45-75% |
| 易吸潮物料 | ≤25°C | ≤60% |
| 易挥发物料 | ≤25°C | 密封 |
| 低温储存物料 | 2-8°C | - |

## 3. 养护措施

- 定期检查温湿度
- 防虫防鼠
- 防霉防潮
- 防过期
- 定期轮换
- 异常情况及时处理

## 4. 效期管理

- 有效期内使用
- 近效期物料优先使用
- 超过效期不得使用
- 特殊情况需重新检验

## 5. 不合格品管理

- 标识清晰（红色标记）
- 隔离存放
- 不得与合格品混放
- 按规定程序处理
