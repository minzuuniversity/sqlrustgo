# 药用明胶硬胶囊检验标准操作程序

## 1 主题内容

本标准规定了本企业外购药用明胶硬胶囊检验的标准操作程序。

## 2 适用范围

本标准适用于本企业外购药用明胶硬胶囊的检验操作。

## 3 责任者

仓库管理员、生测检验员、QC、质量管理部经理。

## 4 试剂试药

### 4.1 试剂
- 重铬酸钾试液—稀盐酸(4:1)的混合液
- 鞣酸试液
- 钠石灰
- 磷酸
- 碳酸氢钠

### 4.2 仪器与设备
- 高温电阻炉
- 崩解仪
- 平氏黏度计
- 气相色谱

## 5 检验项目

### 5.1 品名
- 中文名：药用明胶硬胶囊（空心胶囊）
- 汉语拼音名：Yaoyongmingjiaoyingjiaonang

### 5.2 药用明胶硬胶囊检查项目与检查水平及合格质量水平应符合下表要求（内控标准）

| 质量类别 | 检查项目 | 检查水平IL | 合格质量水平AQL |
| --- | --- | --- | --- |
| 外观质量 | A类不合格数 | 一般检查水平II | 1.0 |
| 外观质量 | B类不合格数 | 一般检查水平II | 4.0 |

### 5.3 检查项目的取样数(批量大小)的确定及检查结果的判断

### 5.4 外观质量
#### 5.4.1 型号、颜色
- O#（绿色帽，白色体）

#### 5.4.2 规格尺寸（一等品）（单位：mm）
| 规格 | 基本尺寸 | 极限偏差 |
| --- | --- | --- |
| 帽 | 11.1 | ±0.46 |
| 体 | 18.7 | ±0.46 |

#### 5.4.3 性状
- 本品呈圆筒状，是由帽和体两节套合而成的质硬而具有弹性的锁口空囊。囊体、囊帽应光洁，色泽均匀，切口平整，无变形，无异臭，不透明(含二氧化钛)。颜色符合标准对照色(由供应商与本企业共同确认)，同一批及不同批明显色差不允许有。

#### 5.4.4 检查方法
- 将胶囊平放于装有30-40W日光灯的毛玻璃灯检台上，由1.0以上视力者，以30cm的距离进行检查。不允许混有其它品种的空心胶囊，否则判该批不合格。

#### 5.4.5 缺陷等级(见表1、表2)

| A级缺陷 | B级缺陷 |
| --- | --- |
| 砂眼 | 气泡 |
| 切口缺裂 | 黑点 |
| 变形 | 皱纹梅花头 |
| 插劈 | 毛口 |
| 瘦头薄头 | 油污 |

### 5.5 鉴别
#### 5.5.1
- 取本品0.25g，加水50ml，加热使溶化，放冷。取溶液5ml，加重铬酸钾试液—稀盐酸(4:1)的混合液数滴，即生成橙黄色絮状沉淀。

#### 5.5.2
- 取鉴别5.5.1项下剩余的溶液1ml，加水50ml，摇匀，加鞣酸试液数滴，即发生浑浊。

#### 5.5.3
- 取本品约0.3g，置试管中，加钠石灰少许，加热，产生的气体能使湿润的红色石蕊试纸变蓝色。

### 5.6 脆碎度
- 取本品50粒，置表面皿中，移入盛有硝酸镁饱和溶液的干燥器内，置25±1℃恒温24小时，取出，立即分别逐粒放入直立在木板(厚度2cm)上的玻璃管(内径为24mm，长为200mm)内，将圆柱形砝码(材质为聚四氟乙烯、直径为22mm、重20g±1g)在玻离管口处自由落下，视胶囊是否破裂，如有破裂，不得超过15粒。

### 5.7 松紧度
- 取本品10粒，用拇指和食指轻捏胶囊两端，旋转拨开，不得有粘结、变形或破裂，然后装满滑石粉，将帽、体套合，检查是否松紧适中。

### 5.8 崩解时限
- 取本品2片，加适量水使药片充分湿润，置崩解仪中，10分钟内全部崩解。

### 5.9 微生物限度
| 项 目 | 法定标准 | 内控标准 |
| --- | --- | --- |
| 细菌总数 | 不得过1000个/克 | 不得过500个/g |
| 霉菌总数 | 不得过100个/克 | 不得过50个/g |
| 大肠杆菌 | 不得检出 | 不得检出 |
| 活螨 | 不得检出 | 不得检出 |

### 5.10 印字缺陷
| 缺陷 | 主要缺陷 | 次要缺陷 |
| --- | --- | --- |
| 漏印 | 胶囊上无字 | |
| 重印 | 胶囊上重复印字，导致图案的辨认有困难 | |
| 不完整 | 至少有一个字缺少，导致不能确认 | 至少有1/4缺少，但图案仍可辨认 |
| 擦糊 | 图案擦糊严重，导致图案无法辨认 | 擦糊导致图案部分不能辨认 |
| 长度出格（直径不准确） | 从锁合位置判断，有一个字出格，导致图案无法辨认 | 至少1/4字缺少，但不影响图案的辨认 |
| 圆周出格（偏置） | 由于图案偏置，导致至少图案的1/3高度缺印 | 图案高度有缺陷，但仍可辨认 |
| 墨迹 | 胶囊上的墨迹超过2.0mm | 胶囊上的墨迹范围0.5mm到2mm |
| 印字线 | | 在印字的图案上有线穿过，但不影响辨认 |
