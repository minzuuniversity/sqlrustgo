# 物料接收标准操作程序

**文件编号**: SOP-QC-003 | **类别**: 质量控制

---

## 1. 目的

规范物料接收操作，确保接收物料信息准确、符合要求。

## 2. 适用范围

适用于高原彝药厂所有原辅料、包装材料的接收。

## 3. 职责

| 部门 | 职责 |
|------|------|
| 仓储部 | 物料接收操作 |
| 质量控制部 | 物料取样 |
| 质量保证部 | 放行审核 |

## 4. 接收流程

### 4.1 来货核对

| 核对项目 | 内容 |
|----------|------|
| 供应商信息 | 与订单一致 |
| 物料信息 | 名称、规格 |
| 批号数量 | 与单据一致 |
| 包装状态 | 完整无损 |

### 4.2 单据审核

| 单据类型 | 审核内容 |
|----------|----------|
| 送货单 | 数量、价格 |
| 检验报告 | COA/分析报告 |
| 合格证明 | 供应商质检证明 |

### 4.3 初检

| 检查项目 | 内容 |
|----------|------|
| 外观 | 包装完好 |
| 标签 | 清晰完整 |
| 数量 | 与单据一致 |
| 温度 | 符合运输条件 |

### 4.4 办理入库

| 步骤 | 内容 |
|------|------|
| 1 | 系统录入 |
| 2 | 打印标签 |
| 3 | 粘贴标识 |
| 4 | 转入待验区 |

### 4.5 取样

| 步骤 | 内容 |
|------|------|
| 1 | QA下达取样指令 |
| 2 | QC执行取样 |
| 3 | 送检 |
| 4 | 等待检验结果 |

## 5. 异常处理

| 异常 | 处理方式 |
|------|----------|
| 单据不符 | 拒收，通知供应商 |
| 包装破损 | 拒收或上报处理 |
| 温度超标 | 拒收，记录异常 |

## 6. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 物料接收记录 | 5年 | 仓储部 |
| 来货异常记录 | 5年 | 仓储部 |
