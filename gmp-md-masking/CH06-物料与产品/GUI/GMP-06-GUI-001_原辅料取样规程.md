# 原辅料取样规程

**文件编号**: SOP-QC-001 | **类别**: 质量控制

---

## 1. 目的

规范原辅料的取样操作，确保样品的代表性和检验结果的准确性。

## 2. 适用范围

适用于高原彝药厂所有原辅料的取样。

## 3. 职责

| 部门 | 职责 |
|------|------|
| 质量控制部 | 执行取样操作 |
| 质量保证部 | 取样监督 |
| 仓储部 | 配合取样 |

## 4. 取样环境要求

| 要求 | 内容 |
|------|------|
| 环境 | 取样间或洁净区域 |
| 温湿度 | 室温条件，避免潮湿 |
| 清洁 | 取样前清洁取样间 |
| 人员 | 穿戴防护服、手套 |

## 5. 取样工具

| 工具 | 用途 |
|------|------|
| 取样勺/探针 | 固体物料取样 |
| 取样管 | 液体物料取样 |
| 取样瓶/袋 | 样品容器 |
| 标签 | 样品标识 |
| 取样记录表 | 记录文件 |

## 6. 取样流程

### 6.1 取样前准备

| 步骤 | 内容 |
|------|------|
| 1 | 审核取样指令，确认物料信息 |
| 2 | 确认取样点位置 |
| 3 | 准备取样工具和容器 |
| 4 | 清洁取样工具 |
| 5 | 填写取样记录表 |

### 6.2 取样操作

| 步骤 | 操作内容 | 要点 |
|------|----------|------|
| 1 | 确认物料包装完整 | 检查密封 |
| 2 | 清洁物料包装表面 | 70%乙醇擦拭 |
| 3 | 开启包装 | 避免异物落入 |
| 4 | 取样 | 按规定取样量取样 |
| 5 | 封口 | 取样后重新封口 |
| 6 | 标识 | 粘贴取样标签 |

### 6.3 取样后

| 步骤 | 内容 |
|------|------|
| 1 | 样品及时送检 |
| 2 | 剩余物料归位 |
| 3 | 填写取样记录 |
| 4 | 取样工具清洁 |

## 7. 取样量要求

| 检验类型 | 取样量 | 备注 |
|----------|--------|------|
| 全检 | 3倍全检量 | 足够检验+留样 |
| 常规检验 | 按规定量 | 符合检验需求 |
| 留样 | 按规定量 | 不少于1次全检量 |

## 8. 取样注意事项

| 注意事项 | 说明 |
|----------|------|
| 代表性 | 均匀取样 |
| 防止污染 | 避免引入异物 |
| 防止混淆 | 每次取完清理工具 |
| 安全防护 | 佩戴防护用品 |

## 9. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 取样记录 | 5年 | 质量控制部 |
| 样品台账 | 5年 | 质量控制部 |
