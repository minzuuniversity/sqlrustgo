# 物料放行管理规程

**文件编号**: SMP-QC-005 | **类别**: 质量控制

---

## 1. 目的

建立物料放行程序，确保只有符合标准的物料才能投入使用。

## 2. 适用范围

适用于高原彝药厂所有原辅料、包装材料的放行。

## 3. 职责

| 部门 | 职责 |
|------|------|
| 质量控制部 | 物料检验 |
| 质量保证部 | 放行审核 |
| 仓储部 | 物料管理 |

## 4. 放行条件

| 条件 | 要求 |
|------|------|
| 检验合格 | 符合质量标准 |
| 资料完整 | COA、发票等 |
| 包装完整 | 符合储存要求 |
| 供应商批准 | 在批准供应商名单 |

## 5. 放行流程

| 步骤 | 内容 | 执行人 |
|------|------|--------|
| 1 | 物料入库 | 仓储部 |
| 2 | 初审 | 仓库管理员 |
| 3 | 取样检验 | QC |
| 4 | 审核放行 | QA |
| 5 | 标识 | 仓库 |

## 6. 紧急放行

| 要求 | 说明 |
|------|------|
| 条件 | 物料急用且检验合格可能性大 |
| 审批 | 质量负责人批准 |
| 追踪 | 尽快完成检验 |

## 7. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 物料放行记录 | 5年 | 质量保证部 |
| 检验报告 | 5年 | 质量控制部 |
