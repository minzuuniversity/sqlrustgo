# 原料药生产特殊要求

**文件编号:** REG-GMP-027
**版本号:** V1.0

## 1. 原料药GMP要求

中国GMP（2010版）第13章专门规定原料药要求，ICH Q7提供国际指南。

## 2. 关键控制点

| 控制点 | 要求 |
|-------|------|
| 原料控制 | 检验合格才能使用 |
| 生产过程 | 按批准工艺操作 |
| 中间体控制 | 过程检验/监控 |
| 杂质控制 | 符合注册标准 |
| 干燥 | 不超过规定温度 |

## 3. 生产过程控制

- 关键工艺参数（CPP）监控
- 中间体质量标准
- 杂质档案建立
- 批生产记录完整

## 4. 稳定性考察

- 影响因素试验
- 加速试验
- 长期试验
- 留样观察

## 5. 起始物料控制

- 供应商审计
- 质量标准
- 检验放行
- 供应商变更通知
