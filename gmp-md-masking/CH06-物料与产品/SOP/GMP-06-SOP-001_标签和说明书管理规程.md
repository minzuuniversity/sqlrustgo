# 标签和说明书管理规程

**文件编号**: SMP-MAT-001 | **类别**: 物料与产品

---

## 1. 目的

规范标签和说明书的管理，确保产品标签和说明书内容准确、合规。

## 2. 适用范围

适用于高原彝药厂所有药品标签和说明书的管理。

## 3. 职责

| 部门 | 职责 |
|------|------|
| 注册部 | 标签说明书内容审核 |
| 质量保证部 | 监督管理 |
| 采购部 | 印刷采购 |
| 生产部 | 使用管理 |

## 4. 标签内容要求

| 内容 | 要求 |
|------|------|
| 药品名称 | 通用名、商品名 |
| 批准文号 | 国药准字 |
| 规格 | 剂型、装量 |
| 批号 | 生产批号 |
| 有效期 | 至日期 |
| 生产企业 | 名称地址 |
| 储存条件 | 温度等 |
| 适应症 | 或功能主治 |
| 用法用量 | 按说明书 |

## 5. 标签管理

| 要求 | 内容 |
|------|------|
| 审核 | 注册部审核内容 |
| 批准 | 质量负责人批准 |
| 版本控制 | 不同版本区分 |
| 库存管理 | 分类存放 |
| 销毁 | 过期或废弃标签销毁 |

## 6. 使用管理

| 要求 | 内容 |
|------|------|
| 领取 | 按批号领取 |
| 使用核对 | 使用前核对 |
| 数量平衡 | 记录使用数量 |
| 废弃处理 | 废弃标签销毁 |

## 7. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 标签发放记录 | 5年 | 生产部 |
| 标签销毁记录 | 5年 | 质量保证部 |
