# 退货产品处理规程

**文件编号**: SMP-MAT-002 | **类别**: 物料与产品

---

## 1. 目的

规范退货产品的处理，确保退货产品得到适当管理。

## 2. 适用范围

适用于高原彝药厂所有退货产品的处理。

## 3. 职责

| 部门 | 职责 |
|------|------|
| 质量保证部 | 退货审核和处理决定 |
| 销售部 | 退货接收和客户沟通 |
| 仓储部 | 退货产品的储存 |

## 4. 退货接收

| 步骤 | 内容 |
|------|------|
| 1 | 客户提交退货申请 |
| 2 | 销售部审核退货原因 |
| 3 | 质促保部审核退货申请 |
| 4 | 批准后退货接收 |

## 5. 退货评估

| 评估项目 | 内容 |
|----------|------|
| 产品信息 | 批号、有效期 |
| 退货原因 | 客户描述的原因 |
| 储存运输 | 是否合规 |
| 包装完整性 | 是否完好 |

## 6. 退货处理决定

| 决定 | 条件 |
|------|------|
| 重新销售 | 符合储存条件、包装完整 |
| 降级使用 | 评估后可用 |
| 销毁 | 不可用 |

## 7. 退货处理流程

| 步骤 | 内容 |
|------|------|
| 1 | 退货接收并检查 |
| 2 | 转入退货区 |
| 3 | 质量评估 |
| 4 | 做出处理决定 |
| 5 | 实施处理 |
| 6 | 记录处理结果 |

## 8. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 退货记录 | 5年 | 销售部 |
| 退货处理记录 | 5年 | 质量保证部 |
