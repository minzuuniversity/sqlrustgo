# 进入受限空间作业安全管理规程

**文件编号**: SMP-SEC-006 | **类别**: 安全与卫生

---

## 1. 目的

规范受限空间作业管理，确保作业安全。

## 2. 适用范围

适用于高原彝药厂所有受限空间作业。

## 3. 受限空间定义

| 定义 | 示例 |
|------|------|
| 封闭空间 | 罐、槽、塔 |
| 半封闭空间 | 沟、池、井 |
| 缺氧空间 | 可能缺氧的场所 |

## 4. 作业许可

| 要求 | 内容 |
|------|------|
| 申请 | 作业前申请 |
| 审批 | 安全部门审批 |
| 条件确认 | 各项条件合格 |
| 监护 | 专人监护 |

## 5. 作业前准备

| 准备 | 内容 |
|------|------|
| 隔离 | 隔离能源 |
| 清理 | 清理物料 |
| 通风 | 强制通风 |
| 检测 | 气体检测 |

## 6. 气体检测

| 项目 | 标准 |
|------|------|
| 氧含量 | 18-23% |
| 可燃气体 | <10%LEL |
| 有毒气体 | <TLV |

## 7. 应急准备

| 要求 | 内容 |
|------|------|
| 救援人员 | 现场待命 |
| 救援设备 | 救援绳、呼吸器 |
| 通信 | 保持通信畅通 |
| 演练 | 定期演练 |

## 8. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 受限空间作业许可 | 5年 | 安全部门 |
| 气体检测记录 | 5年 | 安全部门 |
