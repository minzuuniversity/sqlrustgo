# 实验室安全规范

**文件编号**: SMP-SEC-001 | **类别**: 安全与卫生

---

## 1. 目的

建立实验室安全规范，确保实验室操作安全，防止事故发生。

## 2. 适用范围

适用于高原彝药厂质量控制实验室。

## 3. 基本安全要求

| 要求 | 内容 |
|------|------|
| 个人防护 | 实验服、手套、护目镜 |
| 禁止饮食 | 实验室禁止饮食 |
| 禁止吸烟 | 实验室内禁止吸烟 |
| 熟悉急救 | 了解急救设施位置 |

## 4. 化学试剂安全

| 要求 | 内容 |
|------|------|
| 标签完整 | 试剂瓶标签清晰 |
| MSDS | 危险试剂有MSDS |
| 储存 | 按类别储存 |
| 废液处理 | 分类收集处理 |

## 5. 玻璃器皿安全

| 要求 | 内容 |
|------|------|
| 检查 | 使用前检查破损 |
| 使用 | 正确方法使用 |
| 清洗 | 使用后及时清洗 |
| 废弃 | 破碎玻璃专门处理 |

## 6. 电气安全

| 要求 | 内容 |
|------|------|
| 检查 | 使用前检查电线 |
| 防水 | 远离水源 |
| 过载 | 不超负荷使用 |
| 异常 | 发现异常立即断电 |

## 7. 消防常识

| 类别 | 灭火器类型 |
|------|------------|
| 一般火灾 | ABC干粉 |
| 电气火灾 | CO2干粉 |
| 溶剂火灾 | 泡沫 |

## 8. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 安全检查记录 | 5年 | 质量控制部 |
| 事故报告 | 5年 | 质量保证部 |
