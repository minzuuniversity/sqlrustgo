# 应急响应和事故报告规程

**文件编号**: SMP-SEC-004 | **类别**: 安全与卫生

---

## 1. 目的

建立应急响应和事故报告程序，确保突发事件得到及时有效处理。

## 2. 适用范围

适用于高原彝药厂所有安全事故和突发事件。

## 3. 应急响应分级

| 级别 | 定义 | 响应范围 |
|------|------|----------|
| 一级 | 重大事故 | 全厂响应 |
| 二级 | 较大事故 | 部门响应 |
| 三级 | 一般事故 | 班组响应 |

## 4. 应急响应流程

| 步骤 | 内容 |
|------|------|
| 1 | 发现事故/险情 |
| 2 | 立即报告 |
| 3 | 启动响应 |
| 4 | 现场处置 |
| 5 | 人员救护 |
| 6 | 警戒疏散 |
| 7 | 事后处理 |

## 5. 事故报告

| 报告类型 | 报告时限 |
|----------|----------|
| 立即报告 | 发现后立即 |
| 书面报告 | 24小时内 |
| 详细报告 | 7个工作日内 |

## 6. 事故调查

| 步骤 | 内容 |
|------|------|
| 1 | 保护现场 |
| 2 | 收集证据 |
| 3 | 分析原因 |
| 4 | 制定措施 |
| 5 | 编写报告 |

## 7. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 事故报告 | 10年 | 安全部门 |
| 事故调查报告 | 10年 | 安全部门 |
| 应急演练记录 | 5年 | 安全部门 |
