# 印刷包装材料管理

**文件编号**: SMP-MAT-012 | **类别**: 物料管理

---

## 1. 目的

规范印刷包装材料管理，防止差错。

## 2. 适用范围

适用于高原彝药厂印刷包装材料管理。

## 3. 印刷材料分类

| 类别 | 示例 |
|------|------|
| 标签 | 产品标签、说明文字 |
| 说明书 | 包装说明书 |
| 合格证 | 合格证明 |
| 铝箔 | 批号印刷材料 |

## 4. 管理要求

| 要求 | 内容 |
|------|------|
| 审批 | 文字内容经批准 |
| 验收 | 数量核对 |
| 储存 | 锁闭区域 |
| 销毁 | 过期材料销毁 |

## 5. 放行要求

| 项目 | 要求 |
|------|------|
| 物料检验 | 符合标准 |
| 文字核对 | 与批准一致 |
| 数量确认 | 与需求一致 |
