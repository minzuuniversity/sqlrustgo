# 原料药管理要求

**文件编号**: SMP-MAT-011 | **类别**: 物料管理

---

## 1. 目的

规范原料药管理，确保质量可控。

## 2. 适用范围

适用于高原彝药厂原料药管理。

## 3. 采购要求

| 要求 | 内容 |
|------|------|
| 供应商 | 批准供应商 |
| 资质 | GMP证书、注册批件 |
| 检验 | 全项检验 |

## 4. 储存要求

| 条件 | 要求 |
|------|------|
| 温度 | 2-8℃或常温 |
| 湿度 | 45-75% |
| 包装 | 原始包装 |
| 标识 | 物料卡完整 |

## 5. 发放要求

| 要求 | 内容 |
|------|------|
| 追溯 | 批号可追溯 |
| 先进先出 | FEFO原则 |
| 复核 | 双人复核 |

## 6. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 原料药台账 | 5年 | 仓库 |
