# 包装材料质量标准

**文件编号**: TS-MAT-003 | **类别**: 物料与产品

---

## 1. 目的

建立包装材料的质量标准，确保包装材料质量符合要求。

## 2. 适用范围

适用于高原彝药厂所有使用的包装材料。

## 3. 包装材料分类

| 类型 | 示例 |
|------|------|
| 直接接触材料 | 铝箔、PVC、PVDC |
| 内包装 | 瓶子、盖子、塞子 |
| 外包装 | 盒子、标签、说明书 |

## 4. 质量标准内容

| 项目 | 内容 |
|------|------|
| 材质 | 材料名称、规格 |
| 尺寸 | 长宽厚等 |
| 外观 | 颜色、印刷 |
| 性能 | 阻隔性、密封性 |
| 检验项目 | 外观、尺寸、性能 |

## 5. 检验项目

| 项目 | 要求 |
|------|------|
| 外观 | 无缺陷、印刷清晰 |
| 尺寸 | 符合规格 |
| 物理性能 | 拉伸强度、阻隔性 |
| 化学性能 | 迁移试验 |
| 微生物 | 符合规定 |

## 6. 批准与修订

| 要求 | 说明 |
|------|------|
| 批准 | 质量负责人批准 |
| 修订 | 定期审查 |

## 7. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 质量标准 | 永久 | 质量保证部 |
| 来料检验记录 | 5年 | 质量控制部 |
