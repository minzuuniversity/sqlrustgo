# 原辅料质量标准

**文件编号**: TS-MAT-001 | **类别**: 物料与产品

---

## 1. 目的

建立原辅料的质量标准，确保原辅料质量符合生产要求。

## 2. 适用范围

适用于高原彝药厂所有使用的原辅料。

## 3. 质量标准内容

| 项目 | 内容 |
|------|------|
| 名称 | 中文名、英文名 |
| 来源 | 法定来源 |
| 分子式/结构 | 化学物质 |
| CAS号 | 化学物质登记号 |
| 规格 | 含量、纯度等 |
| 检验项目 | 性状、鉴别、含量等 |
| 检验方法 | 依据药典或内部方法 |
| 储存条件 | 温度、湿度、光照 |
| 复验期 | 定期复验 |

## 4. 检验项目

### 4.1 性状

| 项目 | 要求 |
|------|------|
| 外观 | 颜色、形态 |
| 溶解度 | 溶解性 |
| 熔点/沸点 | 物理常数 |

### 4.2 鉴别

| 方法 | 要求 |
|------|------|
| 化学鉴别 | 特征反应 |
| UV鉴别 | 吸收特征 |
| IR鉴别 | 红外光谱 |
| HPLC保留时间 | 保留时间一致 |

### 4.3 检查

| 项目 | 要求 |
|------|------|
| 酸碱度 | 符合规定 |
| 水分 | 符合规定 |
| 炽灼残渣 | 符合规定 |
| 重金属 | 符合规定 |
| 有关物质 | 符合规定 |

### 4.4 含量测定

| 方法 | 要求 |
|------|------|
| 滴定法 | 含量≥98.0% |
| HPLC法 | 面积归一化法 |
| 其他 | 按注册标准 |

## 5. 批准与修订

| 要求 | 说明 |
|------|------|
| 批准 | 质量负责人批准 |
| 修订 | 定期审查修订 |
| 追溯 | 修订历史记录 |

## 6. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 质量标准 | 永久 | 质量保证部 |
| 修订记录 | 永久 | 质量保证部 |
