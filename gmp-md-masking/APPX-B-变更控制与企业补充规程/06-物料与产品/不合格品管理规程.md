# 不合格品管理规程

**文件编号**: SMP-MAT-003 | **类别**: 物料与产品

---

## 1. 目的

规范不合格品的管理，防止不合格品流出或误用。

## 2. 适用范围

适用于高原彝药厂所有不合格的物料、半成品和成品。

## 3. 职责

| 部门 | 职责 |
|------|------|
| 质量保证部 | 不合格品判定和监督 |
| 各相关部门 | 不合格品处理 |
| 仓储部 | 不合格品隔离存放 |

## 4. 不合格品标识

| 要求 | 内容 |
|------|------|
| 标识 | 红色"不合格"标识 |
| 隔离 | 转入不合格品区 |
| 记录 | 填写不合格品记录 |

## 5. 不合格品处理方式

| 方式 | 适用情况 |
|------|----------|
| 拒绝入库 | 接收时发现不合格 |
| 退货 | 供应商原因 |
| 降级使用 | 评估后可用 |
| 返工 | 重新加工 |
| 销毁 | 不可用 |

## 6. 处理流程

| 步骤 | 内容 |
|------|------|
| 1 | 发现不合格品 |
| 2 | 标识隔离 |
| 3 | 报告QA |
| 4 | 调查评估 |
| 5 | 决定处理方式 |
| 6 | 实施处理 |
| 7 | 记录处理结果 |

## 7. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 不合格品记录 | 10年 | 质量保证部 |
| 处理记录 | 10年 | 质量保证部 |
