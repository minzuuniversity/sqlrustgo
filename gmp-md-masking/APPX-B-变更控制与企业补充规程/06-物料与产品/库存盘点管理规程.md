# 库存盘点管理规程

**文件编号**: SMP-MAT-005 | **类别**: 物料与产品

---

## 1. 目的

规范库存盘点管理，确保库存物料和产品账物相符。

## 2. 适用范围

适用于高原彝药厂所有物料和成品的库存盘点。

## 3. 职责

| 部门 | 职责 |
|------|------|
| 仓储部 | 执行盘点 |
| 质量保证部 | 盘点监督 |
| 财务部 | 账务核对 |

## 4. 盘点类型

| 类型 | 频率 | 内容 |
|------|------|------|
| 月度盘点 | 每月末 | 抽查 |
| 季度盘点 | 每季度 | 全面盘点 |
| 年度盘点 | 每年末 | 全面盘点 |
| 不定期 | 按需 | 针对性盘点 |

## 5. 盘点流程

| 步骤 | 内容 |
|------|------|
| 1 | 制定盘点计划 |
| 2 | 提前通知 |
| 3 | 冻结库存 |
| 4 | 实地盘点 |
| 5 | 记录数据 |
| 6 | 核对账务 |
| 7 | 差异分析 |

## 6. 盘点要求

| 要求 | 内容 |
|------|------|
| 准确性 | 逐件盘点 |
| 及时性 | 按计划完成 |
| 记录完整 | 填写盘点表 |

## 7. 差异处理

| 差异类型 | 处理方式 |
|----------|----------|
| 物料 | 查明原因，报批 |
| 产品 | 查明原因，报批 |
| 正常损耗 | 按规定报批 |

## 8. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 盘点表 | 5年 | 仓储部 |
| 差异报告 | 5年 | 质量保证部 |
