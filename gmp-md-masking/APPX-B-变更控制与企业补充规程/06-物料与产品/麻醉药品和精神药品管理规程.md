# 麻醉药品和精神药品管理规程

**文件编号**: SMP-MAT-006 | **类别**: 物料与产品

---

## 1. 目的

规范麻醉药品和精神药品的管理，确保安全、合规。

## 2. 适用范围

适用于高原彝药厂所有麻醉药品和精神药品。

## 3. 法规依据

| 法规 | 说明 |
|------|------|
| 《药品管理法》 | 药品管理基本法 |
| 《麻醉药品和精神药品管理条例》 | 专项管理条例 |

## 4. 管理要求

| 要求 | 内容 |
|------|------|
| 专库储存 | 双人双锁 |
| 专人管理 | 指定专人 |
| 专用账册 | 专门记录 |
| 审批购用 | 按计划购用 |

## 5. 安全管理

| 要求 | 内容 |
|------|------|
| 安防设施 | 监控、报警 |
| 出入库 | 双人核对 |
| 盘点 | 定期盘点 |
| 报损 | 按规定报批 |

## 6. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 专库进出记录 | 3年 | 仓储部 |
| 专用账册 | 5年 | 仓储部 |
