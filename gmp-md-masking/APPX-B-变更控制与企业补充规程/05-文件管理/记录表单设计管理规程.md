# 记录表单设计管理规程

**文件编号**: SMP-DOC-007 | **类别**: 文件与记录管理

---

## 1. 目的

规范GMP记录表单的设计，确保表单设计合理、信息完整、便于填写和追溯。

## 2. 适用范围

适用于高原彝药厂所有GMP记录表单的设计和管理。

## 3. 职责

| 部门 | 职责 |
|------|------|
| 表单使用部门 | 提出表单设计需求 |
| 质量保证部 | 表单设计的审核和批准 |
| IT部门 | 电子表单系统支持 |

## 4. 表单设计原则

| 原则 | 说明 |
|------|------|
| 必要性 | 确有记录需要才设计 |
| 最小信息量 | 收集必要信息，避免冗余 |
| 便于填写 | 格式清晰，填写简便 |
| 便于追溯 | 关键信息可追溯 |
| 便于统计 | 支持数据汇总分析 |

## 5. 表单基本要素

| 要素 | 内容 | 位置 |
|------|------|------|
| 表单标题 | 表单名称 | 顶部 |
| 表单编号 | 唯一标识 | 右上角 |
| 版本号 | 当前版本 | 右上角 |
| 填写日期 | 填写日期 | 标题下方或右下角 |
| 基本信息区 | 产品/批次/设备等 | 填写区上方 |
| 填写区 | 具体记录内容 | 主体部分 |
| 签名区 | 审核/批准签名 | 底部 |
| 备注区 | 补充说明 | 底部或侧面 |

## 6. 表单设计流程

| 步骤 | 内容 | 执行人 |
|------|------|--------|
| 需求提出 | 填写表单设计申请表 | 使用部门 |
| 初步设计 | 设计表单格式和内容 | 使用部门 |
| QA审核 | 审核表单合理性 | 质量保证部 |
| 批准 | 批准表单设计 | 质量保证部 |
| 编号 | 分配表单编号 | 质量保证部 |
| 试用 | 小范围试用 | 使用部门 |
| 正式启用 | 全面推行 | 使用部门 |

## 7. 表单格式要求

| 要求 | 内容 |
|------|------|
| 纸张大小 | A4或适当规格 |
| 字体字号 | 标题黑体五号，正文宋体五号 |
| 边框 | 表格线清晰 |
| 颜色 | 建议使用黑白打印 |
| 电子表单 | 权限控制，防篡改 |

## 8. 表单更改控制

| 要求 | 内容 |
|------|------|
| 更改申请 | 填写表单更改申请表 |
| 更改审核 | QA审核更改必要性 |
| 版本更新 | 更改后更新版本号 |
| 旧版回收 | 回收旧版表单 |

## 9. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 表单设计申请表 | 5年 | 质量保证部 |
| 表单更改申请表 | 5年 | 质量保证部 |
| 表单版本记录 | 5年 | 质量保证部 |
