# 文件分发与回收管理规程

**文件编号**: SMP-DOC-004 | **类别**: 文件与记录管理

---

## 1. 目的

规范GMP文件的分发和回收管理，确保受控文件有效版本在使用现场的可获得性。

## 2. 适用范围

适用于高原彝药厂所有GMP受控文件的管理。

## 3. 职责

| 部门 | 职责 |
|------|------|
| 质量保证部 | 文件的集中管理和分发 |
| 各使用部门 | 文件的接收、使用和回收 |

## 4. 文件分类

| 分类 | 定义 | 管理要求 |
|------|------|----------|
| 受控文件 | 纳入文件系统管理的文件 | 盖受控章、编号、登记 |
| 非受控文件 | 参考性文件 | 无受控标识 |
| 作废文件 | 已失效的文件 | 隔离保存或销毁 |

## 5. 文件分发流程

| 步骤 | 内容 | 负责部门 |
|------|------|----------|
| 需求申请 | 部门提出文件需求 | 使用部门 |
| 审核批准 | QA确认需求合理性 | 质量保证部 |
| 文件复制 | 按需求数量复制 | 质量保证部 |
| 编号登记 | 填写分发记录 | 质量保证部 |
| 发放签收 | 发放并签收 | 质量保证部/使用部门 |

## 6. 文件分发原则

| 原则 | 说明 |
|------|------|
| 数量控制 | 数量满足使用需要，避免过多 |
| 版本确认 | 确保发放最新有效版本 |
| 场所覆盖 | 所有使用场所均需覆盖 |
| 变更同步 | 变更时同步更新所有分发点 |

## 7. 文件回收流程

| 步骤 | 内容 |
|------|------|
| 版本更新通知 | 发放新版本时通知旧版本回收 |
| 旧版本回收 | 收回旧版本文件 |
| 标识处理 | 盖"作废"章或销毁 |
| 记录登记 | 填写文件回收记录 |

## 8. 作废文件处理

| 处理方式 | 适用情况 |
|----------|----------|
| 销毁 | 无保存价值 |
| 隔离保存 | 法规要求保存期限 |
| 保留参考 | 有参考价值 |

## 9. 文件使用现场管理

| 要求 | 内容 |
|------|------|
| 便于获取 | 放置在使用场所便于查阅 |
| 防止损坏 | 避免污染、损坏、丢失 |
| 版本确认 | 使用前确认版本有效性 |
| 及时更新 | 变更时及时替换 |

## 10. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 文件发放记录 | 5年 | 质量保证部 |
| 文件回收记录 | 5年 | 质量保证部 |
| 作废文件处理记录 | 5年 | 质量保证部 |
