# 文件编号规则

**文件编号**: SMP-DOC-002 | **类别**: 文件与记录管理

---

## 1. 目的

建立统一的文件编号规则，确保所有GMP文件编号唯一、可追溯、便于管理。

## 5. 文件编号格式

### 5.1 SOP编号格式

```
SOP-{部门代码}-{序号}
示例：SOP-QC-001 表示质量控制部第1号SOP
```

### 5.2 SMP编号格式

```
SMP-{专业代码}-{序号}
示例：SMP-QMS-001 表示质量管理体系第1号管理规程
```

### 5.3 验证文件编号格式

```
VP-{系统代码}-{类型代码}-{序号}
示例：VP-HVAC-IQ-001 表示HVAC系统安装确认第1号
```

### 5.4 记录表单编号格式

```
FOR-{部门代码}-{序号}
示例：FOR-QC-001 表示质量控制部第1号表单
```

## 6. 编号使用原则

| 原则 | 说明 |
|------|------|
| 唯一性 | 每份文件有唯一编号 |
| 永久性 | 编号不可重复使用 |
| 可追溯性 | 编号体现文件类别 |
| 连续性 | 序号连续，不跳号 |
