# 电子记录管理规程

**文件编号**: SMP-DOC-008 | **类别**: 文件与记录管理

---

## 1. 目的

规范电子记录的管理，确保电子记录的真实性、完整性、可靠性和可追溯性。

## 2. 适用范围

适用于高原彝药厂所有以电子形式存在的GMP记录。

## 3. 职责

| 部门 | 职责 |
|------|------|
| IT部门 | 电子记录系统维护和数据安全 |
| 质量保证部 | 电子记录质量监督 |
| 使用部门 | 电子记录的填写和保管 |

## 4. 电子记录系统要求

### 4.1 系统功能要求

| 功能 | 要求 |
|------|------|
| 数据输入 | 真实、及时记录 |
| 数据存储 | 防止篡改、永久保存 |
| 权限控制 | 分级授权 |
| 审计追踪 | 记录所有操作 |
| 电子签名 | 合法的电子签名 |

### 4.2 数据完整性要求（ALCOA+）

| 原则 | 说明 |
|------|------|
| Attributable | 可归属到操作者 |
| Legible | 清晰可读 |
| Contemporaneous | 同步记录 |
| Original | 原始记录 |
| Accurate | 准确 |
| Complete | 完整 |
| Consistent | 一致 |
| Enduring | 持久 |
| Available | 可获取 |

## 5. 电子签名管理

| 要求 | 内容 |
|------|------|
| 唯一性 | 电子签名与操作者一一对应 |
| 可追溯 | 电子签名可追溯到签名人 |
| 法律效力 | 符合《电子签名法》要求 |
| 防止盗用 | 密码+生物识别等安全措施 |

## 6. 数据备份与恢复

| 要求 | 频率 | 执行部门 |
|------|------|----------|
| 本地备份 | 每日 | IT部门 |
| 异地备份 | 每周 | IT部门 |
| 备份验证 | 每月 | IT部门 |
| 灾难恢复测试 | 每半年 | IT部门 |

## 7. 数据安全

| 安全措施 | 内容 |
|----------|------|
| 访问控制 | 按岗位授权 |
| 防火墙 | 防止外部攻击 |
| 杀毒软件 | 防止病毒 |
| 加密 | 敏感数据加密存储 |
| 审计日志 | 记录所有访问和操作 |

## 8. 数据生命周期

| 阶段 | 管理要求 |
|------|----------|
| 创建 | 规定创建权限和流程 |
| 使用 | 受控访问和使用 |
| 传输 | 安全传输，加密传输 |
| 归档 | 长期保存，格式不丢失 |
| 销毁 | 规定程序，不可恢复 |

## 9. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 电子记录台账 | 10年 | 质量保证部 |
| 数据备份记录 | 5年 | IT部门 |
| 审计追踪记录 | 10年 | 质量保证部 |
| 电子签名授权记录 | 10年 | 质量保证部 |
