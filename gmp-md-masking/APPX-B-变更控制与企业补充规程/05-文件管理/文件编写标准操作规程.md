# 文件编写标准操作规程

**文件编号**: SMP-DOC-001 | **类别**: 文件与记录管理

---

## 1. 目的

规范GMP文件的编写格式和审核批准流程，确保文件系统完整、规范、有效。

## 2. 适用范围

适用于高原彝药厂所有GMP文件的编写和管理。

## 3. 职责

| 部门 | 职责 |
|------|------|
| 文件起草部门 | 负责文件的起草 |
| 文件审核部门 | 负责文件的审核 |
| 文件批准部门 | 负责文件的批准 |
| 质量保证部 | 文件的发放、收回、归档管理 |

## 4. 文件编码规则

### 4.1 文件编码结构

| 编码段 | 含义 | 示例 |
|--------|------|------|
| 第一段 | 文件类型代码 | SOP、SMP、TS、F等 |
| 第二段 | 部门/专业代码 | QC、QA、PROD、FAC等 |
| 第三段 | 序号 | 001、002等 |
| 第四段 | 版本号 | A、B、C等 |

### 4.2 部门代码

| 代码 | 部门 | 代码 | 部门 |
|------|------|------|------|
| QA | 质量保证 | PROD | 生产部 |
| QC | 质量控制 | FAC | 工程设备 |
| REG | 注册部 | WH | 仓储物流 |
| IT | 信息技术 | HR | 人力资源 |
| PUR | 采购部 | SAL | 销售部 |

## 5. 文件编写要求

### 5.1 文件标题

- 简洁明了，准确反映文件内容
- 使用规范性用语
- 避免模糊表述

### 5.2 文件结构

| 章节 | 内容 | 适用文件类型 |
|------|------|--------------|
| 目的 | 说明文件目的 | 所有文件 |
| 范围 | 适用范围 | 所有文件 |
| 职责 | 相关部门职责 | 管理规程 |
| 定义 | 术语定义 | 需要时 |
| 正文内容 | 具体操作/要求 | 所有文件 |
| 附录 | 表格、清单等 | 需要时 |

### 5.3 文件格式

| 要素 | 要求 |
|------|------|
| 字体 | 宋体/黑体 |
| 字号 | 标题小二，正文五号 |
| 行距 | 1.5倍 |
| 页边距 | 上下2.54cm，左右3cm |
| 页码 | 页面底端居中 |

## 6. 文件审核批准流程

| 步骤 | 执行人 | 时间节点 |
|------|--------|----------|
| 起草 | 相关部门 | 根据计划 |
| 部门审核 | 部门负责人 | 3个工作日 |
| QA审核 | 质量保证部 | 3个工作日 |
| 相关部门会签 | 相关部门 | 2个工作日 |
| 批准 | 质量负责人/总经理 | 2个工作日 |
| 生效日期确定 | 质量保证部 | 批准时确定 |

## 7. 文件版本控制

| 版本 | 表示方法 | 使用场景 |
|------|----------|----------|
| 初始版本 | A | 新文件发布 |
| 修订版 | B、C... | 内容变更 |
| 临时版本 | R1、R2... | 紧急修订 |

## 8. 文件分发与回收

| 要素 | 要求 |
|------|------|
| 受控文件 | 盖"受控文件"章，登记发放 |
| 非受控文件 | 无受控标识，不可正式使用 |
| 版本更新 | 收回旧版，发放新版 |
| 作废文件 | 盖"作废"章，隔离保存 |

## 9. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 文件编制申请表 | 5年 | 质量保证部 |
| 文件发放记录 | 5年 | 质量保证部 |
| 文件回收记录 | 5年 | 质量保证部 |
