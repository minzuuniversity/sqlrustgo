# 防混淆管理规程

**文件编号**: SP-PROD-018

**生效日期**: 2026-01-01
**审核人**: __________

## 1. 目的

建立防止药品生产过程中混淆和差错的管理措施，确保不同品种、规格、批号的物料和产品不发生混淆，保证药品质量可追溯，符合《药品生产质量管理规范（2010年修订）》第一百二十三条要求。

---

## 2. 范围

适用于公司所有药品生产活动，包括：
- 物料储存与发放
- 生产前准备
- 生产过程
- 成品入库
- 包装与贴签
- 物料退库

---

## 3. 职责

| 部门/岗位 | 职责 |
|-----------|------|
| 质量保证部 | 负责防混淆措施的制定、监督检查 |
| 生产部 | 负责执行防混淆操作 |
| 仓储部 | 负责物料储存防混淆 |
| 质量控制部 | 负责产品放行前核对 |

---

## 4. 定义

### 4.1 混淆
指两种或两种以上品种、规格、批号的物料或产品相互混杂，导致无法区分的情况。

### 4.2 差错
指生产过程中由于人为失误导致的质量问题。

### 4.3 标识
用于识别物料、产品、区域的标记。

---

## 5. 防止混淆的基本原则

| 原则 | 说明 |
|------|------|
| 隔离存放 | 不同品种、规格、批号的产品/物料分区存放 |
| 标识清晰 | 所有物料、产品、容器、设备有明确标识 |
| 物理隔离 | 采用专区、专用容器、隔离栏等物理隔离 |
| 流程控制 | 严格按照生产流程操作 |
| 复核制度 | 关键操作双人复核 |
| 可追溯 | 物料、产品全程可追溯 |

---

## 6. 区域隔离管理

### 6.1 生产区域隔离

| 区域类型 | 隔离要求 |
|----------|----------|
| 不同品种生产区 | 必须专区生产，必要时专区专用设备 |
| 不同规格生产区 | 分时段生产或专区生产 |
| 同一品种不同批号 | 分批生产，批间清场 |
| 高致敏性产品 | 专区生产，独立空气系统 |

### 6.2 仓储区域隔离

| 物料类型 | 隔离要求 |
|----------|----------|
| 待验物料 | 待验区，黄色标识 |
| 合格物料 | 合格区，绿色标识 |
| 不合格物料 | 不合格区，红色标识，隔离上锁 |
| 退货产品 | 退货区，隔离存放 |
| 召回产品 | 召回区，隔离存放 |
| 印刷包装材料 | 专区存放，限制进入 |

### 6.3 设备隔离

| 设备类型 | 隔离要求 |
|----------|----------|
| 专用设备 | 单一品种/规格专用 |
| 共用设备 | 清洁验证后方可用于不同品种 |
| 精密仪器 | 专人操作，定期校准 |

## 8. 生产过程防混淆

### 8.1 生产前准备

| 步骤 | 操作 | 防混淆措施 |
|------|------|----------|
| 1 | 确认生产指令 | 核对产品名称、规格、批号、数量 |
| 2 | 领料 | 按批领料，逐件核对物料信息 |
| 3 | 核对物料 | 确认物料与生产指令一致 |
| 4 | 设备检查 | 确认设备已清洁且在有效期内 |
| 5 | 环境检查 | 确认清场合格 |
| 6 | 物料标识 | 粘贴物料标识 |

### 8.2 生产过程控制

| 控制点 | 操作 | 防混淆措施 |
|--------|------|----------|
| 称量 | 逐个称量 | 每称完一个品种后清场再称下一个 |
| 投料 | 逐个投料 | 核对品名、批号后投料 |
| 转料 | 标识清楚 | 容器标识清晰，防止混淆 |
| 换批 | 清场彻底 | 更换批号时彻底清场 |
| 换规格 | 专区操作 | 不同规格分专区或分时段生产 |

### 8.3 关键操作复核

| 关键操作 | 复核要求 |
|----------|----------|
| 领料 | 双人核对 |
| 称量 | 双人核对原始数据 |
| 投料 | 双人核对后投料 |
| 关键参数调整 | 双人确认 |
| 成品入库 | 双人核对 |

### 8.4 包装过程控制

| 控制点 | 操作 | 防混淆措施 |
|--------|------|----------|
| 包装指令 | 核对产品名称、规格、批号、数量 | |
| 印刷包装材料 | 逐件核对品名、批准文号、内容 | |
| 说明书 | 核对版本、内容、数量 | |
| 标签 | 核对批号、有效期、内容 | |
| 换版 | 彻底清理旧版本物料 | |
| 换规格 | 专区操作或分时段 | |

## 9. 仓储防混淆

### 9.1 入库管理

| 步骤 | 操作 | 防混淆措施 |
|------|------|----------|
| 入库前 | 确认检验合格 | 检查放行证 |
| 入库时 | 核对物料信息 | 确认品名、批号、数量 |
| 入库后 | 正确存放 | 按区域存放 |
| 记录 | 及时登记台账 | 准确记录 |

### 9.2 发放管理

| 步骤 | 操作 | 防混淆措施 |
|------|------|----------|
| 发放指令 | 核对领料单 | 确认品名、批号、数量 |
| 备料 | 逐件核对 | 确认物料信息 |
| 发放 | 再次核对 | 交接双方确认 |

### 9.3 退库管理

| 步骤 | 操作 | 防混淆措施 |
|------|------|----------|
| 退库申请 | 说明退库原因 | 填写退库单 |
| 退库前检验 | 必要时复检 | 按规定复检 |
| 退库标识 | 粘贴退库标识 | 注明原批号 |
| 存放 | 专区存放 | 退库物料专区 |

## 10. 清场管理

### 10.1 清场要求

| 清场类型 | 要求 |
|----------|------|
| 换品种清场 | 清除所有物料、产品、文件 |
| 换批清场 | 清除本批物料、产品、文件 |
| 换规格清场 | 清除所有相关物料、产品 |

### 10.2 清场检查清单

| 检查项目 | 检查内容 |
|----------|----------|
| 物料 | 本品规物料是否全部清除 |
| 产品 | 本批产品是否全部入库 |
| 文件 | 本批文件是否全部收回 |
| 标识 | 所有标识是否清除 |
| 容器 | 周转容器是否清洁 |
| 设备 | 设备是否清洁 |
| 地面 | 地面是否清洁 |
| 墙面 | 墙面是否清洁 |
| 管道 | 管道是否清洁 |

## 12. 混淆/差错的发现与处理

### 12.1 发现途径

| 途径 | 说明 |
|------|------|
| 生产过程发现 | 现场操作人员发现 |
| 质量检查发现 | QA/QC检查发现 |
| 物料盘点发现 | 仓储盘点发现 |
| 产品追溯发现 | 追溯过程发现 |

### 12.2 发现后的处理

```
发现混淆/差错 → 立即停止作业 
→ 隔离相关物料/产品 → 报告QA 
→ 偏差调查 → 评估影响 
→ 采取纠正措施 → 整改预防
```

### 12.3 偏差报告要求

发现混淆/差错后应：
1. 立即报告QA
2. 隔离相关物料/产品
3. 详细记录发现经过
4. 配合偏差调查
5. 执行整改措施
