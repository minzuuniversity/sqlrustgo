# 产品防护和交叉污染控制

**文件编号**: SMP-PROD-017 | **类别**: 生产管理

---

## 1. 目的

建立产品防护和交叉污染控制措施。

## 2. 适用范围

适用于高原彝药厂所有生产区域。

## 3. 交叉污染来源

| 来源 | 控制措施 |
|------|----------|
| 人员流动 | 更衣、洗手 |
| 物料流动 | 专用通道 |
| 设备共用 | 清洁验证 |
| 空气流动 | 压差控制 |

## 4. 防护等级

| 等级 | 适用情况 | 防护要求 |
|------|----------|----------|
| 高 | 青霉素、激素类 | 独立厂房、专用设备 |
| 中 | β-内酰胺类 | 单独空调系统 |
| 低 | 普通药品 | 一般防护 |

## 5. 控制措施

| 措施 | 内容 |
|------|------|
| 物理隔离 | 独立区域、气锁 |
| 气流控制 | 负压、正压控制 |
| 清洁规程 | 专用清洁工具 |
| 人员培训 | 防护意识培训 |

## 6. 验证要求

清洁验证需证明交叉污染风险可控。
