# 压片岗位操作规程

**文件编号**: SOP-PROD-004 | **类别**: 生产管理

---

## 1. 目的

规范压片岗位操作，确保压片工艺符合要求，保证产品质量。

## 2. 适用范围

适用于高原彝药厂压片岗位的所有操作。

## 3. 设备

| 设备名称 | 设备编号 |
|----------|----------|
| 压片机 | EQUP-PROD-004 |

## 4. 操作前准备

| 准备项目 | 内容 | 要求 |
|----------|------|------|
| 环境检查 | 确认清场合格 | 符合洁净区要求 |
| 设备检查 | 确认清洁状态 | 有设备清洁标识 |
| 模具检查 | 确认模具规格 | 符合产品规格 |
| 物料检查 | 确认颗粒信息 | 水分、粒度、流速 |
| 个人防护 | 佩戴防护用品 | 洁净服、手套 |

## 5. 操作流程

### 5.1 压片机安装

| 步骤 | 内容 |
|------|------|
| 1 | 清洁冲模和模具 |
| 2 | 安装下冲 | 确认安装到位 |
| 3 | 安装上冲 | 确认安装到位 |
| 4 | 安装中模 | 确认安装到位 |
| 5 | 调整片重参数 | 设置目标片重 |
| 6 | 调整压力参数 | 设置目标压力 |

### 5.2 压片操作

| 步骤 | 操作内容 | 要点 |
|------|----------|------|
| 1 | 加入颗粒 | 确认颗粒信息 |
| 2 | 开机试压 | 调整参数至合格 |
| 3 | 片重调节 | 确保片重符合要求 |
| 4 | 压力调节 | 确保片硬度符合要求 |
| 5 | 崩解时限检查 | 确认崩解合格 |
| 6 | 正式压片 | 监控运行状态 |
| 7 | 定时检查 | 每15分钟检查片重、外观 |

### 5.3 压片结束

| 步骤 | 内容 |
|------|------|
| 1 | 停止加料 | 确认料斗内物料处理完 |
| 2 | 压出余料 | 将残余颗粒压完 |
| 3 | 停机 | 关闭电源 |
| 4 | 收集药片 | 标识转移 |
| 5 | 清场 | 按清场规程执行 |

## 6. 工艺参数

| 参数 | 要求 |
|------|------|
| 片重 | 符合规格±偏差 |
| 压力 | 符合工艺要求 |
| 硬度 | ≥50N |
| 崩解时限 | ≤15分钟 |
| 脆碎度 | ≤1% |

## 7. 质量控制点

| 控制点 | 频率 | 要求 |
|--------|------|------|
| 片重 | 每15分钟 | 符合规格 |
| 外观 | 持续 | 无缺陷 |
| 崩解时限 | 每批 | 符合标准 |
| 硬度 | 每小时 | 符合标准 |

## 8. 异常情况处理

| 异常 | 处理方式 |
|------|----------|
| 粘冲 | 停机检查模具 |
| 片重不稳 | 调整压片机参数 |
| 裂片 | 调整压力或颗粒性质 |
