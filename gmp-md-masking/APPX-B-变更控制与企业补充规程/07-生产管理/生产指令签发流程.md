# 生产指令签发流程

**文件编号**: SMP-PROD-001 | **类别**: 生产管理

---

## 1. 目的

规范生产指令的签发流程，确保生产活动有序进行，物料使用准确。

## 2. 适用范围

适用于高原彝药厂所有生产指令的管理。

## 3. 职责

| 部门 | 职责 |
|------|------|
| 销售部 | 提供销售需求计划 |
| 生产部 | 编制生产计划 |
| 质量保证部 | 生产指令审核批准 |
| 仓储部 | 物料准备 |

## 4. 生产计划制定

| 步骤 | 内容 | 时间节点 |
|------|------|----------|
| 需求收集 | 收集销售订单和库存 | 每月25日 |
| 计划编制 | 生产部编制月度计划 | 每月27日 |
| 计划审核 | 质量负责人审核 | 每月28日 |
| 计划批准 | 总经理批准 | 每月30日 |

## 5. 生产指令类型

| 类型 | 说明 | 签发要求 |
|------|------|----------|
| 月度计划 | 月度生产安排 | 提前1周签发 |
| 周计划 | 周生产安排 | 提前3天签发 |
| 紧急指令 | 紧急订单 | 随时签发 |

## 6. 生产指令内容

| 内容 | 要求 |
|------|------|
| 产品信息 | 名称、规格、批号 |
| 数量 | 批量大小 |
| 开工日期 | 计划开工时间 |
| 完工日期 | 计划完工时间 |
| 物料清单 | 所需物料及数量 |
| 特殊要求 | 质量要求等 |

## 7. 生产指令签发流程

| 步骤 | 执行人 | 内容 |
|------|--------|------|
| 编制 | 生产计划员 | 填写生产指令单 |
| 初审 | 生产部负责人 | 审核生产可行性 |
| 物料确认 | 仓储部 | 确认物料可用 |
| QA审核 | 质量保证部 | 审核指令合规性 |
| 批准 | 质量负责人 | 批准签发 |
| 发放 | 生产部 | 下发至生产车间 |

## 8. 生产指令执行

| 要求 | 内容 |
|------|------|
| 指令确认 | 车间接收后确认 |
| 按指令生产 | 严格按照指令执行 |
| 变更申请 | 需变更时提前申请 |
| 完成报告 | 生产完成后填写完成情况 |

## 9. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 生产指令单 | 5年 | 生产部 |
| 生产计划 | 5年 | 生产部 |
| 生产完成报告 | 5年 | 生产部 |
