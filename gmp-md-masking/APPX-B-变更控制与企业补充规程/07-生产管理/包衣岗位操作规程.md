# 包衣岗位操作规程

**文件编号**: SOP-PROD-005 | **类别**: 生产管理

---

## 1. 目的

规范包衣岗位操作，确保包衣工艺符合要求，保证产品质量。

## 2. 适用范围

适用于高原彝药厂包衣岗位的所有操作。

## 3. 设备

| 设备名称 | 设备编号 |
|----------|----------|
| 包衣机 | EQUP-PROD-005 |

## 4. 操作前准备

| 准备项目 | 内容 | 要求 |
|----------|------|------|
| 环境检查 | 确认清场合格 | 符合洁净区要求 |
| 设备检查 | 确认清洁状态 | 有设备清洁标识 |
| 包衣液配制 | 按配方配制 | 浓度、温度符合要求 |
| 素片检查 | 确认素片信息 | 批号、数量、外观 |
| 个人防护 | 佩戴防护用品 | 洁净服、手套 |

## 5. 包衣液配制

| 步骤 | 操作内容 | 要点 |
|------|----------|------|
| 1 | 量取溶剂 | 按配方量取 |
| 2 | 加入包衣材料 | 边加边搅拌 |
| 3 | 搅拌溶解 | 搅拌至完全溶解 |
| 4 | 过滤 | 使用适当滤网过滤 |
| 5 | 保温待用 | 按规定的温度保温 |

## 6. 包衣操作流程

### 6.1 预热

| 步骤 | 内容 |
|------|------|
| 1 | 启动包衣机 |
| 2 | 设定预热温度 |
| 3 | 预热至设定温度 |

### 6.2 包衣

| 步骤 | 操作内容 | 要点 |
|------|----------|------|
| 1 | 加入素片 | 确认素片信息 |
| 2 | 设定转速 | 根据批量调整 |
| 3 | 喷入包衣液 | 雾化良好 |
| 4 | 控制温度 | 防止片子粘连 |
| 5 | 包衣增重监控 | 监控增重 |
| 6 | 包衣完成判断 | 达到目标增重 |

### 6.3 冷却与出料

| 步骤 | 内容 |
|------|------|
| 1 | 停止喷液 | 继续运转冷却 |
| 2 | 冷却至室温 | 确认温度降至室温 |
| 3 | 出料 | 收集包衣后片子 |
| 4 | 标识转移 | 标识批号等信息 |

## 7. 工艺参数

| 参数 | 要求 |
|------|------|
| 包衣液浓度 | 按配方 |
| 喷液速度 | 根据设备调整 |
| 转速 | 防止片子磨损 |
| 进风温度 | 40-60°C |
| 出风温度 | 35-45°C |
| 包衣增重 | 2-5% |

## 8. 质量控制点

| 控制点 | 要求 |
|--------|------|
| 包衣液配制 | 按配方，混合均匀 |
| 片子外观 | 均匀、光滑 |
| 包衣增重 | 符合标准 |
| 崩解时限 | 符合标准 |
