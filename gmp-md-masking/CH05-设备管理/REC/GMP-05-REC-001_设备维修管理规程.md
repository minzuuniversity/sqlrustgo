# 设备维修管理规程

**文件编号**: SMP-FAC-003 | **类别**: 设施与设备

---

## 1. 目的

规范设备维修管理，确保设备及时修复、安全运行。

## 2. 适用范围

适用于高原彝药厂所有设备的维修管理。

## 3. 维修分类

| 类型 | 说明 | 时效 |
|------|------|------|
| 紧急维修 | 设备故障影响生产 | 即时 |
| 计划维修 | 按计划定期维修 | 按计划 |
| 改进维修 | 设备改进升级 | 安排进行 |

## 4. 职责

| 部门 | 职责 |
|------|------|
| 使用部门 | 报修、配合 |
| 工程设备部 | 维修执行 |
| 质量保证部 | 维修后验证 |

## 5. 维修流程

| 步骤 | 内容 |
|------|------|
| 1 | 使用部门报修 |
| 2 | 工程部接修 |
| 3 | 故障诊断 |
| 4 | 制定维修方案 |
| 5 | 实施维修 |
| 6 | 维修后验证 |
| 7 | 记录归档 |

## 6. 维修记录

| 内容 | 要求 |
|------|------|
| 设备信息 | 名称、编号 |
| 故障描述 | 故障现象 |
| 维修内容 | 维修措施 |
| 更换配件 | 配件名称规格 |
| 维修人员 | 执行人 |
| 维修时间 | 开始和结束时间 |

## 7. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 维修申请 | 5年 | 工程设备部 |
| 维修记录 | 5年 | 工程设备部 |
