# 空气净化系统（HVAC）

**文件编号:** REG-GMP-016
**版本号:** V1.0

## 1. HVAC系统组成

```
送风系统
├── 初效过滤器（G4）
├── 中效过滤器（F7-F9）
├── 高效过滤器（HEPA H13-H14）
└── 末端送风（高效送风口/FFU）

回风/排风系统
├── 回风管道
├── 排风管道
└── 排风处理（活性炭等）

控制系统
├── 温湿度控制
├── 压差控制
├── 风量控制
└── 报警系统
```

## 2. 关键参数控制

| 参数 | 标准要求 | 监控频次 |
|------|---------|---------|
| 温度 | 18-26°C | 连续 |
| 湿度 | 45-65%RH | 连续 |
| 压差 | ≥10Pa | 连续 |
| 风量 | 符合换气次数 | 定期 |
| 尘埃粒子 | 符合级别要求 | 定期 |

## 3. 验证要求

- IQ: 安装确认
- OQ: 运行确认
- PQ: 性能确认
- 日常监控

## 4. 维护要求

- 初效过滤器：每月清洗/更换
- 中效过滤器：每3-6月更换
- 高效过滤器：每年检测，2-3年更换
- 系统验证：每年一次

## 5. 常见问题

- 压差不足/倒灌
- 温湿度超标
- 过滤器泄漏
- 回风短路
