# 中间产品控制

**文件编号:** REG-GMP-032
**版本号:** V1.0

## 1. 中间产品定义

在药品制造过程中，完成部分工序后需要进一步加工的产品。

## 2. 中间产品质量标准

| 项目 | 要求 |
|------|------|
| 性状 | 符合规定 |
| 鉴别 | 符合规定 |
| 含量 | 符合内控标准 |
| 水分 | 符合工艺要求 |
| 微生物 | 符合要求 |

## 3. 过程控制点

| 工序 | 控制项目 | 频次 |
|------|---------|------|
| 粉碎 | 粒度 | 每批 |
| 提取 | 温度/时间/用量 | 每批 |
| 浓缩 | 密度/固含量 | 每批 |
| 干燥 | 温度/时间/水分 | 每批 |
| 混合 | 均匀度 | 每批 |

## 4. 中间产品标识

- 名称
- 批号
- 数量
- 状态（待验/合格/不合格）
- 工序

## 5. 中间产品储存

- 规定时间内完成下步工序
- 防止变质
- 防止混淆
- 防止污染
