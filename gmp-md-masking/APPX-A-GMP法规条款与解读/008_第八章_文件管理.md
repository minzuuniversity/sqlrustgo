# 第八章 文件管理

**条款范围：第251-280条**

## 核心要求

### 8.1 文件体系
- **第251-260条** 质量管理体系文件系统包括：
  - 质量标准（原材料、包装材料、成品）
  - 生产工艺规程
  - 操作SOP
  - 记录（批记录、检验记录、设备记录等）

### 8.2 文件编码
- **第261条** 文件应有唯一的编码
- 编码规则应统一，便于识别、追溯
- 编码结构示例：`类型-部门-序号-版本`
  - 例如：`SOP-PD-001-V01`（生产部SOP第1号，第1版）

### 8.3 文件管理流程
- 文件起草 → 审核 → 批准 → 发放 → 使用 → 收回 → 销毁
- 作废文件应从使用场所收回，防止误用
- 文件更改应记录更改原因

### 8.4 记录管理
- 记录应及时、清晰、真实
- 记录不得涂改，若要修改应划改并签名
- 记录应妥善保管，便于追溯

## 飞检重点
1. 文件编码是否唯一、可追溯
2. 作废文件是否已回收
3. 记录修改是否合规
