# 文件生命周期管理

**文件编号:** REG-GMP-039
**版本号:** V1.0

## 1. 文件生命周期

```
起草 → 审核 → 批准 → 发放 → 使用 → 收回 → 销毁/存档
```

## 2. 各阶段要求

### 起草
- 依据充分
- 内容完整
- 格式规范

### 审核
- 相关性审核
- 准确性审核
- 可行性审核

### 批准
- 授权人批准
- 签字+日期

### 发放
- 受控分发
- 分发号唯一
- 领取人签名

### 使用
- 使用受控版本
- 不得擅自复印

### 收回
- 及时收回旧版
- 防止误用
- 记录收回数量

### 销毁/存档
- 作废文件销毁或标注
- 受控版本存档备查
- 保存期限符合要求

## 3. 保存期限

| 文件类型 | 保存期限 |
|---------|---------|
| 批记录 | 效期后1年 |
| 验证文件 | 5年或产品生命周期 |
| SOP | 废止后3年 |
| 培训记录 | 员工离职后1年 |
| 检验记录 | 效期后1年 |
