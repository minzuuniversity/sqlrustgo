# 物料采购管理

**文件编号:** REG-GMP-025
**版本号:** V1.0

## 1. 供应商选择

**第255条** 企业应建立供应商审计制度，对主要物料供应商进行质量审计。

### 供应商选择标准
- 生产许可证
- GMP证书（如适用）
- 产品质量
- 供货能力
- 价格
- 售后服务

## 2. 供应商审计

| 审计类型 | 频次 | 内容 |
|---------|------|------|
| 首次审计 | 引入新供应商前 | 全面现场审计 |
| 定期审计 | 1-3年 | 回顾性评估 |
| 飞行检查 | 必要时 | 不通知 |

### 审计内容
- 质量管理体系
- 生产条件
- 实验室能力
- 包装运输
- 历史质量数据

## 3. 物料采购流程

```
提出采购申请
    ↓
供应商评估/审计
    ↓
批准合格供应商
    ↓
签订采购合同
    ↓
到货验收
    ↓
检验/放行
```

## 4. 物料编码

- 唯一性编码
- 便于识别
- 可追溯
- 格式统一
