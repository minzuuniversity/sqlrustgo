# GMP总则概述

**文件编号:** REG-GMP-001
**版本号:** V1.0

## 1. GMP的定义

**GMP（Good Manufacturing Practice）** 中文：药品生产质量管理规范
- 是药品生产和质量管理的基本准则
- 适用于药品制剂生产的全过程
- 是国际通行的药品生产质量管理基本准则

## 2. GMP的核心理念

### 2.1 质量风险管理
- 药品质量是对产品全生命周期各环节因素的综合反映
- 必须识别和控制所有可能影响质量的风险

### 2.2 质量体系
- 建立完善的质量管理体系
- 涵盖人员、厂房、设备、物料、生产、质量控制等全要素
- 持续改进

### 2.3 预防为主
- 不能仅依赖最终产品检验
- 必须从源头和生产过程控制质量
- 偏差、变更、 CAPA是预防的重要手段

## 3. GMP的基本要求

| 基本要求 | 说明 |
|---------|------|
| 人员 | 具备适当资质、培训 |
| 厂房设施 | 适宜设计建造、验证维护 |
| 设备 | 选型正确、校准、验证 |
| 物料 | 从合格供应商采购、检验储存 |
| 生产 | 按批准的工艺规程操作 |
| 质量控制 | 检验方法验证、留样观察 |
| 文件 | 完善、可追溯 |
| 投诉召回 | 及时处理、报告 |

## 4. GMP的法律地位

- GMP是《药品管理法》的配套法规
- 药品生产企业必须通过GMP认证
- GMP检查是药品监管的核心手段
- 违反GMP是严重的违法行为
