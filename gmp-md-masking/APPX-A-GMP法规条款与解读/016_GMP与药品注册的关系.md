# GMP与药品注册的关系

**文件编号:** REG-GMP-004
**版本号:** V1.0

## 1. 药品注册与GMP的关系

药品注册和GMP认证是药品上市的 两个基本要求：

| 维度 | 药品注册 | GMP认证 |
|------|---------|---------|
| 性质 | 药品上市的行政许可 | 药品生产的基本资质 |
| 依据 | 《药品注册管理办法》 | GMP及附录 |
| 关注点 | 药品的安全性、有效性、质量可控性 | 生产过程的质量管理 |
| 有效期 | 药品注册批准文号长期有效 | GMP证书5年有效 |

## 2. GMP与注册标准的协调

**第23条** 药品生产必须符合国家药品注册批准的要求。

- 处方必须与注册标准一致
- 工艺必须与注册工艺一致
- 质量标准必须符合注册标准
- 任何变更必须申报批准

## 3. 常见违规风险

| 风险类型 | 说明 |
|---------|------|
| 工艺不一致 | 实际生产与申报工艺不符 |
| 标准不一致 | 实际检验方法与注册标准不符 |
| 擅自变更 | 未申报擅自变更处方工艺 |
| 批记录造假 | 批记录与实际生产不符 |

## 4. 法规要求

- 新药申报必须提供 GMP 证明
- 药品再注册需要 GMP 证书
- GMP 检查结果影响注册审批
- 严重违规可能导致吊销生产许可证
