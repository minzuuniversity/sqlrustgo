# 关键人员资质要求

**文件编号:** REG-GMP-010
**版本号:** V1.0

## 1. 关键人员范围

| 岗位 | GMP要求 | 企业实际 |
|------|---------|---------|
| 生产管理负责人 | 药学或相关专业本科+3年经验 | |
| 质量管理负责人 | 药学或相关专业本科+3年经验 | |
| 质量受权人 | 药学或相关专业本科+5年经验 | |
| 质量保证经理 | 药学或相关专业+GMP经验 | |
| 质量控制经理 | 药学或相关专业+检验经验 | |

## 2. 资质证明材料

| 材料 | 说明 |
|------|------|
| 学历证书 | 药学或相关专业 |
| 职称证书 | 中级以上职称优先 |
| 工作经历证明 | 药品生产质量管理经验 |
| 培训记录 | GMP及专业培训 |
| 岗位职责授权书 | 明确职责范围 |

## 3. 在岗要求

- 关键人员应在职在岗
- 离职需提前3个月通知
- 离职前需完成工作交接
- 监管部门可要求变更

## 4. 常见缺陷

- 关键人员挂名不在岗
- 资质不符合要求
- 培训记录缺失
- 职责授权不明确
