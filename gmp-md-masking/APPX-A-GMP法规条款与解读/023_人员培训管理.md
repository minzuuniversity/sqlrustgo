# 人员培训管理

**文件编号:** REG-GMP-011
**版本号:** V1.0

## 1. 培训要求

**第74-80条** 企业应建立培训管理体系，确保所有人员经过适当培训。

## 2. 培训类型

| 培训类型 | 要求 | 频次 |
|---------|------|------|
| 岗前培训 | 上岗前完成GMP及岗位职责 | 入职 |
| 继续培训 | 持续提升专业能力 | 定期 |
| 特殊培训 | 无菌操作等特殊岗位 | 按需 |
| 法规培训 | 最新法规要求 | 法规更新时 |
| 应急培训 | 偏差、紧急情况处理 | 每年 |

## 3. 培训内容

### 3.1 GMP基础培训
- GMP基本理念
- 偏差报告要求
- 卫生要求
- 文件记录要求

### 3.2 岗位职责培训
- 本岗位操作SOP
- 设备操作规程
- 质量标准
- 安全注意事项

## 4. 培训档案

| 内容 | 保存期限 |
|------|---------|
| 培训计划 | 3年 |
| 培训签到表 | 3年 |
| 培训教材 | 3年 |
| 培训记录 | 员工离职后1年 |
| 考核结果 | 3年 |

## 5. 培训有效性评估

- 理论考核
- 实际操作考核
- 岗位胜任能力评估
- 持续表现监控
