# 组织架构设计

**文件编号:** REG-GMP-013
**版本号:** V1.0

## 1. 组织架构原则

- 与生产规模相适应
- 职责明确、不交叉不空白
- 质量部门独立设置
- 汇报线清晰

## 2. 典型组织架构

```
总经理
├── 生产总监
│   ├── 生产部
│   ├── 工程部
│   └── 仓储部
├── 质量总监（质量受权人）
│   ├── 质量保证部（QA）
│   └── 质量控制部（QC）
├── 技术总监
│   ├── 研发部
│   └── 注册部
└── 行政总监
    ├── 人力资源部
    └── 财务部
```

## 3. 职责矩阵

| 职责 | 生产部 | QA | QC | 工程部 |
|------|-------|----|----|-------|
| 生产操作 | ★ | | | |
| 工艺参数监控 | ★ | | | |
| 质量监控 | | ★ | | |
| 物料检验 | | | ★ | |
| 设备维护 | | | | ★ |
| 偏差调查 | ○ | ★ | ○ | ○ |
| 变更控制 | ○ | ★ | ○ | ○ |

★ 主要职责 ○ 参与

## 4. 关键控制点

- 质量部门可直接向最高管理层汇报
- 生产与质量相互独立
- 质量受权人有一票否决权
