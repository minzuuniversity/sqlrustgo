# 洁净室设计与分级

**文件编号:** REG-GMP-015
**版本号:** V1.0

## 1. 洁净度分级

**第98条** 药品生产洁净室（区）的空气洁净度级别分为四级。

| 级别 | 静态尘埃最大允许数/m³ | 静态微生物最大允许数 |
|------|----------------------|---------------------|
| A级 | ≥0.5μm: 3520; ≥5μm: 20 | 浮游菌: 1/m³; 沉降菌: 1/皿 |
| B级 | ≥0.5μm: 3520; ≥5μm: 20 | 浮游菌: 10/m³; 沉降菌: 5/皿 |
| C级 | ≥0.5μm: 352000; ≥5μm: 2900 | 浮游菌: 100/m³; 沉降菌: 50/皿 |
| D级 | ≥0.5μm: 3520000; ≥5μm: 29000 | 浮游菌: 200/m³; 沉降菌: 100/皿 |

## 2. 适用区域

| 生产类型 | 洁净度要求 |
|---------|-----------|
| 无菌药品灌装 | A级背景（B级） |
| 非无菌药品开放操作 | D级或C级 |
| 最终灭菌药品 | C级或D级 |
| 中药提取 | 30万级或D级 |

## 3. 洁净室设计要求

### 3.1 平面布局
- 人流物流分开
- 减少交叉污染
- 压差梯度合理
- 便于清洁维护

### 3.2 建筑材料
- 表面平整光滑
- 不脱落颗粒
- 耐腐蚀耐消毒
- 不吸附物料

### 3.3 压差控制
- 洁净区与非洁净区≥10Pa
- 不同级别之间≥15Pa
- 气流组织合理
- 防止倒灌
