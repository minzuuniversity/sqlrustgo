# 文件编码规则

**文件编号:** REG-GMP-035
**版本号:** V1.0

## 1. 文件编码原则

**第261条** 质量标准、操作规程等文件应有编码，编码应具有唯一性。

### 编码要素
- 唯一性：不重复
- 系统性：便于识别分类
- 可扩展性：预留发展空间
- 稳定性：编码确定后不变

## 2. 编码结构示例

### 格式一：部门-类型-序号-版本
```
SOP-QA-001-V01
├── SOP: 标准操作规程
│   ├── SOP: 标准操作规程
│   ├── STD: 质量标准
│   ├── VP: 验证方案
│   ├── VR: 验证报告
│   └── FORM: 记录表格
├── QA: 部门
│   ├── QA: 质量部
│   ├── PD: 生产部
│   ├── EN: 工程部
│   ├── WH: 仓库
│   └── QC: 质量控制
├── 001: 流水号
└── V01: 版本号
```

### 格式二：类型-部门-功能-序号
```
GMP-PD-PROD-001
```

## 3. 版本号管理

| 修订类型 | 版本变更 | 说明 |
|---------|---------|------|
| 重大修订 | V1.0 → V2.0 | 内容重大变化 |
| 小幅修订 | V1.0 → V1.1 | 内容小幅调整 |
| 格式调整 | V1.0 → V1.0-R1 | 仅格式/排版变更 |
