# 质量标准编制

**文件编号:** REG-GMP-037
**版本号:** V1.0

## 1. 质量标准类型

| 类型 | 适用范围 | 依据 |
|------|---------|------|
| 原料质量标准 | 原料、辅料 | 注册标准/药典 |
| 包材质量标准 | 包装材料 | 药典/注册标准 |
| 成品质量标准 | 制剂产品 | 注册标准 |
| 中间产品质量标准 | 中间产品 | 企业内控 |

## 2. 质量标准内容

| 内容 | 说明 |
|------|------|
| 名称 | 法定名称 |
| 代码 | 唯一性编码 |
| 性状 | 外观、臭、味 |
| 鉴别 | 特征性鉴别 |
| 检查 | 杂质、水分、灰分等 |
| 含量测定 | 方法和限度 |
| 贮藏条件 | 温度、湿度、光照 |
| 有效期 | 规定的贮藏条件下 |

## 3. 限度制定原则

- 符合注册标准
- 基于科学数据
- 生产可行
- 质量可控

## 4. 审批流程

```
研发/技术部起草
    ↓
QC审核
    ↓
QA审核
    ↓
质量总监批准
    ↓
生效执行
```
