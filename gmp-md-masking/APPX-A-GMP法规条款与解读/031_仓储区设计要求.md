# 仓储区设计要求

**文件编号:** REG-GMP-019
**版本号:** V1.0

## 1. 仓储区基本要求

**第125-130条** 仓储区应有与生产规模相适应的面积和空间。

### 1.1 区域划分
- 收货区
- 待验区
- 合格品区
- 不合格品区
- 退货区
- 留样区
- 冷库/阴凉库

### 1.2 温湿度要求

| 区域 | 温度 | 湿度 |
|------|------|------|
| 常温库 | 10-30°C | 45-75% |
| 阴凉库 | ≤20°C | 45-65% |
| 冷库 | 2-8°C | - |
| 相对湿度高的地区 | - | 可放宽至85% |

## 2. 特殊物料储存

| 物料类型 | 储存条件 |
|---------|---------|
| 活菌/活疫苗 | 2-8°C或-20°C |
| 抗生素 | 阴凉20°C以下 |
| 挥发性物料 | 密闭、单独存放 |
| 精神药品 | 双锁、专库 |
| 特殊药材 | 低温低湿 |

## 3. 仓库管理要求

- 账物卡相符
- 先进先出原则
- 温湿度监控
- 防虫防鼠
- 清洁卫生
- 定期盘点

## 4. 安全要求

- 消防设施齐全
- 防爆电器
- 防雷防静电
- 应急预案
