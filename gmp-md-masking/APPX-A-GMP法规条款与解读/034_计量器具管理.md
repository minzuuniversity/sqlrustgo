# 计量器具管理

**文件编号:** REG-GMP-022
**版本号:** V1.0

## 1. 计量管理要求

**第94条** 用于药品生产、质量控制、设备校准的仪器仪表应按规定进行校准和检定。

## 2. 强检与非强检

| 类型 | 定义 | 管理要求 |
|------|------|---------|
| 强检器具 | 国家强制检定 | 必须经法定机构检定 |
| 非强检器具 | 企业自校 | 按内部校准规程 |

### 强检目录（部分）
- 压力表
- 天平
- 温度计
- 电导率仪
- 分析天平

## 3. 校准周期

| 仪器类型 | 校准周期 |
|---------|---------|
| 分析天平 | 6个月 |
| 滴定管 | 12个月 |
| 温度计 | 12个月 |
| 压力表 | 12个月 |
| pH计 | 6个月 |
| HPLC用UV检测器 | 12个月 |

## 4. 校准证书管理

- 证书编号唯一
- 证书保存齐全
- 证书信息完整（校准值、修正值、不确定度）
- 不合格证书单独标识

## 5. 日常检查

- 使用前检查
- 在用检查
- 期间核查
