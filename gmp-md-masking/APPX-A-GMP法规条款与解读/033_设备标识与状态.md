# 设备标识与状态管理

**文件编号:** REG-GMP-021
**版本号:** V1.0

## 1. 设备标识

### 1.1 设备铭牌
- 设备名称
- 设备编号
- 型号规格
- 生产厂商
- 出厂日期
- 唯一性编号（可追溯）

### 1.2 状态标识

| 颜色 | 含义 | 使用条件 |
|------|------|---------|
| 绿色 | 合格/可用 | 完成确认/验证 |
| 黄色 | 待验/待确认 | 新设备/维修后 |
| 红色 | 不合格/停用 | 故障/报废 |

## 2. 设备台账

| 信息项 | 内容 |
|-------|------|
| 基本信息 | 名称、编号、型号 |
| 位置 | 安装位置 |
| 供应商 | 供应商信息 |
| 确认状态 | IQ/OQ/PQ完成情况 |
| 使用状态 | 运行/停用/报废 |
| 维护记录 | 维护历史 |
| 校准记录 | 校准历史 |

## 3. 使用日志

关键设备应建立使用日志：
- 设备运行时间
- 产品/批次信息
- 操作人员
- 运行参数
- 异常情况
- 维护保养记录

## 4. 维护保养

- 建立维护计划
- 预防性维护为主
- 维护记录完整
- 备件管理规范
