# 工艺规程编制

**文件编号:** REG-GMP-030
**版本号:** V1.0

## 1. 工艺规程要求

**第201条** 每种药品必须编制工艺规程。

## 2. 工艺规程内容

| 内容 | 说明 |
|------|------|
| 名称 | 药品名称 |
| 处方 | 所有物料用量 |
| 生产操作 | 详细步骤 |
| 工艺参数 | 关键/重要参数 |
| 设备 | 设备要求 |
| 质量控制点 | 过程检验点 |
| 批量 | 批量范围 |

## 3. 批生产记录关系

工艺规程是编制批生产记录的基础：
- 批记录按工艺规程编制
- 工艺参数必须与规程一致
- 批记录是工艺规程的执行记录

## 4. 工艺规程管理

- 版本控制
- 不得擅自修改
- 变更需经变更控制
- 旧版本存档备查
- 分发受控
