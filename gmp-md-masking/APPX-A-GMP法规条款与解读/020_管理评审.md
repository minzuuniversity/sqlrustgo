# 管理评审

**文件编号:** REG-GMP-008
**版本号:** V1.0

## 1. 管理评审要求

**第37条** 最高管理者应按计划评审质量管理体系，确保其持续的适宜性、充分性和有效性。

## 2. 评审频次

- 正常：每年一次
- 特殊情况可增加：
  - 重大组织变革
  - 重大质量事件
  - 监管政策重大调整
  - 产品重大变更

## 3. 评审输入

| 输入内容 | 说明 |
|---------|------|
| 内审结果 | 上年度内审发现 |
| 客户反馈 | 投诉、退货、市场反馈 |
| 过程绩效 | 各部门KPI完成情况 |
| 偏差与CAPA | 年度趋势分析 |
| 验证状态 | 设备和工艺验证情况 |
| 供应商绩效 | 供应商审计结果 |
| 资源需求 | 人员、设备、资金需求 |
| 法规变化 | 新法规要求 |

## 4. 评审输出

- 质量体系改进决策
- 资源配置决策
- 产品改进决策
- 管理改进决策

## 5. 记录要求

- 管理评审计划
- 管理评审报告
- 改进措施跟踪记录
