# 排水与废气处理

**文件编号:** REG-GMP-018
**版本号:** V1.0

## 1. 排水系统要求

### 1.1 洁净区排水
- 不得排水（无地面排水口）
- 或采用高质量地漏
- 水封有效
- 防止倒灌

### 1.2 一般区排水
- 材质耐腐蚀
- 畅通无堵塞
- 定期清洁
- 记录完整

## 2. 废气处理

| 废气类型 | 处理方式 |
|---------|---------|
| 有机溶剂废气 | 活性炭吸附/催化燃烧 |
| 粉尘废气 | 布袋除尘 |
| 酸碱废气 | 碱洗/酸洗 |
| 恶臭废气 | 活性炭吸附/生物滤池 |

## 3. 环保合规

- 符合《大气污染物综合排放标准》
- 符合《恶臭污染物排放标准》
- 定期监测并保存记录
- 排污许可证齐全

## 4. 维护要求

- 废水处理设施定期维护
- 废气处理设施定期检测
- 运行记录完整
- 应急措施到位
