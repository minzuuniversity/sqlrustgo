# GMP 第十二条

**文件编号**: GMP-012 | **类别**: GMP条款原文

---

## 原文

第十二条　药品生产企业的质量管理部门应当独立于生产管理部门。

---

## 解读

### 组织架构要求

| 要求 | 说明 |
|------|------|
| 独立性 | 质量部门独立于生产 |
| 报告线 | 直接向质量受权人报告 |
| 否决权 | 质量部门有一票否决权 |

### 质量部门职责

| 职责 | 内容 |
|------|------|
| 质量放行 | 原料、辅料、包装材料、成品放行 |
| 偏差管理 | 偏差调查处理 |
| 变更控制 | 变更评估审核 |
| 投诉处理 | 客户投诉调查处理 |
| 自检审计 | 内部自检、供应商审计 |
| 工艺验证 | 工艺验证、清洁验证 |
| 稳定性考察 | 稳定性监测 |
