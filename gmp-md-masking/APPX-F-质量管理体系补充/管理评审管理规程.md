# 管理评审管理规程

**文件编号**: SMP-QMS-004 | **类别**: 质量管理体系

---

## 1. 目的

建立管理评审程序，定期评估质量管理体系的适宜性、充分性和有效性，推动持续改进。

## 2. 适用范围

适用于高原彝药厂质量管理体系的管理评审活动。

## 3. 职责

| 角色 | 职责 |
|------|------|
| 总经理 | 主持管理评审 |
| 质量负责人 | 汇报质量体系运行情况 |
| 各部门负责人 | 汇报本部门质量体系执行情况 |
| 质量保证部 | 负责评审的组织准备和记录 |

## 4. 评审频率

- 常规管理评审：每年至少一次
- 特殊情况可增加：重大组织变化、法规重大变化、重大质量事件后

## 5. 评审输入

| 信息类型 | 具体内容 |
|----------|----------|
| 体系绩效 | 内审结果、验证结果、偏差汇总 |
| 客户反馈 | 投诉、退货、市场反馈 |
| 过程绩效 | 生产合格率、检验合格率、OOS统计 |
| 供应商绩效 | 供应商审计结果、物料质量问题 |
| 法规动态 | GMP法规更新、行业指南变化 |
| 资源需求 | 人员、设备、设施需求 |
| 上次评审追踪 | 改进措施执行情况 |

## 6. 评审输出

| 输出内容 | 要求 |
|----------|------|
| 体系有效性评价 | 质量管理体系是否有效运行 |
| 改进决定 | 需要采取的改进措施 |
| 资源配置决定 | 人员、设备、资金需求 |
| 目标调整 | 质量目标调整 |
| 风险管理更新 | 风险评估更新 |

## 7. 评审程序

| 阶段 | 时间 | 负责部门 |
|------|------|----------|
| 评审计划制定 | 评审前1个月 | 质量保证部 |
| 数据收集整理 | 评审前2周 | 各部门 |
| 评审会议 | 评审当日 | 质量管理部 |
| 评审报告 | 评审后10个工作日 | 质量保证部 |
| 改进实施 | 按评审决定 | 各部门 |

## 8. 评审会议程序

1. 总经理宣布评审开始
2. 质量负责人汇报质量体系整体运行情况
3. 各部门负责人汇报本部门情况
4. 讨论分析发现的问题
5. 总经理总结并做出决定
6. 明确改进事项和责任人

## 9. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 管理评审计划 | 5年 | 质量保证部 |
| 管理评审报告 | 5年 | 质量保证部 |
| 评审会议纪要 | 5年 | 质量保证部 |
