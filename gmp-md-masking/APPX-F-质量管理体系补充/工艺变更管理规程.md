# 工艺变更管理规程

**文件编号**: SMP-QMS-012 | **类别**: 质量管理体系

---

## 1. 目的

建立工艺变更控制程序，确保所有生产工艺变更经过充分评估、控制和验证，保证产品质量。

## 2. 适用范围

适用于高原彝药厂所有生产工艺变更的管理。

## 3. 变更分类

| 类别 | 定义 | 示例 | 审批级别 |
|------|------|------|----------|
| 重大变更 | 可能影响产品安全性或有效性 | 关键工艺参数重大调整 | 注册批准+内部批准 |
| 主要变更 | 可能影响产品质量 | 设备更换、批量调整 | 质量负责人 |
| 次要变更 | 不直接影响产品质量 | 辅助参数调整 | 部门负责人 |

## 4. 职责

| 部门 | 职责 |
|------|------|
| 变更申请部门 | 发起变更申请 |
| 质量保证部 | 变更申请的评估和协调 |
| 生产部 | 工艺可行性评估 |
| 质量控制部 | 检验方法适用性评估 |
| 工程设备部 | 设备设施影响评估 |
| 注册部 | 涉及注册的变更协调 |

## 5. 变更控制流程

### 5.1 变更申请

| 信息要素 | 内容 |
|----------|------|
| 变更描述 | 详细描述变更内容 |
| 变更原因 | 说明变更目的和必要性 |
| 变更实施计划 | 实施时间表 |
| 涉及产品/批次 | 影响的范围 |
| 风险评估 | 初步风险评估 |

### 5.2 变更评估

| 评估项目 | 评估内容 |
|----------|----------|
| 法规符合性 | 是否符合GMP和注册要求 |
| 产品质量影响 | 对产品质量的潜在影响 |
| 验证必要性 | 是否需要验证 |
| 稳定性影响 | 是否影响产品稳定性 |
| 注册申报必要性 | 是否需要申报 |

### 5.3 变更批准

| 变更级别 | 批准人员 | 依据 |
|----------|----------|------|
| 重大变更 | 总经理+注册批准 | 充分验证数据 |
| 主要变更 | 质量负责人 | 风险评估+验证 |
| 次要变更 | 部门负责人 | 评估报告 |

### 5.4 变更实施

| 步骤 | 要求 |
|------|------|
| 实施前准备 | 完成必要的验证 |
| 实施过程 | 按批准方案执行 |
| 监控 | 变更后加强监控 |
| 评估 | 评估变更效果 |

## 6. 变更后评估

| 评估内容 | 周期 |
|----------|------|
| 工艺参数监控 | 实施后连续3批 |
| 产品质量检验 | 实施后连续3批 |
| 稳定性考察 | 加速+长期试验 |
| 偏差监控 | 实施后6个月 |

## 7. 变更文件更新

| 文件类型 | 更新要求 |
|----------|----------|
| 工艺规程 | 变更批准后更新 |
| 批记录 | 必要时更新 |
| 验证报告 | 完成后存档 |
| 注册申报资料 | 按法规要求 |

## 8. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 变更申请表 | 10年 | 质量保证部 |
| 变更评估报告 | 10年 | 质量保证部 |
| 变更批准文件 | 10年 | 质量保证部 |
| 变更实施记录 | 10年 | 质量保证部 |
