# 验证总计划管理规程

**文件编号**: SMP-QMS-009 | **类别**: 质量管理体系

---

## 1. 目的

建立验证总计划管理程序，系统规划和管理验证活动，确保所有验证活动符合GMP要求。

## 2. 适用范围

适用于高原彝药厂所有验证活动的管理。

## 3. 验证范围

| 验证类型 | 内容 |
|----------|------|
| 厂房验证 | 洁净区 HVAC、压差、温湿度 |
| 设施验证 | 制药用水系统、压缩空气系统 |
| 设备验证 | 生产设备、实验室仪器 |
| 工艺验证 | 生产工艺、清洁工艺 |
| 分析方法验证 | 含量测定、杂质检测等 |
| 计算机系统验证 | ERP、LIMS、MES等 |

## 4. 职责

| 部门 | 职责 |
|------|------|
| 质量保证部 | 验证总计划的制定和协调 |
| 工程设备部 | 设备、设施验证执行 |
| 生产部 | 工艺验证执行 |
| 质量控制部 | 分析方法验证执行 |
| IT部门 | 计算机系统验证 |

## 5. 验证总计划内容

| 章节 | 内容 |
|------|------|
| 概述 | 企业概况、验证方针 |
| 验证策略 | 验证方法、接受标准 |
| 验证项目清单 | 各系统/设备的验证计划 |
| 验证时间表 | 年度/月度验证计划 |
| 职责分工 | 各部门验证职责 |
| 风险管理 | 关键系统风险评估 |
| 偏差处理 | 验证偏差管理 |
| 变更控制 | 验证后变更管理 |

## 6. 验证阶段

| 阶段 | 内容 | 交付物 |
|------|------|--------|
| 设计确认（DQ） | 设计文件审核 | DQ报告 |
| 安装确认（IQ） | 设备安装确认 | IQ报告 |
| 运行确认（OQ） | 功能测试 | OQ报告 |
| 性能确认（PQ） | 工艺性能 | PQ报告 |
| 工艺验证（PV） | 连续生产验证 | PV报告 |

## 7. 验证项目管理

| 管理要素 | 要求 |
|----------|------|
| 验证方案 | 验证前批准 |
| 验证实施 | 按方案执行 |
| 验证记录 | 实时记录 |
| 偏差处理 | 不符合项记录和处理 |
| 验证报告 | 完成后批准 |
| 验证周期 | 再验证周期确定 |

## 8. 再验证周期

| 设备/系统类型 | 再验证周期 |
|--------------|------------|
| 关键设备 | 每年一次或变更后 |
| 一般设备 | 每3年一次或变更后 |
| 工艺 | 重大变更后 |
| 分析方法 | 重大变更后或每2年 |
| 计算机系统 | 每年一次 |

## 9. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 验证总计划 | 永久 | 质量保证部 |
| 各系统验证报告 | 10年 | 质量保证部 |
| 验证方案 | 10年 | 质量保证部 |
