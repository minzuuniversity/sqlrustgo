# 退货管理规程

**文件编号**: SP-QMS-015
**版本**: V1.0
**生效日期**: 2026-01-01
**审核人**: __________
**批准人**: __________

---

## 1. 目的

建立规范的药品退货管理流程，确保退货药品的质量安全，防止不合格药品重新上市销售，符合《药品生产质量管理规范（2010年修订）》第六条要求。

---

## 2. 范围

适用于公司生产的所有药品（包括成品、中间产品）的退货处理，包括：
- 客户退货
- 经销商退货
- 医疗机构退货
- 零售药店退货
- 质量问题退货
- 非质量问题退货

---

## 3. 职责

| 部门/岗位 | 职责 |
|-----------|------|
| 质量保证部 | 负责退货申请的审核、批准及最终处置决定 |
| 质量控制部 | 负责退货药品的质量检验与评价 |
| 仓储部 | 负责退货药品的接收、储存、隔离管理 |
| 销售部 | 负责退货申请提交、退货运输协调 |
| 生产部 | 负责退货原因分析及必要的生产调查 |

---

## 4. 定义

### 4.1 退货
指药品从客户处返回生产企业的行为，包括因质量问题、非质量问题等多种原因导致的退货。

### 4.2 退货申请
客户因各种原因提出将已购药品退回生产企业的正式请求。

### 4.3 退货审批
质量保证部对退货申请进行审核并决定是否接受的过程。

### 4.4 退货检验
对退回的药品进行质量检验，评估其是否符合接收或销毁条件。

---

## 5. 工作流程

### 5.1 退货申请

1. 客户提出退货申请，填写《退货申请单》
2. 销售部审核退货原因，确认退货必要性
3. 销售部将退货申请提交至质量保证部

**退货申请单应包括**：
- 客户名称、联系方式
- 药品名称、规格、批号、数量
- 退货原因
- 购买日期、发票编号
- 储存条件说明

### 5.2 退货审核

1. 质量保证部收到退货申请后2个工作日内完成审核
2. 审核内容包括：
   - 退货原因合理性
   - 药品是否在有效期内
   - 储存运输条件是否合规
   - 包装完整性
   - 历史退货记录

3. 审核结论：
   - **批准退货**：进入退货接收流程
   - **拒绝退货**：通知销售部并说明原因
   - **有条件接受**：要求补充资料或特殊处理后决定

### 5.3 退货接收

1. 仓储部收到退货通知后，准备专用退货接收区
2. 退货到达后，仓储人员核对：
   - 药品名称、规格、批号、数量
   - 包装完整性
   - 外观状态
3. 核对无误后，办理入库手续
4. 将退货移至隔离区（退货区），悬挂黄色待验标识

### 5.4 退货检验

1. 质量控制部收到检验通知后，在3个工作日内完成检验
2. 检验项目根据退货原因确定：

| 退货原因 | 检验项目 |
|----------|----------|
| 质量问题 | 全项检验 + 影响因素分析 |
| 包装破损 | 外观、密封性、微生物检验 |
| 有效期接近 | 稳定性考察加速试验 |
| 客户库存调整 | 外观、含量、有关物质 |
| 疑似假药 | 鉴别、含量、非法添加物 |

3. 检验结果评定：
   - **合格**：可重新入库销售
   - **不合格**：进入不合格品处理流程
   - **不确定**：扩大检验范围或留样观察

### 5.5 退货处置

质量保证部根据检验结果做出处置决定：

| 检验结果 | 处置方式 |
|----------|----------|
| 合格且包装完好 | 重新包装后入库销售 |
| 合格但包装破损 | 更换包装后入库销售 |
| 合格但超过有效期 | 降级使用或销毁 |
| 不合格 | 按不合格品处理 |
| 无法确定 | 隔离存放，继续调查 |

### 5.6 退货记录与报告

1. 质量保证部建立《退货处理记录台账》
2. 每月汇总退货情况，编制《月度退货分析报告》
3. 退货情况纳入产品质量回顾分析

**退货处理记录内容包括**：
- 退货申请编号、日期
- 客户信息
- 药品信息（名称、规格、批号、数量）
- 退货原因分类
- 审核结论
- 检验结果
- 处置方式
- 处理日期、经办人

## 6. 退货原因分类与统计

| 类别 | 代码 | 说明 |
|------|------|------|
| 质量问题 | A | 生产原因导致的质量缺陷 |
| 运输问题 | B | 运输过程导致的损坏 |
| 储存问题 | C | 储存条件不当导致的质量变化 |
| 包装问题 | D | 包装破损、渗漏、污染等 |
| 效期问题 | E | 接近效期或已过效期 |
| 订单问题 | F | 客户订购错误、数量偏差等 |
| 市场问题 | G | 市场策略调整、产品退市等 |
| 其他 | Z | 其他原因 |

## 7. 退货药品的再利用

### 7.1 重新销售条件

退货药品满足以下条件方可重新销售：
- 在有效期内
- 包装完整、标识清晰
- 经质量检验合格
- 储存条件记录完整、合规
- 符合注册批准的所有要求

### 7.2 降级使用

无法按原包装销售但检验合格的药品，可考虑：
- 更换包装
- 降低销售规格
- 用于临床试验
- 作为样品

### 7.3 销毁处理

不符合任何使用条件的退货药品，应：
1. 编制销毁申请
2. 经质量负责人批准
3. 在指定地点进行销毁
4. 记录销毁过程（视频或照片）
5. 保存销毁记录
