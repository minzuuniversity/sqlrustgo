# 供应商审计管理规程

**文件编号**: SMP-QMS-005 | **类别**: 质量管理体系

---

## 1. 目的

建立供应商审计程序，评估和控制物料供应商的质量保证能力，确保采购物料符合要求。

## 2. 适用范围

适用于高原彝药厂所有物料供应商的审计管理。

## 3. 供应商分级

| 级别 | 定义 | 审计频率 |
|------|------|----------|
| A级（关键物料） | 对产品质量有直接影响 | 每年至少1次 |
| B级（重要物料） | 对产品质量有间接影响 | 每2年至少1次 |
| C级（一般物料） | 对产品质量无直接影响 | 每3年至少1次 |

## 4. 职责

| 部门 | 职责 |
|------|------|
| 质量保证部 | 负责供应商审计的组织实施 |
| 采购部 | 负责供应商资料的收集和初步评估 |
| 质量控制部 | 参与物料质量评估 |
| 生产部 | 参与工艺适用性评估 |

## 5. 审计类型

### 5.1 文件审计

| 审核内容 | 要求 |
|----------|------|
| 供应商资质 | 营业执照、GMP证书、药品生产许可证等 |
| 质量体系文件 | 质量手册、验证文件等 |
| 检验报告 | 批检验报告、COA |
| 变更通知能力 | 是否具备变更通知机制 |

### 5.2 现场审计

| 审核内容 | 关注点 |
|----------|--------|
| 厂房设施 | 洁净度、设备状态 |
| 质量控制系统 | 检验设备、人员资质 |
| 生产过程 | 工艺受控状态 |
| 仓储物流 | 储存条件、防护措施 |

## 6. 审计程序

| 步骤 | 内容 | 时间节点 |
|------|------|----------|
| 审计计划 | 制定年度审计计划 | 每年1月 |
| 审计通知 | 提前通知供应商 | 审计前2周 |
| 审计实施 | 现场审计或文件审计 | 计划日期 |
| 审计报告 | 编写审计报告 | 审计后10个工作日 |
| 缺陷整改 | 供应商提交整改报告 | 收到报告后30日 |
| 批准确认 | 质量负责人批准 | 整改验证后 |

## 7. 审计判定标准

| 审计结果 | 判定标准 | 处理措施 |
|----------|----------|----------|
| 合格 | 无主要缺陷或轻微缺陷 | 列入批准供应商名单 |
| 有条件合格 | 有主要缺陷但已整改 | 列入名单，加强监控 |
| 不合格 | 有严重缺陷或整改不到位 | 从名单中移除 |

## 8. 供应商监控

1. 定期收集供应商质量信息
2. 物料质量问题及时反馈
3. 关键物料实施驻厂监控（必要时）
4. 建立供应商质量档案

## 9. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 供应商审计报告 | 10年 | 质量保证部 |
| 供应商资料 | 供应商资质终止后5年 | 质量保证部 |
| 供应商批准名单 | 5年 | 质量保证部 |
