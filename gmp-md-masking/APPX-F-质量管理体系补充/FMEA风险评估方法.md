# FMEA 风险评估方法

**文件编号**: SMP-QMS-011 | **类别**: 风险管理

---

## 1. 目的

提供FMEA风险评估方法指南，规范风险评估操作。

## 2. FMEA概述

FMEA（失效模式与影响分析）是一种系统性风险评估方法。

## 3. FMEA评分标准

| 参数 | 评分 | 说明 |
|------|------|------|
| 严重性(S) | 1-10 | 失效影响的严重程度 |
| 可能性(O) | 1-10 | 失效发生的可能性 |
| 可检测性(D) | 1-10 | 失效被检测的难易程度 |

## 4. RPN计算

| 公式 | 说明 |
|------|------|
| RPN = S × O × D | 风险优先数 |
| RPN范围 | 1-1000 |

## 5. 风险等级判定

| RPN范围 | 风险等级 | 处理措施 |
|---------|----------|----------|
| 1-100 | 低风险 | 可接受 |
| 101-200 | 中风险 | 需要关注 |
| 201-500 | 高风险 | 必须整改 |
| >500 | 严重风险 | 立即整改 |

## 6. FMEA实施步骤

| 步骤 | 内容 |
|------|------|
| 1 | 确定分析对象 |
| 2 | 识别潜在失效模式 |
| 3 | 分析失效影响 |
| 4 | 评估S、O、D |
| 5 | 计算RPN |
| 6 | 制定改进措施 |
| 7 | 跟踪验证 |
