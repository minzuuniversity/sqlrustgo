# 药品不良反应监测管理规程

**文件编号**: SMP-QMS-008 | **类别**: 质量管理体系

---

## 1. 目的

建立药品不良反应监测体系，系统收集、分析和报告药品不良反应信息，保障患者用药安全。

## 2. 适用范围

适用于高原彝药厂所有药品的不良反应监测管理。

## 3. 职责

| 部门 | 职责 |
|------|------|
| 质量保证部 | 不良反应监测的组织管理 |
| 药事服务部 | 临床不良反应信息收集 |
| 注册部 | 不良反应法规报告 |
| 医学部 | 不良反应医学评估 |

## 4. 不良反应分类

| 分类 | 定义 | 报告时限 |
|------|------|----------|
| 严重不良反应 | 导致死亡、危及生命、致畸、致残等 | 15日内报告 |
| 新的不良反应 | 药品说明书中未记载的不良反应 | 15日内报告 |
| 一般不良反应 | 其他类型的不良反应 | 定期汇总报告 |

## 5. 不良反应信息收集

| 信息来源 | 收集方式 |
|----------|----------|
| 医疗机构 | 拜访、函电、文献检索 |
| 销售团队 | 客户拜访报告 |
| 监管部门 | 转发的不良反应报告 |
| 文献资料 | 定期检索医学文献 |
| 上市后研究 | 主动监测数据 |

## 6. 不良反应报告内容

| 报告要素 | 要求 |
|----------|------|
| 基本信息 | 患者信息、联系方式 |
| 药品信息 | 药品名称、批号、规格、用法用量 |
| 不良反应信息 | 症状、体征、检查结果 |
| 时间关系 | 用药时间与反应时间关系 |
| 合并用药 | 其他药物使用情况 |
| 处置情况 | 不良反应处理经过 |
| 随访信息 | 后续跟踪信息 |

## 7. 信号检测与分析

| 分析方法 | 内容 |
|----------|------|
| 个例分析 | 逐一分析每个报告 |
| 聚集性分析 | 识别时间/地区聚集 |
| 发生率估算 | 计算不良反应发生率 |
| 风险因素 | 分析易感因素 |

## 8. 监管部门报告

| 报告类型 | 报告对象 | 报告时限 |
|----------|----------|----------|
| 个例报告 | 国家药品不良反应监测中心 | 15日内（严重） |
| 定期报告 | 国家药品不良反应监测中心 | 每年3月31日前 |

## 9. 风险控制措施

根据不良反应监测结果，适时采取：
- 说明书修订
- 风险沟通
- 暂停销售
- 召回

## 10. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 不良反应报告表 | 10年 | 质量保证部 |
| 不良反应分析报告 | 10年 | 质量保证部 |
| 监管部门通信记录 | 10年 | 注册部 |
