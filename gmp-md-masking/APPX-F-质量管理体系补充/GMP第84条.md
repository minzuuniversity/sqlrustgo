# GMP 第八十四条

**文件编号**: GMP-084 | **类别**: GMP条款原文

---

## 原文

第八十四条　质量控制部门应当制定检验规程，检验规程应当包括检验项目、检验方法、检验仪器设备、试剂和标准品、采样方案、检验结果判定标准等内容。

---

## 解读

### 关键要素

| 要素 | 要求 |
|------|------|
| 检验项目 | 必须覆盖法定标准和企业内控标准 |
| 检验方法 | 优先使用药典方法，必要时验证 |
| 仪器设备 | 满足检验要求，定期校验 |
| 试剂标准品 | 合规来源，规范管理 |
| 采样方案 | 代表性、科学性 |
| 结果判定 | 明确判定标准 |

### 实施要点

1. **检验规程编制**
   - 依据法定标准
   - 结合产品特性
   - 经过验证确认

2. **检验规程审核批准**
   - 质量部负责人审核
   - 质量受权人批准

3. **检验规程变更控制**
   - 重大变更需验证
   - 记录变更原因
