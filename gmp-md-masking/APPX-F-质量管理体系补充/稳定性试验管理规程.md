# 稳定性试验管理规程

**文件编号**: SMP-QMS-011 | **类别**: 质量管理体系

---

## 1. 目的

建立稳定性试验程序，评价药品在规定的储存条件下的质量变化趋势，为药品有效期设定和储存条件提供依据。

## 2. 适用范围

适用于高原彝药厂所有药品的稳定性试验管理。

## 3. 职责

| 部门 | 职责 |
|------|------|
| 质量控制部 | 稳定性试验的实施和样品管理 |
| 质量保证部 | 稳定性方案的批准和结果评价 |
| 注册部 | 注册申报相关稳定性数据 |
| 仓储部 | 留样室条件保证 |

## 4. 稳定性试验类型

| 试验类型 | 目的 | 试验周期 |
|----------|------|----------|
| 影响因素试验 | 考察极端条件影响 | 短期（5-30天） |
| 加速试验 | 预测长期稳定性 | 6个月 |
| 长期试验 | 确定有效期依据 | 不少于36个月 |
| 变更后稳定性 | 变更后稳定性评估 | 按变更级别 |

## 5. 稳定性试验条件

| 气候类型 | 温度 | 湿度 | 适用条件 |
|----------|------|------|----------|
| 常温 | 25±2°C | 60±5%RH | 常温储存产品 |
| 冷藏 | 5±3°C | - | 冷藏产品 |
| 冷冻 | -20±5°C | - | 冷冻产品 |
| 中等温度 | 30±2°C | 65±5%RH | 亚热带气候 |

## 6. 稳定性试验指标

| 检验项目 | 检验频率 | 关注指标 |
|----------|----------|----------|
| 性状 | 每次点 | 颜色、形态 |
| 含量 | 每次点 | 含量变化 |
| 有关物质 | 每次点 | 新增杂质、总杂 |
| 溶出度/崩解时限 | 每次点 | 变化情况 |
| 水分 | 每次点 | 水分变化 |
| 微生物限度 | 选择性 | 如适用 |

## 7. 稳定性试验方案

| 方案要素 | 内容要求 |
|----------|----------|
| 试验目的 | 明确试验目的 |
| 样品信息 | 批号、规格、批量 |
| 试验条件 | 温度、湿度、光照条件 |
| 检验项目 | 具体检验指标和方法 |
| 取样时间点 | 0、3、6、9、12、18、24、36个月 |
| 接受标准 | 各时间点的接受标准 |
| 试验设备 | 温湿度控制设备 |
| 试验周期 | 总试验周期 |

## 8. 取样要求

| 要求 | 内容 |
|------|------|
| 样品数量 | 足够全检量×计划取样次数+留样 |
| 样品摆放 | 避免样品间相互影响 |
| 取样方式 | 按时间点从指定位置取样 |
| 取样记录 | 详细记录取样信息 |

## 9. 稳定性结果评价

| 评价要素 | 内容 |
|----------|------|
| 数据完整性 | 所有时间点数据齐全 |
| 趋势分析 | 关键指标变化趋势 |
| 统计方法 | 适当统计分析方法 |
| 结论建议 | 有效期、储存条件建议 |

## 10. 稳定性数据管理

- 原始数据保存原始记录
- 电子数据定期备份
- 数据可追溯至具体批次
- 稳定性图谱存档

## 11. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 稳定性试验方案 | 10年 | 质量控制部 |
| 稳定性试验报告 | 10年 | 质量控制部 |
| 原始检验记录 | 10年 | 质量控制部 |
| 稳定性样品台账 | 10年 | 质量控制部 |
