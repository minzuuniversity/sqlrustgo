# 设备验证管理规程

**文件编号**: SMP-VAL-001 | **类别**: 验证与确认

---

## 1. 目的

建立设备验证程序，确保设备符合预期用途，满足生产要求。

## 2. 适用范围

适用于高原彝药厂所有生产设备和检验设备的验证。

## 3. 验证阶段

| 阶段 | 内容 | 目的 |
|------|------|------|
| DQ | 设计确认 | 确认设计符合要求 |
| IQ | 安装确认 | 确认安装正确 |
| OQ | 运行确认 | 确认运行正常 |
| PQ | 性能确认 | 确认性能稳定 |

## 4. 职责

| 部门 | 职责 |
|------|------|
| 质量保证部 | 验证总体管理 |
| 工程设备部 | 设备验证执行 |
| 使用部门 | 配合验证 |
| 质量控制部 | 检验相关验证 |

## 5. 验证流程

| 步骤 | 内容 |
|------|------|
| 1 | 制定验证方案 |
| 2 | 审核批准方案 |
| 3 | 执行验证 |
| 4 | 记录验证数据 |
| 5 | 编写验证报告 |
| 6 | 批准验证报告 |

## 6. 验证周期

| 类型 | 周期 |
|------|------|
| 新设备验证 | 使用前 |
| 再验证 | 定期或变更后 |
| 重大维修后 | 维修后 |

## 7. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 验证方案 | 10年 | 质量保证部 |
| 验证报告 | 10年 | 质量保证部 |
| 验证记录 | 10年 | 质量保证部 |
