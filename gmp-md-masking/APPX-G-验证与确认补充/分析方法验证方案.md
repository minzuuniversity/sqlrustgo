# 分析方法验证方案

**文件编号**: VP-QC-001 | **类别**: 验证与确认

---

## 1. 目的

验证分析方法能够准确、可靠地检测样品。

## 2. 适用范围

适用于高原彝药厂所有检验方法。

## 3. 验证参数

| 参数 | 说明 | 要求 |
|------|------|------|
| 特异性 | 区分目标物质 | 必须 |
| 准确性 | 与真值接近 | 必须 |
| 精密度 | 重复性 | 必须 |
| 检测限 | 最低检测量 | 必须 |
| 定量限 | 最低定量量 | 必须 |
| 线性 | 成线性关系 | 必须 |
| 范围 | 线性范围 | 必须 |
| 耐用性 | 条件变化时稳定 | 必须 |

## 4. 验证流程

| 步骤 | 内容 |
|------|------|
| 1 | 制定验证方案 |
| 2 | 执行验证实验 |
| 3 | 收集数据 |
| 4 | 数据分析 |
| 5 | 编写验证报告 |
