# 制药用水系统验证方案

**文件编号**: VP-FAC-002 | **类别**: 验证与确认

---

## 1. 目的

验证制药用水系统能够持续、稳定地生产符合标准的制药用水。

## 2. 适用范围

适用于高原彝药厂纯化水和注射用水系统。

## 3. 系统描述

| 项目 | 描述 |
|------|------|
| 系统类型 | 纯化水系统、注射用水系统 |
| 产水能力 | 按设计 |
| 储存方式 | 循环储存 |

## 4. 验证阶段

| 阶段 | 内容 |
|------|------|
| DQ | 设计确认 |
| IQ | 安装确认 |
| OQ | 运行确认 |
| PQ | 性能确认 |

## 5. IQ确认项目

| 项目 | 接受标准 |
|------|----------|
| 设备安装 | 符合设计 |
| 材质 | 316L不锈钢 |
| 管道连接 | 无死角 |
| 电气 | 正确 |

## 6. OQ确认项目

| 项目 | 接受标准 |
|------|----------|
| 电导率显示 | 正确 |
| 温度控制 | 正常 |
| 报警功能 | 正常 |
| 消毒功能 | 正常 |

## 7. PQ确认项目

| 项目 | 接受标准 |
|------|----------|
| 纯化水水质 | 符合药典 |
| 注射用水水质 | 符合药典 |
| 微生物 | 符合限度 |
| 运行稳定性 | 持续合格 |
