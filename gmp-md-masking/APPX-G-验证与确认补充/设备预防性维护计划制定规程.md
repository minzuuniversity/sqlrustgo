# 设备预防性维护计划制定规程

**文件编号**: SMP-VAL-005 | **类别**: 验证与确认

---

## 1. 目的

建立设备预防性维护计划制定程序，确保设备持续稳定运行。

## 2. 适用范围

适用于高原彝药厂所有生产设备的预防性维护。

## 3. 职责

| 部门 | 职责 |
|------|------|
| 工程设备部 | 制定和维护计划 |
| 使用部门 | 配合维护 |
| 质量保证部 | 监督 |

## 4. 维护分类

| 类型 | 频率 | 内容 |
|------|------|------|
| 日维护 | 每日 | 清洁、检查 |
| 周维护 | 每周 | 润滑、紧固 |
| 月维护 | 每月 | 全面检查 |
| 季维护 | 每季 | 调整、校准 |
| 年维护 | 每年 | 全面维护 |

## 5. 维护计划内容

| 内容 | 说明 |
|------|------|
| 设备信息 | 名称、编号 |
| 维护项目 | 具体维护内容 |
| 维护周期 | 执行频率 |
| 备件需求 | 需要更换的备件 |
| 执行人 | 负责人员 |

## 6. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 维护计划 | 5年 | 工程设备部 |
| 维护记录 | 5年 | 工程设备部 |
