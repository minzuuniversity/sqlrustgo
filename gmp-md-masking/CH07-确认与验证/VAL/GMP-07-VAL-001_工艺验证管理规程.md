# 工艺验证管理规程

**文件编号**: SMP-VAL-003 | **类别**: 验证与确认

---

## 1. 目的

建立工艺验证程序，证明生产工艺能够持续、稳定地生产出符合标准的产品。

## 2. 适用范围

适用于高原彝药厂所有产品生产工艺的验证。

## 3. 工艺验证类型

| 类型 | 说明 | 时机 |
|------|------|------|
| 前验证 | 新工艺/产品首次验证 | 使用前 |
| 同步验证 | 工艺在生产中验证 | 持续工艺确认 |
| 回顾性验证 | 基于历史数据验证 | 已运行工艺 |
| 再验证 | 变更后验证 | 变更后 |

## 4. 工艺验证要求

| 要求 | 内容 |
|------|------|
| 连续批次 | 通常3批 |
| 工艺参数 | 在规定范围内 |
| 过程控制 | 符合控制策略 |
| 成品检验 | 符合质量标准 |

## 5. 验证流程

| 步骤 | 内容 |
|------|------|
| 1 | 制定工艺验证方案 |
| 2 | 审核批准方案 |
| 3 | 执行验证批次 |
| 4 | 数据收集分析 |
| 5 | 编写验证报告 |
| 6 | 批准验证报告 |

## 6. 关键工艺参数

| 参数类型 | 说明 |
|----------|------|
| CPP | 关键工艺参数 |
| CQA | 关键质量属性 |

## 7. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 工艺验证方案 | 10年 | 质量保证部 |
| 工艺验证报告 | 10年 | 质量保证部 |
| 批记录 | 5年 | 生产部 |
