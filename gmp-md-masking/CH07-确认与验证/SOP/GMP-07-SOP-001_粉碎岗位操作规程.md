# 粉碎岗位操作规程

**文件编号**: SOP-PROD-002 | **类别**: 生产管理

---

## 1. 目的

规范粉碎岗位操作，确保粉碎工艺符合要求，保证产品质量。

## 2. 适用范围

适用于高原彝药厂粉碎岗位的所有操作。

## 3. 设备

| 设备名称 | 设备编号 |
|----------|----------|
| 粉碎机 | EQUP-PROD-001 |

## 4. 操作前准备

| 准备项目 | 内容 | 要求 |
|----------|------|------|
| 环境检查 | 确认清场合格 | 符合生产条件 |
| 设备检查 | 确认清洁状态 | 有设备清洁标识 |
| 物料检查 | 确认物料信息 | 批号、规格、重量 |
| 个人防护 | 佩戴防护用品 | 口罩、手套、工作服 |

## 5. 操作流程

### 5.1 粉碎前检查

| 步骤 | 内容 |
|------|------|
| 1 | 确认设备清洁，悬挂"已清洁"状态标识 |
| 2 | 检查筛网规格是否符合工艺要求 |
| 3 | 检查设备各部件是否紧固 |
| 4 | 确认粉碎机门锁紧 |
| 5 | 确认集尘布袋安装正确 |

### 5.2 投料粉碎

| 步骤 | 操作内容 | 要点 |
|------|----------|------|
| 1 | 将原药材放入料斗 | 均匀投放，不过量 |
| 2 | 启动粉碎机 | 先开风机，后开主机 |
| 3 | 监控运行状态 | 注意电流、温度 |
| 4 | 粉碎完成确认 | 确认药材全部粉碎 |
| 5 | 停机 | 先停主机，后停风机 |

### 5.3 粉碎后操作

| 步骤 | 内容 |
|------|------|
| 1 | 打开粉碎室门 |
| 2 | 收集粉碎物料 |
| 3 | 清理设备内壁 |
| 4 | 检查筛网是否有破损 |
| 5 | 填写粉碎记录 |

## 6. 工艺参数

| 参数 | 要求 |
|------|------|
| 粉碎时间 | 根据物料性质 |
| 粉碎细度 | 符合工艺要求 |
| 进料速度 | 均匀进料 |

## 7. 质量控制点

| 控制点 | 要求 |
|--------|------|
| 粉碎前物料确认 | 物料信息正确 |
| 筛网规格确认 | 符合工艺要求 |
| 粉碎细度 | 符合标准 |
| 异物检查 | 无金属异物 |

## 8. 异常情况处理

| 异常 | 处理方式 |
|------|----------|
| 异常声响 | 立即停机检查 |
| 电流过大 | 减少进料量或停机 |
| 物料温度过高 | 暂停粉碎，冷却 |

## 9. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 粉碎岗位记录 | 5年 | 生产部 |
| 设备清洁记录 | 5年 | 生产部 |
