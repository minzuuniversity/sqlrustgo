# 清场管理规程

**文件编号**: SMP-PROD-003 | **类别**: 生产管理

---

## 1. 目的

规范生产车间清场管理，防止交叉污染和混淆，确保产品质量。

## 2. 适用范围

适用于高原彝药厂所有生产区域的清场管理。

## 3. 职责

| 部门 | 职责 |
|------|------|
| 生产车间 | 执行清场操作 |
| 质量保证部 | 清场结果监督 |
| 设备部 | 设备清洁技术支持 |

## 4. 清场分类

| 类型 | 触发条件 | 清场要求 |
|------|----------|----------|
| 每日清场 | 每日生产结束 | 全面清洁消毒 |
| 换品种清场 | 不同品种切换 | 彻底清洁 |
| 换批次清场 | 同品种换批次 | 一般清洁 |
| 换规格清场 | 不同规格切换 | 彻底清洁 |
| 停产清场 | 长时间停产恢复 | 全面清洁验证 |

## 5. 清场内容

### 5.1 物料清理

| 项目 | 要求 |
|------|------|
| 本批物料 | 退回仓库或转入下批 |
| 剩余物料 | 标识清楚，隔离存放 |
| 散落物料 | 收集或清理 |

### 5.2 设备清洁

| 项目 | 要求 |
|------|------|
| 设备内表面 | 清洁无残留 |
| 设备外表面 | 清洁无灰尘 |
| 输送管道 | 按清洁规程执行 |
| 清洁效果 | 目视检查合格 |

### 5.3 环境清洁

| 项目 | 要求 |
|------|------|
| 地面 | 无积尘、无物料残留 |
| 墙壁 | 无积尘、无蜘蛛网 |
| 天花板 | 无积尘 |
| 灯具 | 无积尘 |
| 地漏 | 清洁畅通 |

### 5.4 工器具清洁

| 项目 | 要求 |
|------|------|
| 生产用具 | 清洁后存放 |
| 容器具 | 清洁消毒 |
| 个人防护用品 | 清洁或报废处理 |

### 5.5 文件清理

| 项目 | 要求 |
|------|------|
| 批记录 | 收集整理 |
| 状态标识 | 更新为"已清洁" |
| 清洁标识 | 挂贴设备清洁状态牌 |

## 6. 清场程序

| 步骤 | 内容 |
|------|------|
| 准备 | 准备清洁工具和物料 |
| 清理 | 移除所有物料和废料 |
| 粗清 | 初步清洁表面 |
| 精清 | 详细清洁所有表面 |
| 消毒 | 按规定消毒 |
| 检查 | 质量监督员检查 |
| 记录 | 填写清场记录 |

## 7. 清场检查

| 检查类型 | 检查人 | 检查时机 |
|----------|--------|----------|
| 自查 | 操作人员 | 清场过程中 |
| 监督 | 班组长 | 清场完成后 |
| 确认 | QA监督员 | 下批生产前 |

## 8. 清场记录

清场记录应包括：
- 清场区域/设备
- 清场时间
- 清场内容
- 使用清洁剂/消毒剂
- 清场人员
- 检查确认

## 9. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 清场记录 | 5年 | 生产部 |
| 清洁效果确认记录 | 5年 | 质量保证部 |
