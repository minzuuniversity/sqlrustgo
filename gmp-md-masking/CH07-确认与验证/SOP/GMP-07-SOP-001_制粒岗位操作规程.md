# 制粒岗位操作规程

**文件编号**: SOP-PROD-003 | **类别**: 生产管理

---

## 1. 目的

规范制粒岗位操作，确保制粒工艺符合要求，保证产品质量。

## 2. 适用范围

适用于高原彝药厂制粒岗位的所有操作。

## 3. 设备

| 设备名称 | 设备编号 |
|----------|----------|
| 制粒机 | EQUP-PROD-002 |
| 整粒机 | EQUP-PROD-003 |

## 4. 操作前准备

| 准备项目 | 内容 | 要求 |
|----------|------|------|
| 环境检查 | 确认清场合格 | 符合生产条件 |
| 设备检查 | 确认清洁状态 | 有设备清洁标识 |
| 模具检查 | 确认模具规格 | 符合工艺要求 |
| 物料检查 | 确认物料信息 | 粉末细度、水分 |
| 个人防护 | 佩戴防护用品 | 口罩、手套、工作服 |

## 5. 操作流程

### 5.1 制粒前准备

| 步骤 | 内容 |
|------|------|
| 1 | 确认设备清洁状态 |
| 2 | 安装符合规格的筛网/模具 |
| 3 | 调整工艺参数（转速、压力） |
| 4 | 预热设备至设定温度 |

### 5.2 制粒操作

| 步骤 | 操作内容 | 要点 |
|------|----------|------|
| 1 | 加入粘合剂溶液 | 浓度、温度符合要求 |
| 2 | 启动混合 | 使粉末与粘合剂混合均匀 |
| 3 | 开始制粒 | 观察颗粒形成情况 |
| 4 | 调整参数 | 根据颗粒情况调整 |
| 5 | 粒度达标后出料 | 确认颗粒符合要求 |

### 5.3 整粒操作

| 步骤 | 内容 |
|------|------|
| 1 | 将湿颗粒转移至整粒机 |
| 2 | 调整整粒机转速 |
| 3 | 整粒至目标粒度 |
| 4 | 收集整粒后颗粒 |

### 5.4 干燥

| 步骤 | 内容 |
|------|------|
| 1 | 将颗粒铺入干燥盘 | 厚度均匀 |
| 2 | 设置干燥参数 | 温度、时间 |
| 3 | 干燥过程监控 | 定期翻动 |
| 4 | 干燥终点判断 | 水分达标 |

## 6. 工艺参数

| 参数 | 要求 |
|------|------|
| 粘合剂浓度 | 按工艺配方 |
| 混合时间 | 确保混合均匀 |
| 颗粒大小 | 符合标准 |
| 干燥温度 | 按工艺规定 |
| 干燥时间 | 至水分达标 |

## 7. 质量控制点

| 控制点 | 要求 |
|--------|------|
| 粘合剂加入量 | 按配方准确加入 |
| 颗粒大小分布 | 符合标准 |
| 颗粒松密度 | 符合标准 |
| 干燥后水分 | 符合标准 |
