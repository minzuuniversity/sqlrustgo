# 清洁验证总计划

**文件编号:** VP-QA-CV-001
**版本号:** V1.0

## 1. 目的

建立清洁验证策略，证明清洁操作规程能有效去除残留物，防止交叉污染。

## 2. 范围

适用于所有与产品接触的设备清洁验证：
- 生产设备（反应罐、离心机、干燥箱、粉碎机等）
- 包装设备
- 工艺用水系统
- 清洁工具

## 3. 清洁验证策略

### 3.1 清洁剂选择
- 应选择易于去除的清洁剂
- 清洁剂残留应符合要求
- 优先选择无残留或低残留清洁剂

### 3.2 残留限度

| 残留类型 | 限度标准 |
|---------|---------|
| 活性成分 | 0.1% of minimum therapeutic dose |
| 清洁剂 | 10ppm或10μg/cm² |
| 微生物 | 25CFU/25cm² |
| 内毒素 | 0.5EU/ml |

### 3.3 擦拭取样
- 擦拭取样方法：棉签擦拭法
- 取样位置：最难清洁部位
- 检验项目：化学残留、微生物

### 3.4 淋洗取样
- 最后一轮淋洗液取样
- 检验项目：活性成分残留

## 4. 验证批次

- 连续3批生产后清洁验证
- 定期再验证（每年1次或重大变更后）
