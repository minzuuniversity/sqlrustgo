# 生产过程质量监控规程

**文件编号**: SMP-PROD-004 | **类别**: 生产管理

---

## 1. 目的

建立生产过程质量监控程序，确保生产过程持续受控，产品质量稳定。

## 2. 适用范围

适用于高原彝药厂所有生产过程的监控。

## 3. 职责

| 部门 | 职责 |
|------|------|
| 质量保证部 | 过程监控的组织实施 |
| 生产车间 | 配合监控，执行纠正 |
| 质量控制部 | 过程样品检验 |

## 4. 监控类型

| 类型 | 频率 | 监控内容 |
|------|------|----------|
| 连续监控 | 实时 | 关键参数连续记录 |
| 定时监控 | 每小时/每班 | 规定时间点检查 |
| 巡回监控 | 每天 | 生产区域巡视 |
| 定点监控 | 关键工序 | 重点工序蹲守 |

## 5. 监控项目

### 5.1 工艺参数监控

| 参数类别 | 监控内容 | 监控方式 |
|----------|----------|----------|
| 温度 | 灭菌温度、干燥温度 | 连续记录 |
| 湿度 | 制粒湿度、环境湿度 | 连续记录 |
| 压力 | 压缩空气压力、过滤压力 | 连续记录 |
| 时间 | 混合时间、干燥时间 | 记录关键时间点 |
| 物料量 | 称量投料量 | 复核确认 |

### 5.2 环境监控

| 项目 | 监控点 | 监控频率 |
|------|--------|----------|
| 温湿度 | 各生产区域 | 每班2次 |
| 压差 | 洁净区与非洁净区 | 连续 |
| 尘埃粒子 | 关键区域 | 定期 |
| 微生物 | 关键区域表面 | 定期 |

### 5.3 物料监控

| 监控内容 | 监控方式 |
|----------|----------|
| 物料标识 | 现场检查 |
| 物料状态 | 现场检查 |
| 物料使用 | 投料复核 |
| 物料流向 | 追溯检查 |

### 5.4 设备状态监控

| 监控内容 | 监控方式 |
|----------|----------|
| 设备运行状态 | 运行记录 |
| 设备参数 | 参数记录 |
| 设备清洁状态 | 状态标识检查 |
| 设备维护状态 | 维护记录检查 |

## 6. 监控实施

| 步骤 | 内容 |
|------|------|
| 制定计划 | 制定监控计划 |
| 准备工具 | 准备检查工具和记录表 |
| 实施检查 | 按计划进行检查 |
| 记录结果 | 实时记录检查情况 |
| 异常处理 | 发现异常及时处理 |

## 7. 异常处理

| 异常级别 | 处理方式 |
|----------|----------|
| 轻微偏差 | 现场纠正，记录 |
| 一般偏差 | 报告主管，启动偏差处理 |
| 严重偏差 | 立即停止生产，启动偏差调查 |

## 8. 监控报告

| 报告类型 | 报告内容 | 报告周期 |
|----------|----------|----------|
| 日常报告 | 当日监控情况 | 每日 |
| 周报 | 本周监控汇总 | 每周 |
| 月报 | 本月监控分析 | 每月 |

## 9. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 过程监控记录 | 5年 | 质量保证部 |
| 环境监控记录 | 5年 | 质量控制部 |
| 监控周报/月报 | 5年 | 质量保证部 |
