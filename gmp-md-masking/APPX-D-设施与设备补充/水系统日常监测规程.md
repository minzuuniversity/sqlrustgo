# 水系统日常监测规程

**文件编号**: SP-FAC-006
**版本**: V1.0
**生效日期**: 2026-01-01
**审核人**: __________
**批准人**: __________

---

## 1. 目的

建立制药用水系统日常监测管理规范，确保制药用水质量持续符合要求，防止因水系统问题导致药品质量事故，符合《药品生产质量管理规范（2010年修订）》第六十五条要求。

---

## 2. 范围

适用于公司制药用水系统的日常监测，包括：
- 纯化水系统
- 注射用水系统
- 清洗用水系统

---

## 3. 职责

| 部门/岗位 | 职责 |
|-----------|------|
| 质量控制部 | 负责水系统日常监测取样、检验 |
| 设备工程部 | 负责水系统运行维护 |
| 质量保证部 | 负责监测数据审核、异常处理 |

## 4. 制药用水质量标准

### 4.1 纯化水质量标准

| 检验项目 | 质量标准 | 检验周期 |
|----------|----------|----------|
| 性状 | 无色澄清液体 | 每天 |
| pH值 | 5.0-7.0 | 每天 |
| 电导率 | ≤5.1 μS/cm (25℃) | 每天 |
| 氨 | ≤0.02 μg/mL | 每周 |
| 硝酸盐 | ≤0.06 μg/mL | 每周 |
| 重金属 | ≤0.1 μg/mL | 每周 |
| 微生物限度 | ≤100 CFU/mL | 每周 |
| 总有机碳(TOC) | ≤0.5 mg/L | 每天 |

### 4.2 注射用水质量标准

| 检验项目 | 质量标准 | 检验周期 |
|----------|----------|----------|
| 性状 | 无色澄清液体 | 每天 |
| pH值 | 5.0-7.0 | 每天 |
| 电导率 | ≤1.3 μS/cm (25℃) | 每天 |
| 氨 | ≤0.02 μg/mL | 每周 |
| 硝酸盐 | ≤0.06 μg/mL | 每周 |
| 重金属 | ≤0.1 μg/mL | 每周 |
| 细菌内毒素 | ≤0.25 EU/mL | 每周 |
| 微生物限度 | ≤10 CFU/mL | 每天 |
| 总有机碳(TOC) | ≤0.5 mg/L | 每天 |

## 5. 日常监测项目与频率

### 5.1 在线监测（连续）

| 监测参数 | 监测位置 | 标准 | 报警限 |
|----------|----------|------|--------|
| 电导率 | 总出水口 | 纯化水≤5.1，注射用水≤1.3 | 超出限值报警 |
| 温度 | 注射用水储罐 | 70-85℃（保温）或≤25℃（巴氏消毒后） | 超出范围报警 |
| TOC | 总出水口 | ≤0.5 mg/L | 超出限值报警 |
| 流量 | 总出水口 | 正常流速 | 流量异常报警 |

### 5.2 手动监测（每日）

| 监测参数 | 取样位置 | 监测时间 |
|----------|----------|----------|
| pH值 | 总出水口 | 每天上午8:00-10:00 |
| 电导率 | 总出水口 | 每天上午8:00-10:00 |
| 温度 | 储罐、用水点 | 每天上午8:00-10:00 |

### 5.3 定期监测

| 监测项目 | 纯化水 | 注射用水 | 监测频率 |
|----------|--------|----------|----------|
| 全项化学检验 | 每季度 | 每季度 | 每季度 |
| 微生物限度 | 每周 | 每天 | 按频率 |
| 细菌内毒素 | - | 每周 | 每周 |
| TOC | 每天 | 每天 | 每天 |
| 管网监测点 | 每周 | 每周 | 按监测计划 |

## 6. 取样要求

### 6.1 取样点设置

| 用水类型 | 取样点数量 | 取样点位置 |
|----------|------------|------------|
| 纯化水 | 至少3个 | 总出水口 + 最远用水点 + 关键用水点 |
| 注射用水 | 至少5个 | 总出水口 + 储罐出口 + 最远用水点 + 关键用水点×2 |

### 6.2 取样操作

| 步骤 | 操作要求 |
|------|----------|
| 取样前准备 | 准备已灭菌的取样瓶、酒精灯、止血钳等 |
| 取样点消毒 | 用酒精灯火焰灭菌取样口，冷却后取样 |
| 取样量 | 微生物检验取100mL，化学检验取500mL |
| 取样操作 | 缓慢打开阀门，弃去初流约100mL后取样 |
| 标识 | 粘贴取样标识，注明取样点、日期、时间 |
| 送检 | 尽快送检，微生物样品2小时内送检 |

## 7. 监测操作规程

### 7.1 pH值测定

**仪器**：精密pH计
**操作步骤**：
1. pH计校准（使用标准缓冲液）
2. 用待测水样冲洗电极3次
3. 测量样品pH值
4. 记录结果
5. 再次校准确认

**合格标准**：
- 纯化水：5.0-7.0
- 注射用水：5.0-7.0

### 7.2 电导率测定

**仪器**：电导率仪
**操作步骤**：
1. 检查仪器状态
2. 电导率仪校准（使用标准溶液）
3. 用待测水样冲洗电导池3次
4. 测量样品电导率
5. 记录结果（温度补偿至25℃）

**合格标准**：
- 纯化水：≤5.1 μS/cm (25℃)
- 注射用水：≤1.3 μS/cm (25℃)

### 7.3 微生物限度检测

**仪器/设备**：培养箱、薄膜过滤器、无菌取样瓶
**操作步骤**：
1. 取样（100mL）
2. 薄膜过滤
3. 冲洗（无菌生理盐水）
4. 培养（30-35℃，5天）
5. 计数
6. 记录结果

**合格标准**：
- 纯化水：≤100 CFU/mL
- 注射用水：≤10 CFU/mL

### 7.4 细菌内毒素检测

**方法**：鲎试剂法（LAL）
**操作步骤**：
1. 取样（按说明书要求）
2. 样品处理（如需要）
3. 加鲎试剂
4. 培养（37±1℃，60±5分钟）
5. 结果判定
6. 记录结果

**合格标准**：注射用水≤0.25 EU/mL

### 7.5 TOC检测

**仪器**：TOC分析仪
**操作步骤**：
1. 仪器校准
2. 空白测定
3. 样品测定
4. 记录结果

**合格标准**：≤0.5 mg/L

## 8. 监测结果判定

### 8.1 单项判定

| 监测项目 | 合格标准 | 不合格处理 |
|----------|----------|------------|
| pH值 | 5.0-7.0 | 重新取样检测 |
| 电导率 | 符合规定限值 | 重新取样检测 |
| 微生物限度 | 符合规定限值 | 启动偏差调查 |
| 细菌内毒素 | ≤0.25 EU/mL | 启动偏差调查 |
| TOC | ≤0.5 mg/L | 重新取样检测 |

### 8.2 综合判定

| 判定结果 | 处理方式 |
|----------|----------|
| 全部合格 | 放行使用 |
| 单项不合格 | 重新取样复检 |
| 微生物不合格 | 启动偏差调查，排查原因 |
| 内毒素不合格 | 立即停产，启动偏差调查 |

## 9. 异常情况处理

### 9.1 报警处理流程

```
系统报警 → 确认报警真实性 
→ 评估对产品质量的影响 → 排查原因 
→ 采取纠正措施 → 验证系统正常 → 恢复生产
```

### 9.2 微生物超标处理

| 步骤 | 操作 |
|------|------|
| 1 | 确认超标结果 |
| 2 | 重新取样检测 |
| 3 | 排查污染来源（取样点、系统、管路） |
| 4 | 系统消毒/灭菌 |
| 5 | 连续监测验证消毒效果 |
| 6 | 必要时扩大监测范围 |
| 7 | 评估对产品的影响 |
| 8 | 编制偏差报告 |

### 9.3 内毒素超标处理

| 步骤 | 操作 |
|------|------|
| 1 | 确认超标结果 |
| 2 | 重新取样检测 |
| 3 | 检查注射用水系统运行状态 |
| 4 | 系统全面检查（密封、保温、管路） |
| 5 | 对系统进行灭菌处理 |
| 6 | 连续监测内毒素水平 |
| 7 | 评估对产品的影响 |
| 8 | 编制偏差报告 |

## 11. 水系统维护

### 11.1 日常维护

| 项目 | 频率 | 内容 |
|------|------|------|
| 运行参数检查 | 每班 | 压力、流量、温度 |
| 消毒运行检查 | 每天 | 消毒程序执行情况 |
| 仪器校准 | 按计划 | pH计、电导率仪等 |

### 11.2 定期维护

| 项目 | 周期 | 内容 |
|------|------|------|
| 过滤器更换 | 按压差或周期 | 预过滤器、精过滤器 |
| 紫外灯更换 | 8000小时或每年 | 紫外灯管 |
| 膜更换 | 根据性能 | 反渗透膜、EDI模块 |
| 系统消毒 | 每周/每月 | 巴氏消毒/臭氧消毒 |
| 验证 | 每年或变更后 | 回顾性验证 |
