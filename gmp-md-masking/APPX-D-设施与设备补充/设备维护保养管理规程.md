# 设备维护保养管理规程

**文件编号**: SMP-FAC-002 | **类别**: 设施与设备

---

## 1. 目的

建立设备维护保养制度，确保设备持续稳定运行。

## 2. 适用范围

适用于高原彝药厂所有生产设备的维护保养。

## 3. 维护保养分类

| 类型 | 频率 | 内容 |
|------|------|------|
| 日常维护 | 每日 | 清洁、检查 |
| 一级保养 | 每周 | 清洁、润滑 |
| 二级保养 | 每月 | 检查、调整 |
| 三级保养 | 每季/每年 | 全面检修 |

## 4. 职责

| 部门 | 职责 |
|------|------|
| 操作人员 | 日常维护 |
| 维修人员 | 专业维护 |
| 工程设备部 | 计划制定和监督 |

## 5. 维护保养内容

| 步骤 | 内容 |
|------|------|
| 清洁 | 设备内外清洁 |
| 润滑 | 润滑点加油 |
| 检查 | 运行状态检查 |
| 调整 | 参数调整 |
| 更换 | 更换易损件 |

## 6. 维护计划

| 要求 | 内容 |
|------|------|
| 年度计划 | 制定年度维护计划 |
| 月度计划 | 制定月度维护计划 |
| 记录 | 填写维护记录 |

## 7. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 维护保养计划 | 5年 | 工程设备部 |
| 维护保养记录 | 5年 | 工程设备部 |
