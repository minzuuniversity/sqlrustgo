# 设备退役和拆除管理规程

**文件编号**: SMP-FAC-005 | **类别**: 设施与设备

---

## 1. 目的

规范设备退役和拆除管理，确保拆除过程安全、合规。

## 2. 适用范围

适用于高原彝药厂所有退役和拆除的设备。

## 3. 退役条件

| 条件 | 说明 |
|------|------|
| 报废批准 | 已批准报废 |
| 新设备到位 | 替换设备已安装 |
| 清洁确认 | 已清洁处理 |

## 4. 拆除前准备

| 准备内容 | 要求 |
|----------|------|
| 断电 | 切断所有电源 |
| 断气 | 切断所有气体 |
| 清洁 | 清洁消毒 |
| 确认 | 确认无残留 |

## 5. 拆除流程

| 步骤 | 内容 |
|------|------|
| 1 | 确认拆除指令 |
| 2 | 制定拆除方案 |
| 3 | 安全措施准备 |
| 4 | 实施拆除 |
| 5 | 设备标识转移 |
| 6 | 现场清理 |
| 7 | 记录归档 |

## 6. 安全要求

| 要求 | 内容 |
|------|------|
| 人员 | 专业拆除人员 |
| 防护 | 佩戴防护用品 |
| 现场 | 安全隔离 |
| 废弃物 | 按规定处理 |

## 7. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 拆除方案 | 5年 | 工程设备部 |
| 拆除记录 | 5年 | 工程设备部 |
