# 设施确认和验证管理规程

**文件编号**: SMP-FAC-009 | **类别**: 设施与设备

---

## 1. 目的

建立设施确认和验证程序，确保厂房设施符合GMP要求。

## 2. 适用范围

适用于高原彝药厂所有厂房设施。

## 3. 确认/验证类型

| 类型 | 说明 | 时机 |
|------|------|------|
| 设计确认 | DQ | 设计阶段 |
| 安装确认 | IQ | 安装完成 |
| 运行确认 | OQ | 运行前 |
| 性能确认 | PQ | 正式运行 |
| 再确认 | - | 定期或变更后 |

## 4. 确认范围

| 设施 | 确认内容 |
|------|----------|
| 洁净厂房 | 洁净度、温湿度、压差 |
| HVAC系统 | 过滤、压差、温湿度 |
| 制药用水系统 | 水质、系统运行 |
| 压缩空气系统 | 气体质量 |
| 电力系统 | 供电保障 |
| 照明系统 | 照度 |

## 5. 验证流程

| 步骤 | 内容 |
|------|------|
| 1 | 制定验证方案 |
| 2 | 审核批准 |
| 3 | 执行验证 |
| 4 | 记录数据 |
| 5 | 编写报告 |
| 6 | 批准关闭 |

## 6. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 确认/验证方案 | 10年 | 质量保证部 |
| 确认/验证报告 | 10年 | 质量保证部 |
