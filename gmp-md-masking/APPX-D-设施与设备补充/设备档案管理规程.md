# 设备档案管理规程

**文件编号**: SMP-FAC-001 | **类别**: 设施与设备

---

## 1. 目的

建立设备档案管理制度，确保设备档案完整、可追溯。

## 2. 适用范围

适用于高原彝药厂所有生产设备和检验设备的档案管理。

## 3. 职责

| 部门 | 职责 |
|------|------|
| 工程设备部 | 设备档案建立和维护 |
| 质量保证部 | 档案监督管理 |
| 使用部门 | 配合档案管理 |

## 4. 设备档案内容

| 内容 | 说明 |
|------|------|
| 设备基本信息 | 名称、编号、型号 |
| 技术资料 | 说明书、图纸 |
| 采购资料 | 合同、发票 |
| 安装调试资料 | 安装记录、调试报告 |
| 验证资料 | IQ、OQ、PQ报告 |
| 维护记录 | 维护保养记录 |
| 维修记录 | 故障及维修记录 |
| 报废资料 | 报废申请及批准 |

## 5. 档案管理

| 要求 | 内容 |
|------|------|
| 建立 | 设备到货后30日内建档 |
| 更新 | 及时更新档案内容 |
| 借阅 | 登记借阅 |
| 保存 | 设备报废后继续保存 |

## 6. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 设备档案 | 设备报废后5年 | 工程设备部 |
| 借阅记录 | 5年 | 工程设备部 |
