# 仓库安全管理规程

**文件编号**: SMP-FAC-008 | **类别**: 设施与设备

---

## 1. 目的

建立仓库安全管理制度，确保仓库安全运行。

## 2. 适用范围

适用于高原彝药厂所有仓库区域。

## 3. 安全管理内容

| 内容 | 要求 |
|------|------|
| 消防安全 | 灭火器、消火栓 |
| 用电安全 | 定期检查 |
| 防盗安全 | 门禁监控 |
| 温湿度安全 | 监控报警 |

## 4. 职责

| 部门 | 职责 |
|------|------|
| 仓储部 | 日常安全管理 |
| 安全部门 | 安全监督 |
| 工程设备部 | 设施维护 |

## 5. 安全检查

| 类型 | 频率 | 内容 |
|------|------|------|
| 日常检查 | 每日 | 消防、门禁 |
| 周检查 | 每周 | 全面检查 |
| 月检查 | 每月 | 系统检查 |

## 6. 应急处理

| 情况 | 处理 |
|------|------|
| 火灾 | 报警、疏散、灭火 |
| 泄漏 | 隔离、报告、处理 |
| 盗窃 | 报警、保护现场 |

## 7. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 安全检查记录 | 5年 | 仓储部 |
| 隐患整改记录 | 5年 | 安全部门 |
