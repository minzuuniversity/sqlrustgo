# 健康检查管理规程

**文件编号**: SP-HR-002
**版本**: V1.0
**生效日期**: 2026-01-01
**审核人**: __________
**批准人**: __________

---

## 1. 目的

建立员工健康管理机制，确保从事药品生产的人员身体健康，符合岗位要求，及时发现职业健康风险，保障药品质量安全和员工权益，符合《药品生产质量管理规范（2010年修订）》第三十一条要求。

---

## 2. 范围

适用于公司全体员工（包括正式员工、临时工、实习生、外包人员）的健康管理，包括：
- 入职前体检
- 在岗定期体检
- 离岗体检
- 职业健康监护
- 健康档案管理

---

## 3. 职责

| 部门/岗位 | 职责 |
|-----------|------|
| 行政部（人力资源） | 负责体检组织、健康档案管理 |
| 质量保证部 | 负责评估体检结果对岗位适用性的影响 |
| 生产部 | 负责组织生产人员参加体检 |
| 各部门 | 负责本部门员工的健康管理 |
| 外部医疗机构 | 负责执行体检、提供体检报告 |

---

## 4. 定义

### 4.1 健康检查
对员工身体健康状况进行评估的医学检查，包括常规体检和专项体检。

### 4.2 职业健康监护
对从事特定岗位员工的健康状况进行连续监测和评估。

### 4.3 岗位禁忌
员工因健康原因不适合从事特定岗位工作的情况。

---

## 5. 体检类型与要求

### 5.1 入职体检

**适用对象**：所有新入职员工

| 体检项目 | 要求 |
|----------|------|
| 常规检查 | 身高、体重、血压、内科、外科 |
| 血常规 | 白细胞、红细胞、血小板、血红蛋白 |
| 尿常规 | 蛋白、糖、潜血 |
| 肝功能 | ALT、AST、GGT、TBIL |
| 肾功能 | BUN、Cr |
| 心电图 | 常规心电图 |
| 胸部X光 | DR胸片 |
| 辨色力 | 色觉检查 |
| 视力 | 裸眼视力、矫正视力 |

**体检机构**：二级及以上医院或专业体检机构

**费用承担**：入职体检费用由公司承担

**体检时限**：入职前完成，入职时提交体检报告

### 5.2 在岗定期体检

**适用对象**：全体在职员工

| 岗位类别 | 体检频率 | 特殊项目 |
|----------|----------|----------|
| 一般岗位 | 每年1次 | 常规项目 |
| 生产操作岗位 | 每年1次 | 常规+粉尘/噪声评估 |
| 质量控制岗位 | 每年1次 | 常规+化学试剂接触评估 |
| 特殊岗位（高压/电工） | 每半年1次 | 按特种作业要求 |

**体检时间**：每年3-4月统一安排

### 5.3 离岗体检

**适用对象**：离职员工

**体检要求**：
- 员工离职前1个月内完成
- 体检项目与入职体检相同
- 特殊岗位增加相应专项检查

**费用承担**：公司承担

### 5.4 专项体检

| 体检类型 | 适用对象 | 频率 | 检查内容 |
|----------|----------|------|----------|
| 粉尘作业 | 接触粉尘岗位 | 每年1次 | 肺功能、胸片 |
| 噪声作业 | 接触噪声岗位 | 每年1次 | 纯音测听 |
| 化学毒物 | 接触化学品岗位 | 每半年1次 | 根据化学品特性确定 |
| 放射性 | 接触放射线岗位 | 每半年1次 | 血常规、淋巴细胞微核 |

## 6. 健康评估与岗位适配

### 6.1 体检结果判定

| 判定结果 | 说明 | 处理方式 |
|----------|------|----------|
| 正常 | 所有检查项目合格 | 正常上岗 |
| 复查 | 部分指标异常，需复查确认 | 安排复查，根据复查结果处理 |
| 职业禁忌 | 存在职业禁忌证 | 调离相关岗位 |
| 疑似职业病 | 可能患有职业病 | 上报并进行职业病诊断 |

### 6.2 岗位禁忌证

| 岗位类别 | 禁忌证类型 |
|----------|------------|
| 质量检验 | 色盲、色弱 |
| 生产操作（无菌） | 皮肤病、传染病 |
| 精密操作 | 严重近视、手部残疾 |
| 高处作业 | 高血压、心脏病 |
| 特种设备操作 | 恐高症、癫痫 |

### 6.3 岗位调整流程

```
发现禁忌证 → 通知行政部 → 评估岗位适配性 
→ 与员工沟通 → 调整岗位/治疗 → 跟踪观察
```

## 7. 健康档案管理

### 7.1 档案内容

| 内容 | 说明 |
|------|------|
| 员工基本信息 | 姓名、部门、岗位、入职日期 |
| 体检记录 | 各次体检日期、体检机构、体检结论 |
| 健康状况变化 | 疾病、受伤、妊娠等 |
| 岗位调整记录 | 调岗原因、日期 |

### 7.2 档案建立

- 员工入职体检合格后5个工作日内建立健康档案
- 档案编号与员工工号一致
- 档案电子化和纸质版并行管理

### 7.3 档案使用

| 使用场景 | 使用权限 |
|----------|----------|
| 岗位调整 | 部门负责人、QA、人力资源 |
| 离职办理 | 人力资源 |
| 监管部门检查 | QA配合提供 |
| 员工本人查询 | 本人可查阅本人档案 |

### 7.4 档案保存

- 保存期限：员工离职后保存10年
- 超过保存期限，按规定销毁
- 销毁需经人力资源经理批准

## 8. 特殊健康情况管理

### 8.1 传染病管理

| 传染病类型 | 处理方式 |
|----------|----------|
| 甲类传染病 | 立即离岗治疗，疫区消毒，接触者排查 |
| 乙类传染病 | 离岗治疗，治愈后方可返岗 |
| 其他传染病 | 根据病情决定 |

**报告要求**：
- 发现传染病疑似病例，24小时内报告行政部
- 发现聚集性病例，立即报告并启动应急预案

### 8.2 妊娠期管理

| 要求 | 说明 |
|------|------|
| 申报 | 员工怀孕后主动申报 |
| 岗位调整 | 调离有毒有害岗位 |
| 工作安排 | 避免加班、夜班 |
| 产前检查 | 产前检查时间计入工作时间 |

### 8.3 工伤管理

- 发生工伤后，部门应在24小时内报告行政部
- 工伤治疗期间保留劳动关系
- 工伤康复后，根据康复情况安排工作

## 9. 职业病防护

### 9.1 职业病危害因素

| 危害因素 | 涉及岗位 | 防护措施 |
|----------|----------|----------|
| 粉尘 | 中药粉碎、制粒 | 防尘口罩 |
| 噪声 | 粉碎、制粒 | 耳塞/耳罩 |
| 化学试剂 | QC实验室 | 防护眼镜、手套、通风橱 |
| 高温 | 烘房、灭菌 | 防暑降温措施 |

### 9.2 防护设施

- 各生产车间配备相应职业防护设施
- 定期检测职业病危害因素浓度/强度
- 超标时及时整改

### 9.3 防护用品

| 岗位类别 | 防护用品 |
|----------|----------|
| 生产操作 | 工作服、帽子、口罩、手套 |
| QC检验 | 实验服、护目镜、手套 |
| 维修 | 安全帽、防护手套 |
| 特殊作业 | 按作业要求配备 |

---

## 10. 健康管理与卫生

### 10.1 个人卫生要求

| 要求 | 说明 |
|------|------|
| 清洁 | 勤洗手、勤更衣 |
| 健康 | 有传染病症状时主动报告 |
| 行为 | 不在生产区域吃东西、吸烟 |

### 10.2 患病报告

员工出现以下症状时，应主动报告并离岗：
- 发热、咳嗽
- 腹泻、呕吐
- 皮肤感染
- 其他传染病症状
