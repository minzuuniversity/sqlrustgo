# 计算机系统验证管理规程

**文件编号**: SMP-COM-001 | **类别**: 计算机系统

---

## 1. 目的

建立计算机系统验证程序，确保计算机系统符合预期用途，满足GMP要求。

## 2. 适用范围

适用于高原彝药厂所有与药品生产质量管理相关的计算机系统。

## 3. 计算机系统分类

| 类别 | 示例 | 验证要求 |
|------|------|----------|
| GAMP 1类 | 简单系统 | 基础验证 |
| GAMP 2类 | 微处理器系统 | 简单验证 |
| GAMP 3类 | 标准软件系统 | 中等验证 |
| GAMP 4类 | 配置系统 | 全面验证 |
| GAMP 5类 | 复杂系统 | 全面验证 |

## 4. 验证生命周期

| 阶段 | 内容 |
|------|------|
| 用户需求规格 | URS编写 |
| 功能规格 | FS编写 |
| 设计确认 | DQ |
| 工厂验收测试 | FAT |
| 现场验收测试 | SAT |
| 安装确认 | IQ |
| 运行确认 | OQ |
| 性能确认 | PQ |

## 5. 验证文档

| 文档 | 说明 |
|------|------|
| URS | 用户需求规格 |
| FS | 功能规格 |
| 设计规格 | DS |
| 测试脚本 | 测试用例 |
| 测试报告 | 测试结果 |

## 6. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 验证方案 | 10年 | IT部门 |
| 验证报告 | 10年 | IT部门 |
