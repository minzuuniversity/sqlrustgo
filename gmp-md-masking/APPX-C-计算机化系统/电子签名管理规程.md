# 电子签名管理规程

**文件编号**: SMP-COM-003 | **类别**: 计算机系统

---

## 1. 目的

规范电子签名的管理，确保电子签名具有法律效力并符合GMP要求。

## 2. 适用范围

适用于高原彝药厂所有计算机系统中的电子签名。

## 3. 电子签名要求

| 要求 | 内容 |
|------|------|
| 唯一性 | 与操作者一一对应 |
| 可追溯 | 可追溯到签名人 |
| 法律效力 | 符合《电子签名法》 |
| 安全 | 防止盗用 |

## 4. 电子签名实施

| 要素 | 要求 |
|------|------|
| 用户ID | 唯一标识 |
| 密码 | 复杂密码 |
| 生物识别 | 可选 |
| 电子签名图像 | 可选 |

## 5. 电子签名使用

| 场景 | 要求 |
|------|------|
| 批记录审核 | 电子签名 |
| 检验报告批准 | 电子签名 |
| 偏差批准 | 电子签名 |
| 变更批准 | 电子签名 |

## 6. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 电子签名授权记录 | 10年 | IT部门 |
| 电子签名使用记录 | 10年 | IT部门 |
