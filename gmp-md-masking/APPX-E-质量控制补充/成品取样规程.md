# 成品取样规程

**文件编号**: SOP-QC-002 | **类别**: 质量控制

---

## 1. 目的

规范成品的取样操作，确保样品的代表性和检验结果的准确性。

## 2. 适用范围

适用于高原彝药厂所有成品的取样。

## 3. 职责

| 部门 | 职责 |
|------|------|
| 质量控制部 | 执行取样操作 |
| 质量保证部 | 取样监督 |
| 生产部 | 配合取样 |

## 4. 取样要求

| 要求 | 内容 |
|------|------|
| 时机 | 包装完成后 |
| 代表性 | 从不同位置取样 |
| 数量 | 足够全检+留样 |
| 条件 | 防止污染 |

## 5. 取样流程

### 5.1 取样前准备

| 步骤 | 内容 |
|------|------|
| 1 | 审核取样指令 |
| 2 | 确认成品批信息 |
| 3 | 准备取样工具和容器 |
| 4 | 填写取样记录表 |

### 5.2 取样操作

| 步骤 | 操作内容 | 要点 |
|------|----------|------|
| 1 | 确认包装完整性 | 检查密封 |
| 2 | 随机选取包装件 | 不同位置 |
| 3 | 开封取样 | 避免污染 |
| 4 | 取样 | 按规定数量 |
| 5 | 重新封口 | 恢复密封 |
| 6 | 标识 | 批号等信息 |

## 6. 取样数量

| 批量 | 取样件数 | 取样量 |
|------|----------|--------|
| ≤100件 | 3件 | 足够全检+留样 |
| 100-500件 | 5件 | 足够全检+留样 |
| >500件 | 按平方根取 | 足够全检+留样 |

## 7. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 取样记录 | 5年 | 质量控制部 |
| 样品台账 | 5年 | 质量控制部 |
