# 物料储存条件管理规程

**文件编号**: SMP-QC-007 | **类别**: 质量控制

---

## 1. 目的

规范物料的储存条件管理，确保物料质量稳定。

## 2. 适用范围

适用于高原彝药厂所有物料的储存管理。

## 3. 储存条件分类

| 类型 | 温度 | 湿度 | 适用物料 |
|------|------|------|----------|
| 常温 | 10-30°C | 45-75% | 一般物料 |
| 阴凉 | ≤20°C | 45-75% | 易挥发物料 |
| 冷藏 | 2-8°C | 45-75% | 生物制剂 |
| 冷冻 | -20°C以下 | - | 特殊样品 |
| 干燥 | 室温 | ≤45% | 易吸潮物料 |

## 4. 特殊物料储存

| 物料 | 条件 | 要求 |
|------|------|------|
| 麻醉药品 | 双人双锁 | 专库 |
| 精神药品 | 双人双锁 | 专库 |
| 易燃易爆 | 防火防爆 | 隔离 |
| 腐蚀性 | 防腐蚀 | 隔离 |

## 5. 库房管理

| 要求 | 内容 |
|------|------|
| 分类存放 | 按物料类别分区 |
| 标识清楚 | 物料名称、批号、数量 |
| 先进先出 | 防止过期 |
| 温湿度监控 | 每日记录 |
| 清洁卫生 | 定期清洁 |

## 6. 复验期管理

| 要求 | 说明 |
|------|------|
| 复验周期 | 规定复验周期 |
| 复验项目 | 全检或部分项目 |
| 复验记录 | 记录复验结果 |

## 7. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 温湿度记录 | 5年 | 仓储部 |
| 物料台账 | 永久 | 仓储部 |
| 复验记录 | 5年 | 质量控制部 |
