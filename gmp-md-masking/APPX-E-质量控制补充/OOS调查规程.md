# OOS调查规程

**文件编号**: SMP-QC-002 | **类别**: 质量控制

---

## 1. 目的

建立OOS（超标结果）调查程序，规范检验结果超标时的调查和处理。

## 2. 适用范围

适用于高原彝药厂所有检验结果超标的调查。

## 3. 定义

OOS：检验结果超出规定标准（Out of Specification）

## 4. 职责

| 部门 | 职责 |
|------|------|
| 检验人员 | 初步评估、复检 |
| QC主管 | 主导调查 |
| QA部门 | 监督调查、最终决定 |
| 相关部门 | 配合调查 |

## 5. OOS处理流程

### 5.1 初步评估

| 步骤 | 内容 |
|------|------|
| 1 | 检验人员报告超标结果 |
| 2 | 初步评估是否为明显错误 |
| 3 | 检查计算、样品处理 |

### 5.2 复检

| 步骤 | 内容 |
|------|------|
| 1 | 保留原溶液 |
| 2 | 使用同一样品复检 |
| 3 | 记录复检过程 |

### 5.3 调查

| 调查项目 | 内容 |
|----------|------|
| 样品 | 样品来源、储存、制备 |
| 仪器 | 仪器状态、校准 |
| 试剂 | 试剂有效期、配置 |
| 方法 | 方法执行是否正确 |
| 环境 | 检验环境条件 |
| 人员 | 操作人员是否培训 |

### 5.4 调查报告

| 内容 | 要求 |
|------|------|
| 事实陈述 | 详细描述 |
| 调查过程 | 各项检查结果 |
| 根本原因 | 找到原因则填写 |
| 结论 | 是否OOS |

## 6. 实验室错误分类

| 类型 | 说明 | 处理 |
|------|------|------|
| 明显错误 | 计算错误、操作失误 | 复检后作废 |
| 非明显错误 | 需深入调查 | 按OOS调查 |

## 7. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| OOS调查报告 | 10年 | 质量控制部 |
| 复检记录 | 10年 | 质量控制部 |
