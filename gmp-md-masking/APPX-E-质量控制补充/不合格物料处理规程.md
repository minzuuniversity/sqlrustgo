# 不合格物料处理规程

**文件编号**: SMP-QC-006 | **类别**: 质量控制

---

## 1. 目的

规范不合格物料的处理，防止误用。

## 2. 适用范围

适用于高原彝药厂所有不合格物料的处理。

## 3. 职责

| 部门 | 职责 |
|------|------|
| 质量控制部 | 判定不合格 |
| 质量保证部 | 监督处理 |
| 仓储部 | 物料隔离 |

## 4. 不合格物料标识

| 要求 | 内容 |
|------|------|
| 标识 | 红色"不合格"标识 |
| 隔离 | 隔离存放 |
| 记录 | 填写不合格记录 |

## 5. 处理方式

| 方式 | 适用情况 |
|------|----------|
| 退货 | 供应商原因 |
| 降级使用 | 评估后可用 |
| 销毁 | 不可使用 |

## 6. 处理流程

| 步骤 | 内容 |
|------|------|
| 1 | 确认不合格 |
| 2 | 隔离存放 |
| 3 | 填写处理申请 |
| 4 | 审批处理方式 |
| 5 | 实施处理 |
| 6 | 记录处理结果 |

## 7. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 不合格物料记录 | 10年 | 质量保证部 |
| 处理记录 | 10年 | 质量保证部 |
