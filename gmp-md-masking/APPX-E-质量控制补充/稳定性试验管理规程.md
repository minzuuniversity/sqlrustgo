# 稳定性试验管理规程

**文件编号**: SOP-QA-003  |  **类别**: 实验室管理

---

## 1. 目的
规范药品稳定性考察试验的设计、实施和数据分析，确定产品有效期和储存条件。

## 2. 范围
适用于本企业生产的所有药品的稳定性试验管理。

## 3. 职责
**质量部**：负责稳定性试验方案的制定、实施和数据分析。  
**研发部**：参与新型号的稳定性试验方案设计。  
**仓库**：负责稳定性样品储存条件的管理。

## 4. 流程

| 步骤 | 操作内容 |
|------|---------|
| **方案制定** | 质量部根据ICH Q1A要求制定稳定性试验方案，明确试验条件（温度25±2℃/60±5%RH、30±2℃/65±5%RH）、检测项目、检测周期。 |
| **样品准备** | 按上市批量三批（其中至少两批中试规模）取样，样品应具有代表性。 |
| **储存条件** | 稳定性样品按规定的温湿度条件储存，连续监测并记录储存温湿度。 |
| **按时检测** | 按方案规定的检测节点（0、3、6、9、12、18、24、36月）进行全项检验。 |
| **数据分析** | 采用稳定性数据分析软件，以显著水平0.05判断是否符合货架期标准。 |
| **报告编写** | 完成规定周期后，编写《稳定性试验报告》，确定产品有效期。 |
| **变更评估** | 处方或工艺变更后，应重新进行稳定性试验。 |
