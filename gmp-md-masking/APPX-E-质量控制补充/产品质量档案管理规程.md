# 产品质量档案管理规程

**文件编号**: SP-QC-012
**版本**: V1.0
**生效日期**: 2026-01-01
**审核人**: __________
**批准人**: __________

---

## 1. 目的

建立产品质量档案管理制度，规范产品质量档案的建立、维护和使用，确保产品质量信息的完整性和可追溯性，符合《药品生产质量管理规范（2010年修订）》第一百五十二条要求。

---

## 2. 范围

适用于公司所有药品产品质量档案的管理，包括：
- 产品质量档案的建立
- 产品质量档案的维护
- 产品质量档案的使用
- 产品质量档案的保存与销毁

---

## 3. 职责

| 部门/岗位 | 职责 |
|-----------|------|
| 质量控制部 | 负责产品质量档案的建立和日常维护 |
| 质量保证部 | 负责产品质量档案的审核和监督 |
| 注册部 | 负责产品注册资料的管理 |
| 档案室 | 负责产品质量档案的归档保存 |

---

## 4. 定义

### 4.1 产品质量档案
指记录药品从研发到上市后全过程质量信息的文件系统，包括产品注册资料、生产工艺、质量标准、检验数据、稳定性考察数据等。

### 4.2 产品技术资料
指与产品质量直接相关的技术文件，如工艺规程、质量标准、检验方法等。

## 6. 产品质量档案建立

### 6.1 建立时机

| 产品类型 | 建立时机 |
|----------|----------|
| 新产品 | 获得批准文号后30日内 |
| 已有产品 | 本规程实施后3个月内补建 |
| 变更产品 | 变更批准后更新档案 |

### 6.2 建立流程

```
确定产品 → 收集资料 → 整理归档 
→ 审核 → 批准 → 移交档案室
```

### 6.3 档案编号

**编号规则**：QA-档案-产品代码-版本号

**示例**：QA-档案-YPGXS-001-V1.0

| 编码段 | 说明 |
|--------|------|
| QA-档案 | 质量保证部档案 |
| YPGXS | 产品名称缩写 |
| 001 | 序号 |
| V1.0 | 版本号 |

## 9. 档案保存

### 9.1 保存期限

| 档案类型 | 保存期限 | 说明 |
|----------|----------|------|
| 产品质量档案 | 有效期后5年 | 不少于5年 |
| 注册资料 | 永久 | |
| 批记录摘要 | 有效期后5年 | |
| 稳定性数据 | 有效期后5年 | |
| 验证资料 | 有效期后5年 | |
| 投诉/召回记录 | 永久 | |

### 9.2 保存条件

| 要求 | 说明 |
|------|------|
| 存放地点 | 专用档案室 |
| 环境条件 | 干燥、通风、防潮 |
| 防火防盗 | 配备消防器材 |

### 9.3 电子档案管理

| 要求 | 说明 |
|------|------|

## 10. 档案销毁

### 10.1 销毁条件

| 条件 | 说明 |
|------|------|
| 超过保存期限 | 保存期满且无保留价值 |
| 产品注销 | 药品批准文号注销后 |
| 特殊情况下 | 经质量负责人批准 |

### 10.2 销毁流程

