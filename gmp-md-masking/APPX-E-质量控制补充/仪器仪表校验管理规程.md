# 仪器仪表校验管理规程

**文件编号**: SMP-QC-004 | **类别**: 质量控制

---

## 1. 目的

规范仪器仪表的校验管理，确保检验用仪器仪表准确可靠。

## 2. 适用范围

适用于高原彝药厂所有检验用仪器仪表。

## 3. 校验分类

| 类型 | 说明 | 周期 |
|------|------|------|
| 首次校验 | 新仪器使用前 | - |
| 期间核查 | 两次校准间 | 按计划 |
| 周期校准 | 规定周期 | 1年/半年 |

## 4. 校验范围

| 仪器类型 | 校验参数 |
|----------|----------|
| 天平 | 精度、线性 |
| pH计 | 准确度 |
| 水分测定仪 | 准确度 |
| 溶出仪 | 温度、转速 |
| HPLC | 柱效、压力 |
| UV | 波长、准确度 |

## 5. 校验实施

| 步骤 | 内容 |
|------|------|
| 1 | 制定年度校验计划 |
| 2 | 联系校准机构 |
| 3 | 实施校准 |
| 4 | 贴校准标识 |
| 5 | 更新校验台账 |

## 6. 期间核查

| 要求 | 内容 |
|------|------|
| 对象 | 关键仪器 |
| 方法 | 使用标准物质 |
| 频率 | 半年或按需 |
| 记录 | 记录核查结果 |

## 7. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 仪器校准记录 | 10年 | 质量控制部 |
| 期间核查记录 | 5年 | 质量控制部 |
| 仪器台账 | 永久 | 质量控制部 |
