# 试剂和标准品管理规程

**文件编号**: SMP-QC-001 | **类别**: 质量控制

---

## 1. 目的

规范试剂和标准品的管理，确保检验用试剂和标准品的质量。

## 2. 适用范围

适用于高原彝药厂质量控制部所有试剂和标准品的管理。

## 3. 分类

| 类型 | 说明 |
|------|------|
| 化学试剂 | 一般化学试剂 |
| 基准物质 | 用于标定的物质 |
| 标准品 | 含量/纯度已知的标准物质 |
| 对照品 | 用于鉴别/含量测定的对照 |
| 生物制剂 | 酶、细胞等 |

## 4. 职责

| 部门 | 职责 |
|------|------|
| 质量控制部 | 试剂标准品管理 |
| 采购部 | 采购 |
| 质量保证部 | 监督 |

## 5. 接收与验收

| 验收项目 | 内容 |
|----------|------|
| 外观检查 | 包装完整、标签清晰 |
| 规格数量 | 与订单一致 |
| 证书 | COA/分析证书 |
| 储存条件 | 符合要求 |

## 6. 储存管理

| 要求 | 内容 |
|------|------|
| 条件 | 按试剂要求储存 |
| 标识 | 名称、批号、日期 |
| 位置 | 按类别分区存放 |
| 安全 | 危险品隔离 |
| 库存 | 定期盘点 |

## 7. 标准品管理

| 要求 | 内容 |
|------|------|
| 来源 | 法定标准品或自制 |
| 标化 | 自制标准品需标化 |
| 复标期 | 规定复标周期 |
| 使用记录 | 领用登记 |

## 8. 废弃处理

| 要求 | 内容 |
|------|------|
| 分类 | 按废弃物分类 |
| 处理 | 按规定处理 |
| 记录 | 填写处理记录 |

## 9. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 试剂台账 | 5年 | 质量控制部 |
| 标准品台账 | 5年 | 质量控制部 |
| 领用记录 | 5年 | 质量控制部 |
