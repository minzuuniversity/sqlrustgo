# 稳定性样品取样规程

**文件编号**: SOP-QC-004 | **类别**: 质量控制

---

## 1. 目的

规范稳定性试验样品的取样操作。

## 2. 适用范围

适用于高原彝药厂所有稳定性试验的取样。

## 3. 职责

| 部门 | 职责 |
|------|------|
| 质量控制部 | 执行取样 |
| 质量保证部 | 监督 |
| 稳定性研究部门 | 样品管理 |

## 4. 取样要求

| 要求 | 内容 |
|------|------|
| 时机 | 稳定性试验规定时间点 |
| 数量 | 按稳定性方案 |
| 代表性 | 随机取样 |
| 记录 | 记录取样信息 |

## 5. 取样流程

| 步骤 | 内容 |
|------|------|
| 1 | 确认取样时间点 |
| 2 | 从稳定性箱取出样品 |
| 3 | 检查包装完整性 |
| 4 | 取规定数量样品 |
| 5 | 立即送检 |
| 6 | 剩余样品放回 |

## 6. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 取样记录 | 10年 | 质量控制部 |
| 稳定性样品台账 | 10年 | 质量控制部 |
