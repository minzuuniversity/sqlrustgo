# 药品召回管理规程

**文件编号**: SMP-QMS-006 | **类别**: 质量管理体系

---

## 1. 目的

建立药品召回程序，确保在发现质量问题或安全隐患时能够及时、有效地召回问题药品，保护患者安全。

## 2. 适用范围

适用于高原彝药厂所有药品的召回管理。

## 3. 召回分级

| 级别 | 定义 | 时限要求 |
|------|------|----------|
| 一级召回 | 使用后可能严重危害健康或导致死亡 | 24小时内 |
| 二级召回 | 使用后可能暂时危害健康或导致暂时性问题 | 48小时内 |
| 三级召回 | 一般不会危害健康，但存在质量问题 | 72小时内 |

## 4. 职责

| 部门 | 职责 |
|------|------|
| 质量负责人 | 决定启动召回，批准召回方案 |
| 质量保证部 | 召回的组织协调，法规报告 |
| 销售部 | 经销商和客户联系，货物追溯 |
| 生产部 | 配合库存产品处理 |
| 仓储物流部 | 召回产品的隔离和退回管理 |

## 5. 召回触发条件

| 类型 | 示例 |
|------|------|
| 质量缺陷 | 含量不合格、杂质超标、污染 |
| 安全性问题 | 不良反应严重、假药 |
| 标签错误 | 批号、有效期、名称错误 |
| 生产错误 | 工艺偏差导致质量问题 |
| 法规要求 | 监管部门要求 |

## 6. 召回程序

### 6.1 召回启动

| 步骤 | 内容 | 负责部门 |
|------|------|----------|
| 问题评估 | 评估影响范围和严重程度 | 质量保证部 |
| 召回决定 | 质量负责人决定启动召回 | 质量负责人 |
| 召回等级 | 确定召回级别 | 质量负责人 |

### 6.2 召回实施

| 步骤 | 内容 | 时限要求 |
|------|------|----------|
| 成立召回组 | 指定召回协调人 | 立即 |
| 制定召回方案 | 明确范围、方法、时间表 | 4小时内 |
| 联系客户 | 通知经销商和医疗机构 | 按召回等级 |
| 产品追溯 | 确认问题批次流向 | 8小时内 |
| 产品退回 | 安排产品退回 | 按召回等级 |
| 调查报告 | 编写召回调查报告 | 召回完成后 |

### 6.3 监管部门报告

| 报告内容 | 报告时限 |
|----------|----------|
| 启动报告 | 召回启动后24小时内 |
| 进展报告 | 每隔72小时报告一次 |
| 终结报告 | 召回完成后15个工作日内 |

## 7. 召回记录要求

| 记录内容 | 要求 |
|----------|------|
| 召回原因 | 详细描述质量问题 |
| 涉及批次 | 批号、规格、数量 |
| 销售区域 | 经销商、医院、药店 |
| 召回数量 | 已召回数量和比例 |
| 根本原因 | 质量问题原因分析 |
| 预防措施 | 防止再次发生的措施 |

## 8. 模拟召回

- 每年至少进行一次模拟召回
- 验证召回程序的有效性
- 记录模拟召回结果

## 9. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 药品召回记录 | 10年 | 质量保证部 |
| 监管部门通信记录 | 10年 | 质量保证部 |
| 召回调查报告 | 10年 | 质量保证部 |
| 模拟召回记录 | 5年 | 质量保证部 |
