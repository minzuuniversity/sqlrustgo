## 1. 目的

建立规范的检验记录管理制度，确保检验记录的真实性、完整性、可追溯性，保证检验数据可靠有效，符合《药品生产质量管理规范（2010年修订）》第一百四十五条要求。

---

## 2. 范围

适用于公司所有检验记录的管理，包括：
- 原料、辅料、包装材料检验记录
- 成品检验记录
- 中间产品检验记录
- 工艺用水检验记录
- 环境监测记录
- 仪器使用记录
- 试剂配制记录

---

## 3. 职责

| 部门/岗位 | 职责 |
|-----------|------|
| 质量控制部 | 负责检验记录的填写、收集、整理 |
| 质量保证部 | 负责检验记录的审核、监督检查 |
| 档案室 | 负责检验记录的归档、保存 |

---

## 4. 定义

### 4.1 检验记录
指检验过程中实时记录原始数据的记录表单，包括原始观察、数据计算、设备读数等信息。

### 4.2 检验报告
指根据检验记录数据出具的正式报告，包含检验结论。

### 4.3 原始数据
指检验过程中直接获取的未经处理的数据，如天平读数、仪器原始图谱等。

---

## 5. 检验记录的基本要求

### 5.1 记录填写要求

| 要求 | 说明 |
|------|------|
| 原始性 | 实时记录，非事后补记 |
| 真实性 | 记录实际发生的情况，不伪造 |
| 完整性 | 记录所有必要信息，不遗漏 |
| 清晰性 | 字迹清楚，易于阅读 |
| 及时性 | 操作完成后立即记录 |
| 可追溯性 | 可追溯到人、设备、方法、时间 |

### 5.2 记录书写规范

| 项目 | 规范 |
|------|------|
| 书写工具 | 黑色签字笔（禁用圆珠笔） |
| 字迹 | 工整、清晰 |
| 错误修改 | 单线划改，在旁边写上正确值，签名注明日期和原因 |
| 签名 | 亲手签名，不得代签 |
| 日期格式 | YYYY-MM-DD |
| 时间格式 | 24小时制，如 14:30 |

### 5.3 修改示例

```
正确示例：
  记录值：25.67g    划改：25.67 → 25.76
  签名：[NAME-A-SUPERVISOR] 2026-01-15 原因：称量错误

错误示例：
  ❌ 用涂改液修改
  ❌ 划改后不签名
  ❌ 直接划掉重写
  ❌ 复印后修改
```

## 6. 检验记录内容

### 6.1 原料药检验记录

| 记录项目 | 内容 |
|----------|------|
| 基本信息 | 样品名称、批号、规格、供应商、数量、取样日期 |
| 检验信息 | 检验日期、检验依据（质量标准编号）、检验项目 |
| 检验条件 | 仪器设备型号/编号、试剂批号、环境温湿度 |
| 原始数据 | 称量数据、滴定数据、仪器读数、图谱 |
| 计算过程 | 计算公式、各步计算结果 |
| 检验结果 | 单项结论、最终结论 |
| 检验人/复核人 | 签名、日期 |

### 6.2 辅料检验记录

| 记录项目 | 内容 |
|----------|------|
| 基本信息 | 样品名称、批号、规格、供应商、数量、取样日期 |
| 检验信息 | 检验日期、检验依据、检验项目 |
| 检验条件 | 仪器设备、试剂批号、环境条件 |
| 原始数据 | 称量数据、仪器读数 |
| 计算过程 | 计算公式、计算结果 |
| 检验结果 | 单项结论、最终结论 |
| 检验人/复核人 | 签名、日期 |

### 6.3 成品检验记录

| 记录项目 | 内容 |
|----------|------|
| 基本信息 | 产品名称、规格、批号、生产日期、批量、取样日期 |
| 检验信息 | 检验日期、检验依据、检验项目 |
| 检验条件 | 仪器设备、试剂批号、环境条件 |
| 原始数据 | 称量数据、仪器读数、图谱数据 |
| 计算过程 | 计算公式、计算结果 |
| 检验结果 | 单项结论、最终结论 |
| 审核人/批准人 | 签名、日期 |

### 6.4 中间产品检验记录

| 记录项目 | 内容 |
|----------|------|
| 基本信息 | 产品名称、批号、工序、取样时间 |
| 检验信息 | 检验日期、检验依据、检验项目 |
| 检验条件 | 仪器设备、试剂批号 |
| 原始数据 | 测量数据、仪器读数 |
| 检验结果 | 单项结论、最终结论 |
| 检验人 | 签名、日期 |

### 6.5 环境监测记录

| 记录项目 | 内容 |
|----------|------|
| 监测日期/时间 | |
| 监测位置 | 具体位置描述 |
| 监测项目 | 温度、湿度、压差、微生物等 |
| 监测结果 | 实际读数 |
| 标准限值 | 规定的合格范围 |
| 判定结果 | 合格/不合格 |
| 监测人/复核人 | 签名 |

### 6.6 仪器使用记录

| 记录项目 | 内容 |
|----------|------|
| 仪器名称/编号 | |
| 使用日期/时间 | |
| 使用人 | |
| 检验样品信息 | 样品名称、批号 |
| 使用前状态 | 检查结果 |
| 使用情况 | 操作简要描述 |
| 使用后状态 | 清洁状态 |
| 异常情况 | 异常描述及处理 |
| 备注 | |

## 7. 记录审核流程

### 7.1 审核流程

```
检验完成 → 检验员自检 → 复核人复核 
→ QA抽查 → 整理归档
```

### 7.2 审核要点

| 审核内容 | 检查要点 |
|----------|----------|
| 完整性 | 必填项是否完整 |
| 原始性 | 是否实时记录 |
| 真实性 | 数据是否合理 |
| 计算准确性 | 计算过程是否正确 |
| 修改规范性 | 修改是否符合规定 |
| 签名完整性 | 签名是否齐全 |
| 结论明确性 | 结论是否明确 |

### 7.3 审核发现问题的处理

| 问题类型 | 处理方式 |
|----------|----------|
| 一般问题 | 退回检验员修改 |
| 数据异常 | 启动OOS调查 |
| 记录造假 | 启动偏差调查，追责 |

## 8. 记录保存与归档

### 8.1 保存期限

| 记录类型 | 保存期限 | 说明 |
|----------|----------|------|
| 成品检验记录 | 5年或效期后1年 | 取较长者 |
| 原料/辅料检验记录 | 5年 | |
| 中间产品检验记录 | 5年 | |
| 工艺用水检验记录 | 5年 | |
| 环境监测记录 | 3年 | |
| 仪器使用记录 | 3年 | |
| 试剂配制记录 | 3年 | |
| 验证记录 | 5年 | |

### 8.2 归档流程

| 步骤 | 操作 | 执行部门 |
|------|------|----------|
| 1 | 收集检验记录 | QC |
| 2 | 初审记录完整性 | QC主管 |
| 3 | 复印必要份数 | QC |
| 4 | 移交档案室 | QC |
| 5 | 档案室审核接收 | 档案室 |
| 6 | 归档存放 | 档案室 |

### 8.3 归档要求

| 要求 | 说明 |
|------|------|
| 分类 | 按产品、批次分类 |
| 编号 | 唯一编号，便于检索 |
| 装订 | 装订成册 |
| 存放环境 | 干燥、防潮、防虫、防火 |

## 9. 记录的查阅与复制

### 9.1 查阅权限

| 人员类型 | 查阅范围 | 权限 |
|----------|----------|------|
| QC人员 | 本部门记录 | 可查阅 |
| QA人员 | 所有检验记录 | 可查阅 |
| 生产人员 | 本产品记录 | 可查阅 |
| 监管部门 | 按要求提供 | 配合提供 |
| 其他人员 | 需批准 | 申请后批准 |

### 9.2 复制规定

| 情况 | 是否允许 |
|------|----------|
| 内部使用 | 经部门经理批准后可复制 |
| 监管部门检查 | 按要求提供 |
| 客户审计 | 经QA批准后可提供相关部分 |
| 法律诉讼 | 按法律要求执行 |

### 9.3 记录借阅

| 要求 | 说明 |
|------|------|
| 借阅申请 | 填写借阅申请单 |
| 借阅审批 | 部门经理/QA审批 |
| 借阅期限 | 一般不超过7天 |
| 归还要求 | 借阅到期归还 |
| 损坏赔偿 | 损坏或丢失需赔偿 |

## 10. 电子记录管理

### 10.1 电子记录要求

| 要求 | 说明 |
|------|------|
| 数据完整性 | 电子数据不得丢失或篡改 |
| 审计追踪 | 系统应具备审计追踪功能 |
| 数据备份 | 定期备份，异地保存 |
| 权限管理 | 限制未授权访问和修改 |

### 10.2 电子签名

| 要求 | 说明 |
|------|------|
| 唯一性 | 电子签名与操作人唯一对应 |
| 可追溯 | 记录签名人、时间 |
| 不可伪造 | 采用安全技术防止伪造 |

### 10.3 仪器电子数据

| 数据类型 | 管理要求 |
|----------|----------|
| HPLC/GC图谱 | 原始数据保存，备份 |
| 紫外/红外光谱 | 原始数据保存 |
|天平数据 | 称量记录自动保存 |
| 其他仪器数据 | 按规定保存 |

---

## 11. 记录销毁

### 11.1 销毁条件

| 条件 | 说明 |
|------|------|
| 超过保存期限 | 保存期满且无保留价值 |
| 提前销毁 | 特殊情况下经批准 |
| 损毁灭失 | 不可抗力导致 |

### 11.2 销毁流程

```
申请 → 审核（QA）→ 批准（质量负责人）
→ 销毁 → 记录
```

### 11.3 销毁方式

| 方式 | 适用情况 |
|------|----------|
| 碎纸机 | 一般纸质记录 |
| 焚烧 | 批量销毁 |
| 专业销毁 | 涉密/重要记录 |
