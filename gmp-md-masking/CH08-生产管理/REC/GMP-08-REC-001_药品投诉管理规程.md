# 药品投诉管理规程

**文件编号**: SMP-QMS-007 | **类别**: 质量管理体系

---

## 1. 目的

建立药品投诉处理程序，系统收集、分析和调查投诉，采取有效措施，保护患者权益。

## 2. 适用范围

适用于高原彝药厂所有药品投诉的处理。

## 3. 投诉分类

| 分类标准 | 类型 | 示例 |
|----------|------|------|
| 按性质 | 质量投诉 | 产品变质、含量异常、异物 |
| 按性质 | 服务投诉 | 配送延迟、包装损坏 |
| 按严重程度 | 严重投诉 | 疑似死亡或严重不良反应 |
| 按严重程度 | 一般投诉 | 轻微质量问题、包装瑕疵 |

## 4. 职责

| 部门 | 职责 |
|------|------|
| 质量保证部 | 投诉的接收、登记、协调调查 |
| 质量控制部 | 涉及检验的投诉调查 |
| 生产部 | 涉及生产的投诉调查 |
| 销售部 | 客户沟通，反馈信息收集 |
| 药事服务部 | 临床相关投诉沟通 |

## 5. 投诉处理流程

### 5.1 投诉接收

| 要求 | 内容 |
|------|------|
| 接收渠道 | 电话、邮件、信函、监管部门 |
| 记录内容 | 投诉人信息、产品信息、投诉内容、联系方式 |
| 初步确认 | 确认投诉信息完整性 |

### 5.2 投诉评估

| 评估项目 | 内容 |
|----------|------|
| 产品信息 | 批号、规格、有效期 |
| 问题描述 | 投诉具体内容 |
| 严重程度 | 初步判断级别 |
| 调查必要性 | 是否需要启动调查 |

### 5.3 投诉调查

| 调查内容 | 方法 |
|----------|------|
| 产品调查 | 批记录、检验记录、稳定性数据 |
| 过程调查 | 生产过程、仓储条件 |
| 留样调查 | 留样产品复检 |
| 同批次调查 | 同批次产品市场反馈 |

### 5.4 投诉回复

| 投诉类型 | 回复时限 |
|----------|----------|
| 严重投诉 | 24小时内初步回复 |
| 一般投诉 | 7个工作日内回复 |
| 复杂投诉 | 30个工作日内回复 |

### 5.5 投诉关闭

投诉关闭条件：
- 调查完成，原因明确
- 已采取相应措施
- 客户已收到回复
- 相关记录完整归档

## 6. 投诉数据管理

| 数据分析 | 内容 |
|----------|------|
| 趋势分析 | 按产品、问题类型、地区统计 |
| 根本原因 | 识别投诉根本原因 |
| 预警 | 异常趋势预警 |
| 改进 | 推动产品和工艺改进 |

## 7. 投诉档案

| 档案内容 | 保存要求 |
|----------|----------|
| 投诉原始记录 | 原件保存 |
| 调查过程记录 | 完整可追溯 |
| 客户通信记录 | 保持通信原文 |
| 产品照片/样品 | 如有应保存 |

## 8. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 药品投诉记录 | 10年 | 质量保证部 |
| 投诉调查报告 | 10年 | 质量保证部 |
| 客户回复记录 | 10年 | 质量保证部 |
