# 工艺规程修订管理规程

**文件编号:** SOP-QA-CC-009
**版本号:** V1.0

## 1. 目的

规范药品工艺规程的修订管理，确保工艺规程与实际生产一致，符合注册要求。

## 2. 工艺规程修订触发条件

- 注册标准变更
- 生产设备更新
- 工艺优化
- 偏差调查结果
- 验证结论
- 法规更新

## 3. 修订审批流程

```
生产部提出修订申请
    ↓
QA评估影响范围
    ↓
技术部制定修订草案
    ↓
相关部门会签
    ↓
质量总监批准
    ↓
注册申报（如需）
    ↓
新版本生效
```

## 4. 修订要求

- 修订版本号必须递增
- 修订原因必须记录
- 旧版本存档备查
- 相关培训必须完成
