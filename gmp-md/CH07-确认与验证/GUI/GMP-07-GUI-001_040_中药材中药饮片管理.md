# 中药材中药饮片管理

**文件编号:** REG-GMP-028
**版本号:** V1.0

## 1. 中药材采购

**特殊要求：**
- 来自GAP基地优先
- 供应商资质（药品经营许可证）
- 产地加工品应注意加工方法
- 野生药材应注意资源保护

## 2. 验收要求

| 检查项目 | 要求 |
|---------|------|
| 外观性状 | 符合标准 |
| 杂质 | ≤标准限度 |
| 水分 | ≤安全贮存水分 |
| 灰分 | ≤标准限度 |
| 浸出物 | ≥标准限度 |
| 含量测定 | 符合标准 |
| 农药残留 | 符合标准 |
| 重金属 | 符合标准 |

## 3. 储存养护

- 防虫防霉防鼠
- 分开储存（活血/有毒/易串味）
- 阴凉干燥储存
- 定期养护检查
- 效期管理

## 4. 饮片生产

- 净制、洗润、切制、干燥
- 炮制工艺符合标准
- 质量检验
- 批号编制
