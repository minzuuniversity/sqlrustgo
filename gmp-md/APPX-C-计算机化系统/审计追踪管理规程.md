# 审计追踪管理规程

**文件编号**: SMP-COM-005 | **类别**: 计算机系统

---

## 1. 目的

建立审计追踪管理程序，确保计算机系统操作可追溯。

## 2. 适用范围

适用于高原彝药厂所有具有审计追踪功能的计算机系统。

## 3. 审计追踪内容

| 内容 | 说明 |
|------|------|
| 登录记录 | 用户登录/登出 |
| 操作记录 | 数据创建、修改、删除 |
| 配置变更 | 系统配置变更 |
| 权限变更 | 用户权限变更 |

## 4. 审计追踪要求

| 要求 | 内容 |
|------|------|
| 启用 | 必须启用 |
| 不可修改 | 审计记录不可改 |
| 不可删除 | 审计记录不可删 |
| 时间戳 | 准确时间 |

## 5. 审计追踪审查

| 频率 | 审查内容 |
|------|----------|
| 每日 | 关键系统 |
| 每周 | 重要系统 |
| 每月 | 一般系统 |

## 6. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 审计追踪审查记录 | 10年 | 质量保证部 |
| 异常记录 | 10年 | 质量保证部 |
