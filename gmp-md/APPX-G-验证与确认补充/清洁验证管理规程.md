# 清洁验证管理规程

**文件编号**: SMP-VAL-002 | **类别**: 验证与确认

---

## 1. 目的

建立清洁验证程序，证明清洁方法能有效去除残留物，防止交叉污染。

## 2. 适用范围

适用于高原彝药厂所有生产设备清洁方法的验证。

## 3. 清洁验证内容

| 内容 | 说明 |
|------|------|
| 残留物限度 | 产品残留、清洗剂残留 |
| 微生物限度 | 清洁后微生物水平 |
| 取样方法 | 擦拭法、淋洗法 |
| 检验方法 | 含量测定、微生物检测 |

## 4. 残留限度标准

| 类型 | 限度 |
|------|------|
| 产品残留 | ≤10ppm |
| 清洁剂残留 | ≤10ppm |
| 微生物 | ≤100CFU/25cm² |

## 5. 验证流程

| 步骤 | 内容 |
|------|------|
| 1 | 制定清洁验证方案 |
| 2 | 批准验证方案 |
| 3 | 执行清洁验证 |
| 4 | 取样检测 |
| 5 | 数据分析 |
| 6 | 编写验证报告 |

## 6. 最差条件

| 条件 | 说明 |
|------|------|
| 最后一批产品 | 溶解度最低的产品 |
| 最大批量 | 设备最大使用批量 |
| 最长生产时间 | 最长生产周期 |

## 7. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 清洁验证方案 | 10年 | 质量保证部 |
| 清洁验证报告 | 10年 | 质量保证部 |
