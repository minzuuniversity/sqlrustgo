# 压缩空气系统验证方案

**文件编号**: VP-FAC-003 | **类别**: 验证与确认

---

## 1. 目的

验证压缩空气系统能够持续、稳定地提供符合要求的压缩空气。

## 2. 适用范围

适用于高原彝药厂与产品接触的压缩空气系统。

## 3. 系统描述

| 项目 | 描述 |
|------|------|
| 系统组成 | 空压机、储气罐、干燥机、过滤器 |
| 空气质量 | 无油、干燥 |

## 4. 验证项目

| 项目 | 接受标准 |
|------|----------|
| 压力 | 0.6-0.8MPa |
| 露点 | ≤-40°C |
| 油含量 | ≤0.1mg/m³ |
| 尘埃粒子 | 符合ISO8573 |
| 微生物 | ≤10CFU/m³ |
