# 消防安全管理制度

**文件编号**: SMP-SEC-003 | **类别**: 安全与卫生

---

## 1. 目的

建立消防安全管理制度，预防火灾事故，保障人员和财产安全。

## 2. 适用范围

适用于高原彝药厂所有区域。

## 3. 职责

| 部门 | 职责 |
|------|------|
| 安全部门 | 消防安全归口管理 |
| 各部门 | 本部门消防安全 |
| 全员 | 遵守消防法规 |

## 4. 消防设施

| 设施 | 配置要求 |
|------|----------|
| 灭火器 | 按区域配置 |
| 消火栓 | 按规定间距 |
| 烟雾报警 | 关键区域 |
| 疏散指示 | 显著位置 |
| 应急照明 | 疏散通道 |

## 5. 动火管理

| 要求 | 内容 |
|------|------|
| 申请 | 动火前申请 |
| 审批 | 安全部门审批 |
| 监护 | 动火时监护 |
| 清理 | 动火后清理 |

## 6. 消防检查

| 类型 | 频率 | 内容 |
|------|------|------|
| 日常检查 | 每日 | 消防设施 |
| 周检查 | 每周 | 全面检查 |
| 月检查 | 每月 | 系统检查 |
| 年度检查 | 每年 | 全面检查 |

## 7. 应急响应

| 步骤 | 内容 |
|------|------|
| 报警 | 立即报警 |
| 疏散 | 组织疏散 |
| 灭火 | 初期灭火 |
| 报告 | 报告上级 |

## 8. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 消防检查记录 | 5年 | 安全部门 |
| 动火申请 | 5年 | 安全部门 |
| 消防演练记录 | 5年 | 安全部门 |
