# 纠正和预防措施管理规程

**文件编号**: SMP-QMS-003 | **类别**: 质量管理体系

---

## 1. 目的

建立纠正和预防措施（CAPA）管理程序，系统处理偏差、投诉、审计发现等问题，消除根本原因，防止问题重复发生。

## 2. 适用范围

适用于高原彝药厂所有与产品质量相关的纠正和预防措施。

## 3. 定义

| 术语 | 定义 |
|------|------|
| 纠正措施（CA） | 消除已发生的不符合项的原因的措施 |
| 预防措施（PA） | 消除潜在不符合项的原因的措施 |
| 根本原因 | 导致不符合项发生的最根本原因 |

## 4. 职责

| 部门 | 职责 |
|------|------|
| 质量保证部 | 负责CAPA系统的整体管理 |
| 各相关部门 | 实施本部门的CAPA措施 |
| 质量负责人 | 批准重大CAPA |

## 5. CAPA触发条件

| 触发类型 | 示例 |
|----------|------|
| 偏差 | 生产偏差、检验偏差 |
| 投诉 | 客户投诉、产品投诉 |
| 审计发现 | 内部自检、外部审计 |
| 趋势分析 | 数据异常趋势 |
| 法规变化 | GMP法规更新 |
| 正常审查 | 定期管理审查 |

## 6. CAPA实施流程

### 6.1 问题描述

- 清晰描述发现的问题
- 记录发生的时间、地点、涉及批次
- 初步评估影响范围

### 6.2 根本原因分析

| 方法 | 适用范围 |
|------|----------|
| 5 Why分析 | 简单问题 |
| 鱼骨图 | 复杂问题多因素分析 |
| FMEA | 风险相关问题 |
| 故障树分析 | 系统性故障 |

### 6.3 纠正措施制定

| 要素 | 要求 |
|------|------|
| 措施内容 | 具体、可操作 |
| 责任人 | 明确到人 |
| 完成期限 | 合理、可执行 |
| 验证方法 | 可验证措施有效性 |

### 6.4 预防措施制定

- 基于根本原因分析
- 识别潜在问题
- 制定预防性控制措施

### 6.5 实施与验证

| 步骤 | 要求 |
|------|------|
| 实施 | 按计划执行 |
| 记录 | 详细记录实施过程 |
| 验证 | 确认措施有效 |
| 关闭 | 验证通过后关闭 |

## 7. CAPA分级

| 级别 | 定义 | 示例 | 审批级别 |
|------|------|------|----------|
| 重大 | 可能影响产品放行或患者安全 | 含量超标、污染 | 质量负责人 |
| 主要 | 可能影响产品质量 | 关键参数偏离 | 部门负责人 |
| 次要 | 不直接影响产品质量 | 文件记录缺陷 | 主管 |

## 8. 时效要求

| CAPA级别 | 调查报告提交 | 措施完成 |
|----------|--------------|----------|
| 重大 | 15个工作日 | 30个工作日 |
| 主要 | 20个工作日 | 45个工作日 |
| 次要 | 30个工作日 | 60个工作日 |

## 9. 有效性监控

1. 定期审查CAPA实施效果
2. 确认根本原因已消除
3. 确认类似问题未在其他区域发生
4. 至少跟踪12个月

## 10. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| CAPA记录 | 10年 | 质量保证部 |
| 根本原因分析报告 | 10年 | 质量保证部 |
