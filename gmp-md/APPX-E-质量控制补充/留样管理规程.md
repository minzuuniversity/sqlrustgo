# 留样管理规程

**文件编号**: SOP-QA-005  |  **类别**: 实验室管理

---

## 1. 目的
规范产品留样管理，确保留样品的完整性和可追溯性，为产品质量回顾和调查提供依据。

## 2. 范围
适用于本企业生产的药品成品、关键原辅料和包装材料的留样管理。

## 3. 职责
**质量部**：负责留样的入库、储存和观察管理。  
**仓库**：提供留样储存区域，配合留样取样。

## 4. 流程

| 步骤 | 操作内容 |
|------|---------|
| **留样设置** | 每批产品在入库前，由质量部按批抽取留样。留样量应满足全检需要量的2倍。 |
| **留样入库** | 留样样品贴《留样标识》，登记《留样台账》，存放于专用留样室。 |
| **储存条件** | 成品留样按标签所示的储存条件存放（常温/阴凉/冷藏）。 |
| **定期观察** | 留样期间，每年至少一次对留样进行外观检查，检查结果记入《留样观察记录》。 |
| **留样使用** | 留样品用于质量调查、OOS复验或官方抽检时，须经质量部批准，记录出库原因。 |
| **留样销毁** | 超过留样期限的样品，经质量部批准后，按规定进行销毁处理。 |
