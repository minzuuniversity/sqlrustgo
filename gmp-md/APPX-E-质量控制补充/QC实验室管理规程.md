**文件编号**: SP-QC-001
**版本**: V1.0
**生效日期**: 2026-01-01
**审核人**: __________
**批准人**: __________

## 1. 目的

建立QC实验室规范管理要求，确保实验室环境、设施、设备、人员等符合检验工作要求，保证检验结果的准确性、可靠性，符合《药品生产质量管理规范（2010年修订）》第一百二十五条要求。

---

## 2. 范围

适用于公司QC实验室的所有活动，包括：
- 检验操作
- 仪器设备使用与维护
- 试剂、对照品、标准品管理
- 微生物检验
- 留样观察
- 检验记录管理

---

## 3. 职责

| 部门/岗位 | 职责 |
|-----------|------|
| 质量控制部 | 负责实验室全面管理 |
| 质量保证部 | 负责实验室监督检查 |
| 设备工程部 | 负责实验室设施设备维护 |

## 4. 实验室布局与环境

### 4.1 实验室布局原则

| 原则 | 说明 |
|------|------|
| 合理分区 | 分为理化检验区、仪器分析区、微生物检验区、留样区 |
| 人流物流分开 | 减少交叉污染 |
| 温湿度控制 | 满足检验要求（20-25℃，45-60%RH） |
| 通风良好 | 必要时安装通风柜、排风设施 |
| 采光充足 | 满足视觉检验要求 |

### 4.2 实验室温湿度要求

| 区域 | 温度 | 湿度 | 说明 |
|------|------|------|------|
| 理化检验区 | 20-25℃ | 45-60%RH | 精密称量时≤60%RH |
| 仪器分析区 | 20-25℃ | 45-60%RH | 避免湿度影响仪器 |
| 天平室 | 20-25℃ | 45-60%RH | 精密称量 |
| 微生物检验区 | 20-25℃ | 45-65%RH | 符合洁净区要求 |

### 4.3 实验室清洁卫生

| 项目 | 要求 |
|------|------|
| 地面 | 每日清洁，污染时及时清洁 |
| 台面 | 每班次清洁 |
| 仪器表面 | 定期清洁 |
| 废弃物 | 按规定分类处置 |
| 虫害 | 定期灭虫，防止虫害 |

## 5. 人员要求

### 5.1 人员资质

| 岗位 | 资质要求 |
|------|----------|
| 检验人员 | 药学或相关专业大专以上，有检验员资格证 |
| 微生物检验员 | 额外要求微生物学基础知识培训 |
| 仪器分析员 | 仪器操作专业培训 |
| 实验室主管 | 本科以上，5年以上检验经验 |

### 5.2 培训要求

| 培训类型 | 频率 | 内容 |
|----------|------|------|
| 上岗培训 | 上岗前 | 实验室安全、操作规程、设备使用 |
| 在岗培训 | 年度 | GMP知识、检验技能、安全知识 |
| 专项培训 | 按需 | 新方法、新设备、新法规 |
| 继续教育 | 持续 | 专业知识更新 |

### 5.3 健康管理

| 要求 | 说明 |
|------|------|
| 体检 | 入职体检、年度体检 |
| 健康申报 | 有传染病症状时主动报告 |
| 卫生要求 | 穿戴工作服、禁止饮食 |

## 6. 仪器设备管理

### 6.1 仪器分类

| 类别 | 设备示例 | 管理要求 |
|------|----------|----------|
| 精密仪器 | 高效液相色谱仪、气相色谱仪、紫外分光光度计 | 专人操作、定期校准 |
| 通用仪器 | 天平、pH计、熔点仪、旋光仪 | 定期校准 |
| 前处理设备 | 烘箱、马弗炉、离心机 | 定期维护 |
| 微生物设备 | 灭菌柜、生化培养箱、生物安全柜 | 验证后使用 |

### 6.2 仪器使用

| 步骤 | 操作 |
|------|------|
| 使用前 | 确认仪器状态、检查清洁状态 |
| 使用时 | 按SOP操作、记录使用情况 |
| 使用后 | 清洁、整理、填写使用记录 |
| 异常 | 发现异常立即报告 |

### 6.3 仪器校准

| 校准类型 | 周期 | 执行部门 |
|----------|------|----------|
| 内部校准 | 按计划 | QC |
| 外部校准 | 每年 | 计量机构 |
| 期间核查 | 校准周期内 | QC |

### 6.4 仪器维护

| 维护类型 | 周期 | 内容 |
|----------|------|------|
| 日维护 | 每日 | 清洁、校准检查 |
| 周维护 | 每周 | 清洁、更换耗材 |
| 月维护 | 每月 | 全面检查、保养 |
| 年维护 | 每年 | 专业保养、检修 |

## 7. 试剂与对照品管理

### 7.1 试剂管理

| 管理项目 | 要求 |
|----------|------|
| 采购 | 按需采购，避免浪费 |
| 验收 | 检查品名、规格、批号、有效期 |
| 储存 | 按要求储存（室温/冷藏/避光） |
| 标识 | 名称、规格、批号、日期、有效期、配制日期 |
| 使用 | 遵循"先进先出"原则 |
| 过期处理 | 过期试剂及时处理 |

### 7.2 对照品管理

| 管理项目 | 要求 |
|----------|------|
| 来源 | 使用国家标准品/对照品 |
| 验收 | 检查证书、批号、有效期 |
| 储存 | 按要求储存（多数2-8℃） |
| 标识 | 名称、批号、有效期、储存条件 |
| 使用 | 按使用说明操作 |
| 期间核查 | 定期核查稳定性 |

### 7.3 标准品管理

| 管理项目 | 要求 |
|----------|------|
| 配置 | 按配置规程配制 |
| 标识 | 名称、浓度、配制日期、配制人 |
| 储存 | 按要求储存 |
| 有效期 | 规定使用期限 |
| 期间核查 | 定期核查稳定性 |

## 8. 检验操作规范

### 8.1 检验流程

```
接收检验指令 → 准备试剂/仪器 
→ 取样（配合仓储部）→ 检验 
→ 记录数据 → 计算结果 
→ 出具检验报告 → 报告审核 
→ 报告放行
```

### 8.2 检验操作要求

| 要求 | 说明 |
|------|------|
| 方法依据 | 按经批准的检验规程操作 |
| 环境条件 | 满足检验环境要求 |
| 设备状态 | 设备应在有效期内 |
| 试剂状态 | 试剂应在有效期内 |
| 原始记录 | 实时记录、字迹清晰 |
| 复核制度 | 重要数据双人复核 |

### 8.3 检验记录要求

| 项目 | 要求 |
|------|------|
| 原始性 | 实时记录，非补记 |
| 完整性 | 记录所有操作步骤 |
| 真实性 | 数据真实，不伪造 |
| 可追溯性 | 可追溯到人、设备、方法 |
| 保存期限 | 不少于5年或产品有效期后1年 |

### 8.4 检验报告

| 项目 | 要求 |
|------|------|
| 格式 | 使用规定格式 |
| 内容 | 样品信息、检验项目、结果、结论 |
| 审核 | 检验员出具，主管审核 |
| 签章 | 检验员、审核人签字 |
| 发放 | 登记发放，记录发放对象 |

## 9. 微生物检验管理

### 9.1 微生物实验室布局

| 区域 | 功能 | 洁净级别 |
|------|------|----------|
| 洁净准备区 | 试剂配制、培养基准备 | D级 |
| 阳性对照区 | 阳性对照试验 | D级 |
| 无菌检验区 | 无菌检验、微生物限度检验 | A/B级 |
| 培养区 | 样品培养 | D级 |

### 9.2 微生物检验环境监测

| 项目 | 频率 | 标准 |
|------|------|------|
| 浮游菌 | 每周/每季度 | 按洁净级别 |
| 沉降菌 | 每班生产前 | 按洁净级别 |
| 表面微生物 | 定期 | 按洁净级别 |

### 9.3 微生物检验操作

| 操作 | 要求 |
|------|------|
| 无菌操作 | 在A/B级区域进行 |
| 人员防护 | 穿戴无菌服、手套、口罩 |
| 环境监控 | 检验同时进行环境监控 |
| 阳性对照 | 每批检验同时做阳性对照 |
| 阴性对照 | 每批检验同时做阴性对照 |

## 10. OOS管理与超规处理

### 10.1 OOS定义

超标结果（OOS）是指检验结果超出既定标准的过程控制限或产品规格。

### 10.2 OOS处理流程

```
发现OOS → 立即报告 → 初步调查 
→ 复检 → 全面调查 → 结论与处理
```

### 10.3 OOS调查内容

| 调查阶段 | 调查内容 |
|----------|----------|
| 初步调查 | 重新计算、检查设备状态、复核操作 |
| 复检 | 使用保留样品复检 |
| 全面调查 | 原因分析、评估影响、CAPA |

详见《OOS调查规程》 SP-QC-010

## 11. 留样管理

### 11.1 留样范围

| 样品类型 | 留样数量 | 留样时间 |
|----------|----------|----------|
| 成品 | 3倍全检量 | 有效期后1年 |
| 原料药 | 3倍全检量 | 有效期后2年 |
| 辅料 | 3倍全检量 | 有效期后1年 |
| 包材 | 足够检验量 | 有效期后1年 |

### 11.2 留样条件

| 要求 | 说明 |
|------|------|
| 温度 | 常温（10-30℃）或冷藏（2-8℃） |
| 湿度 | 35-75%RH |
| 避光 | 避光储存 |
| 包装 | 原包装或模拟包装 |

### 11.3 留样观察

| 项目 | 频率 | 内容 |
|------|------|------|
| 外观检查 | 每季度 | 颜色、性状 |
| 稳定性考察 | 按稳定性考察计划 | 全项或部分项目 |
| 异常处理 | 发现异常时 | 报告、调查 |

详见《留样管理规程》 SP-QC-007

## 12. 实验室安全

### 12.1 安全要求

| 项目 | 要求 |
|------|------|
| 个人防护 | 工作服、护目镜、手套 |
| 化学品操作 | 在通风橱中进行 |
| 废弃物处理 | 分类收集，交专业公司处理 |
| 急救设施 | 洗眼器、急救箱 |
| 消防 | 配备灭火器，熟悉逃生路线 |

### 12.2 应急处理

| 情况 | 处理方式 |
|------|----------|
| 化学品溅到眼睛 | 立即用洗眼器冲洗15分钟，就医 |
| 化学品溅到皮肤 | 立即用大量水冲洗，处理后就医 |
| 烫伤 | 冷水冲洗，涂抹烫伤膏，严重时就医 |
| 割伤 | 清洗伤口，消毒包扎，严重时就医 |
| 火灾 | 立即灭火器灭火，疏散人员，报警 |
