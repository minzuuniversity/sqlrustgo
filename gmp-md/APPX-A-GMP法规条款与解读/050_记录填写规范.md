# 记录填写规范

**文件编号:** REG-GMP-038
**版本号:** V1.0

## 1. 记录填写原则

**第168条** 记录应及时、清晰，真实反映操作情况。

| 原则 | 说明 |
|------|------|
| 及时性 | 操作时或操作后立即填写 |
| 真实性 | 如实记录，不造假 |
| 完整性 | 填写所有必填项 |
| 清晰性 | 字迹清晰可读 |
| 可追溯性 | 签名、日期完整 |

## 2. 修改规范

- 划红线错误内容
- 写正确内容
- 签名+日期
- 理由（如需要）
- 原错误内容仍可见

**❌ 错误方式：**
- 涂改液涂抹
- 刀片刮擦
- 喷涂覆盖
- 直接划掉不签名

## 3. 签名要求

| 签名类型 | 要求 |
|---------|------|
| 操作人 | 操作者本人 |
| 复核人 | 上级或指定人员 |
| 审核人 | QA或管理层 |

## 4. 电子记录要求

- 审计追踪开启
- 用户权限控制
- 数据备份
- 修改可追溯
- 符合21 CFR Part 11（如适用）
