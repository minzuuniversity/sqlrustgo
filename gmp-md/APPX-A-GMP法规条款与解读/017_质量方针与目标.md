# 质量方针与目标

**文件编号:** REG-GMP-005
**版本号:** V1.0

## 1. 质量方针

**第31条** 企业最高管理者应确保质量方针：
- 适应企业宗旨和药品生产质量要求
- 提供制定和评审质量目标的框架
- 在企业内部得到沟通和理解
- 定期评审其适宜性

### 质量方针示例
> "以质量为核心，以患者安全为导向，持续改进质量管理水平，确保所有药品符合注册标准要求。"

## 2. 质量目标

### 2.1 目标设定原则
- 可测量
- 可实现
- 与质量方针一致
- 分解到各部门

### 2.2 目标示例

| 部门 | 目标 |
|------|------|
| 生产部 | 成品合格率≥99.5% |
| 质量部 | 偏差按时关闭率≥95% |
| 工程部 | 设备验证完成率100% |
| 采购部 | 物料及时到货率≥98% |

## 3. 管理评审

**第37条** 最高管理者应定期组织管理评审，评估质量体系的适宜性、充分性和有效性。

### 3.1 评审输入
- 审计结果
- 偏差和投诉分析
- CAPA有效性
- 验证状态
- 纠正措施落实情况

### 3.2 评审输出
- 改进决策
- 资源需求
- 体系变更需求

### 3.3 评审频次
- 每年至少一次
- 重大变更时增加
