# 岗位职责编制指南

**文件编号:** REG-GMP-014
**版本号:** V1.0

## 1. 岗位职责结构

每个岗位职责应包含：
- 岗位基本信息
- 任职资格
- 汇报关系
- 主要职责
- 权限范围
- 绩效考核指标

## 2. 职责描述示例

**岗位名称:** 生产操作工

**直属上级:** 生产班组长

**主要职责:**
1. 按批准的SOP进行生产操作
2. 及时填写批生产记录
3. 发现偏差及时报告
4. 保持工作区域清洁
5. 参与设备维护和清洁

**权限:**
- 拒绝执行违章指挥
- 停止可疑操作
- 报告质量隐患

**任职资格:**
- 中专以上学历
- 1年以上生产经验
- 持有健康证

## 3. 职责描述注意事项

- 职责明确，具体可操作
- 不与他人职责重叠
- 与质量方针一致
- 体现GMP要求

## 4. 职责文件管理

- 每年审查一次
- 组织架构变更时更新
- 员工签字确认
- 版本受控
