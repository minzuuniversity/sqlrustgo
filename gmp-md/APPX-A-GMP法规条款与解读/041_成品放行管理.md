# 成品放行管理

**文件编号:** REG-GMP-029
**版本号:** V1.0

## 1. 放行原则

**第285条** 每批产品必须经质量授权人批准后方可放行。

## 2. 放行条件

| 条件 | 要求 |
|------|------|
| 生产 | 按批准工艺生产 |
| 检验 | 全项检验合格 |
| 偏差 | 已关闭或不影响质量 |
| 变更 | 已批准或已备案 |
| 工艺验证 | 验证状态有效 |
| 稳定性 | 符合要求 |

## 3. 放行审核内容

- 批生产记录审核
- 批检验记录审核
- 偏差/变更/投诉审核
- 环境监控记录审核
- 设备确认状态审核

## 4. 批记录审核要点

- 生产工艺参数在范围内
- 物料平衡在限度内
- 产量在正常范围内
- 所有签名完整
- 所有检验结果合格
- 无偏差或偏差已关闭
- 相关记录完整

## 5. 记录保存

- 批记录保存至效期后1年
- 检验记录保存至效期后1年
- 放行记录长期保存
