# 批生产记录

**文件编号:** REG-GMP-031
**版本号:** V1.0

## 1. 批生产记录要求

**第211条** 每批产品应有批生产记录，内容必须完整、可追溯。

## 2. 批生产记录内容

| 内容 | 要求 |
|------|------|
| 产品名称/批号 | 与注册一致 |
| 生产日期 | 实际日期时间 |
| 操作步骤 | 与SOP一致 |
| 工艺参数 | 实际值+记录 |
| 物料信息 | 名称/批号/用量 |
| 设备信息 | 设备编号 |
| 过程检验 | 符合内控标准 |
| 签名 | 实时签名 |
| 偏差记录 | 如有偏差需记录 |

## 3. 填写要求

- 及时、真实
- 不得涂改（划改签名）
- 不得提前填写
- 不得伪造数据
- 内容完整

## 4. 审核要求

- 操作人员签名
- 班组长复核
- QA审核
- 质量受权人批准放行

## 5. 保存要求

- 保存至效期后1年
- 便于追溯查阅
- 防潮防虫防盗
