# 文件审核批准流程

**文件编号**: SMP-DOC-003 | **类别**: 文件与记录管理

---

## 1. 目的

规范GMP文件的审核批准流程，确保文件内容准确、完整、有效。

## 2. 适用范围

适用于高原彝药厂所有GMP管理规程和标准操作规程。

## 3. 流程概述

```
起草 → 部门审核 → QA审核 → 会签 → 批准 → 编号 → 生效
```

## 4. 各环节职责

| 环节 | 执行人 | 职责 |
|------|--------|------|
| 起草 | 专业人员 | 编写文件初稿 |
| 部门审核 | 部门负责人 | 审核业务内容 |
| QA审核 | QA专业人员 | 审核GMP符合性 |
| 会签 | 相关部门 | 确认相关接口 |
| 批准 | 质量负责人 | 最终批准 |
| 编号 | 文件管理员 | 分配编号 |
| 生效 | 文件管理员 | 发布实施 |

## 5. 详细流程

### 5.1 起草

| 要求 | 内容 |
|------|------|
| 起草依据 | 法规要求、公司制度、业务需要 |
| 格式要求 | 符合文件编写规范 |
| 附件 | 必要时附相关支持文件 |

### 5.2 部门审核

| 审核要点 | 内容 |
|----------|------|
| 业务正确性 | 操作流程是否正确 |
| 职责明确性 | 职责是否清晰 |
| 可操作性 | 是否可执行 |
| 协调性 | 与其他部门接口是否合理 |

### 5.3 QA审核

| 审核要点 | 内容 |
|----------|------|
| GMP符合性 | 是否符合GMP要求 |
| 法规符合性 | 是否符合法规要求 |
| 文件格式 | 格式是否符合规范 |
| 可追溯性 | 记录是否完整 |

### 5.4 会签

| 会签部门 | 会签范围 |
|----------|----------|
| 生产部 | 生产相关文件 |
| 质量控制部 | 检验相关文件 |
| 工程设备部 | 设备设施相关文件 |
| 仓储物流部 | 仓储物流相关文件 |

### 5.5 批准

| 文件类别 | 批准人 |
|----------|--------|
| 质量手册 | 总经理 |
| 管理规程 | 质量负责人 |
| 标准操作规程 | 部门负责人或质量负责人 |

## 6. 时效要求

| 环节 | 时限 |
|------|------|
| 部门审核 | 3个工作日 |
| QA审核 | 3个工作日 |
| 会签 | 2个工作日 |
| 批准 | 2个工作日 |

## 7. 文件发布

| 步骤 | 内容 |
|------|------|
| 编号 | 按编号规则分配编号 |
| 盖章 | 盖"受控文件"章 |
| 登记 | 填写文件发放记录 |
| 培训 | 必要时组织培训 |
| 发布 | 发放至规定地点 |

## 8. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 文件审核批准表 | 5年 | 质量保证部 |
| 文件发放记录 | 5年 | 质量保证部 |
| 文件会签记录 | 5年 | 质量保证部 |
