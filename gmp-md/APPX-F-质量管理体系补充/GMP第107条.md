# GMP 第一百零七条

**文件编号**: GMP-107 | **类别**: GMP条款原文

---

## 原文

第一百零七条　每批产品经质量受权人批准后方可放行。

---

## 解读

### 核心要求

| 要求 | 说明 |
|------|------|
| 放行权限 | 质量受权人 |
| 放行依据 | 批生产记录、批检验记录、偏差处理等 |
| 批准条件 | 全部符合标准 |

### 放行审核内容

| 审核项目 | 审核内容 |
|----------|----------|
| 生产 | 批生产记录、工艺参数、中间控制 |
| 检验 | 批检验记录、检验方法 |
| 偏差 | 偏差处理及关闭情况 |
| 变更 | 涉及变更的评估 |
| 稳定性 | 必要时稳定性数据 |
