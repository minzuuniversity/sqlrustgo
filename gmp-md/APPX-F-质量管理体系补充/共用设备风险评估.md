# 共用设备风险评估

**文件编号**: SMP-QMS-018 | **类别**: 质量管理体系

---

## 1. 目的

评估共用设备交叉污染风险。

## 2. 适用范围

适用于高原彝药厂共用设备管理。

## 3. 风险因素

| 因素 | 说明 |
|------|------|
| 产品性质 | 毒性、敏感性 |
| 设备材质 | 吸附、残留 |
| 清洁难度 | 清洁可验证性 |

## 4. 风险评估矩阵

| 残留风险 | 高 | 中 | 低 |
|----------|-----|-----|-----|
| 高 | 高风险 | 高风险 | 中风险 |
| 中 | 高风险 | 中风险 | 低风险 |
| 低 | 中风险 | 低风险 | 低风险 |

## 5. 控制措施

| 措施 | 要求 |
|------|------|
| 专用设备 | 高风险产品使用 |
| 清洁验证 | 证明清洁有效 |
| 变更控制 | 更换产品时评估 |

|----------|--------|----------|
