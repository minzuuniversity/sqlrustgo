# 药品上市后风险管控

**文件编号**: SMP-QMS-016 | **类别**: 质量管理体系

---

## 1. 目的

建立药品上市后风险管控机制。

## 2. 适用范围

适用于高原彝药厂上市后药品风险管理。

## 3. 风险信息来源

| 来源 | 内容 |
|------|------|
| 投诉 | 客户投诉信息 |
| 不良反应 | 药品不良反应 |
| 抽检 | 市场抽检结果 |
| 召回 | 召回信息 |

## 4. 风险评估

| 步骤 | 内容 |
|------|------|
| 收集 | 收集风险信息 |
| 评估 | 评估风险等级 |
| 决策 | 制定管控措施 |
| 沟通 | 报告监管部门 |
| 回顾 | 定期风险回顾 |

## 5. 风险控制措施

| 措施 | 适用情况 |
|------|----------|
| 召回 | 严重风险 |
| 整改 | 中等风险 |
| 监测 | 一般风险 |

## 6. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 风险管控记录 | 10年 | 质量保证部 |
