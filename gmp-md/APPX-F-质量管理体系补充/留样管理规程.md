# 留样管理规程

**文件编号**: SMP-QMS-010 | **类别**: 质量管理体系

---

## 1. 目的

建立留样管理程序，规范原辅料和成品的留样管理，确保留样品的保存条件，满足质量追溯和稳定性考察需要。

## 2. 适用范围

适用于高原彝药厂所有原辅料和成品的留样管理。

## 3. 职责

| 部门 | 职责 |
|------|------|
| 质量控制部 | 留样的接收、储存和管理 |
| 质量保证部 | 留样管理的监督 |
| 仓储部 | 留样室的温湿度监控 |

## 4. 留样要求

### 4.1 留样数量

| 类型 | 留样量 | 备注 |
|------|--------|------|
| 成品 | 至少3个全检量 | 含注册批准的全检项目 |
| 原辅料 | 至少3个检验量 | 关键物料加倍 |
| 包材 | 至少3套 |  |

### 4.2 留样保存条件

| 样品类型 | 保存条件 | 备注 |
|----------|----------|------|
| 成品 | 25±2°C，45±5%RH | 或按注册批准条件 |
| 生物制品 | 2-8°C | 或按特定条件 |
| 原辅料 | 室温或特定条件 | 按储存条件 |
| 特殊样品 | 按特定要求 | 遮光、冷冻等 |

## 5. 留样保存期限

| 类型 | 保存期限 | 备注 |
|------|----------|------|
| 上市产品 | 有效期后1年 | 或注册批准要求 |
| 中间产品 | 必要的保存期 | 超过复验期应复检 |
| 原辅料 | 超过复验期后1年 | 或放行后1年 |
| 退货产品 | 处理完成后1年 |  |

## 6. 留样管理流程

| 步骤 | 内容 | 负责部门 |
|------|------|----------|
| 留样申请 | 质量控制部提出 | 质量控制部 |
| 留样采集 | 按规定数量采集 | 仓库/生产 |
| 留样交接 | 双方签字确认 | 质量控制部 |
| 留样储存 | 按条件储存 | 质量控制部 |
| 留样观察 | 定期观察记录 | 质量控制部 |
| 留样处置 | 到期后按规定处理 | 质量控制部 |

## 7. 留样使用

| 使用场景 | 审批要求 |
|----------|----------|
| 稳定性考察 | 稳定性试验计划批准 |
| 投诉调查 | 质量负责人批准 |
| 召回调查 | 质量负责人批准 |
| 对比检验 | 部门负责人批准 |

## 8. 留样室管理

| 管理要求 | 内容 |
|----------|------|
| 温湿度监控 | 连续监控，记录每日 |
| 安全防护 | 防火、防盗、防虫 |
| 库存管理 | 留样台账、库位管理 |
| 整洁要求 | 定期清洁 |

## 9. 留样观察

| 观察项目 | 频率 | 内容 |
|----------|------|------|
| 外观检查 | 每季度 | 颜色、性状 |
| 温湿度检查 | 每日 | 温湿度记录 |
| 完整性和密封性 | 每年 | 包装完整性 |

## 10. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 留样台账 | 10年 | 质量控制部 |
| 留样观察记录 | 10年 | 质量控制部 |
| 留样领用记录 | 10年 | 质量控制部 |
