# 厂房设施风险评估

**文件编号**: SMP-QMS-019 | **类别**: 质量管理体系

---

## 1. 目的

评估厂房设施对产品质量的影响。

## 2. 适用范围

适用于高原彝药厂所有厂房设施。

## 3. 评估要素

| 要素 | 评估内容 |
|------|----------|
| 选址 | 环境影响评估 |
| 平面布局 | 人流物流分离 |
| 洁净区设计 | 符合级别要求 |
| 公用系统 | 水、电、气、空调 |

## 4. 风险点识别

| 风险点 | 可能影响 |
|----------|----------|
| 压差不足 | 交叉污染 |
| 温湿度失控 | 产品质量 |
| 过滤器失效 | 环境超标 |

## 5. 控制措施

| 措施 | 验证要求 |
|------|----------|
| 压差监测 | 连续监控 |
| 温湿度控制 | 自动控制系统 |
| 过滤器检测 | 定期完整性测试 |

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 厂房风险评估报告 | 10年 | 工程部 |
