# 偏差登记管理规程

**文件编号**: SP-QMS-017
**版本**: V1.0
**生效日期**: 2026-01-01
**审核人**: __________
**批准人**: __________

---

## 1. 目的

建立规范的偏差登记管理制度，确保所有偏差事件能够及时、准确地登记，防止偏差漏登、迟登，保证偏差处理的完整性和可追溯性，符合《药品生产质量管理规范（2010年修订）》第二百五十条规定。

---

## 2. 范围

适用于公司所有药品生产质量管理活动中的偏差登记，包括：
- 生产过程偏差
- 设备设施偏差
- 物料产品偏差
- 检验检测偏差
- 仓储物流偏差
- 验证确认偏差

---

## 3. 职责

| 部门/岗位 | 职责 |
|-----------|------|
| 发现人员 | 及时报告、初步处理 |
| 生产操作人员 | 本岗位偏差的发现与初始登记 |
| 质量保证部 | 偏差登记审核、分配处理 |
| 质量控制部 | 偏差检验、原因分析参与 |
| 相关部门 | 偏差原因调查、纠正预防 |

---

## 4. 定义

### 4.1 偏差
指在药品生产质量管理过程中，实际发生的情况与预期要求之间的差异，包括任何偏离标准操作规程、标准、程序、方法、法规要求的情况。

### 4.2 偏差登记
指将发现的偏差事件按规定的格式和程序进行记录的行为。

### 4.3 偏差分级
根据偏差的严重程度和对产品质量的潜在影响，将偏差分为重大偏差、较大偏差和一般偏差。

---

## 5. 偏差分类

### 5.1 按偏差来源分类

| 偏差类型 | 说明 | 示例 |
|----------|------|------|
| 生产过程偏差 | 生产操作过程中发生的偏离 | 温度偏离、压力异常、转速异常 |
| 设备设施偏差 | 设备、设施故障导致的偏离 | 设备停机、仪表失灵、密封泄漏 |
| 物料产品偏差 | 物料或产品质量异常 | 外观不合格、含量超标、包装破损 |
| 检验检测偏差 | 检验过程中发现的异常 | OOS结果、仪器故障、标准溶液异常 |
| 仓储物流偏差 | 储存、运输过程中发生的偏离 | 温湿度超标、运输条件异常 |
| 验证确认偏差 | 验证过程中发现的偏离 | 验证参数偏离、设备故障 |

### 5.2 按偏差严重程度分级

| 级别 | 定义 | 处理时限 | 审批级别 |
|------|------|----------|----------|
| 重大偏差 | 可能对产品质量造成严重影响的偏差 | 立即报告，24小时内完成初步处理 | 质量负责人 |
| 较大偏差 | 可能对产品质量造成一定影响的偏差 | 24小时内完成登记 | 质量经理 |
| 一般偏差 | 对产品质量影响较小的偏差 | 48小时内完成登记 | QA主管 |

## 6. 偏差登记流程

### 6.1 偏差发现与初步处理

```
发现偏差 → 立即停止操作（如需要）→ 标识隔离 
→ 初步评估 → 报告班组长/QA
```

**偏差发现后的即时行动**：
| 情况 | 即时行动 |
|------|----------|
| 正在生产 | 停止操作，标识该批次物料/产品 |
| 涉及设备 | 停止设备运行，标识"待维修" |
| 涉及物料 | 转移至待验区，粘贴"待验"标识 |
| 涉及检验 | 暂停检验，保留样品和试剂 |
| 安全风险 | 确保人员安全，立即报告 |

### 6.2 偏差登记

**偏差登记表内容**：

```
┌─────────────────────────────────────────────────────┐
│                    偏差登记表                        │
├─────────────────────────────────────────────────────┤
│ 偏差编号：DEV-YYYYMMDD-XXX                         │
├─────────────────────────────────────────────────────┤
│ 登记日期：__________ 登记人：__________             │
├─────────────────────────────────────────────────────┤
│ 【偏差基本信息】                                    │
│ 产品名称/批号：____________________                  │
│ 生产工序/设备：____________________                 │
│ 偏差发现时间：____________________                  │
│ 偏差发现地点：____________________                 │
├─────────────────────────────────────────────────────┤
│ 【偏差描述】                                        │
│ 预期情况：________________________________         │
│ 实际情况：________________________________         │
│ 偏离程度：□轻微 □中等 □严重                       │
├─────────────────────────────────────────────────────┤
│ 【初步影响评估】                                    │
│ 对产品质量的影响：________________________________ │
│ 对其他批次的影响：________________________________ │
│ 是否需要召回：□是 □否                             │
├─────────────────────────────────────────────────────┤
│ 【即时措施】                                        │
│ □停止操作 □标识隔离 □设备停机 □其他               │
│ 措施说明：________________________________         │
├─────────────────────────────────────────────────────┤
│ 登记人签名：__________ 日期：__________            │
│ QA接收确认：__________ 日期：__________            │
└─────────────────────────────────────────────────────┘
```

### 6.3 偏差登记时限

| 偏差级别 | 登记时限 | 说明 |
|----------|----------|------|
| 重大偏差 | 发现后1小时内 | 必须立即报告 |
| 较大偏差 | 发现后24小时内 | 应尽快登记 |
| 一般偏差 | 发现后48小时内 | 应在当班完成登记 |

### 6.4 偏差审核与分配

```
偏差登记 → QA初步审核 → 偏差分级 
→ 指派调查人 → 启动调查
```

**QA初步审核要点**：
| 审核项目 | 审核内容 |
|----------|----------|
| 信息完整性 | 偏差描述是否清晰、完整 |
| 分级准确性 | 分级是否符合标准 |
| 即时措施 | 即时措施是否得当 |
| 影响评估 | 初步影响评估是否合理 |

### 6.5 偏差调查与处理

详见《偏差调查处理程序》 SP-QMS-009

详见《偏差关闭标准》 SP-QMS-011

## 9. 偏差登记常见问题

### 9.1 偏差漏登

**原因**：
- 人员意识不足
- 不知道什么是偏差
- 担心被追责

**预防措施**：
- 加强偏差定义培训
- 建立偏差识别激励机制
- 明确偏差不追责原则（故意隐瞒除外）

### 9.2 偏差迟登

**原因**：
- 生产任务紧迫
- 担心影响生产
- 登记流程繁琐

**预防措施**：
- 简化登记表格
- 允许先处理后登记
- 设置登记时限考核

### 9.3 偏差描述不清

**常见问题**：
- 偏差描述过于简略
- 未说明预期与实际差异
- 未说明发现时间、地点

**规范要求**：
- 详细描述偏差现象
- 明确预期值和实际值
- 记录完整的时间和地点信息

## 10. 偏差登记与相关流程的关系

### 10.1 与CAPA的关系

```
偏差登记 → 偏差调查 → 原因分析 
→ CAPA制定 → CAPA执行 → CAPA验证
```

偏差是触发CAPA的重要来源之一，重大偏差必须制定CAPA。

### 10.2 与变更控制的关系

如果偏差涉及工艺、处方、设备等变更，应同步启动变更控制流程。

### 10.3 与投诉的关系

如果偏差可能导致客户投诉或已造成客户投诉，应同步启动投诉处理流程。

### 10.4 与召回的关系

如果偏差可能导致产品质量问题且已放行，应评估是否需要召回。
