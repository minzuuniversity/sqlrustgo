# 产品质量回顾分析规程

**文件编号**: SP-QMS-016
**版本**: V1.0
**生效日期**: 2026-01-01
**审核人**: __________
**批准人**: __________

---

## 1. 目的

建立产品质量回顾分析机制，定期对药品质量数据进行汇总分析，评估药品质量的趋势和稳定性，及时发现潜在的质量问题并采取预防措施，符合《药品生产质量管理规范（2010年修订）》第八条要求。

---

## 2. 范围

适用于公司生产的所有药品（包括成品、中间产品）的产品质量回顾分析，包括：
- 年度产品质量回顾
- 专项产品质量回顾
- 趋势分析
- 变更影响评估

---

## 3. 职责

| 部门/岗位 | 职责 |
|-----------|------|
| 质量保证部 | 负责年度产品质量回顾的策划、组织、审核及报告 |
| 质量控制部 | 负责提供检验数据、参与趋势分析 |
| 生产部 | 负责提供生产过程数据、参与偏差分析 |
| 仓储部 | 负责提供物料及成品储存数据 |
| 销售部 | 负责提供市场反馈及投诉数据 |
| 设备工程部 | 负责提供设备运行数据 |

---

## 4. 定义

### 4.1 产品质量回顾
对特定时期内药品的质量数据进行系统性的收集、分析和评估，以确认工艺流程、文件系统持续稳定的过程。

### 4.2 趋势分析
运用统计方法对质量数据进行分析，识别数据变化趋势和异常波动。

### 4.3 关键质量指标（CQI）
反映药品质量的关键参数，包括含量、有关物质、溶出度、硬度、水分等。

---

## 5. 回顾周期

### 5.1 年度回顾
每年年初对上一年度的产品质量进行回顾分析，通常在1-3月完成。

### 5.2 专项回顾
针对以下情况开展专项回顾：
- 新产品上市首年（每季度回顾）
- 重大变更后（变更后连续3批）
- 重大偏差发生后
- 监管部门要求时

### 5.3 趋势回顾
对关键质量指标进行月度/季度趋势监控。

---

## 6. 回顾内容

### 6.1 产品基本信息

| 内容 | 说明 |
|------|------|
| 产品名称、规格、批准文号 | 药品注册信息 |
| 生产的批次数、批量范围 | 年度生产概况 |
| 销售区域、市场反馈 | 产品流通情况 |
| 关键变更历史 | 配方、工艺、设备的变更记录 |

### 6.2 物料质量数据

| 数据类别 | 分析内容 |
|----------|----------|
| 原料药 | 供应商、批次、数量、检验结果 |
| 辅料 | 批次、检验结果、变更情况 |
| 包装材料 | 批次、检验结果、变更情况 |
| 物料偏差 | 物料相关偏差数量及分析 |

### 6.3 生产过程数据

| 数据类别 | 分析内容 |
|----------|----------|
| 工艺参数 | 关键工序的温度、时间、压力等参数趋势 |
| 过程控制 | 中间产品检验结果、合格率 |
| 偏差 | 生产偏差数量、类型分布、根本原因 |
| 变更 | 工艺变更数量及影响评估 |
| 返工/重新加工 | 返工/重新加工批次统计及原因 |

### 6.4 成品检验数据

| 检验项目 | 分析内容 |
|----------|----------|
| 鉴别 | 鉴别试验结果是否符合规定 |
| 含量测定 | 含量测定结果分布及趋势 |
| 有关物质 | 单杂、总杂变化趋势 |
| 溶出度/崩解时限 | 溶出度/崩解时限结果趋势 |
| 水分 | 水分测定结果趋势 |
| 微生物限度 | 微生物检验结果 |
| 其他项目 | 根据产品特性确定 |

### 6.5 稳定性考察数据

| 内容 | 说明 |
|------|------|
| 长期稳定性试验 | 各时间点检验结果是否符合规定 |
| 加速稳定性试验 | 影响因素考察结果 |
| 稳定性趋势 | 关键指标随时间的变化趋势 |
| 效期评估 | 是否需要调整有效期 |

### 6.6 不合格品与偏差

| 内容 | 说明 |
|------|------|
| 不合格品 | 数量、批次、不合格类型及原因 |
| OOS调查 | OOS数量、分布、根本原因 |
| 重大偏差 | 重大偏差数量、类型、处理结果 |
| 偏差趋势 | 偏差数量年度变化趋势 |

### 6.7 投诉与召回

| 内容 | 说明 |
|------|------|
| 投诉统计 | 投诉数量、类型分布、年度变化 |
| 重大投诉案例 | 重大投诉原因分析及处理 |
| 召回事件 | 召回数量、原因、处理 |
| 市场反馈 | 市场质量反馈总体评价 |

### 6.8 验证与确认

| 内容 | 说明 |
|------|------|
| 工艺验证 | 工艺验证批次结果汇总 |
| 设备确认 | 关键设备确认状态 |
| 清洁验证 | 清洁验证结果 |
| 方法验证 | 分析方法验证状态 |

### 6.9 供应商管理

| 内容 | 说明 |
|------|------|
| 供应商审计 | 供应商审计数量、结论 |
| 物料质量问题 | 因物料质量导致的偏差数量 |
| 供应商变更 | 供应商变更情况及影响 |

## 7. 分析方法

### 7.1 统计技术应用

| 方法 | 应用场景 |
|------|----------|
| 控制图 | 监控关键质量指标是否在统计控制状态 |
| 直方图 | 分析数据分布 |
| 趋势图 | 展示关键指标随时间的变化趋势 |
| pareto图 | 偏差、投诉类型分布分析 |
| 相关性分析 | 分析工艺参数与产品质量的相关性 |

### 7.2 趋势判定标准

| 判定结果 | 标准 |
|----------|------|
| 正常 | 数据在控制限内，无明显趋势 |
| 关注 | 数据接近控制限，但未超出 |
| 异常 | 数据超出控制限或存在明显不良趋势 |

## 8. 回顾报告编写要求

### 8.1 报告结构

```
一、概述
   1. 回顾目的
   2. 回顾范围
   3. 回顾周期

二、产品基本信息

三、数据汇总分析
   1. 物料质量数据
   2. 生产过程数据
   3. 成品检验数据
   4. 稳定性考察数据
   5. 不合格品与偏差
   6. 投诉与召回
   7. 验证与确认
   8. 供应商管理

四、趋势分析
   1. 关键质量指标趋势
   2. 偏差与投诉趋势
   3. 其他关注事项

五、问题与改进
   1. 发现的问题
   2. 根本原因分析
   3. 纠正预防措施（CAPA）
   4. 措施有效性评估

六、结论与建议
   1. 总体评价
   2. 改进建议
   3. 下一周期关注重点

七、批准
```

### 8.2 报告审核与批准

| 审核层级 | 审核人 | 时限 |
|----------|--------|------|
| 初审 | 质量部经理 | 收到草案后5个工作日 |
| 复审 | 生产部经理 | 初审通过后3个工作日 |
| 批准 | 质量负责人 | 复审通过后2个工作日 |

## 9. 回顾结果应用

### 9.1 CAPA触发条件

出现以下情况应启动CAPA：
- 关键质量指标超出控制限
- 同一问题重复发生（3次及以上）
- 重大偏差或投诉
- 监管部门要求

### 9.2 回顾结果应用方向

| 应用方向 | 说明 |
|----------|------|
| 工艺优化 | 根据趋势分析优化工艺参数 |
| 物料管理 | 调整供应商、变更规格 |
| 质量标准 | 考虑修订质量标准 |
| 验证计划 | 制定下一周期验证计划 |
| 培训计划 | 根据问题制定专项培训 |
