# 设备报废管理规程

**文件编号**: SMP-FAC-004 | **类别**: 设施与设备

---

## 1. 目的

规范设备报废管理，确保设备报废处理合规、有序。

## 2. 适用范围

适用于高原彝药厂所有需要报废的设备。

## 3. 报废条件

| 条件 | 说明 |
|------|------|
| 使用年限 | 超过规定使用年限 |
| 损坏严重 | 无法修复 |
| 技术落后 | 无法满足生产要求 |
| 安全隐患 | 存在安全隐患 |

## 4. 职责

| 部门 | 职责 |
|------|------|
| 使用部门 | 提出报废申请 |
| 工程设备部 | 技术鉴定 |
| 质量保证部 | 审核 |
| 财务部 | 资产处理 |
| 总经理 | 批准 |

## 5. 报废流程

| 步骤 | 内容 |
|------|------|
| 1 | 使用部门填写报废申请 |
| 2 | 工程部技术鉴定 |
| 3 | QA审核 |
| 4 | 财务部资产核算 |
| 5 | 总经理批准 |
| 6 | 设备拆除处理 |
| 7 | 档案归档 |

## 6. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 报废申请 | 5年 | 工程设备部 |
| 报废批准 | 5年 | 工程设备部 |
| 设备档案 | 设备报废后5年 | 工程设备部 |
