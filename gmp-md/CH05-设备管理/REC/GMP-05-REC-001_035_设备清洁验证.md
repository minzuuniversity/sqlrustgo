# 设备清洁验证

**文件编号:** REG-GMP-023
**版本号:** V1.0

## 1. 清洁验证要求

**第143条** 设备的清洁必须经过验证。

## 2. 清洁方法分类

| 类型 | 说明 | 适用范围 |
|------|------|---------|
| 手工清洁 | 人工擦拭、清洗 | 复杂设备、难清洁部位 |
| CIP在位清洁 | 不拆卸设备原地清洁 | 反应罐、管道等 |
| COP在位清洁 | 拆下部件集中清洁 | 泵、阀门等 |

## 3. 残留限度

| 限度类型 | 标准 |
|---------|------|
| 活性成分 | MACO = 0.1% × MTD |
| 清洁剂 | 10ppm 或 10μg/cm² |
| 微生物 | 25CFU/25cm² |
| 内毒素 | 0.5EU/ml（注射剂） |

**注：** MACO = 最大允许携带量；MTD = 最小日治疗剂量

## 4. 清洁验证流程

```
清洁规程制定
    ↓
预验证（最差条件选择）
    ↓
清洁验证方案
    ↓
验证实施（3批）
    ↓
取样检测
    ↓
验证报告
    ↓
定期再验证（每年或变更后）
```

## 5. 取样方法

- 擦拭取样（棉签法）
- 淋洗取样
- 空白样对照
