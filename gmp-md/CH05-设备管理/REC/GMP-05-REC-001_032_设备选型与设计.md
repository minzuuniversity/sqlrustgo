# 设备选型与设计

**文件编号:** REG-GMP-020
**版本号:** V1.0

## 1. 设备选型原则

**第121条** 设备的设计、选型、安装、改造和维护必须符合预定用途。

### 选型考虑因素
- 与产品的适应性
- 材质的化学稳定性（不吸附、不反应）
- 机械性能（耐压、耐温、耐腐蚀）
- 操作便利性
- 清洁便利性
- 维护便利性
- 供应商服务能力

## 2. 材质要求

| 接触产品部件 | 材质要求 |
|------------|---------|
| 反应容器 | 316L不锈钢或搪瓷 |
| 管道 | 304或316L不锈钢 |
| 密封件 | 食品级/医药级 |
| 模具（压片） | 不锈钢 |
| 滤芯 | 聚四氟乙烯/聚偏氟乙烯 |

## 3. 用户需求标准（URS）

设备采购前应编制URS，包含：
- 生产能力要求
- 材质要求
- 参数范围要求
- 清洁要求
- 验证要求
- 供应商要求
- 培训要求
- 售后要求
