# DCF-400型打板/锤式除尘水冷粉碎机组

## 1 主题内容

本标准规定了本企业DCF-400型打板/锤式除尘水冷粉碎机组标准操作程序。

## 2 适用范围

适用于DCF-400型打板/锤式除尘水冷粉碎机组的操作。

## 3 责任者：操作者、车间设备员、维修人员。

## 4 主要技术参数

| 型号 | DCF-400 |
| --- | --- |
| 生产能力（Kg/h） | 50-500 |
| 主轴转速（r/min） | 3800-3900 |
| 进料粒度（mm） | ＜20 |
| 粉碎细度（目） | 40-200 |
| 粉碎电机功率（KW） | 7.5 |
| 吸尘电机功率（KW） | 1.5 |
| 风量（M3/h） | 1800 |
| 风压(Pa) | 850 |
| 外形尺寸（长×宽×高） | 1350×800×1700 |
| 机器重量（Kg） | 约420 |

## 5 操作步骤

### 5.1 操作前设备检查

#### 5.1.1 设备使用前首先要进行润滑，凡是装有油杯的地方都应注入适量的润滑脂（油）。

#### 5.1.2 给壳体接通冷却水源，保证冷却水循环畅通。

#### 5.1.3 开机前检查机器所有紧固螺钉是否全部拧紧，尤其是检查固定打板、刀具等锁紧螺钉与螺母是否松动。

#### 5.1.4 随时检查皮带松紧，若损坏要马上更换。

#### 5.1.5 接通电源之前用手转动主轴时应无卡住现象，主轴活动自如。

#### 5.1.6 检查电器安装是否完整，电器部分应可靠接地。

#### 5.1.7 点动检查主轴旋转方向，旋转方向为面对粉碎机时的逆时针方向。

#### 5.1.8 开机前必须检查主机膛内有无铁质杂物，物料中的铁质杂物也应清除。

### 5.2 操作

#### 5.2.1 经上述检查无误后方可开机，开机时先启动吸尘风机，检查符合粉碎物料后倒入料斗，启动粉碎电机，粉碎完成。

#### 5.2.2 停止进料后3分钟左右再停机，以减少粉碎机膛内存料。关机时关闭粉碎电机再关闭吸尘风机。

一般情况下，空载电流为7—8A。

## 6 注意事项

### 6.1 机器每班使用完毕后，机膛内必须清洗干净，更换物料时应同时更换除尘布袋。

### 6.2 要随时检查刀具和牙板磨损情况并更换，以保证产量与细度的要求。

### 6.3 粉碎电流要控制在15安培以内，以防止超负荷后电机烧毁。

### 6.4 更换刀具时最好同时全部更换，并保证重量相同，防止机器震动。

### 6.5 除尘风机的排风口可与风道相接。
