# 成品质量标准

**文件编号**: TS-MAT-002 | **类别**: 物料与产品

---

## 1. 目的

建立成品的质量标准，确保成品质量符合注册批准和质量要求。

## 2. 适用范围

适用于高原彝药厂所有生产的成品。

## 3. 质量标准内容

| 项目 | 内容 |
|------|------|
| 产品名称 | 中文名、英文名 |
| 规格 | 剂型、装量 |
| 批准文号 | 注册批准号 |
| 检验项目 | 性状、鉴别、含量等 |
| 检验方法 | 依据注册标准 |
| 储存条件 | 温度、湿度、光照 |
| 有效期 | 有效期限 |

## 4. 检验项目

### 4.1 性状

| 项目 | 要求 |
|------|------|
| 外观 | 颜色、形状 |
| 剂型特征 | 片剂、包衣片等 |

### 4.2 鉴别

| 项目 | 要求 |
|------|------|
| 化学鉴别 | 特征反应 |
| TLC鉴别 | Rf值一致 |
| UV鉴别 | 吸收特征 |

### 4.3 检查

| 项目 | 要求 |
|------|------|
| 重量差异 | 符合规定 |
| 崩解时限 | 符合规定 |
| 溶出度 | 符合规定 |
| 有关物质 | 符合规定 |
| 微生物限度 | 符合规定 |

### 4.4 含量测定

| 项目 | 要求 |
|------|------|
| 含量范围 | 标示量的90-110% |
| 测定方法 | HPLC/UV等 |

## 5. 批准与修订

| 要求 | 说明 |
|------|------|
| 批准 | 质量负责人批准 |
| 修订 | 按注册批准修订 |

## 6. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 质量标准 | 永久 | 质量保证部 |
| 注册批件 | 永久 | 注册部 |
