## 1. 目的

建立规范的物料验收流程，确保购进物料的质量符合规定要求，防止不合格物料投入生产，保障药品质量安全，符合《药品生产质量管理规范（2010年修订）》第八十三条要求。

---

## 2. 范围

适用于公司所有用于药品生产的物料验收，包括：
- 原料药
- 辅料
- 包装材料（内包装材料、外包装材料）
- 印刷包装材料
- 中药提取物
- 研发用物料（临床试验用药）

---

## 3. 职责

| 部门/岗位 | 职责 |
|-----------|------|
| 质量保证部 | 负责物料验收标准的制定及最终放行 |
| 质量控制部 | 负责物料检验及检验报告审核 |
| 仓储部 | 负责物料接收、入库、储存管理 |
| 采购部 | 负责供应商沟通、到货协调 |
| 生产部 | 负责特殊物料的使用前确认 |

---

## 4. 定义

### 4.1 物料
指用于药品生产的原料、辅料和包装材料。

### 4.2 原料药
指用于药品生产或提供有效成分的物质，包括有效成分和辅料。

### 4.3 辅料
指药品生产中使用的辅料，不包含有效成分。

### 4.4 包装材料
指药品包装所用的材料，包括内包装材料和直接接触药品的包装材料。

### 4.5 印刷包装材料
指印有文字、图案的包装材料，如药品说明书、标签、纸盒等。

## 5. 物料验收流程

### 5.1 到货接收

**到货信息核对**：
| 核对项目 | 要求 |
|----------|------|
| 供应商名称 | 与供应商名单一致 |
| 物料名称 | 与订单一致 |
| 规格型号 | 与订单一致 |
| 批号 | 批号清晰 |
| 数量 | 与送货单一致 |
| 包装完整性 | 无破损、无污染 |
| 标签完整性 | 标识清晰 |

**收货操作**：
1. 核对送货单与采购订单
2. 检查外包装状态
3. 数量清点
4. 确认物料运输条件（温度、湿度等）
5. 在送货单上签字确认收货
6. 将物料移至待验区

### 5.2 来料登记

**来料登记表内容**：
| 项目 | 说明 |
|------|------|
| 物料名称、规格 | |
| 供应商 | |
| 批号/生产日期 | |
| 到货数量 | |
| 到货日期 | |
| 运输条件 | 温度、湿度记录 |
| 验收状态 | 待验/合格/不合格 |
| 收货人 | |

### 5.3 物料取样

**取样要求**：
| 物料类型 | 取样数量 | 取样方法 |
|----------|----------|----------|
| 原料药 | 按取样规程 | 均匀取样 |
| 辅料 | 按取样规程 | 均匀取样 |
| 内包装材料 | 按取样规程 | 随机取样 |
| 外包装材料 | 按取样规程 | 随机取样 |
| 印刷包装材料 | 按取样规程 | 随机取样 |

**取样操作**：
1. 确认物料状态
2. 按取样规程规定的数量取样
3. 使用专用取样工具
4. 取样后立即密封
5. 粘贴取样标识
6. 填写取样记录

### 5.4 物料检验

**检验项目**：

| 物料类型 | 必检项目 | 备注 |
|----------|----------|------|
| 原料药 | 性状、鉴别、含量、有关物质、微生物限度等 | 按原料药质量标准 |
| 辅料 | 性状、鉴别、含量、pH值、微生物限度等 | 按辅料质量标准 |
| 内包装材料 | 外观、尺寸、密封性、微生物限度 | 按包材质量标准 |
| 外包装材料 | 外观、印刷内容、数量 | 按包材质量标准 |
| 印刷包装材料 | 外观、印刷内容、尺寸 | 按包材质量标准 |

**检验时限**：
| 物料类型 | 检验时限 | 说明 |
|----------|----------|------|
| 原料药 | 5-15个工作日 | 根据检验项目 |
| 辅料 | 3-10个工作日 | 根据检验项目 |
| 内包装材料 | 3-7个工作日 | 根据检验项目 |
| 外包装材料 | 2-5个工作日 | 根据检验项目 |

### 5.5 检验结果判定

| 判定结果 | 处理方式 |
|----------|----------|
| 合格 | 放行使用 |
| 不合格 | 启动不合格品处理流程 |
| 复核 | 重新检验或扩大取样 |

### 5.6 物料放行

**放行条件**：
1. 检验合格
2. 供应商审计通过
3. 运输条件符合要求
4. 包装、标识完整
5. 具有检验报告

**放行流程**：
```
检验合格 → 仓库提交放行申请 → QA审核 
→ 打印/领取物料放行证 → 物料移至合格区
```

## 6. 物料验收标准

### 6.1 原料药验收标准

| 检查项目 | 标准要求 |
|----------|----------|
| 供应商 | 在合格供应商名单内 |
| 包装 | 完整、密封、清洁 |
| 标签 | 物料名称、批号、规格、生产日期、有效期 |
| 检验报告 | COA与批号对应 |
| 运输条件 | 符合物料储存要求 |
| 数量 | 与送货单一致 |

### 6.2 辅料验收标准

| 检查项目 | 标准要求 |
|----------|----------|
| 供应商 | 在合格供应商名单内 |
| 包装 | 完整、清洁 |
| 标签 | 物料名称、批号、规格、生产日期、有效期 |
| 检验报告 | COA与批号对应 |
| 运输条件 | 符合物料储存要求 |
| 数量 | 与送货单一致 |

### 6.3 内包装材料验收标准

| 检查项目 | 标准要求 |
|----------|----------|
| 供应商 | 在合格供应商名单内 |
| 外观 | 无破损、无污渍、无异物 |
| 尺寸 | 符合规格要求 |
| 印刷内容 | 正确、清晰 |
| 密封性 | 符合密封性要求 |
| 微生物限度 | 符合标准要求 |

### 6.4 外包装材料验收标准

| 检查项目 | 标准要求 |
|----------|----------|
| 供应商 | 在合格供应商名单内 |
| 外观 | 无破损、无污渍 |
| 数量 | 与送货单一致 |
| 印刷内容 | 正确、清晰、完整 |

### 6.5 印刷包装材料验收标准

| 检查项目 | 标准要求 |
|----------|----------|
| 标签内容 | 正确（品名、规格、批准文号、批号、生产日期等） |
| 说明书内容 | 正确、完整 |
| 纸盒印刷 | 正确、清晰 |
| 数量 | 与送货单一致 |
| 废品率 | ≤标准要求 |

## 7. 拒收标准

出现以下情况应拒收物料：

| 拒收原因 | 具体情形 |
|----------|----------|
| 包装异常 | 破损、泄漏、污染、潮湿 |
| 标识问题 | 无标签、标签内容错误、批号不清 |
| 数量问题 | 数量不符、短缺 |
| 运输问题 | 运输条件不符合要求 |
| 供应商问题 | 供应商不在合格名单内 |
| 质量问题 | 检验不合格 |
| 证书问题 | 无检验报告、报告内容不符 |
| 过期问题 | 已过有效期 |

## 8. 特殊物料验收

### 8.1 冷链物料验收

| 项目 | 要求 |
|------|------|
| 温度记录 | 到货时测量并记录温度 |
| 合格标准 | 2-8℃（冷藏物料） |
| 异常处理 | 温度超标立即报告QA |

### 8.2 危险化学品验收

| 项目 | 要求 |
|------|------|
| 安全标签 | 有MSDS标签 |
| 包装 | 符合危险化学品运输要求 |
| 数量 | 按规定限量存放 |
| 人员防护 | 验收人员佩戴防护用品 |

### 8.3 中药材/中药饮片验收

| 项目 | 要求 |
|------|------|
| 基原鉴定 | 确认品种正确 |
| 产地 | 符合规定 |
| 外观性状 | 符合标准 |
| 杂质 | 不超过标准限度 |
| 水分 | 符合标准 |
| 灰分 | 符合标准 |
| 浸出物 | 符合标准 |

## 10. 供应商要求

### 10.1 供应商资质

| 物料类型 | 资质要求 |
|----------|----------|
| 原料药 | 药品生产许可证、GMP证书 |
| 辅料 | 药品生产许可证或相应资质 |
| 包材 | 相应生产资质 |
| 进口物料 | 药品注册证、进口注册证 |

新供应商在供货前应完成供应商审计，审计合格后列入合格供应商名单。
