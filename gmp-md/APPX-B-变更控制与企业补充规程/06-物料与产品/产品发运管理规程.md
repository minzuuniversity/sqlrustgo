# 产品发运管理规程

**文件编号**: SMP-MAT-004 | **类别**: 物料与产品

---

## 1. 目的

规范产品发运管理，确保产品安全、及时、准确发运。

## 2. 适用范围

适用于高原彝药厂所有成品发运管理。

## 3. 职责

| 部门 | 职责 |
|------|------|
| 销售部 | 发运计划 |
| 仓储部 | 备货和发运 |
| 质量保证部 | 放行确认 |

## 4. 发运条件

| 条件 | 要求 |
|------|------|
| 已放行 | 质量负责人批准放行 |
| 包装完整 | 符合运输要求 |
| 单据齐全 | 送货单、发票 |

## 5. 发运流程

| 步骤 | 内容 |
|------|------|
| 1 | 接收发货指令 |
| 2 | 核对产品信息 |
| 3 | 备货 |
| 4 | 包装检查 |
| 5 | 装车 |
| 6 | 运输跟踪 |

## 6. 运输要求

| 要求 | 内容 |
|------|------|
| 温度 | 按储存条件 |
| 防护 | 防潮、防震 |
| 时效 | 按时送达 |

## 7. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 发运记录 | 5年 | 仓储部 |
| 运输记录 | 5年 | 销售部 |
