# 危险化学品安全管理规程

**文件编号**: SMP-MAT-007 | **类别**: 物料与产品

---

## 1. 目的

规范危险化学品的安全管理，确保安全储存、使用和处理。

## 2. 适用范围

适用于高原彝药厂所有危险化学品。

## 3. 危险化学品分类

| 类别 | 示例 |
|------|------|
| 易燃 | 乙醇、丙酮 |
| 腐蚀 | 酸、碱 |
| 氧化 | 过氧化氢 |
| 有毒 | 氰化物 |

## 4. 管理要求

| 要求 | 内容 |
|------|------|
| 标识 | MSDS标签 |
| 隔离储存 | 按类别分区 |
| 防护用品 | 专用防护 |
| 泄漏处理 | 应急处理 |

## 5. 储存要求

| 要求 | 内容 |
|------|------|
| 专库 | 专用仓库 |
| 防护 | 防火、防腐 |
| 监控 | 温湿度监控 |
| 通风 | 良好通风 |

## 6. 使用要求

| 要求 | 内容 |
|------|------|
| 审批 | 使用审批 |
| 防护 | 佩戴防护用品 |
| 记录 | 详细记录使用 |
| 废液处理 | 按规定处理 |

## 7. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 危险化学品台账 | 5年 | 仓储部 |
| 使用记录 | 5年 | 使用部门 |
| 废液处理记录 | 5年 | 使用部门 |
