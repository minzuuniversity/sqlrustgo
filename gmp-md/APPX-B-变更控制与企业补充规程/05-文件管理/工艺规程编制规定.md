# 工艺规程编制规定

**文件编号**: SMP-DOC-011 | **类别**: 文件管理

---

## 1. 目的

规范工艺规程编制，确保工艺文件准确完整。

## 2. 适用范围

适用于高原彝药厂所有产品工艺规程。

## 3. 工艺规程内容

| 章节 | 内容 |
|------|------|
| 名称 | 产品名称、代号 |
| 处方 | 原辅料清单及用量 |
| 工艺流程 | 工艺流程图 |
| 操作要点 | 关键工序操作参数 |
| 质量标准 | 中间产品质量标准 |
| 设备 | 使用设备清单 |
| 包装 | 包装规格及要求 |

## 4. 编制要求

| 要求 | 说明 |
|------|------|
| 依据注册批件 | 按批准工艺编制 |
| 验证数据 | 依据验证结果 |
| 参数范围 | 明确上下限 |

## 5. 审核批准

| 审核层级 | 审核内容 |
|----------|----------|
| 生产部 | 工艺可行性 |
| 质量部 | 质量可控性 |
| 技术部 | 技术先进性 |
| 质量受权人 | 批准生效 |

## 6. 变更管理

工艺规程变更需按《变更控制管理规程》执行。

## 7. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 工艺规程 | 产品有效期后1年 | 技术部 |
