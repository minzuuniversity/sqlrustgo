# 记录填写与管理规程

**文件编号**: SMP-DOC-005 | **类别**: 文件与记录管理

---

## 1. 目的

规范GMP记录的填写和管理，确保记录真实、完整、及时、可追溯。

## 2. 适用范围

适用于高原彝药厂所有GMP记录的管理。

## 3. 职责

| 部门 | 职责 |
|------|------|
| 各使用部门 | 记录的填写、收集 |
| 质量保证部 | 记录的审核和归档 |
| 档案室 | 记录的长期保存 |

## 4. 记录填写要求

### 4.1 填写原则

| 原则 | 说明 |
|------|------|
| 真实性 | 如实记录实际操作 |
| 完整性 | 填写所有必填项目 |
| 及时性 | 操作完成后及时填写 |
| 规范性 | 按规定格式和方式填写 |
| 可读性 | 字迹清晰，易于阅读 |

### 4.2 填写规范

| 要求 | 内容 |
|------|------|
| 书写工具 | 黑色中性笔或打印 |
| 文字要求 | 规范汉字，不得使用不规范的简化字 |
| 修改要求 | 划单线修改，签字注明原因和日期 |
| 签名 | 不得使用印章，必须手写签名 |
| 日期格式 | YYYY-MM-DD |
| 时间格式 | HH:MM，24小时制 |

### 4.3 空白项处理

| 情况 | 处理方式 |
|------|----------|
| 暂无数据 | 填写"N/A"或"/" |
| 不适用 | 填写"N/A" |
| 遗漏 | 按记录修改规定补充 |

## 5. 记录审核

| 审核级别 | 审核内容 | 审核人 |
|----------|----------|--------|
| 一级审核 | 数据准确性、完整性 | 班长/组长 |
| 二级审核 | 符合性、规范性 | 主管 |
| 三级审核 | 批准放行 | 部门负责人/QA |

## 6. 记录流转

| 步骤 | 时限 | 负责部门 |
|------|------|----------|
| 填写 | 操作完成后即时 | 操作人员 |
| 一级审核 | 当日或下一班前 | 班长/组长 |
| 二级审核 | 3个工作日内 | 主管 |
| 汇总上报 | 批记录完成3个工作日内 | 部门 |
| 三级审核 | 5个工作日内 | 部门负责人/QA |

## 7. 记录保存

| 记录类型 | 保存期限 | 保存条件 |
|----------|----------|----------|
| 批记录 | 5年或有效期后1年 | 防潮、防虫、防火 |
| 验证记录 | 10年 | 原始记录永久保存 |
| 变更/偏差记录 | 10年 | 原始记录永久保存 |
| 培训记录 | 员工离职后5年 | - |

## 8. 记录查阅

| 级别 | 权限 |
|------|------|
| 本部门 | 可查阅本部门记录 |
| QA/管理层 | 可查阅所有记录 |
| 外部检查 | 经批准后提供 |

## 9. 记录销毁

| 条件 | 要求 |
|------|------|
| 超过保存期 | 经质量负责人批准 |
| 无使用价值 | 登记备案后销毁 |
| 涉密记录 | 按保密制度处理 |

## 10. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 记录发放台账 | 5年 | 质量保证部 |
| 记录审核台账 | 5年 | 质量保证部 |
| 记录归档目录 | 永久 | 质量保证部 |
