# 批生产记录审核规程

**文件编号**: SMP-PROD-002 | **类别**: 生产管理

---

## 1. 目的

建立批生产记录审核程序，确保批生产记录完整、准确、符合工艺要求。

## 2. 适用范围

适用于高原彝药厂所有批生产记录的审核。

## 3. 职责

| 部门 | 职责 |
|------|------|
| 生产车间 | 批生产记录填写和初步整理 |
| 生产部 | 审核生产过程符合性 |
| 质量保证部 | 最终审核和放行决定 |
| 质量控制部 | 审核检验相关记录 |

## 4. 审核流程

| 步骤 | 内容 | 审核人 | 时间节点 |
|------|------|--------|----------|
| 车间自审 | 核对原始记录完整性 | 车间主任 | 生产结束后2个工作日 |
| 生产部审核 | 审核工艺执行情况 | 生产部负责人 | 收到后2个工作日 |
| QC审核 | 审核检验数据 | QC主管 | 收到后2个工作日 |
| QA审核 | 最终审核 | QA负责人 | 收到后3个工作日 |
| 批准放行 | 质量负责人批准 | 质量负责人 | 收到后2个工作日 |

## 5. 审核要点

### 5.1 记录完整性

| 检查项 | 要求 |
|--------|------|
| 必填项目 | 所有必填项已填写 |
| 签名 | 应有签名处均已签名 |
| 日期时间 | 符合逻辑，无逻辑错误 |
| 页码 | 连续完整，无缺页 |

### 5.2 工艺符合性

| 检查项 | 要求 |
|--------|------|
| 参数记录 | 在规定范围内 |
| 操作顺序 | 符合工艺规程 |
| 物料使用 | 与指令一致 |
| 设备使用 | 与规定一致 |
| 中间控制 | 按规程执行 |

### 5.3 数据准确性

| 检查项 | 要求 |
|--------|------|
| 计算正确 | 计算公式和结果正确 |
| 数据一致 | 记录数据前后一致 |
| 修改规范 | 修改处签字注明 |

## 6. 偏差处理

审核中发现偏差应：
1. 记录偏差
2. 启动偏差调查
3. 风险评估
4. 决定是否放行

## 7. 审核记录

| 记录 | 内容 |
|------|------|
| 审核检查表 | 逐项检查结果 |
| 审核签名 | 审核人签字 |
| 审核意见 | 发现问题及建议 |

## 8. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 批生产记录 | 有效期后1年或5年 | 质量保证部 |
| 批审核记录 | 5年 | 质量保证部 |
| 偏差处理记录 | 10年 | 质量保证部 |
