# 中药生产管理特殊要求

**文件编号**: SMP-PROD-016 | **类别**: 生产管理

---

## 1. 目的

明确中药生产特殊管理要求，确保中药质量。

## 2. 适用范围

适用于高原彝药厂中药制剂生产。

## 3. 特殊要求

| 要求 | 内容 |
|------|------|
| 前处理 | 净选、洗涤、切制 |
| 提取 | 水提/醇提工艺控制 |
| 浓缩 | 温度、真空度控制 |
| 干燥 | 温度、时间控制 |

## 4. 质量控制重点

| 控制点 | 控制参数 |
|--------|----------|
| 药材鉴别 | 外观、性状、显微 |
| 中间体 | 浸膏相对密度、水分 |
| 成品 | 特征图谱、含量测定 |

## 5. 防交叉污染

| 措施 | 要求 |
|------|------|
| 专用设备 | 毒性药材专用设备 |
| 清洁验证 | 清洁方法经验证 |
| 物料平衡 | 收率在规定范围内 |

## 6. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 中药生产记录 | 产品有效期后1年 | 生产部 |
