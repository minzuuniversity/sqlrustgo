# 生产用水监控规程

**文件编号**: SMP-PROD-007 | **类别**: 生产管理

---

## 1. 目的

建立生产用水监控程序，确保制药用水质量符合工艺要求。

## 2. 适用范围

适用于高原彝药厂所有制药用水系统的监控。

## 3. 制药用水类型

| 类型 | 用途 | 质量标准 |
|------|------|----------|
| 纯化水 | 一般清洗、配置 | 符合中国药典 |
| 注射用水 | 注射剂配置、器具清洗 | 符合中国药典 |
| 灭菌注射用水 | 溶剂 | 符合中国药典 |

## 4. 职责

| 部门 | 职责 |
|------|------|
| 质量控制部 | 水质检验 |
| 工程设备部 | 制水系统运行维护 |
| 质量保证部 | 水质监控监督 |

## 5. 监控项目与频率

### 5.1 纯化水

| 检验项目 | 检验频率 | 判定标准 |
|----------|----------|----------|
| 性状 | 每周 | 无色澄清液体 |
| pH值 | 每周 | 5.0-7.0 |
| 电导率 | 在线连续 | ≤2.0 μS/cm(25°C) |
| 总有机碳 | 每周 | ≤0.5mg/L |
| 微生物限度 | 每周 | ≤100CFU/mL |
| 硝酸盐 | 每月 | ≤0.000006% |
| 重金属 | 每月 | ≤0.00001% |

### 5.2 注射用水

| 检验项目 | 检验频率 | 判定标准 |
|----------|----------|----------|
| 性状 | 每天 | 无色澄清液体 |
| pH值 | 每天 | 5.0-7.0 |
| 电导率 | 在线连续 | ≤1.3 μS/cm(25°C) |
| 总有机碳 | 每天 | ≤0.5mg/L |
| 微生物限度 | 每天 | ≤10CFU/100mL |
| 内毒素 | 每周 | ≤0.25EU/mL |

## 6. 取样要求

| 要求 | 内容 |
|------|------|
| 取样点 | 总出水口、使用点 |
| 取样容器 | 无菌容器 |
| 取样量 | 全检量+留样 |
| 取样方式 | 规范取样，避免污染 |
| 取样记录 | 记录取样信息 |

## 7. 警戒限与行动限

| 参数 | 警戒限 | 行动限 |
|------|--------|--------|
| 微生物 | 限度的50% | 限度的100% |
| 电导率 | 设定值的80% | 设定值的100% |

## 8. 异常处理

1. 超行动限：立即调查，停产处理
2. 超警戒限：加强监控，查找原因
3. 持续异常：系统清洁消毒，验证

## 9. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 水质检验记录 | 5年 | 质量控制部 |
| 制水系统运行记录 | 5年 | 工程设备部 |
| 水质趋势分析 | 5年 | 质量控制部 |
