# 偏差调查处理程序

**文件编号:** SOP-QA-DEV-001
**版本号:** V1.0

## 1. 目的

建立偏差调查处理程序，确保偏差得到及时记录、调查和处理，防止偏差对产品质量造成不良影响。

## 2. 定义

**偏差：** 指偏离批准指令、标准或规程的任何情况。
- 重大偏差：对产品质量可能有实质性影响的偏差
- 一般偏差：对产品质量影响较小的偏差

## 3. 职责

| 角色 | 职责 |
|------|------|
| 发现人 | 及时记录偏差，通知QA |
| 生产人员 | 配合调查，提供信息 |
| QA | 偏差评估、分级、组织调查 |
| 相关部门 | 参与调查，执行CAPA |
| QA经理 | 批准调查报告 |
| 质量总监 | 批准重大偏差 |

## 4. 偏差处理流程

### 4.1 偏差发现与记录
- 发现偏差立即记录在《偏差记录表》
- 标识、隔离相关物料/产品（如需要）
- 通知QA

### 4.2 偏差初步评估
- QA现场确认偏差情况
- 评估偏差对产品质量的潜在影响
- 确定偏差级别（重大/一般）
- 确定调查范围

### 4.3 偏差调查
- 成立调查小组
- 收集相关证据
- 进行根本原因分析（鱼骨图、5Why等）
- 评估对已放行产品的影响

### 4.4 调查报告
- 编写调查报告
- 制定CAPA
- 审批

### 4.5 偏差关闭与跟踪
- 确认CAPA已实施
- 确认整改有效
- 关闭偏差

## 5. 时限要求

| 阶段 | 时限 |
|------|------|
| 初步评估 | 发现后24小时 |
| 调查完成 | 发现后15个工作日 |
| CAPA实施 | 批准后按计划 |
| 偏差关闭 | CAPA完成后 |
