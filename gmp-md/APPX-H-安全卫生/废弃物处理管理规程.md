# 废弃物处理管理规程

**文件编号**: SMP-SEC-005 | **类别**: 安全与卫生

---

## 1. 目的

建立废弃物处理管理制度，规范废弃物分类、收集和处理。

## 2. 适用范围

适用于高原彝药厂所有废弃物管理。

## 3. 废弃物分类

| 类别 | 示例 |
|------|------|
| 一般废弃物 | 办公垃圾、生活垃圾 |
| 危险废弃物 | 废溶剂、废试剂 |
| 医疗废弃物 | 实验废物 |
| 建筑废弃物 | 装修垃圾 |

## 4. 危险废弃物管理

| 要求 | 内容 |
|------|------|
| 分类收集 | 按化学性质分类 |
| 标识 | 明确标识 |
| 储存 | 专门储存区域 |
| 转移 | 委托资质单位 |

## 5. 废弃物处理方式

| 方式 | 适用类别 |
|------|----------|
| 回收 | 可回收物 |
| 焚烧 | 有机溶剂 |
| 填埋 | 一般废物 |
| 专业处理 | 危险废物 |

## 6. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 废弃物台账 | 5年 | 安全部门 |
| 转移联单 | 5年 | 安全部门 |
