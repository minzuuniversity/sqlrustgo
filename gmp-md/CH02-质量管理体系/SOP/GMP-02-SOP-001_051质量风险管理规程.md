# 质量风险管理规程

## 1. 目的

建立并规范一套系统化的质量风险管理流程，用于主动识别、评估、控制、沟通和回顾可能影响药品质量、患者安全及数据完整性的潜在风险。通过将风险管理整合到整个产品生命周期中，确保基于科学和风险的理念进行决策，合理分配资源，并最终保障产品质量和患者用药安全。

## 2. 范围

本规程适用于所有与药品（包括原料药、中间体、成品药）和医疗器械（如适用）生命周期相关的所有活动。包括但不限于：

产品开发：处方工艺设计、质量标准建立

物料管理：供应商评估、物料控制

生产操作：厂房设施设备确认、工艺验证、清洁验证、中间控制、批生产

质量控制：实验室检验方法验证 / 确认、稳定性考察、超标 / 超常结果调查

包装与放行：包装设计、标签管理、产品放行

储存与分销：仓储条件、运输管理

系统与流程：变更控制、偏差处理、自检、供应商管理、计算机化系统管理

退役：产品 / 设备 / 设施的退役

## 3. 职责

各部门负责人（系统所有者）：负责启动并主导其职责范围内的质量风险管理活动，组建风险评估小组，确保风险控制措施的有效实施。

风险评估小组：由来自不同部门（如生产、QA、QC、研发、工程等）的多学科专家组成，负责执行具体的风险评估工作。

质量保证部（QA）：负责提供质量风险管理的方法论支持与培训；负责审核和批准风险管理工作输出（如风险评估报告）；负责监督本规程的执行。

质量受权人 / 质量管理负责人：负责确保质量风险管理体系在公司内有效建立和实施，并为重大风险决策提供最终批准。

## 4. 定义

风险：伤害发生的可能性及其严重性的组合。（ICH Q9）

危害：可能造成伤害的潜在源。（ICH Q9）

质量风险管理：在产品整个生命周期中，对药品的质量风险进行评估、控制、沟通和回顾的系统化过程。（ICH Q9）

风险可接受水平：风险降低到可接受水平的水平，该水平由公司基于法规要求、患者安全和科学知识来确定。

## 5. 规程内容

质量风险管理是一个持续循环的过程，其核心流程如下，并详细描述如下：

（核心流程说明：启动风险管理→风险识别→风险分析（可能性 x 严重性）→风险评估与分级→判断风险是否可接受；若不可接受，执行风险控制→制定控制措施→效果确认与再评估，再次判断风险是否可接受；若可接受，执行风险沟通→风险回顾→风险管理过程结束（输出归档））

### 5.1 启动风险管理（风险问询）

明确风险管理的范围和目标。应使用《质量风险管理启动表》记录：

议题：需要评估的具体问题（如：新工艺引入、某偏差的根本原因、变更请求等）

范围与边界：明确评估涉及的产品、工艺、系统或区域

风险评估小组：确定小组成员及负责人

风险评估工具：选择适宜的工具（见 5.2）

可接受标准：预先定义风险可接受的标准，为后续决策提供依据

### 5.2 风险评估（包含识别、分析与评估）

#### 5.2.1 风险识别

采用系统化的方法，识别与议题相关的所有潜在危害 / 失效模式。

方法：头脑风暴、流程图、检查表、鱼骨图、失效模式与影响分析（FMEA）前置等

输出：一份清晰的潜在危害 / 失效模式清单

#### 5.2.2 风险分析

对已识别的每个风险，评估其发生的可能性（Probability） 和后果的严重性（Severity）。某些情况下，还需评估风险的可探测性（Detectability）。

可能性（P）：危害 / 失效发生的频率或概率。通常分为 1-5 级（如：1 = 极罕见，5 = 极常见）

严重性（S）：危害 / 失效对产品质量 / 患者安全造成影响的严重程度。通常分为 1-5 级（如：1 = 可忽略，5 = 严重 / 危及生命）

可探测性（D）：在危害 / 失效影响患者或导致产品放行前，被现有控制措施探测到的可能性。通常分为 1-5 级（如：1 = 几乎肯定能探测到，5 = 几乎不可能探测到）

公司应制定标准化的评分标准表，以确保评估的一致性。

通过将风险分析中的分数（如 P、S，或 P x S，或 P x S x D）相结合，计算出风险优先性指数（RPN） 或使用风险矩阵，对每个风险进行分级。

根据 RPN 或风险矩阵，将风险划分为不同等级：

极高 / 高风险：不可接受。必须采取风险控制措施

中等风险：可考虑接受，但建议采取合理的控制措施以降低风险

低风险：可接受。可通过现有程序进行管理

### 5.3 风险控制

目标是将风险降低到可接受水平。

风险降低：针对不可接受的风险，制定并实施具体的纠正与预防措施。措施可能包括：改进工艺、增加控制点、增强培训、修改程序等

风险接受：对于经过控制后残留的风险，或原本就是低 / 可接受的风险，做出正式接受的决定。必须记录接受的理由

效果确认与再评估：实施控制措施后，需重新评估风险，以确认风险已降至可接受水平。记录新的 RPN 或风险等级

### 5.4 风险沟通

在风险管理过程的任何阶段，都应在各相关部门和层级之间分享风险信息。形式包括：

风险评估报告

会议

偏差 / 变更控制记录

管理评审

确保所有相关方对风险及其管理措施有清晰的认知。

### 5.5 风险回顾

风险管理是一个动态过程。应建立机制，定期回顾已接受的风险和已实施的控制措施，特别是在发生以下情况时：

预定的时间间隔（如每年）

出现新的科学知识或法规要求

生产 / 检验数据出现不良趋势

偏差、投诉或召回事件表明当前的风险评估已不充分

## 6. 常用风险管理工具

根据风险的复杂性和评估目的，选择合适的工具：

基本工具：流程图、检查表、因果图（鱼骨图）

进阶工具（推荐使用）：

失败模式与影响分析（FMEA）：适用于工艺、设备、设施的评估

失败模式、影响与关键性分析（FMECA）：FMEA 的扩展，增加了关键性分析

危害分析与关键控制点（HACCP）：适用于生产工艺流程的风险控制

危害操作分析（HAZOP）：适用于复杂工艺或设施的风险识别

初步危害分析（PHA）：用于项目初期的快速风险评估
