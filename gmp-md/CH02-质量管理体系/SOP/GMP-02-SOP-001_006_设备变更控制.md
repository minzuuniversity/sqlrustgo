# 设备变更控制规程

**文件编号:** SOP-QA-CC-003
**版本号:** V1.0

## 1. 目的

规范生产设备、检验仪器的变更控制，确保设备变更不影响产品质量。

## 2. 适用范围

- 新设备引进
- 设备改造、搬迁
- 设备备件更换（影响性能）
- 设备用途变更
- 设备退役

## 3. 设备变更流程

### 3.1 新设备引进
1. 提出设备需求（URS）
2. 设备选型、供应商评估
3. DQ设计确认
4. 采购、安装
5. IQ/OQ/PQ确认
6. 设备验收
7. SOP编制、培训
8. 投入生产

### 3.2 设备改造
1. 变更申请
2. 影响评估
3. 改造方案审批
4. 实施
5. 重新确认
6. 文档更新

## 4. 设备退役
- 退役申请审批
- 产品转移（如需要）
- 清洁确认
- 文件归档
- 设备标识移除
