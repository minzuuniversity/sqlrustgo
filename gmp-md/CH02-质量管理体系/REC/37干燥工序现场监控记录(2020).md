### 填写要求：
1. 由QA监控员如实填写。  
2. 检查符合规定及无偏差打"√"。  
3. 检查不符合规定及有偏差打"×"。  

| 监控点及要求 | 结果记录 | 结论 |
|-------------|----------|------|
| **开工前检查** | | |
| 1. 环境干净、整洁，有"清场合格证"，且在效期内。 | | |
| 2. 设备清洁，有完好状态标示及已清洁标示。 | | |
| 3. 容器、工具、台面清洁。 | | |
| 4. 操作人员工装整洁，个人卫生符合规定。 | | |
| 5. 生产指令正确无误。 | | |
| 6. 无与本批次无关的物料和杂物。 | | |
| 7. 物料标示正确，放置整齐，有质量部检验合格报告书。 | | |
| 8. 计量器具有检定合格证，并在有效期内。 | | |
| **过程监控** | | |
| 监控频次：随时/班。 | | |
| 1. 物料的称量：一人称量，一人复核。 | | |
| 2. 操作执行最新批准的操作规程和工艺规程。 | | |
| 3. 物料放置整齐有序，标示正确，随机抽查品名及重量标示与实物相符。 | | |
| 4. 生产现场整洁，操作人员动作规范。 | | |
| 5. 用贵细、毒性药材、中药饮片等特殊物料收膏时执行《特殊投料现场监控标准操作程序》。 | | |
| 6. 收膏时应妥善防止污染。 | | |
| 7. 浸膏干燥装盘均匀，温度适当，厚度适中，不得翻扑出盘，干燥品应干、脆、疏松。 | | |
| 8. 中间体按规定取样检验。 | | |
| 9. 原始记录：填写真实、准确、完整、及时。 | | |
| 10. 生产偏差：执行《生产过程偏差处理标准管理规程》，并有记录。 | | |
