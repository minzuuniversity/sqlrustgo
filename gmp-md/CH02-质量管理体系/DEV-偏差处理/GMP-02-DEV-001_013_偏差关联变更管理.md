# 偏差关联变更管理规程

**文件编号:** SOP-QA-CC-010
**版本号:** V1.0

## 1. 目的

规范因偏差调查而触发的变更控制，确保根本原因分析后制定的纠正预防措施有效执行。

## 2. 偏差与变更的关系

偏差调查后，可能需要：
- 临时控制措施（当前批次处理）
- 长期纠正措施（变更控制）
- 预防措施（系统性改进）

## 3. 流程要求

### 3.1 偏差关闭后评估
- 偏差关闭前，必须评估是否需要启动变更控制
- 评估内容：
  - 是否涉及工艺参数修改
  - 是否涉及设备改造
  - 是否涉及物料/供应商变更
  - 是否涉及文件更新

### 3.2 变更启动条件
以下情况必须启动变更控制：
- 偏差根本原因涉及系统性缺陷
- 偏差建议措施涉及工艺/设备变更
- 监管机构要求的整改

### 3.3 关联记录
- 偏差记录中注明关联的变更编号
- 变更记录中注明触发的偏差编号
- 确保闭环可追溯

## 4. 整改跟踪

- CAPA措施纳入变更实施计划
- QA跟踪整改进度
- 验证整改有效性
- 纳入管理评审评估
