# 生产偏差处理规程

**文件编号**: SMP-PROD-005 | **类别**: 生产管理

---

## 1. 目的

建立生产偏差处理程序，规范偏差的发现、报告、调查和处理，确保产品质量。

## 2. 适用范围

适用于高原彝药厂所有生产过程中出现的偏差。

## 3. 偏差定义

生产偏差是指生产过程中实际发生的情况与预期或规定要求之间的差异。

## 4. 偏差分类

| 分类 | 定义 | 示例 |
|------|------|------|
| 关键偏差 | 可能对产品质量造成重大影响 | 关键参数严重偏离 |
| 主要偏差 | 可能对产品质量造成影响 | 一般参数偏离 |
| 次要偏差 | 对产品质量影响较小 | 记录不及时等 |

## 5. 职责

| 部门 | 职责 |
|------|------|
| 发现偏差者 | 立即报告，必要时停止操作 |
| 生产车间 | 偏差的初始报告和现场处理 |
| 质量保证部 | 偏差的调查和处理决定 |
| 生产部 | 配合偏差调查 |
| 质量控制部 | 样品检测支持 |

## 6. 偏差处理流程

### 6.1 偏差发现

| 要求 | 内容 |
|------|------|
| 立即报告 | 发现偏差立即报告 |
| 紧急处理 | 必要时停止操作 |
| 标识隔离 | 对物料/产品标识隔离 |
| 记录时间 | 记录偏差发生时间 |

### 6.2 偏差报告

| 报告内容 | 要求 |
|----------|------|
| 偏差描述 | 详细描述偏差情况 |
| 涉及批次 | 影响的批次 |
| 发现时间 | 发现偏差的时间 |
| 发现人 | 发现偏差的人员 |
| 初步评估 | 对影响的初步评估 |

### 6.3 偏差调查

| 调查内容 | 方法 |
|----------|------|
| 根本原因 | 5Why、鱼骨图分析 |
| 影响评估 | 对产品质量的影响 |
| 范围确定 | 涉及的产品批次 |
| 历史回顾 | 类似偏差是否发生过 |

### 6.4 偏差处理决定

| 偏差级别 | 决定权限 |
|----------|----------|
| 关键偏差 | 质量负责人 |
| 主要偏差 | QA负责人 |
| 次要偏差 | 部门负责人 |

### 6.5 偏差处理措施

| 措施类型 | 内容 |
|----------|------|
| 即时措施 | 防止偏差扩大 |
| 纠正措施 | 消除偏差 |
| 预防措施 | 防止再发生 |

## 7. 偏差处理时限

| 偏差级别 | 调查报告提交 | 处理完成 |
|----------|--------------|----------|
| 关键偏差 | 15个工作日 | 30个工作日 |
| 主要偏差 | 20个工作日 | 45个工作日 |
| 次要偏差 | 30个工作日 | 60个工作日 |

## 8. 偏差关闭

偏差关闭条件：
- 根本原因明确
- 处理措施已实施
- 影响评估完成
- 预防措施已制定

## 9. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 偏差报告表 | 10年 | 质量保证部 |
| 偏差调查报告 | 10年 | 质量保证部 |
| 偏差处理记录 | 10年 | 质量保证部 |
