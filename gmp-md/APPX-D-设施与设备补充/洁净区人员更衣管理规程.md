# 洁净区人员更衣管理规程

**文件编号**: SMP-FAC-007 | **类别**: 设施与设备

---

## 1. 目的

规范洁净区人员更衣程序，防止污染和交叉污染。

## 2. 适用范围

适用于高原彝药厂所有进入洁净区的人员。

## 3. 更衣程序

### 3.1 D级区更衣

| 步骤 | 内容 |
|------|------|
| 1 | 换鞋 |
| 2 | 穿连体洁净服 |
| 3 | 戴口罩 |
| 4 | 戴手套 |
| 5 | 手消毒 |

### 3.2 C级区更衣

| 步骤 | 内容 |
|------|------|
| 1 | 换鞋 |
| 2 | 洗手 |
| 3 | 穿内衬服 |
| 4 | 穿连体洁净服 |
| 5 | 戴口罩 |
| 6 | 戴护目镜 |
| 7 | 戴手套 |
| 8 | 手消毒 |

### 3.3 A/B级区更衣

| 步骤 | 内容 |
|------|------|
| 1 | 换鞋 |
| 2 | 洗手 |
| 3 | 穿内衬服 |
| 4 | 穿洁净服 |
| 5 | 护目镜 |
| 6 | 口罩 |
| 7 | 消毒后进入 |

## 4. 更衣注意事项

| 要求 | 内容 |
|------|------|
| 动作轻柔 | 避免扬尘 |
| 包裹严密 | 不暴露皮肤 |
| 定期更换 | 洁净服定期更换 |
| 一人一换 | 不可共用 |

## 5. 记录与归档

| 记录名称 | 保存期 | 负责部门 |
|----------|--------|----------|
| 更衣记录 | 5年 | 生产部 |
| 洁净服更换记录 | 5年 | 生产部 |
