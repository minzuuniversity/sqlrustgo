## 备选与建议

A继续steal并补loser undo；B committed-only snapshot+private workspace；C禁止大事务。

推荐：B：snapshot只能来自committed generation；事务私有行可在有隔离证明的临时spool暂存，不伪装成可恢复committed baseline。

## 风险与取舍
