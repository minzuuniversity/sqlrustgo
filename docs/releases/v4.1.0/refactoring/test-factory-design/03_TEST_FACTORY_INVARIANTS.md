# Test Factory 不变量

| ID | 不变量 | 正向验收 | 反例 |
|---|---|---|---|
| TF-I01 | case_id 在迁移前后稳定且唯一 | 同一源码迁移保持 ID | 重名/改名未登记必须拒绝 |
| TF-I02 | 原始断言语义受保护 | assertion_semantics 哈希一致 | 删除/弱化断言必须拒绝 |
| TF-I03 | 计划 case 全部实际执行 | 集合完全相等 | 零测试或漏一项判 NOT_RUN |
| TF-I04 | 失败归因真实 | 身份与签名精确匹配 | exit 101 但签名不同判 UNEXPECTED_RED |
| TF-I05 | RED→GREEN 独立复验 | Reviewer 独立重跑 | 开发者单跑转绿不得销账 |
| TF-I06 | 发布不可绕过开放缺陷 | 发布检查消费适用开放项 | 未关闭 RED 被遗漏必须拒绝 |
| TF-I07 | 默认 CHECK 零写入 | 前后树和基线哈希一致 | CHECK 改 baseline 必须失败 |
| TF-I08 | ADR/包/Issue/case 可追溯 | 所有引用可解析到固定对象 | 空引用或漂移引用必须拒绝 |
| TF-I09 | 正确实现绿、错误实现红 | 行为 mutation 双向验证 | 只注入名称不构成证明 |
| TF-I10 | 权威来源唯一 | 投影可从正式对象重建 | 手工账本冲突时 fail closed |

所有不变量均须在 TF-07 由独立 Reviewer 执行正向和反例；计划文档本身不构成验证结果。
