## 一、测试概述

### 1.1 测试目标

v1.5.0 测试目标是验证持久化存储、索引支持和表达式优化。

### 1.2 测试范围

- Storage 模块: 页式存储、缓冲池、WAL、表堆存储
- Index 模块: B+Tree 索引、IndexScan 算子
- Optimizer 模块: 常量折叠、表达式简化
- 集成测试: 存储引擎、索引、端到端查询
