## SQLRustGo v1.5.0

**持久化存储 & 表达式优化版**

SQLRustGo v1.5.0 专注于持久化存储，在 v1.4.0 基础上实现持久化存储、索引支持和表达式优化。

### 核心特性

| 特性 | 说明 |
|------|------|
| **页式存储** | 磁盘页管理 |
| **缓冲池** | LRU 内存缓存 |
| **WAL** | 预写日志 |
| **表堆存储** | 持久化表数据 |
| **B+Tree 索引** | 索引结构 |
| **表达式优化** | 常量折叠增强 |

---

## 快速开始

```bash
# 构建
cargo build --all-features

# 运行 REPL
cargo run --bin sqlrustgo

# 运行测试
cargo test --all-features

# 运行集成测试
bash scripts/test/run_integration.sh --quick
```
