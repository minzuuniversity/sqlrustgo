## 测试范围

### P0 功能测试

| 功能 | 测试内容 | 测试方法 |
|------|----------|----------|
| 自动故障检测 | 心跳超时检测 | 模拟节点故障，验证检测时间 < 5s |
| 自动主从切换 | 切换流程 | 模拟主节点故障，验证切换时间 < 30s |
| 脑裂防护 | fencing 机制 | 模拟脑裂场景，验证防护有效 |
| 故障通知 | webhook/邮件 | 触发故障，检查通知送达 |
| 读写分离代理 | 读写路由 | 验证读请求分发到从节点 |
| 备库延迟检测 | 延迟监控 | 模拟延迟，验证自动降级 |

### P1 功能测试

| 功能 | 测试内容 | 测试方法 |
|------|----------|----------|
| 运维 Web 面板 | UI 功能 | 界面测试 + 功能验证 |
| SQL 执行界面 | SQL 执行 | 界面执行 SQL，验证结果 |
| SHOW PROCESSLIST | 进程列表 | 执行命令，验证列表准确性 |
| KILL 命令 | 终止查询 | 执行 KILL，验证查询终止 |
| SHOW STATUS | 状态信息 | 执行命令，验证状态准确 |

## 测试命令

```bash
# 编译测试
cargo build --all-features

# 单元测试
cargo test --lib -p sqlrustgo-ha
cargo test --lib -p sqlrustgo-proxy

# 集成测试
cargo test --test ha_integration
cargo test --test proxy_integration

# E2E 测试
cargo test --test e2e_ha
```
