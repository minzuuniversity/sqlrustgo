## v2.2.0 (2026-03-28) - 中间版本

### 概述

v2.2.0 是一个中间开发版本，聚焦于高可用自动化和读写分离功能。

> **注意**: v2.2.0 为开发中间版本，未正式发布。仅有 DEVELOPMENT_PLAN.md 存在。

---

## 版本目标

v2.2 是"省心线中级版"，实现故障自动检测和切换，1个人能值守，不用人工干预。

### 核心功能

| 功能 | 描述 | 状态 |
|------|------|------|
| 自动故障检测 | 心跳 + 超时检测 | 📋 规划 |
| 自动主从切换 | promote slave | 📋 规划 |
| 脑裂防护 | fencing 机制 | 📋 规划 |
| 故障通知 | webhook/邮件 | 📋 规划 |
| 读写分离 | 读性能 +100% | 📋 规划 |
| 备库延迟检测 | 延迟阈值自动降级 | 📋 规划 |
| 运维 Web 面板 | 状态监控 + SQL 执行 | 📋 规划 |
