## 版本概述

v2.2.0 是"省心线中级版"，实现故障自动检测和切换，1个人能值守，不用人工干预。

> **注意**: v2.2.0 为开发中间版本，未正式发布。

## 快速开始

```bash
# 克隆项目
git clone https://github.com/minzuuniversity/sqlrustgo.git
cd sqlrustgo
git checkout develop/v2.2.0

# 构建
cargo build --release

# 运行高可用测试
cargo test --test ha_tests
```
