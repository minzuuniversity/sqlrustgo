# v1.2.0 Release Notes

> **版本**: 1.2.0
> **更新日期**: 2026-05-23
> **维护人**: Hermes + Claude
> **阶段状态**: Beta (GA 前完成)
> **基于版本**: v1.1.0 (2026-05-22)

---

## 概述

GMP 内审检索系统 v1.2.0 是 v1.1.0 的功能扩展版本，主要新增 Agent 编排层、JWT 认证、E2E 测试和移动端支持。本版本保持 v1.1.0 的性能基线（96.1% 通过率，MRR 0.497，QPS 8.3），同时扩展系统能力至企业级 GMP 合规管理。

---

## 核心变更

### 1. Agent 编排层

**功能描述**: 
- DSL 生成器：支持 GMP 工作流 DSL 定义
- 防火墙规则引擎：基于规则的访问控制
- 流程编排器：多步骤任务协调执行

**技术实现**:
- AgentEngine crate 新增编排逻辑
- 支持复杂工作流程定义
- 与现有四通道检索无缝集成

**影响**: 系统从检索能力扩展到智能编排能力。

### 2. JWT 认证与电子签名

**功能描述**:
- JWT Token 身份验证
- 电子签名合规支持
- 会话管理与刷新机制

**安全增强**:
- API 端点认证保护
- 操作审计日志
- 合规性提升 (GMP 要求)

### 3. E2E 测试套件

**新增测试**:
- TS-WEI-001~010 端到端测试
- 防火墙中文注入规则测试
- 全链路测试覆盖

**测试范围**:
| 测试类型 | 覆盖范围 |
|---------|---------|
| 单元测试 | 135 tests |
| 集成测试 | 多通道融合 |
| E2E 测试 | TS-WEI-001~010 |

### 4. 移动端 CLI 模拟器

**功能描述**:
- Mobile CLI 仿真支持
- 跨平台终端接口
- 轻量级客户端

### 5. 闭环节验证流水线

**6步验证流程**:
1. 文档录入 → 2. 规则匹配 → 3. 向量检索 → 4. Rerank → 5. 答案生成 → 6. 合规验证

**价值**: 确保 GMP 审计全流程可追溯、可验证。

### 6. 合规审计与文档

**新增文档**:
- OpenAPI 规范 (RESTful API)
- 合规审计报告
- GMP 称重工作流用户手册
- FAQ 知识库

## 升级路径

### 从 v1.1.0 升级

本版本为增量更新，升级步骤：

1. 停止 v1.1.0 服务
2. 拉取最新代码 `git checkout develop/v1.2.0`
3. 重新编译 `cargo build --release`
4. 启动 v1.2.0 服务

**数据兼容性**: v1.2.0 完全兼容 v1.1.0 的数据库，无需数据迁移。

**新增依赖**:
- JWT 库 (如 jsonwebtoken)
- 电子签名库
