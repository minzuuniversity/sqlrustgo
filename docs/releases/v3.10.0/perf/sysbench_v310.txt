## sysbench OLTP Status

sysbench cannot run because:

1. **sysbench prepare** creates tables with AUTO_INCREMENT → server crash
2. Even if tables exist, TRUNCATE between test rounds → server crash
3. DROP TABLE between test rounds → server crash

Workaround: manual table creation without AUTO_INCREMENT (100 rows inserted one-by-one):

```sql
CREATE TABLE sbtest1 (id INT PRIMARY KEY, k INT, c CHAR(120), pad CHAR(60));
-- Insert 100 rows manually
```

Point-select works:
```sql
SELECT * FROM sbtest1 WHERE id=50;
-- Returns correct row in ~0.5s (mysql CLI overhead, server is fast)
```

## Root Causes of Remaining Crashes

1. **TRUNCATE**: Not implemented — server panics when processing `TRUNCATE` statement
2. **DROP TABLE**: Bug in table drop cleanup — server panics during cascade cleanup
3. **AUTO_INCREMENT**: Bug in AUTO_INCREMENT column handling in CREATE TABLE

## Required Fixes (v3.11.0)

1. Implement TRUNCATE TABLE properly (or return "not supported" error gracefully)
2. Fix DROP TABLE cleanup (handle cascade deletion without panic)
3. Fix AUTO_INCREMENT in CREATE TABLE (or parse but return "not implemented" gracefully)
