## 一、版本概述

### 1.1 战略定位

| 版本 | 定位 | 核心能力 | 发布日期 |
|------|------|----------|----------|
| **v1.2.0** | Vector Engine | 矢量化执行、统计信息 | 2026-03-13 |
| **v1.3.0** | Enterprise Ready | Volcano Model、可观测性 | 2026-03-15 |

### 1.2 核心目标

v1.3.0 是架构稳定版，核心目标：

1. **统一执行模型**: Volcano trait 统一所有算子
2. **可观测性**: Metrics + Health + Prometheus
3. **测试覆盖**: 整体覆盖率 ≥65%
