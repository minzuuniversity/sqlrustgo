## 四、性能测量命令

### 4.1 QPS 压测

```bash
# 单次查询
cargo run --release --bin gmp-retrieve bench --single

# 并发压测
cargo run --release --bin gmp-retrieve bench --concurrent 10 --rounds 100

# 输出示例:
# QPS: 8.3, P50: 1.2s, P95: 1.4s, P99: 1.8s
```

### 4.2 391 场景基准测试

```bash
gmp-eval --test-set test-data/391_scenarios.json \
  --output perf_v130.json \
  --metrics pass_rate,mrr,recall@10,recall@20
```

### 4.3 72h 连续压测

```bash
python3 scripts/stress_test_72h.py --output stress_v130.json
```
