# GMP-Platform v1.3.0 开发计划

> **版本**: 1.0
> **日期**: 2026-05-24
> **分支**: `develop/v1.3.0`
> **目标**: 为 v2.0 综合管理平台打造坚实的能力基座

---

## 一、版本目标

v1.3.0 整合原 v1.3/v1.4/v1.5 的全部功能聚焦于"数据完备 + 知识管线 + 能力扩展"，为 v2.0 平台化奠定技术和数据基础。

**三大核心目标：**
1. **数据完备** — 生成 13809 embeddings 向量索引，解决历史遗留的向量缺失问题
2. **知识管线** — 实现 Layer 0 离线知识抽取管线（术语库 + NER + RE + 分类 + 预评分）
3. **平台基座** — 图持久化、MQTT 集成、技术债清理，构建可扩展的底层能力
