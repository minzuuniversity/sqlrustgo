## 安装信息

### 安装方法

```bash
# 通过 cargo 安装
cargo install --git https://github.com/minzuuniversity/sqlrustgo.git

# 从源码构建
git clone https://github.com/minzuuniversity/sqlrustgo.git
cd sqlrustgo
cargo build --release
```

### 系统要求

- Rust 1.75.0 或更高版本
- 支持 macOS、Linux、Windows
