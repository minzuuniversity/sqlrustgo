## 概述

GMP 内审检索系统 v1.0.0 是首个基于 SQLRustGo 统一数据底座的合规性审核检索系统，实现四层架构：数据存储 → 多路检索 → Reranker 重排 → LLM 问答。

---

## 核心特性

### 1. SQLRustGo 统一数据底座

- 单二进制数据库：内嵌 RDBMS + 向量索引 + 全文索引 + 图存储
- 零外部数据库依赖，部署简化
- GMP 合规特性内置（审计链、电子签名）

### 2. 四通道检索引擎

| 通道 | 技术 | 能力 |
|------|------|------|
| 规则通道 | agent-knowledge YAML | 结构化规则精确匹配，weight=2.0 |
| 向量通道 | bge-m3 1024d + HNSW | 语义相似度检索 |
| 全文通道 | BM25 + FMM GMP 分词 | 关键词/短语精确检索 |
| 图谱通道 | Cypher + BFS | 实体关系扩展召回 |

### 3. RRF 融合 + Reranker 重排

- Reciprocal Rank Fusion（k=60）融合四通道结果
- bge-reranker-v2-m3 Cross-Encoder 相关性重排
- CPU 优先设计，GPU 可选加速

### 4. LLM 辅助问答

- qwen2.5:14b 基于检索上下文生成答案
- 7 种意图自动分类
- 引用溯源：每个回答标注来源文档

### 5. CLI 工具

```bash
gmp-retrieve index --source gmp-md/       # 数据导入 + 索引构建
gmp-retrieve search "偏差分级" --all       # 全通道检索
gmp-retrieve evaluate --test-set 391.json  # 批量评估
gmp-retrieve shell                          # 交互式问答
```

## 已知限制

1. **中国 GMP 条文缺失**: 当前知识库以 EU GMP 为主，中国 GMP 2010 版待补充
2. **设备操作细节不足**: 缺少设备手册等高度情境化数据
3. **GPU 兼容性**: NVIDIA 5080 新驱动可能与当前 Ollama 版本存在兼容问题
4. **LLM 幻觉**: 14B 模型在复杂多步推理中可能出现编造
5. **仅支持 CLI**: v1.1.0 规划 Web API
