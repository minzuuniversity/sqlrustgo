## 一、版本目标

v1.0.0 是 SQLRustGo 的首个 GA 版本，实现数据库核心功能。

### 核心交付物

| 模块 | 功能 | 状态 |
|------|------|------|
| Parser | SQL 解析 (SELECT/INSERT/UPDATE/DELETE) | ✅ |
| Executor | 火山模型查询执行 | ✅ |
| Optimizer | 基于规则的查询优化 | ✅ |
| Storage | B+ 树存储引擎 + MVCC | ✅ |
| Transaction | WAL + 快照隔离 | ✅ |
