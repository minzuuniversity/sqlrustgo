## 一、追踪机制

### 1.1 版本延续原则

依据 `docs/governance/GOVERNANCE_STANDARD.md` 第二章第四节「版本延续原则」：

```
未完成任务必须映射到下版本，不得丢失
```

### 1.2 Issue 状态定义

| 状态 | 说明 |
|------|------|
| OPEN | 问题已识别，待修复 |
| IN_PROGRESS | 正在修复中 |
| CLOSED | 已修复并验证通过 |

### 1.3 追踪规则

```
门禁 FAIL → 创建 Issue → 关联本文档 → 修复 PR → 验证 → 关闭 Issue
```
