## v1.1.0 (2026-03-05) - 改进版本

### 概述

v1.1.0 是基于 v1.0.0 GA 的改进版本，解决 DeepSeek 评估报告中发现的问题。

#### 错误处理改进

| Issue | 任务 | 状态 |
|-------|------|------|
| P0-2.1 | executor 模块 unwrap 替换 | ✅ |
| P0-2.2 | storage 模块 unwrap 替换 | ✅ |
| P0-2.3 | 其他模块 unwrap 替换 | ✅ |

| Issue | 任务 | 状态 |
