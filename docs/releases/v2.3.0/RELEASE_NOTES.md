## 发布说明

### 为什么不发布？

v2.3.0 是一个并行执行优化版本，聚焦于多核 CPU 利用率提升。由于以下原因，未进行正式发布：

1. **功能开发中**: ParallelAggregateExecutor 等核心组件开发中
2. **性能测试未完成**: 加速比验证未通过
3. **调度优化未完成**: 自适应并行度和数据局部性优化未实现

### 后续版本

v2.3.0 的功能延续到后续版本:

| 版本 | 功能 | 状态 |

| v2.4.0 | 分布式执行框架（Exchange 算子） | 规划中 |
