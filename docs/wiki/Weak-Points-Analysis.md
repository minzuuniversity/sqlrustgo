## 三、架构性弱项

### 3.1 优化器架构

```
当前问题:
┌─────────────────────────────────────────────────────────────┐
│                    Optimizer 现状                           │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│  ✅ PredicatePushdown 已激活                                │
│  ✅ ProjectionPruning 已激活                                │
│  ✅ ConstantFolding 已激活                                 │
│  ⚠️ SimpleCostModel 存在但未接入 planner                  │
│  ❌ 索引选择 未实现                                        │
│  ❌ Join 重排序 未实现                                       │
│                                                              │
│  问题: CBO 三大核心功能缺失一半                             │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

**改进方向:**
1. 激活 CostModel 并接入 planner
2. 实现基于代价的索引选择
3. 实现动态规划 Join 重排序

### 3.2 执行器架构

| 问题 | 根因 | 改进方案 |
|------|------|----------|
| Hash Join 独占 | 无并发执行器 | 引入并行执行框架 |
| 无 MERGE JOIN | 算法未实现 | 实现 Sort-Merge Join |
| ~~窗口函数不完整~~ | ✅ 已完整实现 | 无需改进 |

### 3.3 存储层架构

| 问题 | 根因 | 改进方案 |
|------|------|----------|
| 无聚簇索引 | B+Tree 设计限制 | 重新设计聚簇索引 |
| 无压缩 | 未实现 | 支持 page 级压缩 |
| 无分区表 | 未实现 | 实现 RANGE/HASH 分区 |

└─────────────────────────────────────────────────────────────┘

### 4.3 覆盖率提升策略

| 阶段 | 目标 | 时间 | 重点 |
|------|------|------|------|
| Week 1-2 | 补全链路文档 | 完成执行链路图 | 时序图 + 状态图 |
| Week 3-4 | 边界条件覆盖 | NULL/类型转换 | 等价类划分 |
| Week 5-6 | 集成路径覆盖 | 模块接口测试 | 端到端测试 |
| Week 7-8 | 性能压力测试 | 并发 + 回归 | 稳定性验证 |
