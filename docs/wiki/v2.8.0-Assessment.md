# v2.8.0 MySQL 协议兼容性差距评估

> 评估日期: 2026-05-02 | 目标版本: rc/v2.8.0

---

## 评估范围

本评估针对 SQLRustGo v2.8.0 的 MySQL 协议兼容性进行差距分析。覆盖范围包括：

- MySQL 5.7 / 8.0 核心协议握手流程
- SQL 语法兼容性（DML / DDL / 函数）
- 预处理语句与二进制协议
- 认证机制（mysql_native_password, caching_sha2_password）
- 连接与会话管理

---

## 已知限制 (v2.8.0)

### P0 阻塞项

- **MVCC 实现不完整** — `mvcc_proof: FAIL`，影响并发事务隔离
- **MySQL 5.7 兼容故障** — 57 个测试失败（主要涉及协议细节）
- **列级权限系统** — 开发中，GRANT 缺少列级控制

### P1 高优先级

- GROUP BY / HAVING 聚合查询缺失
- UNION 集合查询缺失
- 子查询支持不完整
- JSON 数据类型缺失
- 字符串/数值/日期函数支持不完整
- 外键约束缺失
- 复合索引支持缺失
- EXPLAIN 执行计划缺失
- 行级锁缺失

### P2 中优先级

- 条件函数 (IF/COALESCE) 缺失
- ENUM / SET 数据类型缺失
- CASE WHEN 表达式缺失
- WITH (CTE) 公用表表达式
- 索引提示缺失
- CHECK 约束缺失
- BINARY / VARBINARY 类型缺失

### P3 低优先级（后续版本）

- 空间数据类型 (GEOMETRY)
- 窗口函数
- 分区表
- 存储过程 / 触发器 / 视图
- SSL/TLS 加密连接
