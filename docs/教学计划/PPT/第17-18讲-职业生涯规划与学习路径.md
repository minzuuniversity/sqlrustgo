经过16周的项目实践，你已经具备：

# Part 1: 薪资真相

---

## 1.1 2026年：20K月薪是什么水平？

```
1997年月薪 ≈ 800元  (刚毕业)
2026年月薪 ≈ 20,000元 (刚毕业)

通胀调整后：20K ≈ 1997年的 1,000-1,500元
```

不是天价。但需要你拿出**不一样的履历**。

---

## 1.2 招聘市场的真实信号

| 类型 | 薪资 | 要求 |
|------|------|------|
| 传统CRUD后端 | 8-12K | 能写增删改查 |
| 系统/基础设施方向 | 15-25K | 理解数据库内核、分布式 |
| AI工程化方向 | 18-30K | RAG、Agent、模型部署 |
| 纯AI模型研发 | 25-40K+ | 硕士起步，顶会论文 |

**我们的定位**：系统方向 + AI工程化 = **20K起步**

---

## 1.3 招聘方真正看什么？

❌ 不看：成绩单分数、背了哪些框架API、会多少种语言
✅ 真看：

- GitHub上的项目（能不能跑？架构清晰吗？）
- 系统理解深度（为什么快？为什么不丢失数据？）
- 问题解决记录（技术博客、开源PR）

> 简历上写"熟悉MySQL" vs 简历上写"用Rust实现了一个SQL数据库"——高下立判。

# Part 2: 书单评估

---

## 2.1 整体评价

26本书的原始书单 —— 覆盖很广，但：

- **太重**：大二到大四根本读不完
- **太散**：从UML到深度学习，没有聚焦线
- **缺AI时代关键能力**：Prompt Engineering、RAG、Agent
- **缺系统实战**：DDIA、OSTEP、数据库内核

---

## 2.2 精简分类：必读精读（5-7本）

| 书名 | 理由 | 时间 |
|------|------|------|
| 《深入理解计算机系统》(CSAPP) | 系统能力的基石 | 大二下~大三上 |
| 《数据密集型应用系统设计》(DDIA) | 分布式系统圣经 | 大三上~大三下 |
| 《设计模式》(GoF) | 模式思维，配合代码实践 | 大三期间 |
| 《编程珠玑》 | 算法思维，比刷题更深刻 | 碎片时间 |
| 《程序员修炼之道》 | 工程哲学，每学期重读 | 持续 |

---

## 2.3 方向补充（选1-2本）

**后端/系统方向**：
- 《操作系统：三个简单部分》(OSTEP) — 免费在线
- 《数据库系统概念》第5-8章（索引、事务、并发）

**AI工程方向**：
- 《动手学深度学习》
- LangChain官方文档

**通用进阶**：
- 《Effective Java/Python》
- 《重构：改善既有代码的设计》

| 书名 | 理由 |

# Part 3: AI时代的核心竞争力

---

## 3.1 金字塔模型

```
         ┌─────────┐
         │ CSAPP   │ ← 塔尖（1-2本，反复读）
         │ + DDIA  │
         ├─────────┤
         │ 设计模式  │
         │ 编程珠玑  │ ← 塔身（3-5本）
         │ 修炼之道  │
         ├─────────┤
         │ AI文档    │
         │ 开源项目  │ ← 塔基（动态资源，持续更新）
         │ MIT课程   │
         └─────────┘
```

---

## 3.2 AI时代的"不可替代"能力

**AI能做什么**：
- 生成CRUD代码、写单元测试、翻译文档

**AI不能做什么**：
- 设计一个数据库的存储引擎
- 排查分布式系统的一致性bug
- 决定一个系统的架构取舍
- 理解需求背后的业务逻辑

> **我们的策略**：让AI处理"能做的"，你来处理"不能做的"。

---

## 3.3 两个核心能力方向

### 系统能力

理解计算机从头到尾的工作原理：
- CPU如何执行指令 → 内存层次 → 操作系统 → 网络协议 → 分布式一致性

### AI工程化能力

不是"训练模型"，而是：
- 将大模型接入生产系统（RAG、Agent、Tool Use）
- 评估、监控、安全保障
- 知道什么时候该用AI，什么时候不该用

# Part 6: 最后的话

---

## 6.1 给指导者（老师）

1. **不要期望学生读完所有书**：按阶段只给1-2本核心书
2. **每周检查产出**：建议维护公开的"学习周报"
3. **允许失败和调整**：Bomb Lab卡一周可以求助AI，但要理解原因
4. **AI是工具，不是作弊**：鼓励用Cursor写代码，但能口头解释每一行

---

## 6.2 给学生

### 三条铁律

1. **不背八股**：面试官能区分"背了DDIA"和"读了DDIA"
2. **不出"商城项目"**：一个自制数据库 >> 十个商城Demo
3. **不停止输出**：每两周一篇博客，坚持两年

---

## 6.2 给学生（续）

### 每周12-15小时计划

```
上课之外的时间分配：
├── 6-8h 核心学习（读书 + 实验）
├── 2-3h 实践项目
├── 2h   写博客/文档
├── 1h   开源浏览
└── 1h   技术社区（知乎/掘金/Twitter）
```

### 心态

> 你不是在和身边的人竞争。你是在和2028年全中国的应届生竞争。AI让"会用Spring Boot写CRUD"的人贬值，但让"理解数据库内核"的人升值。
