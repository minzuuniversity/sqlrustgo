# Knowledge Loop：自我学习闭环

**版本**：v4.0.0
**日期**：2026-10-19
**关联**：`TEST_PHASES_STANDARD.md`、`GATE_CONDITIONS.md`

## 1. 核心思想

**AI Agent 不是「一次性工具」，而是「持续进化的系统」。**

每一圈循环：知识增加 → 决策更准 → 实施更好 → 观察更细

## 2. 闭环机制

```
┌─────────────────────────────────────────────────────────┐
│              自我学习闭环 (Knowledge Loop)              │
│                                                         │
│  ┌──────────┐    ┌──────────┐    ┌──────────┐          │
│  │  观察    │───▶│  记录    │───▶│  分析    │          │
│  │ (Observ) │    │ (Record) │    │ (Analyz) │          │
│  └──────────┘    └──────────┘    └────┬─────┘          │
│       ▲                                │                │
│       │                                ▼                │
│  ┌──────────┐    ┌──────────┐    ┌──────────┐          │
│  │  改进    │◀───│  实施    │◀───│  决策    │          │
│  │ (Improv) │    │ (Implem) │    │ (Decide) │          │
│  └──────────┘    └──────────┘    └──────────┘          │
│                                                         │
│  每一圈：知识增加 → 决策更准 → 实施更好 → 观察更细      │
└─────────────────────────────────────────────────────────┘
```

## 3. 知识来源

| 来源 | 说明 | 本项目实现 |
|---|---|---|
| **测试证据** | 每次测试的结果 | `tests/` + `gate-results/` |
| **门禁结果** | 每次门禁的 PASS/FAIL | `GATE_CONDITIONS.md` + 结果文件 |
| **性能数据** | BTB/TPC-H/SOAK 数据 | `btb-baseline/` |
| **缺陷记录** | 发现的 bug 和修复 | `debt-registry.yaml` |
| **架构决策** | 为什么这样设计 | `adr/` |
| **经验教训** | 踩过的坑 | `lessons/` |

## 4. 自我改进机制

### 4.1 门禁驱动
- 门禁 FAIL → 必须修复 → 修复后记录原因 → 下次避免
- 例：G3 FAIL → 分析性能瓶颈 → 优化 → 记录优化策略

### 4.2 债务驱动
- 发现技术债 → 登记到 `debt-registry.yaml` → 排期修复 → 修复后关闭
- 例：发现 MVCC 清理开销大 → 登记债务 → 优化清理算法 → 关闭债务

### 4.3 经验驱动
- 踩坑 → 记录到 `lessons/` → 下次遇到类似问题时参考
- 例：发现 SOAK 测试内存泄漏 → 记录教训 → 下次设计时避免

## 5. 自我进化方向

### 5.1 短期（v4.0.0）
- 完成四阶段测试体系
- 建立性能基线
- 积累测试证据

### 5.2 中期（v4.1.0）
- 自动化性能回归检测
- 智能缺陷预测
- 自适应测试策略

### 5.3 长期（v5.0.0+）
- AI Agent 自主规划测试策略
- 基于历史数据预测性能瓶颈
- 自主优化代码路径

## 6. 与 Harness Engineering 的关系

```
┌─────────────────────────────────────────────────────────┐
│          Harness + Knowledge Loop                       │
│                                                         │
│  Harness（约束）                                        │
│  ┌─────────────────────────────────────────────────┐   │
│  │  Gitea + Governance + AGENTS.md + Gates         │   │
│  └──────────────────────┬──────────────────────────┘   │
│                          │                             │
│                          ▼                             │
│  Knowledge Loop（进化）                                 │
│  ┌─────────────────────────────────────────────────┐   │
│  │  观察 → 记录 → 分析 → 决策 → 实施 → 改进       │   │
│  └──────────────────────┬──────────────────────────┘   │
│                          │                             │
│                          ▼                             │
│  下一圈 Harness 更智能                                  │
│  （基于积累的知识，门禁更精准，测试更智能）              │
└─────────────────────────────────────────────────────────┘
```

**关键洞察**：
- Harness 是「笼子」，约束 AI Agent 的行为
- Knowledge Loop 是「大脑」，让 AI Agent 持续进化
- 两者结合：AI Agent 在笼子里学习，越学越聪明，笼子越用越精准
