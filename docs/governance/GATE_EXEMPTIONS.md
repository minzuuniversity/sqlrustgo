## 一、豁免申请规则

### 1.1 可豁免条件

以下情况可申请豁免：
- 外部依赖不可用（如 Ollama 服务器暂时离线）
- 已知问题已有 Issue 追踪且 P2 及以下
- 环境限制（非代码问题，如 CI 资源不足）

### 1.2 不可豁免条件

以下情况**不可**申请豁免：
- P0/P1 问题
- 核心功能（编译、测试、clippy）失败
- 安全漏洞（HIGH/CRITICAL）
- 文档内容缺失或错误
