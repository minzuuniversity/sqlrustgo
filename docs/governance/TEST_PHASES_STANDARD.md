## 1. 阶段定义

| 阶段 | 目标 | 测试深度 | 门禁数 |
|---|---|---|---|
| **Alpha** | 核心功能可用 | 单元 + 集成 | G1-G5 |
| **Beta** | 并发性能验证 | + 性能 + SOAK 1h + TPC-H 基础 | G1-G8 |
| **RC** | 发布候选 | + TPC-H 全部 + SOAK 24h + 用户验收 | G1-G12 |
| **GA** | 正式发布 | + 性能回归 + 发布证据 | G1-G16 |
