## 0. 怎么用

每条一个可勾选项。**「关闭方式」列写明什么动作算关闭**；不需要动作的，写明**为什么不需要**。
**「谁来关」列写明责任方**。属主勾完这一份，残余就归零。

状态四档：

| 状态 | 含义 |
|---|---|
| **已关闭** | 动作已做完，且有可复算的证据 |
| **已不适用** | 前提已消失（不是被修，是不再成立），附前提消失的证据 |
| **可作残余** | 真实但无下游依赖，或代价高于收益 —— **不需动作**，附「为什么可以放着」 |
| **待属主** | 属主专属动作（门禁清单变更 / 治理裁决 / 扩哈希范围），实施者与控制者**不得代行** |
